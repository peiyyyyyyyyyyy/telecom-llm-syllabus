# 7.4.2 個人帳務：身分驗證後轉專人

所屬：[7.4 追問與轉介](7-4.md)

## 內文

#### 1. 是什麼、什麼時候會用到

個人帳務是指和特定門號、特定客戶有關的資料，例如帳單金額、繳費紀錄、欠費狀態、合約到期日、通話與上網紀錄、申辦資料。這些都是個人資料，客戶來問時，助理不能在對話裡直接查詢或透露，而是要引導客戶完成身分驗證，再由有權限的專人處理。常見情況有：「我上期繳了沒」「我的合約什麼時候到期」「幫我查我先生的門號」「我上個月打了哪些電話」。

個人資料保護法對非公務機關蒐集、處理、利用個人資料設有限制：蒐集、處理應有特定目的並符合法定情形（[個人資料保護法第 19 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0050021&flno=19)），利用應在蒐集的特定目的必要範圍內（[第 20 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0050021&flno=20)），保有個人資料檔案者應採行適當的安全措施（[第 27 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=I0050021&flno=27)）（舊第 27 條，非公務機關保有個資檔案應採適當安全措施；114/11/11 修正刪除第 27 條、增訂第 20-1 條，施行日由行政院定，尚未施行）。法律只規定到這一層；「先驗證身分再轉專人」的具體步驟是業者自己的作法，以下用虛構的甲電信程序說明。

#### 2. 怎麼做／怎麼判斷

**先判斷是不是個人帳務：**

| 問題 | 是否屬個人帳務 | 處理 |
|---|---|---|
| 「999 方案月租多少？」 | 否，公開資費 | 直接依公告答覆 |
| 「日割怎麼算？」 | 否，計算規則 | 依公告解釋規則 |
| 「我這期帳單多少？」 | 是 | 驗證身分後轉專人 |
| 「我的合約剩幾個月？」 | 是 | 驗證身分後轉專人 |
| 「幫我查家人的通話紀錄」 | 是，且不是本人 | 不提供；說明需由門號申請人本人依程序申請 |

**甲電信客服作業程序第 12 條（虛構）規定的流程：**

1. 客戶詢問個人帳務時，助理說明需要先驗證身分。
2. 引導客戶透過官方 App 登入，或撥打客服專線由專人驗證；**助理不在對話中收集身分證字號、密碼或完整證件資料**。
3. 驗證完成後，由專人查詢並答覆；助理不在對話中說出任何帳務內容。
4. 非門號申請人本人要求查詢時，不提供資料，說明申請人本人才能申請，或依程序出具授權文件。

**助理可以做的：**

- 解釋公開的規則與計算方式。
- 說明驗證流程與管道。
- 記錄客戶的問題，讓專人接手時不必重問（7.5.2）。

**助理不能做的：**

- 在對話裡說出帳單金額、欠費狀態、通聯內容。
- 用客戶在對話中自稱的身分代替正式驗證。
- 承諾退款、減免等結果。

#### 3. 實際例子

```
【客戶訊息】2026/11/26 19:05
我是 0912-000-xxx 的用戶（虛構），我身分證是 A12345xxxx，
幫我查一下我上個月有沒有繳，順便看我老婆那支 0933-000-xxx 欠多少。
```

逐步判斷：

1. **分類**：兩個問題都屬個人帳務。自己門號的繳費狀態，需要驗證身分；配偶門號的欠費，客戶不是該門號申請人，不能提供。
2. **客戶主動提供證件號碼**：不能把對話中自稱的身分當成驗證，也不要在回覆裡重複這個號碼；依程序引導到正式驗證管道。
3. **答覆**：

```
為了保護您的個人資料，繳費紀錄需要先完成身分驗證才能查詢。
您可以登入甲電信 App 查看，或撥打客服專線，由專人驗證後幫您查。
提醒您，請不要在這裡提供身分證字號等個人資料。

您太太的門號，需要由她本人查詢，或依程序提供她的授權文件，
我們無法在這裡提供其他門號的資料。
依據：甲電信客服作業程序第 12 條（虛構）。
```

4. **錯誤做法**：「我幫您查了，上個月已經繳了」，或「您太太的門號目前欠 1,280 元」，都是在對話中透露個人帳務。

#### 4. 容易搞混的地方

- **客戶自稱本人不等於已驗證**：知道門號和證件號碼的人不一定是本人。
- **家人、同事也不行**：即使是配偶或子女，非申請人本人就不能直接查詢。
- **解釋規則可以，查個資不行**：客戶貼出自己的帳單問算法時，可以解釋計算規則；但不能主動查詢或補充帳單上沒有的個人資料。
- **不要引用法條說流程**：個資法規定的是限制與義務，具體驗證步驟是業者程序，引用時要寫業者程序。

#### 5. 和其他小節的關係

帳單（7.1.1）、合約（7.1.2）、門號狀態（7.2.4）的個人查詢都會轉到本節流程。資格判斷需要個人資料時，由 7.4.1 接到本節；轉專人時要寫通話摘要（7.5.2），讓專人不必重問。

**詳解**　把業者程序說成「依個資法第 X 條」會讓客戶以為是法律硬性規定，屬於錯誤引用。
