# 7.1.4 開通

所屬：[7.1 問題類型](7-1.md)

## 內文

#### 1. 是什麼、什麼時候會用到

開通問題是客戶「新卡或新門號還不能用」，或想知道怎麼辦理開通。常見情況有三種：新申辦門號、攜碼（保留原門號，從另一家業者轉進來）、eSIM 啟用。客戶多半在申辦後當天或攜碼生效日來問，訊息通常很短，例如「新卡沒訊號」「攜碼好了沒」，所以助理要先問清楚是哪一種開通、走到哪一步，再依業者的作業程序判斷原因。作業程序的寫法請參考 2.5.3。

攜碼依[電信事業號碼可攜服務管理辦法（全國法規資料庫查詢）](https://law.moj.gov.tw/Law/LawSearchResult.aspx?ty=ONEBAR&kw=%E8%99%9F%E7%A2%BC%E5%8F%AF%E6%94%9C)辦理；本節只引用法規名稱，具體時程與條件以下用虛構的業者程序說明，審查時請對照現行條文。

#### 2. 怎麼做／怎麼判斷

**三種開通的流程差異：**

| 類型 | 主要步驟 | 客戶最常卡住的地方 |
|---|---|---|
| 新申辦 | 證件審核 → 配號 → 給 SIM 卡 → 系統開通 | 證件還在審核、SIM 卡插好但沒重新開機 |
| 攜碼 | 向新業者申請 → 新舊業者核對資料 → 約定生效時間 → 移轉 | 生效時間還沒到、資料不一致被退件、移轉過程中短暫無服務 |
| eSIM | 申辦 → 取得啟用碼（QR code）→ 手機下載設定檔 → 開通 | 手機不支援 eSIM 或被鎖、QR code 已使用過、下載時沒有網路 |

**判斷步驟：**

1. **問清楚類型與時間**：哪一種開通、何時申請、業者告知的生效時間是何時。
2. **對照作業程序的時程**：例如甲電信攜碼作業程序第 4 條（虛構）規定：「攜碼於約定生效日 00:00 至 06:00 間完成移轉，移轉期間原門號可能暫時無法使用。」客戶在生效時間前來問，答案就是「還沒到時間」。
3. **排除終端與設定**：重新開機、確認 SIM 卡插好、確認手機沒有被鎖定只能用特定業者的卡、確認行動網路設定（APN）。
4. **查不到原因就轉專人**：申請資料是否退件、系統狀態如何，屬於個人申辦紀錄，要驗證身分後由專人查詢（7.4.2）。

**開通失敗的常見原因（依甲電信作業程序附件 2，虛構）：**

- 申請人資料與原業者登記資料不一致（攜碼）。
- 原門號已停用或已在辦理其他異動（攜碼）。
- 證件審核未完成（新申辦）。
- 手機鎖定特定業者、不支援 eSIM 或頻段不符。
- 未重新開機，或行動網路設定錯誤。

#### 3. 實際例子

```
【客戶訊息】2026/11/22 09:15
我從別家攜碼過來，昨天拿到你們的卡，今天早上換上去還是沒訊號，
舊卡也不能打了，是不是壞了？

【甲電信攜碼作業程序（虛構）】
第 4 條　攜碼於約定生效日 00:00 至 06:00 間完成移轉，
　　　　移轉期間原門號可能暫時無法使用。
第 6 條　移轉完成後，用戶應將新 SIM 卡插入手機並重新開機；
　　　　如生效日 09:00 後仍無法使用，請洽客服由專人查詢移轉狀態。

【客戶補充】約定生效日：2026/11/22
```

逐步判斷：

1. **分類**：攜碼開通。
2. **時程**：生效日是 11/22，依第 4 條，移轉在 00:00～06:00 間完成；現在是 09:15，理論上應已完成。舊卡不能打，代表原業者那端已經切換，符合移轉已完成的跡象。
3. **先排除終端**：依第 6 條，先請客戶確認新卡插好並重新開機；再確認手機是否鎖定只能用原業者的卡（從原業者購買的綁約手機可能有這個情況）。
4. **仍無法使用**：已超過 09:00，依第 6 條要由專人查詢移轉狀態，助理不能自己判斷「已經成功」或「系統壞了」。
5. **答覆要點**：說明舊卡停用是攜碼正常現象，請客戶重新開機並檢查手機是否鎖卡；若仍無訊號，說明要驗證身分後由專人查詢移轉狀態，並告知下一步流程。

#### 4. 容易搞混的地方

- **攜碼期間舊卡停用是正常的**：不要當成故障，也不要叫客戶換回舊卡。
- **eSIM 的 QR code 通常只能用一次**：刪除設定檔後要重新申請，不是重新掃描就好（依虛構程序）。
- **「開通」和「可以上網」是兩件事**：門號開通了但 APN 或數據設定錯誤，仍然不能上網。
- **攜碼條件以法規與業者程序為準**：不要憑印象回答「欠費就不能攜碼」之類的條件，查不到原文就說明要轉專人確認。

#### 5. 和其他小節的關係

開通後收不到訊號，如果排除了開通問題，就回到 7.1.5 的收訊判斷。申辦資格（身分、門號狀態）在 7.2.4 細講；查個人申辦紀錄要依 7.4.2 先驗證身分。作業程序的文件結構見 2.5.3。

