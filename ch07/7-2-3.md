# 7.2.3 方案

所屬：[7.2 拆出要核對的條件](7-2.md)

## 內文

#### 1. 是什麼、什麼時候會用到

很多客服問題的答案取決於「客戶現在是什麼方案」：同樣問「超量怎麼算」「能不能轉 499」，不同方案的規定完全不同。所以助理在答覆前要先確認三件事：客戶目前的方案（含申辦時的版本）、想轉的目標方案，以及兩個方案之間有沒有轉換限制。常見情況有：客戶記錯自己的方案名稱、同名方案有新舊版本、家庭共享方案的主副卡、預付卡轉月租，以及合約期內的轉換限制。方案要素的介紹見 7.1.2，本節的重點是「拆出方案條件並逐項核對」。

本節的方案與轉換規則都是虛構；方案的依據是業者核准的契約與公告（[電信管理法第 17 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0060111&flno=17)）。

#### 2. 怎麼做／怎麼判斷

**要確認的方案資訊：**

| 項目 | 要確認的內容 | 為什麼 |
|---|---|---|
| 目前方案名稱與版本 | 名稱、申辦日或專案代碼 | 同名方案不同版本，條件可能不同 |
| 合約狀態 | 是否綁約、剩餘月數 | 決定轉換是否要付補貼款 |
| 方案類型 | 個人、家庭主卡、家庭副卡、預付 | 決定由誰可以申請變更 |
| 目標方案 | 名稱、是否仍在受理期間 | 已停售的方案不能轉入 |
| 轉換規則 | 升級、降轉、平轉的生效時間與限制 | 決定答覆內容 |

**判斷步驟：**

1. **確認目前方案**：客戶說的名稱要和公告或客戶貼出的帳單對照；說不清楚時，不要猜，請客戶提供帳單上的方案名稱，或驗證身分後由專人查詢（7.4.2）。
2. **確認目標方案仍可申辦**：看目標方案的申辦期間（7.2.1）。
3. **找轉換規則**：在目前方案的條款中找「轉換」「變更」條文，同時看目標方案有沒有「不受理轉入」的限制。
4. **逐項比對限制**：例如合約內降轉要付補貼款、副卡變更要主卡同意、每期只能異動一次。
5. **整理成條件清單**：哪些已符合、哪些不符合、哪些還不知道，再依 7.3.2 說明或依 7.4.1 追問。

#### 3. 實際例子

```
【客戶訊息】2026/11/26 16:05
我是我爸那張家庭方案的副卡，想自己轉成 499 的個人方案，
我自己去門市辦就可以了嗎？

【甲電信家庭共享 1199 方案條款（虛構，生效日 2025/06/01）】
第 3 條　本方案含主卡 1 門、副卡最多 3 門；副卡月租 299 元。
第 7 條　副卡轉為個人方案，須經主卡申請人同意，
　　　　副卡持有人得自行辦理，惟應出具主卡申請人之同意書。
第 8 條　方案變更於次期生效，每期以變更一次為限。

【甲電信個人 499 方案公告（虛構）】
申辦期間：2026/10/01～2026/12/31
第 4 條　家庭方案副卡轉入，免收補貼款。
```

逐步判斷：

1. **目前方案**：家庭共享 1199 的副卡，副卡月租 299 元。
2. **目標方案**：個人 499，申辦期間到 2026/12/31，今天（11/26）仍可申辦。
3. **轉換規則**：第 7 條要主卡申請人（客戶的父親）同意；副卡持有人可以自己辦，但要帶同意書。
4. **其他限制**：第 8 條，次期生效、每期限變更一次；個人 499 第 4 條，副卡轉入免收補貼款。
5. **資料不足的地方**：本期是否已經做過其他變更，資料裡沒有，需要驗證身分後由專人確認。
6. **答覆要點**：可以自己去辦，但要帶主卡申請人的同意書；次期生效，月租從副卡的 299 元變成 499 元；本期是否已變更過要由專人查詢。

#### 4. 容易搞混的地方

- **副卡持有人不等於申請人**：副卡的變更權限常受主卡申請人限制。
- **同名不同版**：「499 方案」可能有好幾個版本，條件要看申辦當時的專案條款。
- **目標方案停售**：舊方案停止受理後，就算客戶想轉回也不能轉入。
- **生效時間**：立即生效和次期生效，對帳單的影響不同，要說清楚。
- **預付卡轉月租不是單純換方案**：依甲電信作業程序（虛構），預付卡轉月租視同新申辦月租方案，要重新核對身分與門號資格（7.2.4），原預付卡餘額如何處理也要依程序說明。

#### 5. 和其他小節的關係

方案的要素與補貼款計算見 7.1.2；版本判斷用 7.2.1；資格（身分、門號狀態）在 7.2.4。查詢個人方案紀錄要依 7.4.2 先驗證身分；說明轉換條件見 7.3.2，引用條款見 7.3.1。

#### 目標方案是否仍在受理期間
