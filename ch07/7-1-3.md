# 7.1.3 漫遊

所屬：[7.1 問題類型](7-1.md)

## 內文

#### 1. 是什麼、什麼時候會用到

漫遊是客戶在國外使用國內門號，透過國外合作業者的網路通話或上網。漫遊問題大致分成兩類：一類在出國前，例如「日本漫遊怎麼算」「要先設定什麼」；另一類在國外或回國後，例如「到了國外收不到訊號」「漫遊費怎麼這麼高」。漫遊費率由業者自訂，依國家、合作網路、計費方式而不同，所以一定要找到對應國家和方案的漫遊公告，不能用另一個國家的費率類推。

本節的漫遊公告、費率、計日方式都是虛構。漫遊屬於業者服務契約的一部分，見[電信管理法第 17 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0060111&flno=17)；實際費率以各業者公告為準。

#### 2. 怎麼做／怎麼判斷

**漫遊公告通常會寫的內容：**

| 項目 | 要確認的內容 |
|---|---|
| 適用國家與合作網路 | 只有指定合作業者適用優惠費率，連到其他網路會改按一般費率 |
| 計費方式 | 一般費率按量計費，或日租型（每日固定金額） |
| 日租的「一日」怎麼算 | 依台灣時間的日曆日，或從啟用起連續 24 小時 |
| 上網量與降速 | 日租是否定量，用完後是降速還是停用 |
| 漫遊上限 | 費用到某個金額時是否通知或暫停數據漫遊 |
| 開通方式 | 是否需要事先申請漫遊服務、是否需要另外申請日租 |

**出國前要提醒客戶確認的事項：**

1. 門號是否已開通漫遊服務（有些門號預設關閉）。
2. 如果要用日租，是否已申請，以及生效時間。
3. 手機的「數據漫遊」開關要打開；不想產生上網費時則要關閉。
4. 是否要手動選擇合作網路。

**在國外收不到訊號時，依序排除：**

1. 門號是否開通漫遊服務。
2. 手機的數據漫遊是否開啟（只能通話不能上網，常是這個原因）。
3. 是否連到非合作網路，或自動選網失敗；可以試手動選網。
4. 手機是否支援當地頻段。
5. 以上都正常，但同一地區的其他客戶也反映收不到時，就可能是合作業者那端的問題，要記錄地點和時間轉專人。

#### 3. 實際例子

```
【客戶訊息】2026/11/06 21:30
我這次去日本，日租不是一天 199 嗎？
我用了 11/3、11/4、11/5 三天，為什麼帳上顯示 597？
是不是多算？我以為最後一天不會計算在內。

【甲電信日本漫遊日租公告第 3 條（虛構）】
日租每日 199 元，以首次使用數據漫遊起連續 24 小時為一日，
未滿 24 小時以一日計。

【客戶提供的使用時間】
首次上網：2026/11/03 10:00（日本當地時間 11:00）
最後上網：2026/11/05 15:00（台灣時間）
```

逐步判斷：

1. **分類**：客戶質疑漫遊日租天數，屬於漫遊計費問題，也牽涉帳單（7.1.1）。
2. **找計日規則**：公告寫「連續 24 小時為一日」，不是日曆日，所以要用首次使用時間切段。注意要統一用同一個時區；客戶提供的兩個時間都換成台灣時間來算。
3. **切段**：
   - 第 1 日：11/03 10:00～11/04 10:00
   - 第 2 日：11/04 10:00～11/05 10:00
   - 第 3 日：11/05 10:00～11/06 10:00（11/05 15:00 落在這一段，未滿 24 小時以一日計）
4. **計算**：3 日 × 199 = 597 元，與帳上金額相符。
5. **答覆要點**：先說明沒有多算，再解釋「24 小時為一日」與日曆日的差別，把三段時間列給客戶看。如果客戶要求查實際使用紀錄，就屬於個人帳務，依 7.4.2 處理。若客戶原本以為最後一天不計，則應預期 2 日 ×199＝398 元。

#### 4. 容易搞混的地方

- **一日的定義各家不同**：有的按台灣時間日曆日，有的按連續 24 小時，回答前一定要看公告原文。
- **時差**：國外時間和台灣時間不同，計日時要統一用公告規定的時區。
- **數據漫遊開關和漫遊服務開通是兩件事**：前者是手機設定，後者是門號在業者端的狀態。
- **非合作網路不適用日租**：手機自動連到非合作業者時，可能改按一般費率計算。

#### 5. 和其他小節的關係

漫遊費會出現在帳單上（7.1.1）。日租的時間計算要用到 7.2.1 的日期判斷；某些漫遊方案只限特定國家或地區，屬於 7.2.2。國外收訊問題的排除思路和 7.1.5 相同，只是多了合作網路這一層。

**004.** 某漫遊公告規定數據「以每日累計用量計，未滿 1MB 以 1MB 計」。客戶某一天只用了 0.1MB，當天的數據用量應怎麼計？

1. 未滿 1MB 不收費
2. 以 1MB 計費
3. 按 0.1MB 依比例計費
4. 併入隔天的用量一起累計後再進位

<details><summary>看答案</summary>

**答案**　2

**詳解**　「未滿 1MB 以 1MB 計」的意思是每日累計量不足 1MB 時直接進位成 1MB，所以 0.1MB 計 1MB。選項 1 把進位規則誤解成免收門檻；選項 3 是按實際量比例計，與「以 1MB 計」相反；選項 4 錯在公告是「每日」累計，不能跨日合併。

**出處**　甲電信韓國漫遊按量費率公告第 2 條（虛構）

</details>

**005.** 什麼是漫遊的「按量計費」？它和「日租」最主要的差別是什麼？

<details><summary>看答案</summary>

**答案**　按量計費是依實際使用量（數據的 MB 數、通話分鐘數、簡訊則數）乘上公告單價計費的方式；日租則是在計費的一日內收固定金額，不論當日用量多少（定量型另有用量上限）。差別在於按量的費用隨用量增加，日租的費用隨天數增加。

**詳解**　回答名詞解釋題要先給定義，再說差別。按量計費適合用量很少的客戶；日租適合每天都要上網、用量較大的客戶。漫遊計費方式屬業者服務契約與公告的內容，費率以業者公告為準。

**出處**　甲電信韓國漫遊按量費率公告第 2～4 條（虛構）；[電信管理法第 17 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=K0060111&flno=17)

</details>

**104.** 客戶提供手機內建的數據用量統計截圖，主張某一天沒有使用漫遊數據而不該收日租。若業者公告規定「計費以業者計費系統紀錄為準」，下列敘述何者正確？

1. 截圖可以作為參考，但計費以業者計費系統紀錄為準，需由專人核對
2. 截圖可以任意修改，一律不予參考
3. 截圖是客戶的使用證明，應直接依截圖調整帳單
4. 只要截圖顯示 0MB，業者就必須退費
