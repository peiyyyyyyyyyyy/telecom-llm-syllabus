# 10.2.2 個人資料的處理

所屬：[10.2 權限與資料](../10-2.md)

## 正文

In 5G the permanent subscription identifier (SUPI) uniquely identifies a subscriber across all networks. Transmitting the SUPI in clear text would allow anyone listening on the radio interface to link activities to a specific user, violating privacy regulations and exposing the network to tracking attacks. To protect the subscriber, the UE must replace the SUPI with a Subscription Concealed Identifier (SUCI) before any over‑the‑air (OTA) transmission, except for routing information such as MCC and MNC that the network needs to route the message. This privacy mechanism is mandated by 3GPP TS 33.501 §5.2.5 and §6.12 [TS 33.501 §5.2.5] [TS 33.501 §6.12].

### Key definitions

- **SUPI** – the globally unique subscription permanent identifier (e.g., an IMSI or NAI) defined in TS 23.501.  
- **SUCI** – a privacy‑preserving identifier that contains the concealed SUPI.  
- **5G‑GUTI** – a temporary identifier assigned after successful registration; once obtained the UE no longer needs to send a SUCI.  
- **Home Network Public Key (HNPK)** – the asymmetric public key provisioned by the home network and stored in the USIM; it is used to encrypt the SUPI part of the SUCI.  
- **Protection Scheme Identifier (PSI)** – indicates which cryptographic protection scheme (as listed in Annex C) is applied to the SUPI.  
- **Home Network Public Key Identifier (HNPKI)** – a reference to the specific HNPK used.  
- **Routing Indicator (RI)** – a value stored in the USIM that the UE includes unencrypted in the SUCI to help the network route the message.  

All of the above parameters (HNPK, PSI, HNPKI, RI, and the SUCI calculation indication) are stored in the USIM under the control of the home network operator [TS 33.501 §5.2.5].

### How the UE builds a SUCI

The UE first constructs a **scheme‑input** from the subscription identifier part of the SUPI:

* For an IMSI‑based SUPI the scheme‑input is the **MSIN** (the subscriber part of the IMSI) [TS 33.501 §6.12.2].  
* For an NAI‑based SUPI the scheme‑input is the **username** portion of the NAI [TS 33.501 §6.12.2].

The UE then executes the selected protection scheme (identified by PSI) with the HNPK as the raw public key, producing the **Scheme Output**. The final SUCI is assembled from the following fields (all defined in TS 23.003 but reproduced here for completeness):

$$
\text{SUCI}= \{ \text{SUPI Type},\; \text{MCC},\; \text{MNC},\; \text{RI},\; \text{PSI},\; \text{HNPKI},\; \text{Scheme Output} \}
$$

The Home Network Identifier (MCC + MNC) and the Routing Indicator are **never concealed** [TS 33.501 §6.12.2].

### When the UE must include a SUCI

A SUCI is transmitted only in three NAS situations:

1. **Initial Registration Request** – when the UE does not yet have a 5G‑GUTI for the target PLMN.  
2. **Identity Response** – when the network explicitly requests the permanent identifier.  
3. **De‑Registration Request** – if the UE aborts an initial registration before receiving a 5G‑GUTI.  

In all three cases the UE includes the SUCI; it never sends the SUPI in clear text [TS 33.501 §6.12.2].

### Null‑scheme handling

If the home network has not provisioned an HNPK, or if the operator has configured the null‑scheme, the UE must fall back to the **null‑scheme**, which simply places the HNPKI with a default value and does not encrypt the SUPI part. The null‑scheme is also mandatory for **unauthenticated emergency sessions** when the UE lacks a 5G‑GUTI [TS 33.501 §6.12.2] [TS 33.501 §5.2.5].

### PEI transmission rules

The Permanent Equipment Identifier (PEI) may be sent in NAS messages **only after a NAS security context has been established**. The only exception is an emergency registration where no security context can be set up [TS 33.501 §5.2.5].

### Operator control and provisioning

All privacy‑related parameters (HNPK, HNPKI, PSI, RI, and the SUCI calculation indication) are provisioned and updated by the home network, typically via an Over‑the‑Air (OTA) mechanism. The UE must respect the indication stored in the USIM that tells whether the **USIM** or the **ME** performs the SUCI calculation. If the indication is absent, the calculation defaults to the ME [TS 33.501 §5.2.5].

### Worked example (numeric)

Assume a subscriber with:

* MCC = 310, MNC = 260 (USA operator)  
* MSIN = 123456789 (the subscriber part of the IMSI)  
* Protection Scheme Identifier = 0x01 (scheme 1 from Annex C)  
* Home Network Public Key Identifier = 0x02  
* Routing Indicator = 0x0A (default value)  

The UE retrieves the HNPK and the calculation indication from the USIM. Because the indication specifies **ME calculation**, the UE builds the scheme‑input = MSIN = 123456789, encrypts it with the HNPK using scheme 1, and obtains a Scheme Output (e.g., `0xA1B2C3D4`). The resulting SUCI fields are:

| Field                     | Value                               |
|---------------------------|-------------------------------------|
| SUPI Type                 | IMSI (0)                            |
| MCC, MNC                  | 310‑260                             |
| Routing Indicator (RI)    | 0x0A                                |
| Protection Scheme ID (PSI)| 0x01                                |
| HNPK Identifier (HNPKI)   | 0x02                                |
| Scheme Output             | 0xA1B2C3D4                          |

The assembled SUCI (hex representation) might be: `0x00 310260 0A 01 02 A1B2C3D4`. This SUCI is placed in the **Initial Registration Request** NAS message. The network, knowing the HNPK corresponding to identifier 0x02, can recover the original MSIN and thus the SUPI, but any passive observer only sees the opaque SUCI [TS 33.501 §6.12.2].

### Common mistakes and practical notes

* **Sending SUPI in clear** – Some implementations mistakenly include the SUPI in a registration request; the standard explicitly forbids this except for MCC/MNC routing information [TS 33.501 §5.2.5].  
* **Ignoring the calculation indication** – If the USIM indicates USIM‑side calculation, the ME must delete any locally cached parameters; failure to do so may leak the HNPK or PSI [TS 33.501 §5.2.5].  
* **Using the wrong scheme for emergency calls** – An unauthenticated emergency session must use the null‑scheme; employing a non‑null scheme would violate the privacy exception rule [TS 33.501 §6.12.2].  
* **Transmitting PEI before security** – Sending the PEI prior to NAS security establishment is prohibited, except during emergency registration [TS 33.501 §5.2.5].  
* **Mismatched Routing Indicator** – If the RI is absent in the USIM, the UE must fall back to the default value defined in TS 23.003; using an undefined value can cause routing failures [TS 33.501 §5.2.5].

Adhering to these rules ensures that subscriber privacy is preserved across the air interface while still allowing the network to route and authenticate the UE correctly.

## 練習題

**1.** Which identifier(s) must never be concealed when constructing a SUCI?

- A. Home Network Public Key Identifier only
- B. Routing Indicator only
- C. Home Network Identifier and Routing Indicator
- D. SUPI Type only

<details><summary>看答案</summary>

正解：C。The specification states that the UE must not conceal the Home Network Identifier and the Routing Indicator.

</details>

**2.** Under which condition is the null‑scheme **required** for SUCI generation?

- A. When the UE has a valid 5G‑GUTI but the network requests a null‑scheme.
- B. When the UE is making an unauthenticated emergency session and it does not have a 5G‑GUTI.
- C. When the Home Network Public Key is provisioned but the ME lacks processing power.
- D. When the SUPI is of NAI format with variable length.

<details><summary>看答案</summary>

正解：B。The null‑scheme is mandated for unauthenticated emergency sessions without a 5G‑GUTI.

</details>

**3.** Where is the Home Network Public Key stored in the UE?

- A. In the ME’s volatile memory.
- B. In the USIM.
- C. In the SIM’s file system accessible to the network.
- D. In the network’s UDM database only.

<details><summary>看答案</summary>

正解：B。The standard mandates that the HNPK be stored in the USIM.

</details>

**4.** In which NAS message does the UE include a SUCI during the first attempt to register with a PLMN?

- A. Authentication Request
- B. Registration Request (initial registration)
- C. Identity Request
- D. Service Request

<details><summary>看答案</summary>

正解：B。The UE includes a SUCI in the Initial Registration Request if it does not already have a 5G‑GUTI.

</details>

**5.** Who decides whether the SUCI calculation is performed by the USIM or by the ME?

- A. The UE firmware automatically decides based on battery level.
- B. The network’s AMF sends a command during registration.
- C. The home network’s decision indicated by the USIM.
- D. The subscriber selects the option in the device UI.

<details><summary>看答案</summary>

正解：C。The decision is indicated by the USIM, reflecting the home network’s policy.

</details>
