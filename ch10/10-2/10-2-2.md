# 10.2.2 個人資料的處理

所屬：[10.2 權限與資料](../10-2.md)

## 練習題

**1.** Which identifier(s) must never be concealed when constructing a SUCI?

- A. Home Network Public Key Identifier only
- B. Routing Indicator only
- C. Home Network Identifier and Routing Indicator
- D. SUPI Type only

<details><summary>看答案</summary>

正解：C。The specification states that the UE must not conceal the Home Network Identifier and the Routing Indicator.

</details>

**2.** Where is the Home Network Public Key stored in the UE?

- A. In the ME’s volatile memory.
- B. In the USIM.
- C. In the SIM’s file system accessible to the network.
- D. In the network’s UDM database only.

<details><summary>看答案</summary>

正解：B。The standard mandates that the HNPK be stored in the USIM.

</details>

**3.** In which NAS message does the UE include a SUCI during the first attempt to register with a PLMN?

- A. Authentication Request
- B. Registration Request (initial registration)
- C. Identity Request
- D. Service Request

<details><summary>看答案</summary>

正解：B。The UE includes a SUCI in the Initial Registration Request if it does not already have a 5G‑GUTI.

</details>

**4.** Who decides whether the SUCI calculation is performed by the USIM or by the ME?

- A. The UE firmware automatically decides based on battery level.
- B. The network’s AMF sends a command during registration.
- C. The home network’s decision indicated by the USIM.
- D. The subscriber selects the option in the device UI.

<details><summary>看答案</summary>

正解：C。The decision is indicated by the USIM, reflecting the home network’s policy.

</details>
