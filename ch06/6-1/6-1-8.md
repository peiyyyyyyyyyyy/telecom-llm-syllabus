# 6.1.8 傳輸中斷與核心網問題

所屬：[6.1 根因的類型](../6-1.md)

## 練習題

**1.** 在 TS 32.111‑1 中，哪一類故障是因為過載而導致的功能失效？

- A. 硬體失效
- B. 軟體問題
- C. 功能性故障
- D. 因過載而失去部分或全部規定能力

<details><summary>看答案</summary>

正解：D。過載會使網路元素失去其規定的功能或容量。

</details>

**2.** 當 AMF 主動發送 NG RESET 時，NG‑RAN 節點在回覆 NG RESET ACKNOWLEDGE 前必須先執行哪項動作？

- A. 立即回傳 ACK，不需釋放任何資源
- B. 釋放所有與 UE 相關的 NG 與 Uu 資源並移除 UE context
- C. 只釋放 NG 資源，Uu 資源保留
- D. 等待無線資源全部釋放後才回覆

<details><summary>看答案</summary>

正解：B。NG‑RAN 必須先清除與 UE 相關的所有 NG 與 Uu 資源，才能回覆 ACK。

</details>

**3.** 若 NG RESET 訊息中的 UE‑associated Logical NG‑connection Item 同時缺少 AMF UE NGAP ID 以及 RAN UE NGAP ID，AMF 應如何處理？

- A. 直接回傳錯誤訊息給 NG‑RAN
- B. 嘗試以其他資訊辨識 UE
- C. 忽略該 UE‑associated Logical NG‑connection Item
- D. 仍回傳空的 UE‑associated Logical NG‑connection Item

<details><summary>看答案</summary>

正解：C。沒有任何 ID 可用於辨識時，AMF 必須忽略該項目。

</details>

**4.** O‑RU 用於監控 C/U‑plane 連線的預設計時器值是多少？

- A. 100 ms
- B. 120 ms
- C. 150 ms
- D. 160 ms

<details><summary>看答案</summary>

正解：D。標準規定的預設值是 160 毫秒。

</details>

**5.** 在 OVERLOAD START 程序中，若 *Overload Action* IE 被設定為「reject RRC connection establishments for signalling」，NG‑RAN 應採取的主要行動是什麼？

- A. 完全拒絕所有 RRC 連線請求
- B. 減少訊號流量，若有 *AMF Traffic Load Reduction Indication* IE 則依其百分比減少
- C. 只允許緊急服務的 RRC 連線
- D. 不做任何變更，僅記錄此狀態

<details><summary>看答案</summary>

正解：B。NG‑RAN 必須根據指示的百分比減少訊號流量，或在未提供百分比時只排除被拒絕的流量。

</details>
