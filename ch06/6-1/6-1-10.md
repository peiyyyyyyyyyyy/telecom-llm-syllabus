# 6.1.10 上下行涵蓋不平衡

所屬：[6.1 根因的類型](../6-1.md)

## 練習題

**1.** Which of the following is listed as a type of coverage problem that includes a mismatch between downlink and uplink channels?

- A. Pilot pollution
- B. Coverage hole
- C. DL and UL channel coverage mismatch
- D. Overshoot coverage

<details><summary>看答案</summary>

正解：C。The specification explicitly names “DL and UL channel coverage mismatch” as one of the coverage problem types.

</details>

**2.** According to the document, which symptom may occur as a result of a downlink/uplink coverage mismatch?

- A. Failure of random access
- B. Increased transmit power
- C. Higher antenna tilt
- D. Reduced number of cells

<details><summary>看答案</summary>

正解：A。Coverage problems, including DL/UL mismatches, can cause failures in procedures such as random access.

</details>

**3.** To detect a DL/UL coverage mismatch, the MDA must correlate which kind of data?

- A. Only UE location reports
- B. Only antenna configuration data
- C. Multifold data such as performance measurements, MDT reports, UE location reports, etc.
- D. Only terrain data

<details><summary>看答案</summary>

正解：C。The specification states that multiple data sources must be combined to describe coverage problems.

</details>

**4.** Which remedial action is suggested for a coverage problem that may involve DL/UL imbalance?

- A. Reconfigure or add cells, beams, antennas
- B. Reduce UE transmit power
- C. Disable handover procedures
- D. Increase paging interval

<details><summary>看答案</summary>

正解：A。The document lists reconfiguration or addition of radio elements as a recommended remedy.

</details>

**5.** What parameter(s) does the Radio Environment Map show to help identify a DL/UL coverage mismatch?

- A. Number of active users
- B. RSRP or SINR values
- C. Cell IDs only
- D. Firmware versions

<details><summary>看答案</summary>

正解：B。The map can display signal strength or quality metrics such as RSRP and SINR, which reveal coverage imbalances.

</details>
