# 9.4.1 影響範圍

所屬：[9.4 變更前檢查](../9-4.md)

## 練習題

**1.** Which of the following is NOT listed as a system modification function in TS 32.600 §6.1?

- A. Creation of Network Elements and Network Resources
- B. Deletion of Network Elements and Network Resources
- C. Conditioning of Network Elements and Network Resources
- D. Migration of Network Elements

<details><summary>看答案</summary>

正解：D。The specification enumerates creation, deletion, and conditioning; migration is not mentioned.

</details>

**2.** Before a resource can be put back into service after a modification, what must be ensured?

- A. Only physical installation is required.
- B. Only logical installation is required.
- C. All required actions are completed correctly.
- D. No actions are needed if the modification is minor.

<details><summary>看答案</summary>

正解：C。The standard mandates that all actions be correctly finished before service restoration.

</details>

**3.** In the conditioning process, which step is performed first?

- A. Unlocking the MO/NR.
- B. Required modification.
- C. Locking or logical removal of the MO/NR.
- D. Verification of the result.

<details><summary>看答案</summary>

正解：C。The standard lists locking/logical removal as the initial action.

</details>

**4.** A modification to which type of data can directly affect resource throughput during the change?

- A. Physical equipment specifications.
- B. Executable software version numbers.
- C. Logical data with controlling influence.
- D. None of the above.

<details><summary>看答案</summary>

正解：C。Data that controls resources can impact throughput while being modified.

</details>
