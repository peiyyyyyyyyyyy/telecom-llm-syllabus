# 9.5.1 工單、核可、紀錄

所屬：[9.5 異動流程](../9-5.md)

## 練習題

**1.** Which condition must be satisfied before a network configuration change can be performed?

- A. The change must be documented in a public forum.
- B. The operator must have an appropriate authorisation profile.
- C. The hardware must be replaced.
- D. The change must be approved by the regulator.

<details><summary>看答案</summary>

正解：B。The reference explicitly links configuration changes to operator authorisation profiles.

</details>

**2.** If an engineer’s authorisation profile does not include the required privilege, what does the reference imply will happen to their change request?

- A. The request will be automatically approved.
- B. The request will be ignored but logged.
- C. The request cannot be executed.
- D. The request will be sent to the regulator.

<details><summary>看答案</summary>

正解：C。The specification limits configuration changes to operators with appropriate profiles; lacking that, the change is not permitted.

</details>
