# 1.2.7 核心網信令：NAS、NGAP、GTP、Diameter、SBI

所屬：[1.2 通訊協定](1-2.md)

## 內文

行動網路使用多種協定把終端控制、接取網控制、核心服務和用戶資料分開。判讀封包或工單中的縮寫時，可先辨認協定所處的層級及實際端點，然後判斷它是傳達控制決定、封裝資料，或查取訂閱與服務資訊。相同的終端連網事件可同時留下多種紀錄，因此有必要把各種訊息按程序與時間串起來。 [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 23.401 Release 18](https://www.etsi.org/deliver/etsi_TS/123400_123499/123401/18.08.00_60/ts_123401v180800p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf)

5G NAS 在終端與核心之間承載接取、移動性及會話訊息。接取網可藉 NGAP 在 N2 轉遞 NAS，同時處理自身所需的上下文和資源程序。用戶面資料跨 N3 時，GTP-U 在基地台與 UPF 之間封裝原用戶資料，並以隧道資訊辨認轉送對象。LTE 的 S6a 可由 MME 經 Diameter 向 HSS 取得訂閱相關資料。5GC 的 SBI 則用於適用的控制面網路功能之間，相關服務及 HTTP 承載可查 TS 29.500。上述邏輯面向有交集，例如訂閱資訊可影響接取程序，但各接口仍依自己的協定交換資訊。 [3GPP TS 24.501 Release 18](https://www.etsi.org/deliver/etsi_ts/124500_124599/124501/18.11.01_60/ts_124501v181101p.pdf) [3GPP TS 38.413 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138413/18.09.00_60/ts_138413v180900p.pdf) [3GPP TS 29.281 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129281/18.04.00_60/ts_129281v180400p.pdf) [3GPP TS 29.272 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129272/18.04.00_60/ts_129272v180400p.pdf) [3GPP TS 29.500 Release 18](https://www.etsi.org/deliver/etsi_ts/129500_129599/129500/18.10.00_60/ts_129500v181000p.pdf)

容易混淆的是 NAS 訊息與承載它的 NGAP、隧道的外層端點與用戶端點，以及 LTE Diameter 與 5GC 的 SBI。NAS 可以被轉遞，邏輯送達端由訊息所屬程序決定。GTP-U 在用戶資料外建立傳送上下文，需同時辨認內外資訊。Diameter 與 SBI 對應的架構和接口應分開查。 [3GPP TS 24.501 Release 18](https://www.etsi.org/deliver/etsi_ts/124500_124599/124501/18.11.01_60/ts_124501v181101p.pdf) [3GPP TS 38.413 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138413/18.09.00_60/ts_138413v180900p.pdf) [3GPP TS 29.281 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129281/18.04.00_60/ts_129281v180400p.pdf) [3GPP TS 29.272 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129272/18.04.00_60/ts_129272v180400p.pdf) [3GPP TS 29.500 Release 18](https://www.etsi.org/deliver/etsi_ts/129500_129599/129500/18.10.00_60/ts_129500v181000p.pdf)

接入異常時，請無線及核心控制團隊按時間核對 NAS、NGAP 程序及彼此交接的最後成功訊息。會話建立後若資料不通，核心用戶面團隊核對隧道端點與方向計數。若錯誤出現在訂閱或跨網路功能查詢，保留接口、請求結果及對端識別，由相關控制面團隊查服務可達性與程序狀態。多類日誌同時存在時，可先建立事件索引，把終端程序、無線節點到核心的交接，以及核心內的服務操作分欄，讓各團隊核對同一筆網路事件。 [3GPP TS 24.501 Release 18](https://www.etsi.org/deliver/etsi_ts/124500_124599/124501/18.11.01_60/ts_124501v181101p.pdf) [3GPP TS 38.413 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138413/18.09.00_60/ts_138413v180900p.pdf) [3GPP TS 29.281 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129281/18.04.00_60/ts_129281v180400p.pdf) [3GPP TS 29.272 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129272/18.04.00_60/ts_129272v180400p.pdf) [3GPP TS 29.500 Release 18](https://www.etsi.org/deliver/etsi_ts/129500_129599/129500/18.10.00_60/ts_129500v181000p.pdf)
