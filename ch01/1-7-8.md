# 1.7.8 最小化路測（MDT）

所屬：[1.7 網路優化與終端](1-7.md)

## 內文

TS 37.320 使用 Minimization of Drive Tests 指讓網路收集符合條件的終端無線量測，減少全靠專人行車或定點測試的需求。終端量測與小區、時間等資訊結合，可提供日常使用條件下的品質和覆蓋線索。它特別適合長期蒐集或擴大觀測範圍，讓無線優化人員先找出需要再量測的區域。 [3GPP TS 37.320 V19.4.0](https://www.etsi.org/deliver/etsi_ts/137300_137399/137320/19.04.00_60/ts_137320v190400p.pdf)

規格區分即時量測與記錄量測。即時類型在對應的連線條件下，以既有 RRC 量測及回報程序配合適用擴充取得結果。記錄類型則由終端依組態在適用狀態暫存量測，待條件符合後再走上報程序，供網路收集。資料解讀要同時考量配置範圍、終端狀態、實際量測時間與上報時間。定位資訊須按規格規定的可用條件搭配量測，並保持位置來源和精度的可辨識性。分析端收到記錄資料後，可先查看上報是否完整、量測時間是否在有效範圍，以及小區和其他條件能否與運維系統對應。 此處並列不同 Release 的文件，用來分別定位 MDT 流程及對應的 RRC 訊息。實作與驗收應依專案指定的 Release 核對對應條款。 [3GPP TS 37.320 V19.4.0](https://www.etsi.org/deliver/etsi_ts/137300_137399/137320/19.04.00_60/ts_137320v190400p.pdf)  [3GPP TS 38.331 V17.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138331/17.02.00_60/ts_138331v170200p.pdf)

量測可包括以 dBm 表示的接收功率及適用的品質量，應隨數值保留對應小區、頻段、時間與參考信號類型。地理資料彙總時要記錄樣本量以及位置資訊有無缺漏，避免將樣本密集處誤認為問題最集中處。沒有位置的樣本仍可供某些小區層級分析，但不能直接放到精確地點。 此處並列不同 Release 的文件，用來分別定位 MDT 流程及對應的 RRC 訊息。實作與驗收應依專案指定的 Release 核對對應條款。 [3GPP TS 37.320 V19.4.0](https://www.etsi.org/deliver/etsi_ts/137300_137399/137320/19.04.00_60/ts_137320v190400p.pdf)  [3GPP TS 38.215 V18.3.0](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.03.00_60/ts_138215v180300p.pdf)

較晚收到記錄量測時，退化可能早於資料入庫時間。即時量測也有適用對象和配置限制，只有被選中的樣本會進入結果。道路、高樓或室內分布容易不同，因此要區分終端自然使用的抽樣與刻意規劃的現場路測。必要時用固定路線比較量測，並保留觀測方向。 [3GPP TS 37.320 V19.4.0](https://www.etsi.org/deliver/etsi_ts/137300_137399/137320/19.04.00_60/ts_137320v190400p.pdf)

工單若說某地頻繁掉到低速，請無線優化先拉該點附近的量測樣本、適用配置、位置可信度及前後小區關係。若樣本不足，再安排補測。位置資訊的查閱及匯出應依工作範圍和權限，分享報告時優先使用足以分析的範圍和聚合結果。 [3GPP TS 37.320 V19.4.0](https://www.etsi.org/deliver/etsi_ts/137300_137399/137320/19.04.00_60/ts_137320v190400p.pdf)  [NIST SP 800-53 Rev. 5](https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final)
