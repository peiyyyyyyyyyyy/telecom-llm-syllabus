# 1.3.3 數據服務與 QoS

所屬：[1.3 服務與多媒體](1-3.md)

## 內文

5GS 以 QoS Flow 處理流量差異，5QI 對應已定義的 QoS 特性，例如封包延遲預算及封包錯誤率。檢查端到端品質時也要納入負載和應用端行為。[3GPP TS 23.501](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)
