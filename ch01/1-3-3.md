# 1.3.3 數據服務與 QoS

所屬：[1.3 服務與多媒體](1-3.md)

## 內文

行動數據服務會同時承載可容忍緩衝的流量和對延遲較敏感的流量。5GS 以 QoS Flow 表達流量應取得的封包處理方式，再由核心用戶面與接取網依配置執行。QoS 特性的適用範圍需連同會話和流量分類理解。它讓工程師在應用體驗退化時，能確認封包走的是哪條處理路徑，以及是否取得預期的傳送配置。 [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf)

在同一 PDU Session 中，流量可依封包過濾條件分類至不同 QoS Flow。核心可由 SMF 安排 UPF 的適用分類及轉送規則，並向接取網提供無線側所需的 QoS 設定。接取網再依實際配置把 QoS Flow 映射到無線承載。5QI 可以參照對應的 QoS 特性，例如資源類型、優先程度、封包延遲預算與封包錯誤率。終端、核心與接取網各有自己的分類或承載配置，因此排查時可沿同一流量追查分類在哪一側建立，配置在何時下發，資料又由哪條承載送出。 [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 23.502 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123502/18.11.00_60/ts_123502v181100p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 29.244 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129244/18.09.00_60/ts_129244v180900p.pdf)

TS 23.501 V18.9.0 的表 5.7.4-1 例如為標準化 5QI 6 列出 300 ms 的封包延遲預算及 10⁻⁶ 的封包錯誤率。前者以時間表示，後者是無單位比率，兩者都須理解其適用範圍與表註。延遲預算所界定的兩端尤其重要，測速工具回報的應用往返延遲還可能涵蓋資料網和伺服器。 [3GPP TS 23.501 V18.9.0，表 5.7.4-1](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.09.00_60/ts_123501v180900p.pdf) [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)

常見混淆是把 5QI 當成個別流的識別值、把 QoS Flow 一概視為實體無線承載，以及把特性表的值當作任何應用都能取得的端到端結果。工程紀錄要分開保留流識別、QoS 設定及無線承載映射，再以服務實測檢視應用體驗。 [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf)

收到速率或時延工單時，可先取得應用端點、測點、時窗和方向，再由核心團隊對照會話的流量分類及規則，無線團隊追承載與排程，資料網團隊核對路徑及伺服器處理。若只有特定應用變慢，同時對照其他應用及共用路段的計數。 [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 29.244 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129244/18.09.00_60/ts_129244v180900p.pdf)
