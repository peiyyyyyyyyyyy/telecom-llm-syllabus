# 1.7.5 終端能力與類別

所屬：[1.7 網路優化與終端](../1-7.md)

## 正文

In a cellular system the *terminal* (also called User Equipment, UE) is the bridge between the radio access network (RAN) and the end‑user application.  The network can only schedule resources, apply advanced radio techniques, or invoke higher‑layer services if it knows exactly what the UE is able to do.  Consequently, the concept of **terminal capability**—a structured description of the UE’s supported radio and protocol features—underpins almost every optimisation function covered in this chapter (coverage, interference, handover, load balancing, etc.).  An inaccurate capability description leads to resource waste, increased interference, or even call drops.

### Capability Categories

Standardisation bodies (3GPP, ITU‑R) define **categories** that group UEs by their maximum achievable performance.  The most widely used are:

| Category | Typical Radio Features | Maximum Theoretical Downlink (DL) Rate* |
|----------|------------------------|----------------------------------------|
| LTE Cat‑1 | 1.4 MHz BW, 1×1 MIMO, QPSK/16‑QAM | 10 Mbps |
| LTE Cat‑4 | 20 MHz BW, 2×2 MIMO, 64‑QAM, 7 symbols/subframe | 150 Mbps |
| LTE Cat‑20 | 100 MHz BW (5 CC), 8×8 MIMO, 256‑QAM | 2 Gbps |
| NR (5G) n78, Band n78, 100 MHz, 4×4 MIMO, 256‑QAM, 2‑codeword | ~2.5 Gbps (DL) |
| NR (5G) n258, 400 MHz, 8×8 MIMO, 4096‑QAM, 4‑code‑word | >10 Gbps (DL) |

\*Maximum theoretical rates assume ideal channel conditions, full‑buffer traffic, and that the UE can use all allocated resources.  Real‑world rates are lower.

Categories are **hierarchical**: a Cat‑20 UE also supports all features of lower categories (e.g., it can fall back to 20 MHz bandwidth or 2×2 MIMO if the network requires).

### Capability Information Elements

During the RRC (Radio Resource Control) connection setup, the UE transmits **UE Capability Information** (UCI) messages.  The key information elements (IEs) are:

| IE | Description | Typical Units / Values |
|----|-------------|------------------------|
| `ueCategory` | LTE/NR category number | integer (e.g., 4, 20) |
| `maxBandwidth` | Highest contiguous system bandwidth the UE can decode | MHz |
| `maxMIMOlayers` | Maximum simultaneous MIMO layers | integer (e.g., 2, 4, 8) |
| `supportedModulations` | List of modulation orders | {QPSK, 16‑QAM, 64‑QAM, 256‑QAM, …} |
| `supportedCA` | Number of Component Carriers (CC) that can be aggregated | integer |
| `powerClass` | UE transmit power class (e.g., Class 1 = 23 dBm) | dBm |
| `ueTxAntennas` / `ueRxAntennas` | Number of transmit/receive antennas | integer |

The network stores this data in the **UE Context** and uses it for:

* **Scheduler decisions** – allocate only supported MCS (Modulation and Coding Scheme) and bandwidth.
* **Carrier Aggregation (CA) planning** – avoid aggregating more CCs than the UE can handle.
* **Power control** – respect the UE’s power class to limit interference.
* **Handover preparation** – ensure the target cell can satisfy the UE’s minimum capability.

### Data‑Rate Formula

For LTE, the **peak downlink physical layer rate** can be approximated by:

$$
R_{\text{DL}} = N_{\text{RB}} \times N_{\text{SC/RB}} \times \eta_{\text{mod}} \times N_{\text{sym}} \times \frac{1}{T_{\text{subframe}}}
$$

where  

* $N_{\text{RB}}$ – number of Resource Blocks allocated (1 RB = 180 kHz).  
* $N_{\text{SC/RB}}$ – subcarriers per RB (12).  
* $\eta_{\text{mod}}$ – bits per symbol determined by modulation (e.g., QPSK = 2, 16‑QAM = 4, 64‑QAM = 6, 256‑QAM = 8).  
* $N_{\text{sym}}$ – OFDM symbols per subframe (normally 7 for normal CP).  
* $T_{\text{subframe}}$ – subframe duration (1 ms).  

If MIMO is used, the rate is multiplied by $L_{\text{MIMO}}$, the number of spatial layers.

### Worked Example

**Problem:** Compute the theoretical peak downlink rate for an LTE Cat‑4 UE operating on a 20 MHz carrier (100 RB), using 2×2 MIMO, 64‑QAM, and normal CP (7 symbols/subframe).

**Solution:**

1. Identify parameters:  

   * $N_{\text{RB}} = 100$ (20 MHz ÷ 180 kHz)  
   * $N_{\text{SC/RB}} = 12$  
   * $\eta_{\text{mod}} = 6$ bits/symbol (64‑QAM)  
   * $N_{\text{sym}} = 7$  
   * $T_{\text{subframe}} = 1\,\text{ms} = 10^{-3}\,\text{s}$  
   * $L_{\text{MIMO}} = 2$ (2 spatial layers)

2. Plug into the formula:

$$
\begin{aligned}
R_{\text{DL}} &= 100 \times 12 \times 6 \times 7 \times \frac{1}{10^{-3}} \times 2 \\
&= 100 \times 12 \times 6 \times 7 \times 1000 \times 2 \\
&= 100 \times 12 \times 6 \times 14\,000 \\
&= 100 \times 12 \times 84\,000 \\
&= 100 \times 1\,008\,000 \\
&= 100\,800\,000 \ \text{bits/s} \\
&\approx 100.8 \ \text{Mbps}.
\end{aligned}
$$

The result (≈ 100 Mbps) is lower than the *category* ceiling of 150 Mbps because we have not accounted for higher‑order coding gains (e.g., using the full 64‑QAM MCS table) and we assumed the full 100 RBs are allocated continuously.  In practice, the scheduler may achieve up to the 150 Mbps figure by exploiting the highest MCS and perfect link quality.

### Practical Notes & Common Mistakes

| Mistake | Why it Happens | Correct Approach |
|---------|----------------|------------------|
| **Assuming the UE can use the full system bandwidth** | The UE may be limited to a lower *maxBandwidth* (e.g., 10 MHz) due to hardware or certification. | Always read `maxBandwidth` from the UE Capability Information; schedule only within that limit. |
| **Neglecting power class in interference‑limited cells** | Power class is often considered only for uplink power control, not for downlink interference. | When configuring eNodeB/ gNodeB transmission power for a cell, respect the UE’s `powerClass` to avoid unnecessary UL interference. |
| **Treating category as a static ceiling** | Some UEs support *dynamic* category scaling (e.g., Cat‑20 devices can downgrade to Cat‑4 when only 20 MHz is available). | Use the *minimum* supported category for mandatory services, but allow higher categories when resources permit. |
| **Forgetting MIMO layer limits** | Scheduler may allocate more layers than the UE can decode, leading to decoding failures. | Enforce `maxMIMOlayers` during the MAC scheduler’s spatial‑layer assignment. |
| **Overlooking CA limits** | A UE may support up to 5 CCs, but the network may try to aggregate 6. | Verify `supportedCA` before initiating carrier aggregation; fallback to a supported subset if needed. |

**Bottom line:** Accurate, up‑to‑date capability exchange is a prerequisite for any optimisation algorithm discussed elsewhere in this chapter.  Network operators should routinely audit UE capability databases, especially after major firmware upgrades that may change supported categories.

## 練習題

**1.** Which information element directly tells the network the highest contiguous bandwidth a UE can decode?

- A. `ueCategory`
- B. `maxMIMOlayers`
- C. `maxBandwidth`
- D. `powerClass`

<details><summary>看答案</summary>

正解：C。`maxBandwidth` specifies the maximum system bandwidth (in MHz) the UE can handle.

</details>

**2.** For an LTE Cat‑4 UE using 20 MHz bandwidth, 2×2 MIMO, and 64‑QAM, the theoretical peak downlink rate is closest to:

- A. 75 Mbps
- B. 100 Mbps
- C. 150 Mbps
- D. 200 Mbps

<details><summary>看答案</summary>

正解：B。Plugging the parameters into the LTE rate formula yields ≈ 100.8 Mbps.

</details>

**3.** In the UE Capability Information, the field that limits the number of component carriers that can be aggregated is:

- A. `supportedCA`
- B. `ueCategory`
- C. `supportedModulations`
- D. `ueTxAntennas`

<details><summary>看答案</summary>

正解：A。`supportedCA` indicates how many CCs the UE can aggregate simultaneously.

</details>

**4.** Which of the following is *not* a typical mistake when handling terminal capabilities?

- A. Assuming the UE can always use the full system bandwidth.
- B. Ignoring the UE’s supported modulation orders.
- C. Applying the UE’s downlink power class to uplink scheduling.
- D. Forgetting to enforce the UE’s maximum MIMO layer count.

<details><summary>看答案</summary>

正解：C。Power class concerns UE transmit power (uplink); it is not applied to downlink scheduling.

</details>

**5.** A 5G NR UE reports `ueCategory = n78` and `maxMIMOlayers = 4`. Which statement is correct regarding its peak downlink capability?

- A. It can achieve the same peak rate as an LTE Cat‑20 UE.
- B. It can use up to 4 spatial layers, but the exact rate depends on carrier bandwidth and modulation.
- C. It is limited to 100 MHz bandwidth regardless of network configuration.
- D. It cannot support carrier aggregation because NR does not use CA.

<details><summary>看答案</summary>

正解：B。The peak rate depends on bandwidth, modulation, and other factors; the UE can use up to 4 MIMO layers.

</details>
