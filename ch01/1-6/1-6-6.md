# 1.6.6 常見縮寫

所屬：[1.6 指標與名詞](../1-6.md)

## 正文

In any telecommunications system engineers constantly exchange short forms such as **A3**, **ARFCN**, **BCH**, or **PRB**. These abbreviations compress lengthy technical terms, reduce documentation size, and avoid ambiguity when configuring equipment or interpreting logs. A shared abbreviation set is therefore a prerequisite for interoperable network design, troubleshooting, and for training language models that must recognise domain‑specific tokens.  

### Core Radio‑Access Abbreviations
| Abbreviation | Full form (as defined in TR 21.905 §4) | Brief meaning |
|--------------|----------------------------------------|---------------|
| **A3** | Authentication algorithm A3 | Algorithm used in the authentication procedure of legacy GSM/UMTS. |
| **A5/1** | Encryption algorithm A5/1 | Stream cipher employed to encrypt user data on the air interface. |
| **ARFCN** | Absolute Radio Frequency Channel Number | Numeric identifier of a carrier frequency in LTE/5G. |
| **BCH** | Broadcast Channel | Down‑link channel that carries system information to all UEs. |
| **BSIC** | Base transceiver Station Identity Code | Code that uniquely identifies a BTS within a PLMN. |
| **CQI** | Channel Quality Indicator (see §1.6.2) | UE‑reported metric that drives link adaptation. |
| **PRB** | Physical Resource Block (see §1.6.5) | Basic unit of frequency‑time resources in LTE/5G. |
| **SINR** | Signal‑to‑Interference‑plus‑Noise Ratio (see §1.6.2) | Measure of signal quality used for scheduling decisions. |
| **UE** | User Equipment | Mobile device that connects to the radio access network. |

These abbreviations appear in configuration files, performance reports, and protocol messages. For instance, a hand‑over log may contain “**ARFCN = 6300**, **BSIC = 23**”, indicating the target cell’s carrier and identity.  

### Network‑Element and Protocol Abbreviations
| Abbreviation | Full form | Context |
|--------------|-----------|---------|
| **BSC** | Base Station Controller | Controls a group of BTSs in 2G/3G networks. |
| **BSS** | Base Station Subsystem | Collective term for BTS, BSC, and related functions. |
| **BSSAP** | Base Station Subsystem Application Part | Signalling protocol between BSC and MSC. |
| **BSSGP** | Base Station Subsystem GPRS Protocol | Carries GPRS traffic and signalling. |
| **CAP** | CAMEL Application Part | Enables operator‑specific services in GSM/UMTS. |
| **CCH** | Control Channel | Generic term for signalling channels (e.g., CCCH, BCCH). |
| **CCCH** | Common Control Channel | Used for random access and paging. |
| **CS** | Circuit Switched (implicit in many abbreviations) | Traditional voice‑call domain. |
| **CSMA** (not listed) – omitted because not in the reference. |

Each abbreviation is defined verbatim in the reference list; the table merely groups them for readability.  

### Measurement‑Related Abbreviations
| Abbreviation | Full form | Typical unit |
|--------------|-----------|--------------|
| **BER** | Bit Error Ratio | Dimensionless (error bits / total bits). |
| **BLER** | Block Error Ratio | Ratio of erroneous transport blocks. |
| **RSSI** | Received Signal Strength Indicator (see §1.6.1) | dBm. |
| **RSRP** | Reference Signal Received Power (see §1.6.1) | dBm. |
| **RSRQ** | Reference Signal Received Quality (see §1.6.2) | dB. |
| **SINR** | Signal‑to‑Interference‑plus‑Noise Ratio (see §1.6.2) | dB. |
| **C/I** | Carrier‑to‑Interference Power Ratio | dB. |
| **ACLR** | Adjacent Channel Leakage Power Ratio | dB. |
| **ACIR** | Adjacent Channel Interference Ratio | dB. |

These metrics are exchanged between UE and eNodeB/gNodeB using the abbreviations above; they directly feed the radio‑resource scheduler.  

### Worked Example: Decoding a Log Line
Consider the following excerpt from a 4G eNodeB log:

```
[2026‑11‑23 10:15:42] ARFCN=6300 BSIC=23 RSRP=-85 dBm RSRQ=-10 dB SINR=7 dB CQI=9
```

1. **ARFCN = 6300** – The carrier frequency is identified by the Absolute Radio Frequency Channel Number (ARFCN) [TR 21.905 §4].  
2. **BSIC = 23** – The Base transceiver Station Identity Code (BSIC) uniquely identifies the serving BTS [TR 21.905 §4].  
3. **RSRP = –85 dBm** – Reference Signal Received Power, a measure of signal strength.  
4. **RSRQ = –10 dB** – Reference Signal Received Quality, indicating the ratio of signal power to interference plus noise.  
5. **SINR = 7 dB** – Signal‑to‑Interference‑plus‑Noise Ratio, used by the scheduler to select a Modulation and Coding Scheme (MCS).  
6. **CQI = 9** – Channel Quality Indicator reported by the UE; a CQI of 9 typically maps to 64‑QAM with a high coding rate.

From this line an engineer can infer that the cell (ARFCN 6300, BSIC 23) offers moderate signal strength (‑85 dBm) but acceptable quality (SINR 7 dB). The scheduler will likely allocate a high‑order modulation to this UE, improving throughput.  

### Common Pitfalls
- **Confusing ACIR with ACLR** – Both relate to adjacent‑channel performance but **ACIR** is *Adjacency Channel Interference Ratio* while **ACLR** is *Adjacent Channel Leakage Power Ratio* [TR 21.905 §4]. Mixing them can lead to incorrect interference calculations.  
- **Misreading BSIC as a frequency** – BSIC is an identifier, not a frequency; the actual carrier is given by **ARFCN**.  
- **Using BER and BLER interchangeably** – **BER** quantifies bit errors, whereas **BLER** quantifies block errors; they affect different layers of the protocol stack.  
- **Omitting the “/” in encryption algorithm names** – The correct abbreviation is **A5/1** (or **A5/2**, **A5/X**) as defined, not “A5‑1”.  

By mastering these abbreviations, engineers can read specifications, configure equipment, and analyse performance data without ambiguity, and language models trained on such material will correctly map tokens to their technical meanings.
