# 1.6.6 常見縮寫

所屬：[1.6 指標與名詞](../1-6.md)

## 正文

In modern cellular systems the sheer number of performance indicators, protocol layers, and network functions makes it impossible to write out full terms every time a metric is discussed. Abbreviations (or “short‑forms”) are therefore an essential part of the engineering language; they enable concise documentation, rapid troubleshooting, and unambiguous exchange of information between vendors, operators, and standards bodies. A solid grasp of the most frequently used abbreviations is a prerequisite for interpreting measurement reports, configuring radio‑resource management (RRM) algorithms, and designing automated analytics pipelines for network optimization.

Below is a curated list of abbreviations that appear throughout Chapter 1 and are repeatedly referenced in later chapters. Each entry includes a brief definition, the typical unit (if any), and, where applicable, the mathematical relationship that connects the abbreviated quantity to other measurable parameters.

| Abbreviation | Full form | Typical usage / unit | Key relationship / comment |
|--------------|-----------|----------------------|----------------------------|
| **RSRP** | Reference Signal Received Power | dBm (linear power in W = $10^{\frac{\text{dBm}-30}{10}}$) | Average power of the LTE/NR cell‑specific reference signals over the bandwidth of a single resource block (RB). |
| **RSSI** | Received Signal Strength Indicator | dBm | Total received power (signal + inter‑cell interference + thermal noise) measured over the entire carrier bandwidth. |
| **RSRQ** | Reference Signal Received Quality | dB | $$\text{RSRQ} = \frac{N_{\text{RB}} \times \text{RSRP}}{\text{RSSI}}$$ where $N_{\text{RB}}$ is the number of RBs over which RSSI is measured. |
| **SINR** | Signal‑to‑Interference‑plus‑Noise Ratio | dB | $$\text{SINR} = 10 \log_{10}\!\left(\frac{P_{\text{sig}}}{P_{\text{int}} + P_{\text{noise}}}\right)$$ |
| **CQI** | Channel Quality Indicator | Index (1–15 for LTE, 1–15 for NR) | Maps to a Modulation and Coding Scheme (MCS); higher CQI → higher spectral efficiency. |
| **PRB** | Physical Resource Block | 12 sub‑carriers × 1 slot (0.5 ms) for LTE; 12 sub‑carriers × 1 ms for NR (depending on numerology) | The smallest allocatable unit of frequency‑time resources in the MAC layer. |
| **TTI** | Transmission Time Interval | ms (e.g., 1 ms in LTE, 0.5 ms in NR) | Duration of a scheduling unit; determines latency granularity. |
| **MIMO** | Multiple‑Input Multiple‑Output | – | Uses multiple antennas at transmitter and receiver to increase capacity; expressed as $N_t \times N_r$ (e.g., 4×4). |
| **OFDM** | Orthogonal Frequency‑Division Multiplexing | – | Modulation scheme that splits the channel into orthogonal sub‑carriers; basis for LTE and NR air‑interface. |
| **HO / HOF** | Handover / Handover Failure | – | Procedure to transfer an active UE from one cell to another; HOF is the event where the handover does not complete successfully. |
| **RRC** | Radio Resource Control | – | Layer‑3 protocol that manages connection states, security, and mobility. |
| **MAC** | Medium Access Control | – | Layer‑2 protocol responsible for scheduling, HARQ, and multiplexing of logical channels onto PRBs. |
| **PDCP** | Packet Data Convergence Protocol | – | Layer‑2 protocol that performs header compression, ciphering, and integrity protection. |
| **RAN** | Radio Access Network | – | The part of the mobile network that includes eNodeB/gNodeB and associated radio‑resource functions. |
| **EPC** | Evolved Packet Core | – | Core network architecture for LTE (see 3GPP TS 23.401). |
| **MME** | Mobility Management Entity | – | Control‑plane node in the EPC handling NAS signaling, authentication, and session management. |
| **SGW** | Serving Gateway | – | User‑plane node that routes and forwards user data packets within the EPC. |
| **PGW** | Packet Data Network Gateway | – | User‑plane node that provides connectivity to external IP networks. |
| **NR** | New Radio | – | The 5G air‑interface defined by 3GPP TS 38.211‑38.215. |
| **LTE** | Long‑Term Evolution | – | 4G air‑interface defined by 3GPP TS 36.211‑36.213. |
| **QoS** | Quality of Service | – | Set of mechanisms (e.g., QCI, ARP) that guarantee performance for different traffic classes. |
| **QCI** | QoS Class Identifier | – | Numeric identifier (1–9) that maps to specific QoS parameters such as priority and packet delay budget. |
| **ARP** | Allocation‑Retention Priority | – | Determines pre‑emption behavior among bearers with different QoS requirements. |
| **UE** | User Equipment | – | The mobile device (handset, IoT module, etc.) that communicates with the RAN. |
| **eNB / gNB** | E‑UTRAN Node B / Next‑Generation Node B | – | Base‑station hardware for LTE (eNB) and NR (gNB). |

### Worked Example – Computing RSRQ

A field measurement yields the following values for a 20 MHz LTE carrier:

* Measured **RSRP** = –95 dBm  
* Measured **RSSI** = –70 dBm  
* The carrier occupies $N_{\text{RB}} = 100$ PRBs (each 180 kHz, total 18 MHz usable bandwidth; the remaining 2 MHz is guard band and not counted).

Compute the **RSRQ** in dB.

**Step 1 – Convert dBm to linear power (W).**  
$$
P_{\text{RSRP}} = 10^{\frac{-95-30}{10}} = 3.16\times10^{-13}\,\text{W}
$$
$$
P_{\text{RSSI}} = 10^{\frac{-70-30}{10}} = 1.00\times10^{-10}\,\text{W}
$$

**Step 2 – Apply the RSRQ formula.**  
$$
\text{RSRQ}_{\text{lin}} = \frac{N_{\text{RB}} \times P_{\text{RSRP}}}{P_{\text{RSSI}}}
= \frac{100 \times 3.16\times10^{-13}}{1.00\times10^{-10}}
= 0.316
$$

**Step 3 – Convert back to dB.**  
$$
\text{RSRQ}_{\text{dB}} = 10\log_{10}(0.316) \approx -5.0\ \text{dB}
$$

Thus the cell’s RSRQ is **–5 dB**, indicating moderate quality; values closer to 0 dB are better, while values below –10 dB typically trigger radio‑resource re‑selection or handover.

### Practical Notes and Common Pitfalls

| Pitfall | Why it happens | Remedy |
|---------|----------------|--------|
| **Confusing RSSI with RSRP** | Both are expressed in dBm, but RSSI includes interference and noise. | Always verify the measurement context; use RSRP for link‑budget calculations, RSSI for total received power. |
| **Treating CQI as a direct throughput value** | CQI is an index that maps to an MCS; the actual throughput depends on bandwidth, PRB allocation, and scheduling efficiency. | Consult the CQI‑to‑MCS table (e.g., 3GPP TS 36.213) and then compute spectral efficiency. |
| **Using the wrong $N_{\text{RB}}$ in RSRQ** | $N_{\text{RB}}$ must match the bandwidth over which RSSI is measured, not the total carrier bandwidth. | Confirm the measurement bandwidth (often the “measurement bandwidth” parameter in the UE). |
| **Assuming SINR = SNR** | Inter‑cell interference can dominate thermal noise, especially in dense deployments. | Separate interference from noise when possible; use $P_{\text{int}}$ and $P_{\text{noise}}$ values from the UE’s measurement report. |
| **Neglecting numerology when counting PRBs** (NR) | NR supports multiple sub‑carrier spacings; a “PRB” width in kHz varies with numerology. | Use the appropriate numerology (μ) to convert PRBs to Hz before comparing with LTE figures. |
| **Mixing LTE and NR abbreviations** | Some terms (e.g., CQI) have similar meanings but different numeric ranges or mapping tables. | Keep the radio‑access technology context explicit when reporting metrics. |
| **Over‑looking guard bands in PRB utilization** | PRB utilization percentages can be inflated if guard‑band PRBs are mistakenly counted as usable. | Exclude guard‑band PRBs from the denominator when computing utilization. |

By mastering these abbreviations and their associated formulas, engineers can read measurement logs, design RRM policies, and communicate findings with precision—an indispensable skill in the fast‑evolving landscape of mobile communications.

## 練習題

**1.** Which of the following formulas correctly expresses RSRQ?

- A. $\displaystyle \text{RSRQ} = \frac{\text{RSSI}}{N_{\text{RB}}\times\text{RSRP}}$
- B. $\displaystyle \text{RSRQ} = 10\log_{10}\!\left(\frac{\text{RSRP}}{\text{RSSI}}\right)$
- C. $\displaystyle \text{RSRQ} = \frac{N_{\text{RB}}\times\text{RSRP}}{\text{RSSI}}$
- D. $\displaystyle \text{RSRQ} = \frac{\text{RSRP}}{N_{\text{RB}}+\text{RSSI}}$

<details><summary>看答案</summary>

正解：C。RSRQ is defined as $(N_{\text{RB}}\times\text{RSRP})/\text{RSSI}$, with $N_{\text{RB}}$ the number of RBs used for the RSSI measurement.

</details>

**2.** If a UE reports RSRP = –85 dBm and RSSI = –65 dBm on a 10 MHz LTE carrier that occupies 50 PRBs, what is the RSRQ (in dB) rounded to one decimal place?

- A. –4.5 dB
- B. –6.0 dB
- C. –8.2 dB
- D. –10.0 dB

<details><summary>看答案</summary>

正解：B。Converting to linear power, applying $\text{RSRQ} = (50\times P_{\text{RSRP}})/P_{\text{RSSI}}$, yields a linear value ≈0.251, which is $10\log_{10}(0.251) \approx -6.0$ dB.

</details>

**3.** Which abbreviation refers to the smallest allocatable unit of frequency‑time resources in the MAC layer?

- A. TTI
- B. PRB
- C. RB
- D. OFDM

<details><summary>看答案</summary>

正解：B。A Physical Resource Block (PRB) is the basic scheduling unit (12 sub‑carriers × one slot) used by the MAC scheduler.

</details>

**4.** In LTE, a CQI index of 7 typically maps to which modulation scheme?

- A. QPSK with rate‑1/3
- B. 16‑QAM with rate‑1/2
- C. 64‑QAM with rate‑3/4
- D. QPSK with rate‑1/2

<details><summary>看答案</summary>

正解：B。CQI 7 corresponds to 16‑QAM and a medium coding rate (≈1/2) in the LTE CQI‑to‑MCS table.

</details>

**5.** When calculating PRB utilization, which of the following should be excluded from the denominator?

- A. PRBs used for control channels
- B. Guard‑band PRBs
- C. PRBs carrying user data
- D. PRBs allocated to high‑priority bearers

<details><summary>看答案</summary>

正解：B。Guard‑band PRBs are not usable for data transmission and must be omitted to avoid overstating utilization.

</details>
