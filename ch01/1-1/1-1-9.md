# 1.1.9 網路與用戶識別碼：SUPI、GUTI、DNN、gNB／Cell ID

所屬：[1.1 網路架構](../1-1.md)

## 正文

In a 5G System every signalling transaction must be tied to an identifier that is unique, unambiguous, and, where required, privacy‑preserving.  The identifiers are used by the Access and Mobility Management Function (AMF) to locate the subscriber, by the radio access network (gNB) to address the UE in the air interface, and by the core network to select the correct data network (DNN).  Correct handling of these identifiers is essential for subscriber authentication, roaming, and for protecting the user’s identity from eavesdropping.

---

### 5G Subscription Permanent Identifier (SUPI)

A **SUPI** is a *globally unique* subscription identifier provisioned in the Unified Data Management (UDM) or Unified Data Repository (UDR) and is used *only inside* the 3GPP system [TS 23.501 §5.9.2].  The SUPI may be one of the following forms:

| Form | Description |
|------|-------------|
| **IMSI** | As defined in TS 23.003. |
| **Network‑specific identifier** | Formatted as a Network Access Identifier (NAI) per RFC 7542. |
| **GLI + operator ID** | Used for supporting FN‑BRGs (TS 23.316). |
| **GCI + operator ID** | Used for supporting FN‑CRGs and 5G‑CRG (TS 23.316). |

When a UE must present its SUPI (e.g., during registration) it does so in a *concealed* form called the **Subscription Concealed Identifier (SUCI)**, which hides the SUPI from the radio link [TS 23.501 §5.9.2a].

*Why it matters*: The SUPI uniquely binds a subscription to a home network (MCC/MNC) and therefore enables roaming and inter‑working with LTE EPC, which requires an IMSI‑based SUPI [TS 23.501 §5.9.2].

---

### Permanent Equipment Identifier (PEI)

Although not part of the subsection title, the **PEI** is defined alongside the SUPI.  For UEs that support any 3GPP radio technology the PEI is an **IMEI** or **IMEISV** (TS 23.003) [TS 23.501 §5.9.3].  The PEI is presented together with an indication of its format.

---

### 5G Globally Unique Temporary Identifier (5G‑GUTI)

To protect subscriber privacy on the radio interface the AMF allocates a **temporary** identifier, the **5G‑GUTI**, which is common to both 3GPP and non‑3GPP access [TS 23.501 §5.9.4].  The AMF may re‑assign a new GUTI at any time.

The 5G‑GUTI is composed of two parts:

$$
\boxed{5G\text{-}GUTI = \text{GUAMI} \; || \; 5G\text{-}TMSI}
$$

* **GUAMI (Globally Unique AMF Identifier)**  

$$
\text{GUAMI} = \text{MCC} \;||\; \text{MNC} \;||\; \text{AMF Region ID} \;||\; \text{AMF Set ID} \;||\; \text{AMF Pointer}
$$

* **5G‑TMSI (5G Temporary Mobile Subscriber Identity)** – a locally unique number within the AMF.  

If the GUAMI refers to a *single* AMF, the 5G‑TMSI uniquely identifies the UE inside that AMF.  When the GUAMI is shared among several AMFs, the AMF must ensure that the 5G‑TMSI does not clash with values used by the other AMFs [TS 23.501 §5.9.4].

A shortened version, the **5G‑S‑TMSI**, is defined for efficient radio signalling:

$$
\boxed{5G\text{-}S\text{-}TMSI = \text{AMF Set ID} \;||\; \text{AMF Pointer} \;||\; 5G\text{-}TMSI}
$$

The NG‑RAN uses the *10 least‑significant bits* of the 5G‑TMSI for paging timing, so the AMF must distribute these bits evenly [TS 23.501 §5.9.4].

---

### Worked Example – Constructing a 5G‑GUTI  

Assume a network with the following parameters (all values are decimal unless otherwise noted):

| Field | Value |
|-------|-------|
| MCC | 310 |
| MNC | 260 |
| AMF Region ID | 01 |
| AMF Set ID | 02 |
| AMF Pointer | 03 |
| 5G‑TMSI | 0xABCD1234 |

1. **Build GUAMI**  

$$
\text{GUAMI}=310\;||\;260\;||\;01\;||\;02\;||\;03 = \text{“310260010203”}
$$

2. **Append 5G‑TMSI** (hexadecimal)  

$$
5G\text{-}GUTI = \text{“310260010203”} \;||\; \text{ABCD1234}
$$

Resulting **5G‑GUTI** = *310260010203ABCD1234* (hex string).  

If the UE moves to a different AMF that shares the same GUAMI, the AMF must allocate a new 5G‑TMSI that does not duplicate any existing value in the shared GUAMI set [TS 23.501 §5.9.4].

---

### DNN, gNB and Cell ID – Scope Note  

The **Data Network Name (DNN)**, the **gNB identifier**, and the **Cell ID** are defined in other 3GPP specifications (e.g., TS 23.501 for DNN, TS 38.331 for gNB/Cell ID).  Because the present reference (TS 23.501 §5.9) does not contain their definitions, they are mentioned here only to acknowledge their relevance; detailed structures are outside the scope of this subsection.

---

### Practical Notes & Common Mistakes  

| Issue | Typical Mistake | Correct Practice |
|-------|----------------|------------------|
| **Confusing SUPI and SUCI** | Treating the concealed identifier as the permanent one. | The UE always sends the **SUCI** (concealed SUPI) on the radio; the network de‑conceals it only inside the core. |
| **Re‑using a 5G‑TMSI across AMFs** | Assuming the same 5G‑TMSI can be reused when GUAMI is shared. | The AMF must ensure **uniqueness** of the 5G‑TMSI within the shared GUAMI set [TS 23.501 §5.9.4]. |
| **Ignoring LSB distribution** | Randomly assigning 5G‑TMSI values that cluster the 10 LSBs. | Distribute the **10 least‑significant bits** of the 5G‑TMSI evenly to avoid paging collisions [TS 23.501 §5.9.4]. |
| **Using non‑IMSI SUPI for EPC interworking** | Providing a network‑specific identifier when the UE must interwork with LTE EPC. | The SUPI **shall always be based on an IMSI** for EPC interworking [TS 23.501 §5.9.2]. |
| **Omitting PEI format indication** | Sending only the IMEI value without declaring the format. | The UE must present the **PEI together with an indication of the PEI format** [TS 23.501 §5.9.3]. |

By respecting the structure and lifecycle rules of SUPI, SUCI, PEI, and 5G‑GUTI, engineers can design secure, interoperable, and privacy‑aware 5G deployments.  

[TS 23.501 §5.9]

## 練習題

**1.** What does the AMF allocate to a UE for temporary identification?

- A. PEI
- B. SUCI
- C. 5G‑GUTI
- D. DNN

<details><summary>看答案</summary>

正解：C。The AMF allocates the 5G‑GUTI as a temporary identifier.

</details>

**2.** Which component is *not* part of the GUAMI structure?

- A. MCC
- B. AMF Region ID
- C. 5G‑TMSI
- D. AMF Set ID

<details><summary>看答案</summary>

正解：C。GUAMI consists of MCC, MNC, AMF Region ID, AMF Set ID, and AMF Pointer; 5G‑TMSI is a separate part of the GUTI.

</details>

**3.** When a UE registers with a network that uses EPC, what must the SUPI be based on?

- A. Network‑specific identifier
- B. GLI + operator ID
- C. IMSI
- D. GCI + operator ID

<details><summary>看答案</summary>

正解：C

</details>

**4.** Which statement about the 5G‑S‑TMSI is correct?

- A. It includes the MCC and MNC.
- B. It is the full 5G‑GUTI.
- C. It consists of AMF Set ID, AMF Pointer, and 5G‑TMSI.
- D. It is used only for non‑3GPP access.

<details><summary>看答案</summary>

正解：C。The definition of 5G‑S‑TMSI includes those three fields.

</details>
