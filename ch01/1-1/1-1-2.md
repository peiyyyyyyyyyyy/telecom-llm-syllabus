# 1.1.2 無線接取網：基地台、天線、頻段

所屬：[1.1 網路架構](../1-1.md)

## 正文

In a 5G New Radio (NR) access network the term *base station* refers to the radio node that terminates both user‑plane (UP) and control‑plane (CP) protocols with the mobile terminal (UE).  According to the 3GPP specification, an NG‑RAN node can be either  

* a **gNB**, which provides **NR** user‑plane and control‑plane protocol terminations towards the UE, or  
* an **ng‑eNB**, which provides **E‑UTRA** (LTE) user‑plane and control‑plane protocol terminations towards the UE.  

These two node types are the only radio access entities defined in the reference architecture for the wireless access network [TS 38.300 §4.1].

### Interface Overview

The base stations are not isolated islands; they must exchange signalling and user data with peers and with the 5G Core (5GC).  The specification defines three logical interfaces that are mandatory for every NG‑RAN node:

| Interface | Counter‑part | Function |
|-----------|--------------|----------|
| **Xn**    | Other gNBs / ng‑eNBs | Inter‑node connectivity for handover, load‑balancing, and coordination. |
| **NG‑C**  | AMF (Access and Mobility Management Function) | Carries control‑plane messages from the base station to the core. |
| **NG‑U**  | UPF (User Plane Function) | Carries user‑plane data from the base station to the core. |

The reference text states that *“The gNBs and ng‑eNBs are interconnected with each other by means of the Xn interface”* and that they *“are also connected by means of the NG interfaces to the 5GC… to the AMF … by means of the NG‑C interface and to the UPF … by means of the NG‑U interface”* [TS 38.300 §4.1].

### Symbolic representation

If we denote the number of Xn links a base station maintains as $N_{\text{Xn}}$, the total count of logical interfaces $N_{\text{if}}$ attached to that node can be expressed as  

$$
N_{\text{if}} = 1_{\text{NG‑C}} + 1_{\text{NG‑U}} + N_{\text{Xn}} .
$$  

Here $1_{\text{NG‑C}}$ and $1_{\text{NG‑U}}$ are constant because every NG‑RAN node must support exactly one NG‑C and one NG‑U interface.  $N_{\text{Xn}}$ depends on the network topology (e.g., number of neighbour cells with which handover coordination is required).

### Worked Example

Consider a gNB deployed in a dense urban macro‑cell environment.  The operator configures the node to maintain Xn links to three immediate neighbour gNBs for fast handover.  Compute the total number of logical interfaces $N_{\text{if}}$ for this gNB.

* Given: $N_{\text{Xn}} = 3$ (three neighbour gNBs).  
* Apply the formula:  

$$
N_{\text{if}} = 1_{\text{NG‑C}} + 1_{\text{NG‑U}} + N_{\text{Xn}} = 1 + 1 + 3 = 5 .
$$

Thus the gNB will expose **five** logical interfaces: one NG‑C, one NG‑U, and three Xn links.  This simple count is useful during network planning, as each Xn link consumes back‑haul capacity and requires configuration in the RAN management system.

### Antennas and Frequency Bands – Scope Note

The reference specification excerpt does **not** describe antenna architectures (e.g., panel, MIMO array) nor the allocation of frequency bands (e.g., FR1, FR2).  Those topics are covered in other 3GPP technical specifications and are therefore outside the scope of this subsection.  Readers should consult the appropriate TS‑38‑101 (radio‑frequency) and TS‑38‑104 (physical layer) documents for detailed treatment of antenna design and spectrum usage.

### Practical Notes and Common Mistakes

1. **Confusing NG‑C with NG‑U** – Engineers sometimes treat the two NG interfaces as a single logical link.  In practice they are distinct: NG‑C carries signalling (e.g., RRC, NAS) while NG‑U carries user data packets.  Mixing them can lead to protocol violations and dropped sessions.  

2. **Assuming a base station always has an Xn link** – The Xn interface is required only when a node needs to coordinate with peers.  A standalone gNB that serves a remote area with no handover neighbours may have $N_{\text{Xn}} = 0$, resulting in $N_{\text{if}} = 2$.  Forgetting this can cause over‑provisioning of back‑haul resources.  

3. **Neglecting the ng‑eNB role** – While 5G deployments focus on gNBs, legacy LTE cells continue to operate as ng‑eNBs within the NG‑RAN.  Their presence is mandatory for NSA (Non‑Standalone) deployments, and they provide E‑UTRA terminations exactly as defined in the reference.  Overlooking ng‑eNBs can cause coverage gaps for LTE‑only devices.  

4. **Mis‑labeling interfaces in documentation** – The specification uses precise terminology (Xn, NG‑C, NG‑U).  Using generic terms such as “back‑haul” or “control link” without mapping them to the official names can cause confusion during integration testing.  

By adhering strictly to the definitions and interface relationships given in TS 38.300 §4.1, network engineers can avoid these pitfalls and ensure interoperable, standards‑compliant deployments.
