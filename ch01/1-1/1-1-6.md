# 1.1.6 5G 核心網（5GC）與服務化架構

所屬：[1.1 網路架構](../1-1.md)

## 正文

**5G Core (5GC) and Service‑Based Architecture (SBA)**  

The 5G System (5GS) replaces the monolithic “node” concept of earlier generations with a collection of **Network Functions (NFs)** that expose **services** to one another through **service‑based interfaces (SBIs)**. This design, called the *Service‑Based Architecture*, enables flexible scaling, independent evolution of functions, and rapid deployment of new services such as network slicing or edge computing. In a real operator network, SBA allows the same core to support both massive‑IoT and ultra‑reliable low‑latency traffic without redesigning the underlying hardware [TS 29.500 §4].

### Key Definitions

| Symbol | Meaning | Unit / Note |
|--------|---------|-------------|
| **NF** | Network Function – a logical entity that performs a specific set of tasks (e.g., AMF, SMF, UPF). | – |
| **NF Service** | Capability offered by an NF (the *producer*) to other authorized NFs (the *consumer*) via an SBI. | – |
| **SBI** | Service‑Based Interface – the HTTP‑based API through which a consumer invokes operations of a producer. | – |
| **NRF** | Network Repository Function – the catalogue that stores NF instance information and the services they provide. | – |
| **NF Service Framework** | Set of mechanisms for registration, discovery, authorization, and communication of NF services. | – |
| **AMF** | Access and Mobility Management Function – handles registration, mobility, NAS security, and transport of SM/SMS messages. | – |
| **UDR** | Unified Data Repository – stores subscription, policy, and structured data for consumption by other NFs. | – |

The SBA defines **named SBIs**; each name identifies the service offered by a particular NF. The specification lists the following (excerpt) [TS 23.501 §4.2.6]:

- **Namf** – exhibited by AMF  
- **Nsmf** – exhibited by SMF  
- **Nnef** – exhibited by NEF  
- **Npcf** – exhibited by PCF  
- **Nudm** – exhibited by UDM  
- **Naf** – exhibited by AF  
- **Nnrf** – exhibited by NRF  
- … (continues through a total of 30 distinct SBIs).

### NF Service Framework

The framework provides four essential mechanisms [TS 29.500 §4.3.1]:

1. **NF service registration / de‑registration** – an NF informs the NRF of its instance ID and the services it offers.  
2. **NF service discovery** – a consumer queries the NRF to obtain the URI of a producer that provides the required service.  
3. **NF service authorization** – the NRF checks that the consumer is permitted to use the requested service.  
4. **Inter‑service communication** – consumers and producers may communicate **directly** or **indirectly via a Service Communication Proxy (SCP)** [TS 29.500 §4.3.1].

When a consumer invokes an operation that uses HTTP methods with a body (PUT, POST, PATCH), it may include **NF Service Advertisement URI(s)** so that the producer can later discover services offered by the consumer [TS 29.500 §4.3.2].

### Representative Network Functions

### Access and Mobility Management Function (AMF)

The AMF terminates the RAN control‑plane (N2) and NAS (N1) interfaces, performs registration, connection, reachability, and mobility management, and acts as a **Security Anchor Function (SEAF)** [TS 23.501 §6.2.1]. It also transports SM (Session Management) and SMS messages, provides location‑service transport, and supports network‑slice‑specific authentication and charging. For non‑3GPP access, the AMF may handle N2 with N3IWF/TNGF and manage separate security contexts [TS 23.501 §6.2.1].

### Unified Data Repository (UDR)

The UDR stores **subscription data** for the UDM, **policy data** for the PCF, and various structured data such as Packet Flow Descriptions (PFDs) or 5G‑VN group information. It is accessed via the **Nudr** intra‑PLMN interface [TS 23.501 §6.2.11].

### Worked Example – Counting Service‑Based Interfaces

The specification enumerates 30 distinct SBIs (from **Namf** to **Neif**). An operator wishes to verify that all expected SBIs are present in its catalogue.

| Step | Action | Result |
|------|--------|--------|
| 1 | List all SBIs defined in TS 23.501 §4.2.6 | Namf, Nsmf, Nnef, Npcf, Nudm, Naf, Nnrf, Nnsacf, Nnssaaf, Nnssf, Nausf, Nudr, Nudsf, N5g‑eir, Nnwdaf, Nchf, Nucmf, Ndccf, Nmfaf, Nadrf, Naanf, N5g‑ddnmf, Nmbsmf, Nmbsf, Ntsctsf, Nbsp, Neasdf, Nupf, Neif |
| 2 | Count entries | **30** SBIs |

Thus the core network advertises **30** service‑based interfaces, each mapped to a specific NF service. This count is useful when designing the NRF database or validating a deployment against the 3GPP specification.

### Common Mistakes & Practical Notes

| Pitfall | Why it occurs | Correct practice |
|---------|---------------|------------------|
| **Treating SBIs as static point‑to‑point links** | Early‑generation cores used fixed interfaces (e.g., S1‑MME). | Remember that SBIs are *service* APIs; the same NF may have multiple instances, discovered at run‑time via the NRF. |
| **Skipping NRF registration** | Operators sometimes launch NFs without updating the NRF. | Ensure every NF instance registers its services with the NRF before attempting discovery. |
| **Assuming one NF instance per service** | Scaling often requires multiple SMF or UPF instances. | Design each NF service to be self‑contained so that instances can be added or removed independently. |
| **Omitting NF Service Advertisement URIs** | The specification allows a consumer to advertise its own services, but this step is often ignored. | Include the advertisement URI in POST/PATCH bodies when the operator’s policy requires reciprocal service discovery. |
| **Confusing AMF with SEAF** | The AMF *contains* the SEAF functionality, but they are not separate NFs. | Treat SEAF as a logical role inside the AMF, not a distinct network element. |

By adhering to the SBA principles—explicit service registration, discovery via the NRF, and proper use of SBIs—engineers can build a 5GC that is both modular and future‑proof.

## 練習題

**1.** Which service‑based interface is exhibited by the Access and Mobility Management Function (AMF)?

- A. Namf
- B. Nsmf
- C. Npcf
- D. Nudr

<details><summary>看答案</summary>

正解：A。The AMF exposes the “Namf” interface for other network functions to invoke its services.

</details>

**2.** Which of the following is NOT a functionality of the AMF as described in TS 23.501 §6.2.1?

- A. Access Authentication
- B. Provide transport for SM messages between UE and SMF
- C. EPS Bearer ID allocation for interworking with EPS
- D. User Plane Function management

<details><summary>看答案</summary>

正解：D。The listed AMF functions include authentication, SM message transport, and EPS Bearer ID allocation, but not management of the UPF.

</details>

**3.** In the NF Service Framework, which mechanism guarantees that a consumer may use a producer’s service?

- A. NF service registration
- B. NF service discovery
- C. NF service authorization
- D. Inter service communication

<details><summary>看答案</summary>

正解：C。NF service authorization is defined to ensure the consumer is permitted to access the producer’s service.

</details>

**4.** Which interface is used by other network functions within the same PLMN to access the Unified Data Repository (UDR)?

- A. Nnrf
- B. Nudr
- C. Nsmf
- D. Npcf

<details><summary>看答案</summary>

正解：B。The UDR is accessed intra‑PLMN via the Nudr interface.

</details>

**5.** The service‑based interfaces exhibited by MB‑SMF and MBSF are defined in which 3GPP Technical Specification?

- A. TS 23.501
- B. TS 23.247
- C. TS 33.535
- D. TS 29.500

<details><summary>看答案</summary>

正解：B。The reference notes that the MB‑SMF and MBSF interfaces are specified in TS 23.247.

</details>
