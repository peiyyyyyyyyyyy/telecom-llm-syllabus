# 1.2.5 MPLS 與 VPN

所屬：[1.2 通訊協定](1-2.md)

## 內文

MPLS 讓網路節點依封包上的標籤選擇後續轉送動作。標籤把適合相同轉送處理的封包歸在一起，方便業者把核心轉送與服務邊界的路由分工接起來。BGP/MPLS IP VPN 是其中一種跨站私有網路服務，藉由各客戶的路由及轉送環境維持隔離，允許不同服務的站點有重疊前綴。 [IETF RFC 3031](https://www.rfc-editor.org/rfc/rfc3031.html) [IETF RFC 4364](https://www.rfc-editor.org/rfc/rfc4364.html)

以 BGP/MPLS IP VPN 為例，客戶設備把路由交給與其相連的業者邊界節點。業者把該站點接到適當的 VRF，並依路由屬性控制哪些遠端路由可匯入。Route Distinguisher 幫助建立可區分的 VPN 路由，Route Target 用於表達彼此可交換路由的政策。發送封包時，入口業者節點依目的路由加上適用標籤，核心沿標籤路徑送往出口。若使用外層傳輸標籤和內層服務標籤，外層與核心傳送相關，內層讓出口節點做對應的服務轉送。標籤處理會依路徑和節點而變化。 [IETF RFC 3031](https://www.rfc-editor.org/rfc/rfc3031.html) [IETF RFC 4364](https://www.rfc-editor.org/rfc/rfc4364.html)

標籤堆疊每個項目占 32 位元，其中標籤值占 20 位元，還有流量類別、堆疊與生存時間相關欄位。假設同一封包加入兩個堆疊項目，光這些項目就增加 2 × 4 = 8 位元組。端到端可用封包大小仍需同時計入其他封裝與下層介面設定。 [IETF RFC 3032](https://www.rfc-editor.org/rfc/rfc3032.html) [IETF RFC 5462](https://www.rfc-editor.org/rfc/rfc5462.html)

容易混淆的是私有路由隔離與加密、標籤值與全球識別，以及 Route Distinguisher 與 Route Target。VPN 的服務隔離來自路由和轉送控制，若需要機密性另依服務配置加密。標籤的解讀要配合適用的標籤空間及節點。兩種 VPN 路由欄位在唯一性及匯入政策上分工不同。 [IETF RFC 3031](https://www.rfc-editor.org/rfc/rfc3031.html) [IETF RFC 4364](https://www.rfc-editor.org/rfc/rfc4364.html)

跨站不通時，由業者邊界團隊對照雙端站點的 VRF、前綴與匯入政策，再請骨幹團隊查標籤路徑與下一跳。記錄受影響路由、站點及封包方向。若小封包可通而大封包失敗，請傳輸與業者團隊一起核對實際封裝開銷及沿途可用封包大小。 [IETF RFC 3031](https://www.rfc-editor.org/rfc/rfc3031.html) [IETF RFC 4364](https://www.rfc-editor.org/rfc/rfc4364.html) [IETF RFC 3032](https://www.rfc-editor.org/rfc/rfc3032.html)
