# 1.1.2 無線接取網：基地台、天線、頻段

所屬：[1.1 網路架構](1-1.md)

## 內文

基地台的任務是使終端依照無線協定收發資料。天線決定發射與接收在空間中的分布，頻段則指定載波可使用的射頻範圍。規劃覆蓋時要考慮部署環境、天線配置、可用頻譜以及終端是否支援所用頻段。當客訴集中在某個樓層、街廓或扇區邊緣，先辨認現場實際服務小區與載波，才能把覆蓋與容量分開查。 [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 38.104 Release 18](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf)

同一站址可有多個小區與載波。天線方位、下傾與波束形狀會影響哪個方向收到較強訊號。具備相應能力的無線系統可按程序選擇和管理波束，終端也可依量測設定回報參考訊號的功率或品質。應把天線及射頻配置和實際量測對在一起看。例如，遇到室內深處收訊差時，工程師可把樓層、外牆、服務波束與相鄰小區記在同一觀測表，再檢驗變化是否與既有天線方向相符。若訊號功率相近但品質下滑，則須加入同頻干擾及負載線索。 [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 38.104 Release 18](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf) [3GPP TS 38.215 Release 18](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.03.00_60/ts_138215v180300p.pdf)

規格的頻帶邊界、通道帶寬與頻譜遮罩採用不同欄位。射頻頻率及通道帶寬常以 MHz 表示，功率讀值可用 dBm。規格表中的通道帶寬須對應工作頻段及適用配置。現場小區的載波頻寬要從組態查，並跟終端能力和所觀察的方向配對，以免拿規格中允許的多種配置之一當成全網現況。 [3GPP TS 38.104 Release 18](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf) [3GPP TS 38.133](https://www.3gpp.org/dynareport/38133.htm)

容易混淆的是站址與小區、頻段與載波頻寬，以及功率與品質。站址是設備所在位置，小區是服務與量測對象。頻段描述射頻範圍，載波頻寬描述某次部署的通道配置。參考訊號功率較高時，接收品質仍會受到干擾與雜訊影響。 [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 38.104 Release 18](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf) [3GPP TS 38.215 Release 18](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.03.00_60/ts_138215v180300p.pdf)

維運先取服務小區、頻段、量測種類、室內外位置、時段與儀表來源，由無線團隊核對載波、天線及鄰區配置。再比對同時段的功率、品質、資源使用及用戶吞吐量。若多個頻段同時出現退化，保留站址、扇區與告警時間，供基站設備或傳輸團隊檢查共用資源。 [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 38.104 Release 18](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf) [3GPP TS 38.133](https://www.3gpp.org/dynareport/38133.htm)
