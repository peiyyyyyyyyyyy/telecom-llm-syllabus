# 1.9.1 新興多天線與多重接取：大規模 MIMO、NOMA、RIS 與網路控制中繼器

所屬：[1.9 電信研究前沿](../1-9.md)

## 正文

Modern wireless systems rely on large antenna arrays to increase spectral efficiency, improve coverage, and enable advanced multiple‑access schemes. In 3GPP specifications the fundamental description of such arrays is given by the *2‑D planar uniformly spaced antenna array model* (TS 36.897 §5.2.1). Understanding this model is a prerequisite for analysing massive MIMO, non‑orthogonal multiple access (NOMA), re‑configurable intelligent surfaces (RIS), and relay‑aided control, because all of these techniques ultimately manipulate the spatial degrees of freedom offered by the array.  

### Antenna‑array configuration

The model is characterised by the triple $(M, N, P)$ :

* $M$ – **number of antenna elements with the same polarization in each column**.  
* $N$ – **number of columns**.  
* $P$ – **number of polarization dimensions** (e.g., dual‑polarised cross‑pol or optional co‑pol)【TS 36.897 §5.2.1】.  

The total number of radiating elements is therefore  

$$
N_{\text{elem}} = M \times N \times P .
$$

The spacing between elements is uniform:

* Horizontal spacing $d_{\text{H}} = 0.5\lambda$ (where $\lambda$ is the wavelength).  
* Vertical spacing $d_{\text{V}}$ together with $M$ can take the pairs $(0.8\lambda, 8)$ or $(0.5\lambda, 4)$ for the scenarios listed in the table【TS 36.897 §5.2.1】.  

These spacings are chosen to balance grating‑lobe suppression and mutual coupling while keeping the array physically compact.

### Column count and priority

The specification distinguishes **priority levels** for the number of columns $N$ in evaluation studies:

| Priority | Allowed $N$ values |
|----------|-------------------|
| 1st      | $\{1, 2, 4\}$      |
| 2nd      | $\{8, 16\}$        |

The first priority is mandatory for Phase 1, while the second priority is encouraged (NOTE‑0)【TS 36.897 §5.2.1】.  

A hard limit on the product $M \times N$ is imposed:

$$
M \times N \le 32 \quad\text{(Max(M·N) = 32)} .
$$

When $N = 16$, the only compliant value for $M$ is $2$ (because $2 \times 16 = 32$)【TS 36.897 §5.2.1】.

### Relevance to Massive MIMO, NOMA, RIS, and Relays

* **Massive MIMO** exploits a large $N_{\text{elem}}$ to form narrow beams and serve many users simultaneously. The reference model defines the admissible $M$, $N$, $P$ that a massive‑MIMO base station may employ.  

* **NOMA** relies on super‑position coding and successive interference cancellation, which become more efficient when the spatial separation provided by a dense antenna array is available. The array model supplies the geometric constraints that determine how many orthogonal spatial streams can be generated.  

* **RIS** (intelligent surfaces) are often modelled as passive antenna arrays that reflect incident waves with controllable phase shifts. Although the RIS internal architecture is not detailed in the reference, the same $(M,N,P)$ description can be used to parameterise the number of controllable elements.  

* **Network‑controlled relays** act as intermediate nodes that may also be equipped with planar arrays following the same model, enabling coordinated beamforming across hops.  

Because the reference only defines the physical array geometry, deeper protocol‑level aspects of NOMA, RIS, and relay control are **outside the scope of this subsection’s references** and are not elaborated here.

### Worked example

Consider a base‑station antenna panel specified for a 3.5 GHz small‑cell deployment. The table lists the pair $(d_{\text{V}}, M) = (0.5\lambda, 4)$. Suppose the design chooses:

* $M = 4$ (four vertically stacked elements per column, same polarization)  
* $N = 4$ (four columns, first‑priority value)  
* $P = 2$ (dual cross‑polarisation)  

The total number of radiating elements is  

$$
N_{\text{elem}} = 4 \times 4 \times 2 = 32 .
$$

The product $M \times N = 16$ satisfies the maximum of 32, and the chosen $N$ belongs to the first‑priority set. The horizontal spacing is $d_{\text{H}} = 0.5\lambda$, and the vertical spacing is $d_{\text{V}} = 0.5\lambda$, giving a compact 4 × 4 × 2 array that can support massive‑MIMO beamforming with up to 32 simultaneous spatial streams (subject to channel conditions).  

### Common mistakes and practical notes

| Mistake | Why it occurs | Correct practice |
|---------|---------------|------------------|
| **Confusing $M$ and $N$** – treating the number of rows as columns. | The notation uses *columns* for $N$ and *elements per column* for $M$, which is opposite to the usual matrix convention. | Always refer to the definition: $M$ = elements per column, $N$ = number of columns. |
| **Ignoring polarization dimension $P$** – counting only $M \times N$ elements. | $P$ adds a factor of 2 (or 1) depending on cross‑ or co‑polarisation. | Multiply by $P$ to obtain the true element count. |
| **Choosing $N = 8$ without checking $M$** – exceeding the $M \times N \le 32$ limit. | The second‑priority column set is allowed, but the product constraint remains. | Verify that $M \le 32/N$; e.g., for $N=8$, $M$ must be ≤ 4. |
| **Using non‑standard spacing** – assuming arbitrary $d_{\text{H}}$ or $d_{\text{V}}$. | The specification mandates $d_{\text{H}} = 0.5\lambda$ and only the two listed $(d_{\text{V}},M)$ pairs. | Adhere to the listed spacings; any deviation requires a separate specification. |
| **Assuming $P$ can be larger than 2** – some literature mentions 4‑polarisation. | TS 36.897 only defines $P = 1$ (co‑pol) or $P = 2$ (cross‑pol). | Limit $P$ to the values defined in the standard. |

When designing or evaluating massive‑MIMO, NOMA, RIS, or relay‑assisted systems, engineers must first ensure that the underlying antenna array complies with the geometric constraints above; otherwise, higher‑layer performance predictions become invalid.
