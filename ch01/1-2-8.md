# 1.2.8 Wi-Fi 與 IEEE 802 區域網路（第 1／3 頁）

所屬：[1.2 通訊協定](1-2.md)

## 內文

IEEE 802 系列規格涵蓋區域網路相關技術。IEEE 802.11 定義無線區域網路的媒介存取及實體層，IEEE 802.3 則定義 Ethernet。使用者可能將手機連網、場館 Wi-Fi 與有線網路都描述成同一種故障。判定終端當時採用的接取方式，以及無線基地台如何連接上游網路，是找對觀測點的第一步。 [IEEE Std 802.11-2024](https://standards.ieee.org/ieee/1531/10548/) [IEEE 802.3 工作組](https://www.ieee802.org/3/)

在常見的基礎設施設定中，終端先選擇並關聯到合適的無線基地台，依配置完成所需的保護程序，再透過該接取網與其他網路交換資料。共享無線媒介上的發送受媒介存取機制和頻道環境影響。基地台可經有線網路接到上游交換及路由資源，資料進入其他網段時還需要 IP 路徑。排查時可沿著終端、無線基地台、上游實體連線、交換網和目的服務依序觀察。同一地點若有多個可用接取來源，最好先鎖定測試當下實際使用的基地台與接取介面。 [IEEE Std 802.11-2024](https://standards.ieee.org/ieee/1531/10548/) [IEEE 802.3 工作組](https://www.ieee802.org/3/) [IETF RFC 1122](https://www.rfc-editor.org/rfc/rfc1122.html)

容易混淆的是無線關聯與取得 IP 連通性、網路名稱與實際服務的無線基地台，以及 Wi-Fi 無線段與後方有線段。關聯資訊指出終端在該無線網內的接取狀態，外部可達性另須查端點配置及路由。多個基地台也可採相同網路名稱，仍應核對實際對端識別。連上基地台後若只在外部服務失敗，可沿上游網段繼續查。 [IEEE Std 802.11-2024](https://standards.ieee.org/ieee/1531/10548/) [IEEE 802.3 工作組](https://www.ieee802.org/3/) [IETF RFC 1122](https://www.rfc-editor.org/rfc/rfc1122.html)

維運回報記下終端、實際接取、對端識別、發生位置、時間及影響的應用。無線團隊查關聯及媒介狀態，場館或企業網路團隊查基地台上行、交換及終端配置。若同一位置可在行動網與 Wi-Fi 之間重測，把兩次結果分開記錄。若只有特定基地台的用戶受影響，先檢查該基地台及其上游埠，再和相鄰基地台在同等條件下的結果對照。在無線段蒐集媒介忙碌及重送線索，在有線段確認實體介面與交換路徑，最後從終端檢查跨網段的實際可達性。 [IEEE Std 802.11-2024](https://standards.ieee.org/ieee/1531/10548/) [IEEE 802.3 工作組](https://www.ieee802.org/3/) [IETF RFC 1122](https://www.rfc-editor.org/rfc/rfc1122.html)
