# 1.3.2 簡訊與訊息服務

所屬：[1.3 服務與多媒體](../1-3.md)

## 正文

Short Message Service (SMS) is one of the most widely used value‑added services in mobile networks. Even after the advent of rich‑messaging applications, SMS remains essential for network‑initiated notifications (e.g., authentication OTPs), emergency alerts, and machine‑to‑machine (M2M) signaling. In 5G, SMS can be delivered directly over the Non‑Access Stratum (NAS) without requiring a separate circuit‑switched fallback, which simplifies the user‑plane and enables unified control‑plane handling of both voice and messaging traffic. The 3GPP specification *TS 23.501 §4.4.2* defines the “legacy SMS over NAS” architecture, where the control‑plane interfaces between the SMS Function (SMSF), the Unified Data Management (UDM), and the legacy SMS‑GMSC / IP‑SM‑GW remain based on MAP or Diameter protocols [TS 23.501 §4.4.2].

---

### 1.3.2.1 Key Reference Points and Service‑Based Interfaces

The SMS‑over‑NAS flow is built on four control‑plane reference points, each realised by a service‑based interface (SBI):

| Reference point | Description (as per TS 23.501 §4.4.2.2) |
|-----------------|----------------------------------------|
| **N1** | *Reference point for SMS transfer between UE and AMF via NAS.* |
| **N8** | *Reference point for SMS Subscription data retrieval between AMF and UDM.* |
| **N20** | *Reference point for SMS transfer between AMF and SMS Function.* |
| **N21** | *Reference point for SMS Function address registration management and SMS Management Subscription data retrieval between SMS Function and UDM.* |

The SBI that the SMSF exposes to the AMF is named **Nsmsf** [TS 23.501 §4.4.2.3].

---

### 1.3.2.2 Architecture Overview

Two logical topologies are defined:

* **Non‑roaming** – all network elements belong to the same PLMN. Figures 4.4.2.1‑1 and 4.4.2.1‑2 in the specification illustrate the service‑based and reference‑point representations, respectively [TS 23.501 §4.4.2.1].

* **Roaming** – the UE may be served by a visited PLMN while the SMSF resides in the home PLMN. The corresponding diagrams are Figures 4.4.2.1‑3 and 4.4.2.1‑4 [TS 23.501 §4.4.2.1].

A crucial rule is that **each UE is associated with only one SMS Function in the registered PLMN** [TS 23.501 §4.4.2.1]. Consequently, the network does not support dynamic SMSF re‑allocation while the UE stays in the *RM‑REGISTERED* state (i.e., after a successful NAS registration) [TS 23.501 §4.4.2.1].

---

### 1.3.2.3 Interaction with the IMS Domain

When the SMS is destined for an IMS‑based Service Centre, the **IP‑SM‑GW** acts as an SIP Application Server (SIP‑AS) to perform protocol interworking [TS 23.228 §4.17.1]. All of its functionalities and interfaces are defined in *TS 23.204* [TS 23.228 §4.17.1].

---

### 1.3.2.4 Worked Example (Numerical Illustration)

Consider a UE (UE‑ID = `001`) that wishes to send a Mobile‑Terminated (MT) SMS to a subscriber in the same PLMN. The network elements have the following identifiers:

| Element | Identifier |
|---------|------------|
| UE      | `001` |
| AMF     | `A1` |
| SMSF    | `S1` |
| UDM     | `U1` |
| IP‑SM‑GW| `G1` |

The message flow proceeds as follows:

1. **NAS Transfer (N1)** – The SMS payload is encapsulated in a NAS `SMS` message and sent from UE `001` to AMF `A1` over reference point **N1**.  
2. **Subscription Data (N8)** – AMF `A1` queries UDM `U1` via **N8** to retrieve the UE’s SMS subscription profile (e.g., allowed services, SMSF identifier).  
3. **SMSF Selection** – Since the UE is already registered, the AMF uses the stored SMSF identifier `S1`. (No re‑allocation is performed, per the specification.)  
4. **SMS Transfer to SMSF (N20)** – AMF `A1` forwards the NAS‑encapsulated SMS to SMSF `S1` via **N20**.  
5. **SMSF‑UDM Interaction (N21)** – SMSF `S1` may contact UDM `U1` over **N21** to confirm address registration or to obtain additional subscription attributes.  
6. **Delivery via IP‑SM‑GW** – SMSF `S1` forwards the message to IP‑SM‑GW `G1`, which, acting as an SIP‑AS, translates the message into SIP/IMS signalling and delivers it to the destination Service Centre.

If the UE moves to a visited PLMN and the serving AMF is re‑allocated, the source AMF includes the SMSF identifier `S1` in the UE context transfer to the target AMF, ensuring continuity [TS 23.501 §4.4.2.1].

---

### 1.3.2.5 Common Mistakes and Practical Notes

| Mistake | Why it occurs | Correct practice |
|---------|---------------|------------------|
| Assuming the UE can switch SMSF without re‑registration. | The spec explicitly forbids SMSF re‑allocation while the UE is in *RM‑REGISTERED* state. | Keep the SMSF fixed for the duration of the NAS registration; any change must be triggered by a new registration or inter‑PLMN handover. |
| Ignoring the N21 interface when implementing SMSF‑UDM signalling. | N21 carries both address registration management and subscription data retrieval. | Implement both functions on N21 as defined, otherwise subscription queries may fail. |
| Treating IP‑SM‑GW as a generic gateway rather than an SIP‑AS. | The spec positions IP‑SM‑GW within the IMS domain as an SIP‑AS. | Deploy IP‑SM‑GW with IMS‑aware SIP capabilities to guarantee proper protocol interworking. |
| Forgetting that each UE maps to a single SMSF per PLMN. | Over‑looking NOTE 3 leads to ambiguous routing. | Enforce a one‑to‑one UE‑SMSF relationship in the PLMN’s database. |
| Assuming SMS over NAS works identically in roaming without additional steps. | Roaming introduces extra reference points (e.g., inter‑PLMN SMSF selection). | Follow the roaming architecture (Figures 4.4.2.1‑3/‑4) and ensure the visited AMF can obtain the home SMSF identifier. |

By respecting these architectural constraints, network engineers can design robust 5G SMS services that interoperate with legacy SMS‑GMSC and modern IMS‑based Service Centres.

## 練習題

**1.** Which reference point is defined for SMS transfer between the UE and the AMF via NAS?

- A. N8
- B. N20
- C. N1
- D. N21

<details><summary>看答案</summary>

正解：C。N1 is the reference point that carries SMS messages between the UE and AMF over the NAS signalling layer.

</details>

**2.** According to the specification, how many SMS Functions can a UE be associated with in its registered PLMN?

- A. One
- B. Two
- C. Up to the number of active bearers
- D. Unlimited

<details><summary>看答案</summary>

正解：A。The spec states that each UE is linked to a single SMSF within the PLMN.

</details>

**3.** What is the role of the IP‑SM‑GW in the IMS domain?

- A. It acts as an SIP‑AS to interwork short‑message delivery.
- B. It functions as the SMS Function (SMSF).
- C. It provides subscription data to the AMF.
- D. It replaces the UDM for SMS management.

<details><summary>看答案</summary>

正解：A。The IP‑SM‑GW is defined as an SIP Application Server that bridges SMS to the IMS Service Centre.

</details>

**4.** When a serving AMF is re‑allocated for a UE, how is the SMSF identifier conveyed to the target AMF?

- A. It is included in the UE context transfer.
- B. It is sent via the N1 interface after re‑registration.
- C. The UE selects a new SMSF and informs the target AMF.
- D. The SMSF identifier is not transferred; a new SMSF is always selected.

<details><summary>看答案</summary>

正解：A。The source AMF embeds the SMSF identifier in the UE context that it hands over to the target AMF.

</details>

**5.** Which service‑based interface is exposed by the SMS Function to the AMF?

- A. N1
- B. Nsmsf
- C. N8
- D. N21

<details><summary>看答案</summary>

正解：B。The SMSF provides the Nsmsf interface for communication with the AMF.

</details>
