# 1.3.4 漫遊

所屬：[1.3 服務與多媒體](../1-3.md)

## 正文

*Why roaming matters* – In a mobile network a subscriber’s equipment (UE) is normally attached to its **Home Public Land Mobile Network (HPLMN)**, the core network that holds the subscriber’s subscription data. When the UE moves outside the coverage of the HPLMN it must continue to receive service by attaching to a **Visiting Public Land Mobile Network (VPLMN)**. This inter‑PLMN attachment is called **roaming**. Roaming enables seamless voice, SMS and data continuity for users travelling internationally or across operator borders, and it is a key revenue source for operators that negotiate roaming agreements.

### Roaming reference architectures

3GPP defines two principal roaming architectures for the 5G System (5GS) – **Local Break‑Out (LBO)** and **Home‑Routed (HR)** – both expressed with service‑based interfaces (SBIs) in the control plane.

| Architecture | Where user‑plane traffic exits the VPLMN | Key control‑plane interaction |
|--------------|------------------------------------------|--------------------------------|
| **Local Break‑Out (LBO)** | Traffic is terminated in the VPLMN and is sent to the Internet or the visited operator’s data network. | The **Policy Control Function (PCF)** in the VPLMN generates PCC rules using *locally configured policies* that are derived from the roaming agreement with the HPLMN. The PCF **has no access to subscriber policy information** from the HPLMN. [TS 23.501 §4.2.4] |
| **Home‑Routed (HR)** | User‑plane traffic is routed through the **Home UPF (H‑UPF)** belonging to the HPLMN, possibly via a nearby H‑UPF deployment. | The **SMF** in each PLMN may activate the **IPUP‑S (Inter‑PLMN UP Security)** function in the UPF to protect the N9 interface. [TS 23.501 §4.2.4] |

Both architectures rely on a set of common network functions (NFs) that are *proxied* at PLMN borders to hide internal topology: **SEPP** (Security Edge Protection Proxy) and **NRF** (Network Repository Function) for NF discovery, **SCP** (Service Communication Proxy) for indirect NF‑to‑NF signalling, and optional **RE‑NWDAF** (Network Data Analytics Function with roaming exchange capability). The specifications explicitly omit these elements from the diagrams for clarity, but they are part of a production deployment. [TS 23.501 §4.2.4]

### Control‑plane signaling flow (illustrative)

1. **Registration request** – The UE sends a **Location Registration (LR) request** on the VPLMN radio interface. Successful registration requires (a) a suitable cell is found and (b) the LR request is accepted. [TS 23.122 §4.4.2]  
2. **Authentication & Authorization** – The V‑SMF contacts the **Home AMF (H‑AMF)** via the **SEPP** to retrieve authentication vectors.  
3. **Policy enforcement** – The V‑PCF creates PCC rules for the UE’s PDU sessions, using the roaming agreement as input. The V‑PCF cannot read the subscriber’s home‑policy set. [TS 23.501 §4.2.4]  
4. **User‑plane setup** – For LBO the V‑UPF terminates the user plane; for HR the traffic is tunneled to the H‑UPF (which may be colocated with the V‑UPF for latency optimisation). [TS 23.501 §4.2.4]

### PLMN selection process

Before any registration the UE must **select a PLMN** to camp on. The selection follows the algorithm described in TS 23.122 §4.4:

* The UE reads the following SIM‑stored files:  
  – **HPLMN Selector with Access Technology** (home PLMN list)  
  – **User Controlled PLMN Selector with Access Technology** (manual preferences)  
  – **Operator Controlled PLMN Selector with Access Technology** (operator‑defined priorities)  
  – **Forbidden PLMNs** (PLMNs that must never be selected)  
  – **Equivalent HPLMN** (list of PLMNs treated as home for hand‑over) [TS 23.122 §4.4.3]

* The UE builds a **priority‑ordered list** of PLMN/access‑technology pairs. If an entry contains multiple access technologies the priority among them is implementation‑specific.  

* When the UE detects a cell broadcasting several PLMN IDs (shared network), it selects **one** PLMN. If the currently registered PLMN is among the candidates the UE must **not** switch to a different PLMN. [TS 23.122 §4.4.3]

* The **EHPLMN list** (Extended HPLMN) may override the IMSI‑derived HPLMN. The highest‑priority entry that is available is chosen. [TS 23.122 §4.4.3]

### Worked example – PLMN selection in a shared cell

A UE with IMSI `310150123456789` (home PLMN `310‑150`) is turned on in a city where a **shared macro cell** broadcasts three PLMN IDs:

| PLMN (MCC‑MNC) | Access technologies announced |
|----------------|-------------------------------|
| 310‑150 (home) | LTE, NR |
| 310‑260        | LTE |
| 311‑480        | NR |

The SIM contains:

* **EHPLMN list** = {`311‑480` (priority 1), `310‑150` (priority 2)}  
* **Forbidden PLMNs** = {`310‑260`}  

**Selection steps**

1. The UE discards `310‑260` because it is forbidden. [TS 23.122 §4.4.3]  
2. The remaining candidates are `310‑150` and `311‑480`. According to the EHPLMN list the highest‑priority available PLMN is `311‑480`.  
3. The UE camps on the cell, selects `311‑480` as the **selected PLMN**, and proceeds with registration on the VPLMN that owns that PLMN ID.  

Thus, even though the home PLMN is present, the EHPLMN list forces the UE to roam onto a different operator because it has higher priority.

### Practical notes & common mistakes

| Mistake | Why it is wrong (reference) |
|---------|-----------------------------|
| **Assuming the V‑PCF can read the subscriber’s home‑policy set** | The V‑PCF *has no access* to subscriber policy information from the HPLMN; it uses only locally configured policies derived from the roaming agreement. [TS 23.501 §4.2.4] |
| **Neglecting the role of the SEPP** | Although omitted from the architecture diagrams for clarity, the SEPP secures the inter‑PLMN interfaces and is required in any production roaming deployment. [TS 23.501 §4.2.4] |
| **Treating the home‑routed UPF as optional** | In the HR scenario the H‑UPF **must** terminate the N9 tunnel and can optionally host the IPUPS function; omitting it would break the user‑plane security model. [TS 23.501 §4.2.4] |
| **Using the “HPLMN Selector with Access Technology” file for PLMN selection** | The UE **shall not use** the PLMN codes contained in that file for selection; it is only for obtaining access‑technology information. [TS 23.122 §4.4.3] |
| **Assuming a shared cell automatically triggers a PLMN change** | The UE must keep the current PLMN if it is still among the candidates; a change occurs only if the current PLMN is absent or a higher‑priority EHPLMN is available. [TS 23.122 §4.4.3] |

*In summary*, roaming in 5G is realized through well‑defined control‑plane interactions between the VPLMN and HPLMN, with two distinct user‑plane routing options (LBO vs HR). Correct PLMN selection, policy handling, and security proxying are essential to guarantee service continuity and operator compliance.

## 練習題

**1.** In the Local Break‑Out (LBO) roaming architecture, which statement is true regarding the PCF in the VPLMN?

- A. It can retrieve subscriber policy information directly from the HPLMN.
- B. It generates PCC rules using locally configured policies derived from the roaming agreement.
- C. It must be co‑located with the H‑UPF to enforce home‑routed traffic.
- D. It acts as a SEPP to secure inter‑PLMN signaling.

<details><summary>看答案</summary>

正解：B。The V‑PCF creates PCC rules based on policies from the roaming agreement and does not access home subscriber policies.

</details>

**2.** Which SIM file is *not* consulted by the UE during PLMN selection according to TS 23.122?

- A. Forbidden PLMNs
- B. Operator Controlled PLMN Selector with Access Technology
- C. HPLMN Selector with Access Technology
- D. User Controlled PLMN Selector with Access Technology

<details><summary>看答案</summary>

正解：C。The specification explicitly states that the UE shall not use the HPLMN Selector with Access Technology for PLMN selection.

</details>

**3.** In the Home‑Routed (HR) roaming scenario, what optional function can the UPF perform to protect the N9 interface?

- A. SEPP
- B. IPUPS
- C. RE‑NWDAF
- D. SCP

<details><summary>看答案</summary>

正解：B。The UPF may activate the Inter‑PLMN UP Security (IPUPS) function to terminate GTP‑U N9 tunnels and protect inter‑PLMN traffic.

</details>

**4.** When a UE detects a shared cell broadcasting multiple PLMN IDs, under which condition must it *stay* on its currently registered PLMN?

- A. If the current PLMN has the highest priority in the EHPLMN list.
- B. If the current PLMN is among the PLMNs indicated by the cell.
- C. If the current PLMN is not listed in the Forbidden PLMNs.
- D. If the current PLMN uses a different access technology than the others.

<details><summary>看答案</summary>

正解：B。The UE must not switch to another PLMN if the currently registered PLMN is present among the candidates.

</details>

**5.** Which network function is *explicitly* omitted from the reference architecture diagrams for clarity, but is still part of a realistic roaming deployment?

- A. PCF
- B. SEPP
- C. SMF
- D. AF

<details><summary>看答案</summary>

正解：B。The SEPP is not shown in the diagrams to keep them clear, yet it is required for securing inter‑PLMN interfaces.

</details>
