# 1.7.5 終端能力與類別

所屬：[1.7 網路優化與終端](1-7.md)

## 內文

終端能力描述裝置在指定無線技術及配置下可使用的功能。對 NR 終端而言，重點包括支援頻段、可併用的頻段組合，以及特定組合中的方向、頻寬與傳輸能力。分類或設備型號可協助建立初步範圍，真正能否啟用某項網路功能，需看終端上報的能力、網路給定的組態和軟體版本。 此處並列不同 Release 的文件，用來分別定位能力定義及交換能力的 RRC 程序。實作與驗收應依專案指定的 Release 核對對應條款。 [3GPP TS 38.306 V19.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138306/19.02.00_60/ts_138306v190200p.pdf)  [3GPP TS 38.331 V17.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138331/17.02.00_60/ts_138331v170200p.pdf)

網路可藉由 RRC 能力詢問，依所需無線接取技術取得終端能力資訊。TS 38.306 對 NR 能力列出不同層級的欄位，先有頻段清單，再從頻段組合找相關的能力集合。組合可參照每個頻段及每個載波的能力，例如方向、可用頻寬及支援的多天線層。網路決定組態時，還需套用服務小區支援的配置與頻譜資源。單一支援欄位所描述的功能，必須放回它所屬的能力組合來判讀。比如只看到手冊中的一項功能可用，仍需找出實際能力訊息中適用的頻段或組合欄位，再核對網路指定的載波方向和頻寬。 此處並列不同 Release 的文件，用來分別定位能力定義及交換能力的 RRC 程序。實作與驗收應依專案指定的 Release 核對對應條款。 [3GPP TS 38.306 V19.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138306/19.02.00_60/ts_138306v190200p.pdf)  [3GPP TS 38.331 V17.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138331/17.02.00_60/ts_138331v170200p.pdf)

記錄能力時可把頻寬以 MHz、子載波間距以 kHz 及空間層數以層數呈現，並保留方向與相關條件。規格表格的頻寬類別或能力識別值，需依欄位定義對應到實際單位。某個能力在較新 Release 出現時，報告宜列出設備聲明的版本和實際上報的欄位，以免按錯版本解讀。 [3GPP TS 38.306 V19.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138306/19.02.00_60/ts_138306v190200p.pdf)  [3GPP TS 38.300 V19.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf)

終端分別支援兩個頻段，只代表兩個頻段各自都在能力範圍內。若要載波聚合，還需有所用的組合和方向能力。設備說可支援某種多天線配置，也要檢查在該頻段與頻寬條件下所對應的能力。終端支援和網路已成功配置分屬兩個查證點。 此處並列不同 Release 的文件，用來分別定位能力定義及交換能力的 RRC 程序。實作與驗收應依專案指定的 Release 核對對應條款。 [3GPP TS 38.306 V19.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138306/19.02.00_60/ts_138306v190200p.pdf)  [3GPP TS 38.331 V17.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138331/17.02.00_60/ts_138331v170200p.pdf)

若工單報告某款終端無法進入載波聚合或預期功能，請終端相容性人員提供型號、版本與對應的能力上報，無線值班補上頻段、組合與實際組態。先以相同網路條件測試另一終端或另一軟體版本，並保留能力交換與功能啟用訊息及時間。 此處並列不同 Release 的文件，用來分別定位能力定義及交換能力的 RRC 程序。實作與驗收應依專案指定的 Release 核對對應條款。 [3GPP TS 38.306 V19.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138306/19.02.00_60/ts_138306v190200p.pdf)  [3GPP TS 38.331 V17.2.0](https://www.etsi.org/deliver/etsi_ts/138300_138399/138331/17.02.00_60/ts_138331v170200p.pdf)
