# 1.2.10 網路介面：NG、Xn、F1、E1 與 N4（PFCP）

所屬：[1.2 通訊協定](1-2.md)

## 內文

5G 網路的介面描述功能節點之間的分工。介面名稱可用來辨認兩端、控制內容及資料有沒有經過該段。了解拓樸時應先問介面是在接取網與核心之間、兩個接取節點之間，還是某個分離式設備或核心功能內部。定位告警前，把工單上的介面名和實際設備角色對齊，可避免請錯團隊或查看不同路徑。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 29.244 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129244/18.09.00_60/ts_129244v180900p.pdf)

| 介面 | 兩端 | 典型用途與出處 |
| --- | --- | --- |
| NG | NG-RAN 與 5G 核心 | NG-C 接 AMF，NG-U 接 UPF，分別處理控制與用戶資料。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) |
| Xn | 兩個 NG-RAN 節點 | Xn-C 處理節點間控制，適用時 Xn-U 提供節點間的用戶面傳送。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) |
| F1 | gNB-CU 與 gNB-DU | NR 分離架構可用 F1-C 管控制，F1-U 送收用戶資料。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) |
| E1 | gNB-CU-CP 與 gNB-CU-UP | 集中單元內控制、用戶面功能之間的控制接口。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) |
| N4 | SMF 與 UPF | 用 PFCP 進行會話控制並配置用戶面處理規則。 [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 29.244 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129244/18.09.00_60/ts_129244v180900p.pdf) |

例如分離式基地台建立資料承載時，無線側可先經 F1-C 交換必要配置，再透過對應的 F1-U 路徑承載資料。集中單元分開部署控制與用戶面功能時，可以用 E1 協調用戶面資源。資料送往核心時再使用 NG-U，而核心 SMF 透過 N4 配置 UPF 的轉送處理。跨接取節點的移動則可能涉及 Xn 上的協調，具體流程取決於部署和採用的交遞方式。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 29.244 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129244/18.09.00_60/ts_129244v180900p.pdf)

常見混淆是把 F1 認作 O-DU 到 O-RU 的開放前傳，把 E1 認作跨基地台接口，或把 N4 看到的控制紀錄當成 GTP-U 用戶資料。F1 的責任界線在 CU 與 DU，E1 的責任界線在兩類 CU 功能，跨接取節點另有 Xn。N4 與 N3 要分開取證，前者指示用戶面處理，後者可用於觀察實際轉送。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) [ETSI TS 103 982，O-RAN Architecture Description](https://www.etsi.org/deliver/etsi_ts/103900_103999/103982/08.00.00_60/ts_103982v080000p.pdf) [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 29.244 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129244/18.09.00_60/ts_129244v180900p.pdf) [3GPP TS 29.281 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129281/18.04.00_60/ts_129281v180400p.pdf)

維運記下介面名稱和分面、兩端節點、相關小區或會話、發生時段及程序最後完成的事件。無線架構團隊查 Xn、F1、E1 和相應功能分配，核心團隊查 NG 交接與 N4 規則，傳輸團隊核對實體連通與兩端流量。若介面多項指標一起異常，先找共用節點或承載，再依控制、用戶面狀態循序縮小。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 29.244 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129244/18.09.00_60/ts_129244v180900p.pdf) [ITU-T G.8300](https://www.itu.int/rec/T-REC-G.8300/en)
