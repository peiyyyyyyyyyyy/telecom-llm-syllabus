# 1.1.8 雙連接與 NSA／SA 部署選項

所屬：[1.1 網路架構](1-1.md)

## 內文

雙連接讓終端在符合能力與配置時，由主節點及次節點提供無線資源。常見商用演進中，既有 LTE 與 EPC 可先保留接取錨點，再加入 NR。另一種部署讓 NR 接取網直接連至 5GC。兩種部署的控制路徑、核心程序及故障邊界不同，因此辨認機型狀態時，要核對實際主節點、次節點和核心類型。 [3GPP TS 37.340 Release 18](https://www.etsi.org/deliver/etsi_ts/137300_137399/137340/18.05.00_60/ts_137340v180500p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 38.533 Release 15，§3A.1.1](https://www.etsi.org/deliver/etsi_ts/138500_138599/138533/15.00.00_60/ts_138533v150000p.pdf)

典型的 NSA Option 3 屬於 EN-DC，主節點是 LTE eNB，次節點是 en-gNB，核心採 EPC。網路依終端能力、量測和配置建立或變更次側資源，並依所採承載配置走對應的用戶面路徑。典型 SA Option 2 採 NR 接取，gNB 透過 NG 接至 5GC。終端依 5GS 程序完成註冊及 PDU Session 建立，控制面和用戶面各走其對應接口。3GPP Release 15 的一致性測試規格可核對兩種 Option 編號，架構與雙連接細節則可查 TS 37.340 與 TS 38.300。 [3GPP TS 37.340 Release 18](https://www.etsi.org/deliver/etsi_ts/137300_137399/137340/18.05.00_60/ts_137340v180500p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 23.502 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123502/18.11.00_60/ts_123502v181100p.pdf) [3GPP TS 38.533 Release 15，§3A.1.1](https://www.etsi.org/deliver/etsi_ts/138500_138599/138533/15.00.00_60/ts_138533v150000p.pdf)

容易混淆的是終端顯示 NR 與實際採用的核心類型、雙連接與載波聚合，以及次節點已配置與次側已有資料流。雙連接涉及兩個節點的分工，載波聚合著重多載波資源配置。次節點配置成功後，是否使用次側用戶面仍須查承載和流量。Option 編號描述特定組合，遇到其他互通部署時仍應從主節點、次節點與核心三項辨識。 [3GPP TS 37.340 Release 18](https://www.etsi.org/deliver/etsi_ts/137300_137399/137340/18.05.00_60/ts_137340v180500p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 38.533 Release 15，§3A.1.1](https://www.etsi.org/deliver/etsi_ts/138500_138599/138533/15.00.00_60/ts_138533v150000p.pdf)

若工單反映 NR 間歇出現，可請接取團隊查主小區狀態、終端頻段組合能力、次節點加入或釋放原因及相關量測。若服務走 SA，應查 5GS 註冊、會話與 N2、N3 狀態。交接時記下測試終端、量測時窗、所屬小區及網路回答的程序結果。必要時把同地點的不同能力終端分組比較，區分終端限制與網路側變更。最後應按所採部署分別驗證控制程序和服務實際走的資料通道。 [3GPP TS 37.340 Release 18](https://www.etsi.org/deliver/etsi_ts/137300_137399/137340/18.05.00_60/ts_137340v180500p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [3GPP TS 23.502 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123502/18.11.00_60/ts_123502v181100p.pdf)
