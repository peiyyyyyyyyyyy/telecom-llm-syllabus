# 第 1 章　電信網路知識課綱與練習題

本章依公開版《電信 LLM 課綱》第 9 版的九節、67 個小節擴寫。學習對象為電信領域的小模型，也可供新進維運人員自學。完成本章後，應能沿著網路路徑正確定位名詞與指標，從維運對話或工單辨識相關網段、協定和量測資料，再指出負責角色與下一個查證步驟。[原課綱與能力要求](https://pyyy.gitbook.io/itri-docs/ch01)

建議先讀各節教學內容，再作答該節兩道原創題。工單題可依「已知線索 → 可能網段與協定 → 要看的資料及其口徑 → 負責角色 → 待驗證事項」作答。若證據只支持候選原因，答案應列出驗證方式。計算題應保留算式、單位與量測條件。

> 本版說明（編者）：每個小節一頁，先內文再練習題。GSMA 題目足夠的細項，練習題用 GSMA 訓練題；GSMA 不足的 1.6、1.8 加上補充題，原創示範題放在細項頁。
