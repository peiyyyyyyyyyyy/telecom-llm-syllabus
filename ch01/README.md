# 第 1 章　電信網路知識

- 階段：第一階段　知識與基本功
- 從哪裡來：N1 知識查詢 → A1 電信網路知識
- 學完要做到：看到名詞或指標，說得出意思和所屬網段；聽到一個問題，指得出要看哪類資料、找哪個角色。
- 怎麼考：給維運對話或工單裡的描述，答出網段、相關協定、要看的指標。
