# 1.4.8 用戶身分隱私：SUPI 與 SUCI

所屬：[1.4 網管、計費、安全與密碼學](1-4.md)

## 內文

SUPI 是 5G 系統用來識別訂閱的永久識別，供歸屬網路查找對應訂閱資料。SUCI 是依規格所形成的訂閱識別表示，讓終端在適用程序中可傳遞必要的識別資訊，並在採用保護方案時降低直接暴露永久識別的風險。這項機制把訂閱辨認所需的功能與空口上可見的資料分開處理。 [3GPP TS 23.003 V18.7.0](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/18.07.00_60/ts_123003v180700p.pdf) [3GPP TS 33.501 V18.9.0 §6.12、附錄 C](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/18.09.00_60/ts_133501v180900p.pdf)

在需要使用 SUCI 的程序中，終端依配置選擇適用的保護方案來組成這個識別表示。相關資料包含可辨識的識別型態與歸屬網路資訊，以及依方案決定的輸出。使用非空保護方案時，規格指定如何利用歸屬網的相關公鑰資訊形成受保護部分。網路再由歸屬側負責解開對應內容的功能取得所需的永久識別，供後續訂閱或鑑權流程使用。 [3GPP TS 23.003 V18.7.0](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/18.07.00_60/ts_123003v180700p.pdf) [3GPP TS 33.501 V18.9.0 §6.12、附錄 C](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/18.09.00_60/ts_133501v180900p.pdf)

各欄位扮演不同角色。歸屬網路相關資訊協助將處理送到適用的網路，保護方案及其識別協助選擇正確的處理方式，方案輸出則依該方案不同而變化。判讀捕捉或網管媒介上看到的欄位時，應先確認其識別型態及程序，有效地區分可供處理的路由資訊和用於查找訂閱資料的識別內容。對跨網的交易，看到路由相關欄位也只能據此確認預期的處理方向。 [3GPP TS 23.003 V18.7.0](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/18.07.00_60/ts_123003v180700p.pdf) [3GPP TS 33.501 V18.9.0 §6.12、附錄 C](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/18.09.00_60/ts_133501v180900p.pdf) [3GPP TS 33.501 V18.9.0 §6.1](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/18.09.00_60/ts_133501v180900p.pdf)

SUCI 的保護效果取決於實際方案與配置。規格也定義空方案，不能只因欄位名為 SUCI 就推定永久識別相關內容一定已受公鑰保護。臨時識別與 SUCI 都可能出現在接取相關環節，但各有自己的來源與使用條件。訂戶身分已被歸屬網路查得之後，主要鑑權仍有獨立的程序與結果。 [3GPP TS 23.003 V18.7.0](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/18.07.00_60/ts_123003v180700p.pdf) [3GPP TS 33.501 V18.9.0 §6.12、附錄 C](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/18.09.00_60/ts_133501v180900p.pdf) [3GPP TS 33.501 V18.9.0 §6.1](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/18.09.00_60/ts_133501v180900p.pdf)

遇到訂戶辨認異常時，先確認終端使用的識別型態、歸屬側是否收到交易、方案或金鑰識別是否和預期配置一致，以及鑑權是否有進展。訂閱或保護配置由歸屬側訂戶及安全團隊查證，拜訪側可提供程序狀態及時間。工單宜使用案件所需的相關識別，並限制永久識別的揭露範圍。 [3GPP TS 23.003 V18.7.0](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/18.07.00_60/ts_123003v180700p.pdf) [3GPP TS 33.501 V18.9.0 §6.12、附錄 C](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/18.09.00_60/ts_133501v180900p.pdf) [3GPP TS 33.501 V18.9.0 §6.1](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/18.09.00_60/ts_133501v180900p.pdf)
