# 1.4.8 用戶身分隱私：SUPI 與 SUCI

所屬：[1.4 網管、計費、安全與密碼學](../1-4.md)

## 正文

In 5G the permanent identifier of a subscriber is the **Subscription Permanent Identifier (SUPI)**. The SUPI uniquely identifies a user equipment (UE) across the entire 3GPP system and is required for authentication, mobility management and charging. Because the SUPI is globally unique, transmitting it in the clear would expose the subscriber’s identity to any eavesdropper. To protect privacy, the 5G system introduces the **Subscription Concealed Identifier (SUCI)**, a cryptographically protected version of the SUPI that is sent over the air. The SUCI therefore enables the network to locate the correct home network while preventing third‑party observers from learning the subscriber’s permanent identifier. This privacy mechanism is mandated by 3GPP TS 33.501 § 6.12 and is applied to every initial registration, identity response, and certain de‑registration procedures. [TS 33.501 §6.12]

### 1. Definition of SUPI
The SUPI is the globally unique subscription identifier defined in TS 23.501. It can be expressed in two formats:

* **IMSI‑based SUPI** – the identifier contains the Mobile Subscriber Identification Number (MSIN) as defined in TS 23.003.
* **NAI‑based SUPI** – the identifier follows the Network Access Identifier format defined in RFC 7542, where the “username” portion is the subscription identifier.

The reference text specifies that for IMSI‑based SUPIs the subscription identifier part of the SUPI includes the MSIN, and for NAI‑based SUPIs the username portion is used. [TS 33.501 §6.12.2]

### 2. Definition of SUCI
The SUCI is a privacy‑preserving identifier that contains the concealed SUPI. The UE creates the SUCI by applying a **protection scheme** (public‑key encryption) using the Home Network Public Key (HNPK) that has been securely provisioned by the home network. The protection schemes are listed in Annex C of the specification or may be defined by the home network operator. [TS 33.501 §6.12.2]

The UE first builds a **scheme‑input** from the subscription identifier part of the SUPI:

* For IMSI‑based SUPIs, the scheme‑input is the MSIN.
* For NAI‑based SUPIs, the scheme‑input is the username portion of the NAI.

The UE then executes the protection scheme with this input and obtains the **Scheme Output**, which becomes part of the SUCI. [TS 33.501 §6.12.2]

### 3. SUCI Structure for IMSI‑based SUPI
When the SUPI contains an IMSI, the UE constructs the SUCI with the following fields (all defined in TS 23.003):

| Field | Meaning |
|-------|---------|
| **SUPI Type** | Identifies the SUPI type (e.g., IMSI). |
| **Home Network Identifier** | MCC and MNC of the IMSI. |
| **Routing Indicator** | As specified in TS 23.003. |
| **Protection Scheme Identifier** | Indicates which scheme from Annex C is used. |
| **Home Network Public Key Identifier** | Identifies the HNPK used for encryption. |
| **Scheme Output** | Result of the protection scheme (ciphertext). |

The Home Network Identifier and Routing Indicator are **not** concealed; only the subscription identifier part (MSIN) is encrypted. [TS 33.501 §6.12.2]

### 4. SUCI Structure for NAI‑based SUPI
For a SUPI that uses the NAI format, the SUCI consists of:

* **realm part** – copied directly from the SUPI realm.
* **username part** – assembled from SUPI Type, Routing Indicator, Protection Scheme Identifier, Home Network Public Key Identifier, and Scheme Output, following the format in TS 23.003.

Thus the privacy‑preserving portion is the encrypted username; the realm remains visible to route the request to the correct home network. [TS 33.501 §6.12.2]

### 5. When a UE Must Send a SUCI
The UE includes a SUCI only in specific NAS messages:

1. **Initial Registration Request** – if the UE does not already possess a 5G‑GUTI for the target PLMN.
2. **Identity Response** – when the network explicitly requests the permanent identifier.
3. **De‑Registration Request** – during an initial registration where the UE never received a 5G‑GUTI.

In all these cases the UE **never** sends the SUPI in clear; the response always contains a SUCI. [TS 33.501 §6.12.2]

### 6. Null‑Scheme Generation
A **null‑scheme** (i.e., no encryption) may be used only in limited circumstances:

* Emergency unauthenticated sessions when the UE lacks a 5G‑GUTI.
* When the home network configures null‑scheme, or when the required public key is unavailable.

If a null‑scheme is used, the Home Network Public Key Identifier is set to a default value defined in TS 23.003. [TS 33.501 §6.12.2]

### 7. Worked Example (Conceptual)
Assume a UE possesses an IMSI‑based SUPI with MSIN = “123456789”. The home network has provisioned a public key **PK\_HN** and assigned it identifier **KID = 01**. The UE selects Protection Scheme Identifier **PSID = 1** (as defined in Annex C).  

1. The UE forms the scheme‑input = “123456789”.  
2. It encrypts this input with **PK\_HN**, producing ciphertext **C** (the Scheme Output).  
3. The UE assembles the SUCI fields:  
   * SUPI Type = IMSI,  
   * Home Network Identifier = MCC/MNC of the IMSI,  
   * Routing Indicator = value from TS 23.003,  
   * Protection Scheme Identifier = 1,  
   * Home Network Public Key Identifier = 01,  
   * Scheme Output = C.  

The resulting SUCI is transmitted in the Initial Registration Request. The network, upon receiving the SUCI, extracts the Home Network Identifier and Routing Indicator to forward the message to the correct home network, then uses **KID = 01** to retrieve **PK\_HN** and decrypt **C** to recover the original MSIN and thus the SUPI. This example follows the exact steps prescribed in the specification without revealing the SUPI in the radio interface. [TS 33.501 §6.12.2]

### 8. Common Mistakes and Practical Notes
* **Concealing Home Network Identifier** – The specification explicitly forbids hiding the Home Network Identifier and Routing Indicator; doing so would break routing.  
* **Length Leakage in NAI SUPIs** – Variable‑length usernames can leak length information even when encrypted. Operators should enforce fixed‑length usernames or pad them in the USIM and UDM.  
* **Using Null‑Scheme Accidentally** – Null‑scheme must only be employed in the three scenarios listed; using it elsewhere removes privacy protection.  
* **Incorrect Key Provisioning** – The UE must use the Home Network Public Key that was securely provisioned. If the key is missing, the UE must fall back to null‑scheme (if permitted) rather than sending the clear SUPI.  
* **USIM vs. ME Calculation** – If the USIM is instructed to compute the SUCI, the ME must delete any locally cached parameters (e.g., HNPK, identifiers) to avoid duplication.  

Adhering to these rules ensures that subscriber identity privacy is preserved throughout the 5G registration and mobility procedures. [TS 33.501 §6.12.2]

## 練習題

**1.** Which field of the SUCI is **not** concealed and must be transmitted in clear?

- A. Scheme Output
- B. Home Network Identifier
- C. Protection Scheme Identifier
- D. Username part (for NAI)

<details><summary>看答案</summary>

正解：B。The Home Network Identifier is required for routing and is explicitly not concealed.

</details>

**2.** In which NAS message **must** a UE include a SUCI when it does not already have a 5G‑GUTI?

- A. Registration Accept
- B. Initial Registration Request
- C. Authentication Request
- D. Service Request

<details><summary>看答案</summary>

正解：B。During initial registration without a 5G‑GUTI the UE includes a SUCI in the Registration Request.

</details>

**3.** For an IMSI‑based SUPI, what part of the SUPI is used as the scheme‑input for SUCI generation?

- A. MCC
- B. MNC
- C. MSIN
- D. Routing Indicator

<details><summary>看答案</summary>

正解：C。The scheme‑input is the subscription identifier part, which for IMSI includes the MSIN.

</details>

**4.** Which of the following is a permitted circumstance for using a null‑scheme to generate a SUCI?

- A. Regular mobile broadband session after successful authentication
- B. Emergency unauthenticated session without a 5G‑GUTI
- C. Any session when the UE prefers lower latency
- D. When the home network wants to save computational resources

<details><summary>看答案</summary>

正解：B。Null‑scheme is allowed for unauthenticated emergency sessions lacking a 5G‑GUTI.

</details>
