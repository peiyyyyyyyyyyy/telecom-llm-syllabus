# 1.2.3 傳輸層：TCP、UDP、SCTP

所屬：[1.2 通訊協定](../1-2.md)

## 正文

The transport layer is the fourth layer of the TCP/IP model and is responsible for moving application data between end‑points reliably (TCP), unreliably (UDP), or with a hybrid set of services (SCTP). In 5G non‑standalone (NG) networks the signalling between the Access and Mobility Management Function (AMF) and the NG‑RAN node (gNB) uses SCTP as the mandatory transport protocol because it offers multi‑streaming, multi‑homing, and built‑in congestion control that are essential for robust control‑plane traffic [TS 38.412 §7].

### SCTP Basics

* **Association** – the SCTP equivalent of a TCP connection; it is identified by the pair of IP addresses at each end and a set of streams.  
* **Stream identifier** – a logical channel within an association that carries ordered messages; streams are independent, so loss on one stream does not block others.  
* **Payload Protocol Identifier (PPID)** – a 32‑bit field that tells the receiver which upper‑layer protocol the payload belongs to. IANA assigns PPID 60 for NGAP and PPID 66 for DTLS over SCTP, and the field is transmitted in big‑endian order [TS 38.412 §7].  
* **Destination Port** – SCTP uses a well‑known port for NGAP traffic; the IANA‑assigned value is 38412, although dynamic ports may be used for additional associations [TS 38.412 §7].

The specification requires that each NG‑RAN node and AMF support at least one SCTP association per node‑pair, and optionally multiple associations when the network topology demands it [TS 38.412 §7].

### Stream Reservation Rules

For a given AMF–NG‑RAN node pair the following reservations are mandatory:

| Signalling type | Minimum reserved streams |
|-----------------|--------------------------|
| Non‑UE‑associated NGAP procedures | **1 pair** of stream identifiers (i.e., one inbound and one outbound stream) [TS 38.412 §7] |
| UE‑associated NGAP procedures | **At least 1 pair**, but *a few* pairs (more than one) are recommended [TS 38.412 §7] |

A “pair” means one inbound and one outbound stream that are used together for a bidirectional NGAP elementary procedure. When a single UE‑associated signalling session is active, the NG‑RAN node must keep the same association and stream for the whole session; it may only change after the association fails or a TNL binding update occurs [TS 38.412 §7].

### Multi‑homing and Redundancy

SCTP can bind each endpoint to multiple IP addresses (multi‑homing). This enables transport‑network redundancy: if one path fails, traffic automatically switches to another without tearing down the association [TS 38.412 §7]. Both ends must support a multi‑homed remote endpoint, and either endpoint may initiate an **INIT** chunk at any time to add or remove IP addresses from an existing association [TS 38.412 §7].

### Dynamic Management of Associations

When the network is configured for multiple SCTP endpoints per AMF–NG‑RAN node pair, the AMF may request the addition or removal of associations at run‑time [TS 38.412 §7]. If no restriction information is supplied, any type of NG‑C signalling may traverse the association; otherwise the AMF can limit an association to specific signalling classes [TS 38.412 §7].

### Worked Example: Configuring Streams for Two UEs

Assume an AMF and a gNB are connected with a single SCTP association that supports **4 streams** (IDs 0–3). According to the reservation rules:

1. Reserve stream pair **0** for non‑UE signalling.  
2. Reserve stream pairs **1** and **2** for UE‑associated signalling (two pairs, satisfying the “few pairs” recommendation).  
3. Stream **3** remains free for future UE sessions or for optional signalling classes.

If UE‑A uses stream pair 1 and UE‑B uses stream pair 2, both can exchange NGAP messages simultaneously without head‑of‑line blocking. Should a third UE appear, the network may either open a new association (using port 38412 or a dynamic port) or allocate a new stream pair if the current association has free streams.

**Numerical check:**  
- Total streams required = 1 (non‑UE) + 2 × 1 (two UE pairs) = **3**.  
- Available streams = **4**, so the configuration is sufficient.

If a stream failure occurs on stream 1, UE‑A’s signalling must wait for the association to be re‑established or for the AMF to request a new SCTP association, because the specification forbids changing the stream during an active UE‑associated session [TS 38.412 §7].

### Practical Notes and Common Pitfalls

* **Port selection:** Always use the IANA‑assigned port 38412 for the primary NGAP association; only use dynamic ports for additional associations after confirming the AMF’s request [TS 38.412 §7].  
* **Stream misuse:** Assigning UE‑associated signalling to the non‑UE reserved stream (or vice‑versa) violates the reservation rule and may cause unexpected ordering issues.  
* **Multi‑homing configuration:** Forgetting to configure both ends with the same set of IP addresses will prevent the redundancy mechanism from activating.  
* **INIT handling:** An unexpected INIT on an established association must be processed according to RFC 4960 subclause 5.2; failure to do so can break the association [TS 38.412 §7].  
* **Congestion control impact:** SCTP may trigger higher‑layer throttling; network planners should be aware that heavy signalling bursts can be back‑pressured by the transport layer [TS 38.412 §7].

Understanding these SCTP specifics ensures that 5G control‑plane traffic remains reliable, ordered where needed, and resilient to transport failures—key attributes for carrier‑grade mobile networks.

## 練習題

**1.** Which IANA‑assigned Payload Protocol Identifier (PPID) value is used for NGAP over SCTP?

- A. 60
- B. 66
- C. 38412
- D. 0

<details><summary>看答案</summary>

正解：A。PPID 60 is defined for NGAP; PPID 66 is for DTLS over SCTP, and 38412 is a port number.

</details>

**2.** What is the IANA‑assigned destination port number that must be used for NGAP over SCTP?

- A. 60
- B. 66
- C. 38412
- D. Any dynamic port

<details><summary>看答案</summary>

正解：C。The specification explicitly assigns port 38412 for NGAP traffic.

</details>

**3.** For a single AMF–NG‑RAN node pair, how many stream identifier pairs must be reserved for non‑UE‑associated NGAP procedures?

- A. Zero
- B. One pair
- C. Two pairs
- D. At least three pairs

<details><summary>看答案</summary>

正解：B。The standard mandates exactly one pair for non‑UE signalling.

</details>

**4.** Which SCTP feature provides transport‑network redundancy by allowing multiple IP addresses per endpoint?

- A. Stream multiplexing
- B. Multi‑homing
- C. Congestion window scaling
- D. Payload fragmentation

<details><summary>看答案</summary>

正解：B。Multi‑homing enables redundancy across multiple IP paths.

</details>

**5.** When multiple SCTP associations are supported, what dynamic operation may the AMF request?

- A. Change the PPID of an existing association
- B. Dynamically add or remove SCTP associations
- C. Reassign the destination port to 60
- D. Force all streams to be used for UE‑associated signalling

<details><summary>看答案</summary>

正解：B

</details>
