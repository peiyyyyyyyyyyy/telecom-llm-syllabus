# 1.2.4 路由協定：OSPF、BGP

所屬：[1.2 通訊協定](../1-2.md)

## 正文

### Why routing protocols matter

In any IP‑based network, a router must decide **where to forward each packet**. That decision is expressed as a **routing table** containing a set of destination prefixes and the next‑hop interface to reach them. Routing protocols are the distributed algorithms that populate and maintain those tables automatically, reacting to topology changes, policy requirements, and scale constraints. Two families dominate the Internet and large enterprise backbones:

* **Open Shortest Path First (OSPF)** – an interior gateway protocol (IGP) that computes the *least‑cost* paths inside a single autonomous system (AS).  
* **Border Gateway Protocol (BGP)** – an exterior gateway protocol (EGP) that exchanges *policy‑controlled* reachability information between autonomous systems.

Understanding the mechanics of OSPF and BGP is essential for designing resilient carrier‑grade networks, troubleshooting route leaks, and tuning traffic engineering (TE) mechanisms such as MPLS TE or BGP‑based traffic steering.

### Open Shortest Path First (OSPF)

OSPF (RFC 2328) is a link‑state IGP that operates within an **area**. An OSPF network is hierarchically divided:

| Symbol | Meaning |
|--------|---------|
| $A$    | Area identifier (32‑bit) |
| $R_i$  | Router *i* |
| $L_{ij}$ | Link cost between $R_i$ and $R_j$ (unitless, often derived from bandwidth) |
| $LSA$  | Link‑State Advertisement – a packet that describes the state of a router’s links |
| $SPF$  | Shortest Path First algorithm (Dijkstra) |

Each router floods LSAs throughout its area, creating a **link‑state database (LSDB)** that is identical for every router in the same area. The SPF algorithm runs on the LSDB to compute the **shortest‑path tree (SPT)** rooted at the local router. The cost of a path $P = (R_0,R_1,\dots,R_n)$ is

$$
\text{Cost}(P) = \sum_{k=0}^{n-1} L_{k,k+1}.
$$

The **least‑cost path** to each destination prefix is stored in the routing table. OSPF supports **virtual links**, **stub areas**, and **traffic engineering extensions (OSPF‑TE)**, but the core principle remains the SPF computation on a synchronized LSDB.

*Area 0 (Backbone)* – All non‑zero‑area routers must have a **virtual or physical** connection to Area 0, otherwise inter‑area routing fails.

### Border Gateway Protocol (BGP)

BGP (RFC 4271) is the de‑facto inter‑AS routing protocol for the global Internet. It is a **path‑vector** protocol: each UPDATE message carries not only the reachable prefix but also the **AS‑PATH** attribute that records the sequence of autonomous systems the route has traversed.

| Symbol | Meaning |
|--------|---------|
| $AS$   | Autonomous System number (16‑bit or 32‑bit) |
| $P$    | IP prefix, e.g., $192.0.2.0/24$ |
| $PA$   | Path attribute set (e.g., LOCAL\_PREF, MED, ORIGIN) |
| $next\_hop$ | IP address of the next‑hop router for $P$ |
| $R$    | BGP speaker (router) |

A BGP router maintains a **Adj‑RIB‑In** (routes learned from peers), applies **policy** (import filters, attribute modifications), and selects the *best* path per the BGP decision process:

1. **Highest LOCAL\_PREF** (default 100) – local to the AS.  
2. **Shortest AS‑PATH length**.  
3. **Lowest origin type** (IGP < EGP < INCOMPLETE).  
4. **Lowest MED (Multi‑Exit Discriminator)** – only compared among routes from the same neighbor AS.  
5. **eBGP over iBGP** – prefer routes learned from external peers.  
6. **Lowest IGP metric to BGP next‑hop** – uses the IGP (often OSPF) distance.  
7. **Tie‑breakers** (router ID, then neighbor address).

The **best path** is installed into the **Loc‑RIB**, from which the router programs its forwarding plane.

BGP also supports **route reflectors**, **confederations**, and **MPLS VPN** extensions (BGP‑VPN) that allow a single BGP speaker to distribute VPN‑specific routes.

### Worked Example

**Scenario:** A small enterprise backbone runs OSPF Area 0 with four routers (R1–R4). Link costs are derived from bandwidth: 1 Gbps = cost 1, 100 Mbps = cost 10, 10 Mbps = cost 100.

| Link | Bandwidth | Cost |
|------|-----------|------|
| R1‑R2 | 1 Gbps | 1 |
| R2‑R3 | 100 Mbps | 10 |
| R3‑R4 | 10 Mbps | 100 |
| R1‑R4 | 1 Gbps | 1 |

All routers have LSAs for each directly attached link. Compute the OSPF least‑cost path from **R1** to **R3**.

1. Build LSDB (identical for all routers).  
2. Run Dijkstra from R1:

   *Initialize:* distance(R1)=0, others = ∞.  

   *Iteration 1:* Pick R1 (dist 0). Update neighbors:  
   - dist(R2) = 0 + 1 = 1  
   - dist(R4) = 0 + 1 = 1  

   *Iteration 2:* Pick R2 (dist 1). Update R3:  
   - tentative dist(R3) = 1 + 10 = 11  

   *Iteration 3:* Pick R4 (dist 1). Update R3 via R4:  
   - tentative dist(R3) = 1 + 100 = 101 → keep 11 (lower).  

   *Result:* Shortest path R1 → R2 → R3 with total cost **11**.

If the R1‑R4 link fails, the SPF recomputation yields the same path (cost 11) because the alternative via R4 is now cost ∞.

**BGP example:** An ISP (AS 65001) receives two routes to prefix 203.0.113.0/24:

| Route | AS‑PATH | LOCAL\_PREF | MED |
|-------|---------|-------------|-----|
| A | 65001 65002 65003 | 200 | 0 |
| B | 65001 65004 | 100 | 10 |

Applying the BGP decision process:

1. LOCAL\_PREF: Route A (200) > Route B (100) → **Route A selected** despite longer AS‑PATH.  

If the ISP changes its policy to set LOCAL\_PREF = 100 for all routes, the decision falls to step 2: shortest AS‑PATH. Route B (length 2) wins over Route A (length 3).

### Common Mistakes & Practical Tips

| Mistake | Why it hurts | Remedy |
|---------|--------------|--------|
| **Missing Area 0** in OSPF design | Inter‑area traffic cannot traverse, leading to black holes. | Ensure every non‑zero area has at least one physically or virtually connected router to Area 0. |
| **Setting identical OSPF link costs** for vastly different bandwidth links | SPF will treat a 10 Mbps link as equal to a 1 Gbps link, causing sub‑optimal traffic distribution. | Derive cost from bandwidth using the OSPF reference formula $Cost = \frac{Reference\;Bandwidth}{Link\;Bandwidth}$. |
| **Over‑advertising LOCAL\_PREF** on iBGP peers | Can unintentionally override upstream provider policies, risking route leaks. | Apply LOCAL\_PREF only on routes received from eBGP peers; propagate unchanged on iBGP. |
| **Ignoring MED comparison across different neighbor ASes** | MED is only comparable within the same neighboring AS; mixing can give unexpected selections. | Use MED only when multiple paths are learned from the *same* external AS, or configure “MED compare” to ignore it otherwise. |
| **Failing to enable graceful‑restart** on BGP routers | Hard resets cause temporary loss of all routes, leading to traffic spikes. | Enable BGP graceful‑restart and verify that both peers support it. |

**Practical note:** In hybrid networks where OSPF supplies the IGP and BGP the inter‑AS reachability, the **IGP metric to the BGP next‑hop** (step 6 of BGP decision) is often the decisive factor when multiple eBGP paths have identical attributes. Keep the IGP topology tidy and avoid asymmetric costs that could bias traffic unintentionally.

## 練習題

**1.** In OSPF, which of the following statements about Area 0 is correct?

- A. Area 0 can be omitted if all routers are in a single non‑zero area.
- B. Every router must have a direct physical link to Area 0.
- C. Non‑zero areas must have at least one virtual or physical connection to Area 0.
- D. Area 0 is only used for external BGP routes.

<details><summary>看答案</summary>

正解：C。OSPF requires that every non‑zero area be connected to the backbone (Area 0) via a physical link or a virtual link; otherwise inter‑area routing fails.

</details>

**2.** Which BGP attribute is evaluated first when selecting the best path?

- A. MED (Multi‑Exit Discriminator)
- B. AS‑PATH length
- C. LOCAL\_PREF
- D. Origin type

<details><summary>看答案</summary>

正解：C。The BGP decision process begins with the highest LOCAL\_PREF; only if equal does it proceed to AS‑PATH length.

</details>

**3.** Given an OSPF link with bandwidth 100 Mbps and the default reference bandwidth of 100 Mbps, what is the OSPF cost of that link?

- A. 1
- B. 10
- C. 100
- D. 0.01

<details><summary>看答案</summary>

正解：A。OSPF cost = ReferenceBandwidth / LinkBandwidth = 100 Mbps / 100 Mbps = 1.

</details>

**4.** In the BGP example above, if both routes have the same LOCAL\_PREF, which attribute will cause Route B to be selected?

- A. ORIGIN type
- B. AS‑PATH length
- C. IGP metric to next‑hop
- D. Router ID

<details><summary>看答案</summary>

正解：B。With equal LOCAL\_PREF, BGP next compares AS‑PATH length; Route B has a shorter AS‑PATH (2 vs 3).

</details>

**5.** Which of the following is a primary reason to use OSPF‑TE (traffic engineering) extensions?

- A. To advertise BGP route attributes.
- B. To compute shortest‑hop paths instead of least‑cost.
- C. To distribute link bandwidth and delay information for MPLS TE path computation.
- D. To enable OSPF over IPv6 only.

<details><summary>看答案</summary>

正解：C。OSPF‑TE carries TE attributes (bandwidth, delay, etc.) so that MPLS TE can compute constrained paths.

</details>
