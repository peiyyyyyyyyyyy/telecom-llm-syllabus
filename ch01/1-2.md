# 1.2 通訊協定

**學習目標**　能依封包或信令指出協定層級、介面兩端及用戶面或控制面，並運用子網與最長前綴比對判讀路由。[原課綱 1.2](https://pyyy.gitbook.io/itri-docs/ch01/1-2)

- **1.2.1 OSI 與 TCP/IP 分層**　OSI 七層模型用來分析協定職責，TCP/IP 常以鏈路、網際網路、傳輸與應用層描述。沿封裝順序把應用資料、傳輸標頭、IP 標頭及鏈路訊框對起來。[RFC 1122](https://www.rfc-editor.org/rfc/rfc1122.html)
- **1.2.2 IP 定址與子網路**　IPv4／IPv6 以 CIDR 前綴表示網段，前綴長度指定共同的高位元數。路由表有多個符合目的位址的項目時，轉送採最長前綴比對。[RFC 4632](https://www.rfc-editor.org/rfc/rfc4632.html) [RFC 8200](https://www.rfc-editor.org/rfc/rfc8200.html)
- **1.2.3 TCP、UDP 與 SCTP**　TCP 提供可靠且依序的位元組流，UDP 提供資料報，SCTP 提供具多串流能力的可靠訊息傳輸。5G N2 的 NGAP 採 SCTP 承載。[RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html) [RFC 768](https://www.rfc-editor.org/rfc/rfc768.html) [RFC 9260](https://www.rfc-editor.org/rfc/rfc9260.html) [3GPP TS 38.412](https://www.3gpp.org/dynareport/38412.htm)
- **1.2.4 OSPF 與 BGP**　OSPF 在自治系統內以鏈路狀態資訊計算路徑。BGP 以路徑屬性與政策交換可達性，常用於自治系統之間，也可在自治系統內分發 BGP 路由。[RFC 2328](https://www.rfc-editor.org/rfc/rfc2328.html) [RFC 4271](https://www.rfc-editor.org/rfc/rfc4271.html)
- **1.2.5 MPLS 與 VPN**　MPLS 按標籤轉送。業者可用 BGP/MPLS IP VPN 的虛擬路由與轉送表（VRF）及路由政策，維持不同客戶的路由隔離，加密需求則另依服務設計評估。[RFC 3031](https://www.rfc-editor.org/rfc/rfc3031.html) [RFC 4364](https://www.rfc-editor.org/rfc/rfc4364.html)
- **1.2.6 RRC、SDAP、PDCP、RLC、MAC 與 PHY**　RRC 管理無線連線與量測設定，SDAP 對應 QoS Flow 與資料無線承載。PDCP 處理序號及依配置提供安全功能，RLC 負責分段與依模式重傳，MAC 負責多工與排程相關功能，PHY 實作無線傳送與接收。[3GPP TS 38.300](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf)
- **1.2.7 NAS、NGAP、GTP、Diameter 與 SBI**　5G NAS 在 UE 和核心網間承載接取、移動性及會話訊息，NGAP 可在 N2 轉遞 NAS。GTP-U 承載 N3 用戶面隧道，Diameter 可見於 LTE S6a，SBI 用於 5GC 控制面服務互通。[3GPP TS 23.501](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [TS 29.281](https://www.etsi.org/deliver/etsi_ts/129200_129299/129281/18.04.00_60/ts_129281v180400p.pdf) [TS 29.272](https://www.3gpp.org/dynareport/29272.htm)
- **1.2.8 Wi-Fi 與 IEEE 802 區域網路**　IEEE 802.11 定義無線區域網路，802.3 定義 Ethernet。當 Wi-Fi 或行動網路出現問題，可先依終端當下接取方式決定要查基地台、小區或無線基地台 AP。[IEEE 802](https://www.ieee802.org/)
- **1.2.9 控制面與用戶面堆疊**　以 gNB 到核心為例，N2 使用 NGAP／SCTP／IP，N3 使用 GTP-U／UDP／IP 承載內層用戶資料。比對內外層位址可分辨服務目的地與隧道端點。[3GPP TS 38.300](https://www.3gpp.org/dynareport/38300.htm) [TS 29.281](https://www.etsi.org/deliver/etsi_ts/129200_129299/129281/18.04.00_60/ts_129281v180400p.pdf)
- **1.2.10 NG、Xn、F1、E1 與 N4**　NG 接 NG-RAN 與核心，Xn 接不同 NG-RAN 節點，F1 接 CU 與 DU，E1 接 CU-CP 與 CU-UP。N4 連 SMF 與 UPF，採 PFCP 管理用戶面處理規則。[3GPP TS 38.401](https://www.3gpp.org/dynareport/38401.htm) [TS 29.244](https://www.3gpp.org/dynareport/29244.htm)
