# 1.3.5 網路切片

所屬：[1.3 服務與多媒體](1-3.md)

## 內文

網路切片是提供特定網路能力與特性的邏輯網路。它讓同一業者可為不同服務需求設計可識別的網路選擇和管控方式。終端接取某切片，涉及訂閱、業者配置、所在地區的能力與會話選擇。維運上需要先知道客戶預期使用哪個切片，再確認實際允用及建立的會話。 [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)

S-NSSAI 由切片服務型態 SST 與可選的切片區分資訊 SD 組成。終端可在註冊中攜帶 Requested NSSAI，業者依配置、訂閱與服務區域等條件決定可用項目，再向終端提供 Allowed NSSAI。必要時，相關網路功能會協助切片選擇與 AMF 的選擇。進一步建立 PDU Session 時，終端與網路依切片及所選資料網名稱等條件完成會話處理。一次查核可以從終端所請求的項目、網路實際允許的項目和會話所用識別逐層比對。 [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 23.003 V18.7.0](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/18.07.00_60/ts_123003v180700p.pdf)

SST 表達服務型態。SD 在同一服務型態內提供區分資訊，供業者辨認不同切片。網路切片可共用部分網路功能或基礎設施，有無專用資源需查設計及承諾。跨業者使用時，要核對歸屬與拜訪側識別的映射和支援情形。只用顯示名稱或對照畫面上的顏色，無法證實哪一個切片被選中。 [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 23.003 V18.7.0](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/18.07.00_60/ts_123003v180700p.pdf)

容易混淆的概念包括切片、資料網與流量處理。切片識別邏輯網路，資料網名稱協助選出會話所通往的資料網，QoS Flow 則描述會話內某批封包受到的處理。Allowed NSSAI 表示在相關條件下允用的集合，已經建立的會話還要查會話資訊。切片識別也無法單獨證明延遲或可靠度已符合承諾。如果同一切片可連多個資料網，驗收時需列明預期的服務端點和實際路徑，再確認要求的業務配置。 [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)

若工單描述某區可用、另一區失敗，可先查註冊的請求與允用結果，核對訂戶設定、服務區域和 S-NSSAI 相關配置。會話已建立時再查資料網、路由及該切片的實測績效。訂閱問題交訂戶資料團隊，選擇或會話問題交核心控制面團隊，小區能力或容量則請接取網維運確認。 [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 28.552 V19.6.0](https://www.etsi.org/deliver/etsi_ts/128500_128599/128552/19.06.00_60/ts_128552v190600p.pdf)
