# 1.1.9 網路與用戶識別碼：SUPI、GUTI、DNN、gNB／Cell ID

所屬：[1.1 網路架構](1-1.md)

## 內文

行動系統用不同識別碼區分訂戶、服務網路、資料網路、節點與小區。每一類識別碼都有用途與作用範圍。觀察到同樣一串數字時，必須先知道欄位型別、來源程序和是否包含網路範圍。掌握這些資訊，才能用紀錄關聯同一服務事件，也可避免在工單傳遞與排障無關的訂戶資料。 此處並列不同 Release 的文件，用來分別查證各識別碼在系統架構、編碼或協定訊息中的用途。實作與驗收應依專案指定的 Release 核對對應條款。 [3GPP TS 23.003 Release 19](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/19.06.00_60/ts_123003v190600p.pdf) [3GPP TS 33.501 Release 17](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/17.14.00_60/ts_133501v171400p.pdf)

SUPI 用來長期識別訂戶，5G-GUTI 用於對應程序中的暫時識別，後者可隨程序重新指派。SUCI 在適用保護方式下，提供可由歸屬網路處理的識別表示，以保護永久訂戶識別。DNN 涉及終端與哪個資料網路建立會話。節點與小區另有各自的識別，gNB ID 用於識別節點，NCI 用於識別 NR 小區，NCGI 再結合 PLMN ID 提供全球辨識範圍。若要跨站、跨區域或跨系統關聯，優先保留具備完整範圍的組合及其資料來源。 此處並列不同 Release 的文件，用來分別查證各識別碼在系統架構、編碼或協定訊息中的用途。實作與驗收應依專案指定的 Release 核對對應條款。 [3GPP TS 23.003 Release 19](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/19.06.00_60/ts_123003v190600p.pdf) [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 33.501 Release 17](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/17.14.00_60/ts_133501v171400p.pdf)

容易混淆的是暫時識別與長期訂戶識別、DNN 與使用者位址，以及小區識別與節點識別。暫時值變更時，應由獲授權程序紀錄關聯。DNN 的作用是指明資料網，終端的位址及其分配狀態需查看個別會話。只取小區部分的數值，跨 PLMN 比較時可能失去辨識範圍。另應保留字串格式與前置零，避免日誌工具自動轉為整數後無法還原。 此處並列不同 Release 的文件，用來分別查證各識別碼在系統架構、編碼或協定訊息中的用途。實作與驗收應依專案指定的 Release 核對對應條款。 [3GPP TS 23.003 Release 19](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/19.06.00_60/ts_123003v190600p.pdf) [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)

接到識別碼對不上的工單，先請回報者指出欄位型別、網路範圍、時刻和相關程序。無線團隊可核對廣播及小區組態，核心團隊查註冊和會話紀錄，涉及訂戶資訊時由有權限的團隊處理。一般交接宜用遮罩值或事件參照串接紀錄，再在受控環境還原詳細資料。若跨平台比對失敗，也要核對是否有十六進位、十進位或字串長度的表示差異，並利用發生時間核實暫時值在當時是否有效。 此處並列不同 Release 的文件，用來分別查證各識別碼在系統架構、編碼或協定訊息中的用途。實作與驗收應依專案指定的 Release 核對對應條款。 [3GPP TS 23.003 Release 19](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/19.06.00_60/ts_123003v190600p.pdf) [3GPP TS 33.501 Release 17](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/17.14.00_60/ts_133501v171400p.pdf) [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)
