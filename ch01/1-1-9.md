# 1.1.9 網路與用戶識別碼：SUPI、GUTI、DNN、gNB／Cell ID

所屬：[1.1 網路架構](1-1.md)

## 內文

SUPI 是永久訂戶識別，5G-GUTI 是暫時識別，DNN 用於識別資料網路。gNB ID 識別節點，NR 小區的全球識別 NCGI 由 PLMN ID 與 NCI 組成。[3GPP TS 23.003](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/19.06.00_60/ts_123003v190600p.pdf)
