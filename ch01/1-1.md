# 1.1 網路架構

**學習目標**　能說明 4G／5G 的接取和核心路徑、區分控制面與用戶面，並由部署和識別碼判斷事件影響範圍。[原課綱 1.1](https://pyyy.gitbook.io/itri-docs/ch01/1-1)

- **1.1.1 行動網路整體架構**　終端 UE 透過無線接取網連入業者網路。以典型 5G SA 上網為例，資料由 UE 經基地台 gNB、用戶面功能 UPF 到資料網路 DN，接取和會話由核心網控制功能管理。[3GPP TS 23.501](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)
- **1.1.2 基地台、天線與頻段**　基地台提供無線接取，天線的方位、下傾和波束影響訊號在空間的分布。判讀覆蓋與容量時，同時核對載波頻段、頻寬、環境和負載。[3GPP TS 38.300](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf)
- **1.1.3 CU／DU／RU 分離**　CU 處理較上層協定功能，DU 負責靠近無線端的即時處理與排程，RU 負責射頻及採用特定切分時的部分低層實體層功能。功能部署位置決定傳輸路徑與同步要求。[3GPP TS 38.401](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) [O-RAN 架構](https://www.etsi.org/deliver/etsi_ts/103900_103999/103982/08.00.00_60/ts_103982v080000p.pdf)
- **1.1.4 傳輸網、前傳、中傳與回傳**　以常見切分為例，前傳接 RU 和 DU，中傳接 DU 和 CU，回傳接 RAN 和核心網方向的傳輸網。光纖和微波是承載媒介，實際端點及同步條件要看部署拓樸。[ITU-T G.8300](https://www.itu.int/itu-t/recommendations/rec.aspx?id=14217&lang=en)
- **1.1.5 4G 核心網 EPC**　MME 負責接取信令及移動性管理，S-GW 與 P-GW 參與用戶面轉送，HSS 保存訂閱相關資料。利用元件分工區分接入失敗與用戶面不通。[3GPP TS 23.401](https://www.3gpp.org/dynareport/23401.htm)
- **1.1.6 5G 核心網與服務化架構**　AMF 管理接取與移動性，SMF 管理 PDU Session 並透過 N4 控制 UPF，UPF 執行封包處理與轉送。5GC 控制面網路功能可藉服務化介面 SBI 互通。[3GPP TS 23.501](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)
- **1.1.7 IP 網與網際網路互連**　路由器依目的 IP 前綴選擇下一跳，自治系統之間可用 BGP 交換可達資訊與施行路由政策。單一外部網站不通時，可對照其他目的地與互連路徑。[RFC 4632](https://www.rfc-editor.org/rfc/rfc4632.html) [RFC 4271](https://www.rfc-editor.org/rfc/rfc4271.html)
- **1.1.8 雙連接與 NSA／SA**　典型 NSA Option 3 由 LTE eNB 作主節點，NR 作次節點，使用 EPC。典型 SA Option 2 由 NR gNB 接 5GC，判讀應查看接取與核心組合。[3GPP TS 37.340](https://www.3gpp.org/dynareport/37340.htm) [TS 38.300](https://www.3gpp.org/dynareport/38300.htm)
- **1.1.9 網路與用戶識別碼**　SUPI 是永久訂戶識別，5G-GUTI 是暫時識別，DNN 用於識別資料網路。gNB ID 識別節點，NR 小區的全球識別 NCGI 由 PLMN ID 與 NCI 組成。[3GPP TS 23.003](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/19.06.00_60/ts_123003v190600p.pdf)
