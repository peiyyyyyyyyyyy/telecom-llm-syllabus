# 1.1.6 5G 核心網（5GC）與服務化架構

所屬：[1.1 網路架構](1-1.md)

## 內文

5G 核心網管理終端接取、會話及網路內的封包處理。服務化架構讓控制面功能透過定義好的服務相互請求資訊或動作，便於描述某次程序是誰發起、誰回應。服務化介面是整體架構的一部分，基地台接入、用戶面傳輸及控制用戶面節點的參考點也需保留。理解這些邊界有助於找出控制信令成功後流量仍中斷的原因。 [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 23.502 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123502/18.11.00_60/ts_123502v181100p.pdf)

終端註冊後要求建立會話時，AMF 依程序與適當的 SMF 配合。SMF 決定會話相關處理，例如選擇 UPF、安排與資料網相連的路徑，並經 N4 向 UPF 安裝或更新規則。UPF 根據規則辨認資料流、轉送及回報。控制面有需要時可使用 NRF 提供的功能登錄與探索服務，依部署採用直接或間接的通信方式。以一次會話更新為例，先看控制面是否完成該項更新，再依規則版本及回報核對 UPF 目前採用的處理。這能減少把控制服務的回應視為實際轉送已生效的誤判。 [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 23.502 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123502/18.11.00_60/ts_123502v181100p.pdf) [3GPP TS 29.244 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129244/18.09.00_60/ts_129244v180900p.pdf)

常見混淆包括服務化介面與 N4、AMF 與 SMF，以及 UPF 與應用伺服器。服務化介面可用來表達控制功能提供的服務，N4 用在 SMF 配置用戶面處理。AMF 管理接取與移動性，SMF 處理會話，UPF 提供用戶面轉送，資料網中的應用另有自己的服務狀態。針對外部服務故障，先區分業者網內的封包處理與資料網裡的應用處理。 [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 23.502 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123502/18.11.00_60/ts_123502v181100p.pdf) [3GPP TS 29.244 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129244/18.09.00_60/ts_129244v180900p.pdf)

維運須保留註冊或會話程序的時間、網路功能實例、服務回應、會話識別，以及上行與下行的封包線索。核心控制面團隊可查服務探索、服務請求和會話管理，核心用戶面團隊核對 N4 規則與 N3、N6 計數。若故障集中於某一資料網、服務或版本，將正常與異常案例按同一篩選條件並列，找出兩者最早分歧的節點和程序。另保留同一設備上的正反向流量和轉送動作，便於確認控制規則套用後的實際影響。 [3GPP TS 23.501 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 23.502 Release 18](https://www.etsi.org/deliver/etsi_ts/123500_123599/123502/18.11.00_60/ts_123502v181100p.pdf) [3GPP TS 29.244 Release 18](https://www.etsi.org/deliver/etsi_ts/129200_129299/129244/18.09.00_60/ts_129244v180900p.pdf)
