# 1.1.3 RAN 架構演進：CU／DU／RU 分離

所屬：[1.1 網路架構](1-1.md)

## 內文

基地台可以用分離架構把協定功能佈建到不同節點。3GPP 的 gNB-CU 與 gNB-DU 劃出集中單元及分布單元的邏輯邊界。O-RAN 的 O-RU 則提供射頻相關功能，並在其所定義的前傳切分承擔部分較低層的實體層處理。分離之後，可以依同步、傳輸及現地設備需求安排節點位置，也能指明不同團隊要觀測哪個介面。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) [ETSI TS 103 982，O-RAN Architecture Description](https://www.etsi.org/deliver/etsi_ts/103900_103999/103982/08.00.00_60/ts_103982v080000p.pdf)

依 3GPP 架構，gNB-CU 可部署 RRC、SDAP 與 PDCP 等功能，gNB-DU 部署 RLC、MAC 與 PHY。兩者由 F1 相連。在進一步區分控制面與用戶面的部署中，gNB-CU-CP 與 gNB-CU-UP 之間由 E1 相連。採用 O-RAN 開放前傳時，O-DU 與 O-RU 分別承擔切分界線兩側的功能，射頻訊號由 O-RU 連向天線側。以資料送出為例，上層用戶資料由集中側進入分布側，分布側做成對應的無線調度和訊號處理，再與無線單元配合形成實際發射。無線堆疊各層的職責見 1.2.6。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) [3GPP TS 38.300 Release 19](https://www.etsi.org/deliver/etsi_ts/138300_138399/138300/19.02.00_60/ts_138300v190200p.pdf) [ETSI TS 103 982，O-RAN Architecture Description](https://www.etsi.org/deliver/etsi_ts/103900_103999/103982/08.00.00_60/ts_103982v080000p.pdf)

常見混淆是把節點名稱直接當成實體機箱、把 F1 當成開放前傳，或把 E1 當成基地台對核心的接口。邏輯節點可依部署落在不同設備，也可能共置。F1 的端點是 CU 與 DU，開放前傳的端點則是 O-DU 與 O-RU。E1 是集中單元控制面與用戶面的分工接口。這些邊界決定封包、計數和告警該在哪裡查。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) [ETSI TS 103 982，O-RAN Architecture Description](https://www.etsi.org/deliver/etsi_ts/103900_103999/103982/08.00.00_60/ts_103982v080000p.pdf)

若小區告警同時涉及 DU 與 RU，維運先核對小區所屬 CU、DU、RU 及各端點的對應關係，接著比對 F1 狀態、開放前傳狀態、同步來源和異常範圍。多個分布單元同時受影響時，集中側或共用傳輸值得先核對。單一無線單元出現告警時，則可請無線及前傳團隊按鏈路、射頻與同步分別確認。交接應保留軟體版本、組態變更時刻以及共同時間基準下的兩端事件。 [3GPP TS 38.401 Release 18](https://www.etsi.org/deliver/etsi_ts/138400_138499/138401/18.01.00_60/ts_138401v180100p.pdf) [ETSI TS 103 982，O-RAN Architecture Description](https://www.etsi.org/deliver/etsi_ts/103900_103999/103982/08.00.00_60/ts_103982v080000p.pdf) [ITU-T G.8271](https://www.itu.int/rec/T-REC-G.8271/en) [ITU-T G.8275.1](https://www.itu.int/rec/T-REC-G.8275.1/en)
