# 1.3.6 企業專網：非公眾網路（SNPN、PNI-NPN）與 5G LAN

所屬：[1.3 服務與多媒體](1-3.md)

## 內文

企業專網讓工廠、園區或其他組織依自己的服務範圍與接取需求提供行動通訊。3GPP 的非公眾網路架構涵蓋 SNPN 與 PNI-NPN。企業使用者也可能需要一組裝置間的私有網路通訊，採用相應的 5G LAN-type service。理解這兩組概念，有助把部署主體、接取資格與群組資料服務分別驗收。 [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)

SNPN 自主管理其網路功能，業者與終端可用 PLMN 識別及網路識別 NID 的組合辨認該網。PNI-NPN 由公眾行動網支援，可依部署使用切片或封閉接取群組等方式限制存取。終端選網時需取得相應的選網和接取資料，網路再核對訂戶權限。至於群組私有通訊，要在業務設計中設定成員、群組資料和會話方式，再按選定的 IP 或 Ethernet 資料型態提供群組內服務。 [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 23.003 V18.7.0](https://www.etsi.org/deliver/etsi_ts/123000_123099/123003/18.07.00_60/ts_123003v180700p.pdf)

5G LAN-type service 的群組資料協助網路了解哪些裝置屬於同一服務，相關 PDU Session 與用戶面配置支援其封包處理。實際封包可能在同一用戶面功能內處理，或經由設計中選用的其他用戶面路徑轉送。部署時可為企業應用定義一組明確的測試端點、成員身分及預期可達範圍，以區別服務未開通和路徑配置問題。實際比對時可為同一群組及不同群組分別保留結果，確認服務允許的互通與隔離。 [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)

專網身分可決定終端可接取的網路，群組成員設定則影響裝置互通。具有專網接取許可的終端，仍需符合群組服務條件。Ethernet 類型承載的資料語意和 IP 類型不同，應以實際會話類型與群組設計判讀。能成功連上公眾或企業資料網，也無法單憑此結果確認企業裝置之間的預期隔離或互通。 [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)

園區值班收到部分裝置無法互通的工單時，先比對終端所在網路、註冊狀態、群組成員資料、會話類型和實際拓樸。若只有特定終端無法註冊，請終端或訂閱團隊確認配置。已進入群組卻送不到指定端點時，由核心用戶面與企業網路團隊分段查驗流量。 [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)
