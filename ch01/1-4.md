# 1.4 網管、計費、安全與密碼學

**學習目標**　能從工單辨識網管、用量計費和身分驗證需求，選擇相應資料與防護措施。[原課綱 1.4](https://pyyy.gitbook.io/itri-docs/ch01/1-4)

- **1.4.1 FCAPS、OSS 與 BSS**　FCAPS 涵蓋故障、組態、計帳、績效和安全管理。常見分工是 BSS 處理訂單、客戶與帳務，OSS 處理資源、開通和服務保障，可利用服務識別碼把兩端資料對起來。[ITU-T M.3400](https://www.itu.int/rec/T-REC-M.3400/en) [TM Forum eTOM（GB921）](https://www.tmforum.org/business-process-framework/)
- **1.4.2 績效量測工作、結果產生與傳送**　設定量測工作的管理物件、量測項目、統計粒度及回報方式。例如用 15 分鐘窗口收集小區 PRB 使用率和切換結果，再按小區與時間合併報表。[3GPP TS 28.550](https://www.etsi.org/deliver/etsi_ts/128500_128599/128550/16.10.00_60/ts_128550v161000p.pdf)
- **1.4.3 離線、線上與融合計費**　離線計費在用量事件後產生或回報帳務相關資料。線上計費的授權或配額可影響當下的使用權限，5G 融合計費由 CHF（Charging Function）提供相關服務。[3GPP TS 32.240](https://www.etsi.org/deliver/etsi_TS/132200_132299/132240/18.09.00_60/ts_132240v180900p.pdf) [TS 32.290](https://www.3gpp.org/dynareport/32290.htm)
- **1.4.4 用戶鑑權與金鑰協商**　5G-AKA 透過認證流程驗證訂戶端與網路並建立後續安全使用的金鑰材料。判讀鑑權失敗時，依程序階段檢查失敗碼、訂閱資料與網路紀錄。[3GPP TS 33.501](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/16.17.00_60/ts_133501v161700p.pdf)
- **1.4.5 加密與完整性保護**　加密保護機密性，完整性保護用於偵測竄改。適用範圍要看介面及規格，維運 API 的傳輸保護可使用經妥善驗證對端的 TLS，操作授權由服務本身管理。[3GPP TS 33.501](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/16.17.00_60/ts_133501v161700p.pdf) [IETF RFC 9846](https://www.rfc-editor.org/info/rfc9846/)
- **1.4.6 對稱、公鑰、雜湊與亂數**　對稱加密使用共享金鑰，公鑰密碼可用於簽章等目的，雜湊產生資料摘要。安全亂數供金鑰等安全參數使用，前提是隨機來源和生成器符合用途的安全需求。[NIST FIPS 197](https://csrc.nist.gov/pubs/fips/197/final) [FIPS 180-4](https://csrc.nist.gov/pubs/fips/180-4/upd1/final) [FIPS 186-5](https://csrc.nist.gov/pubs/fips/186-5/final) [SP 800-90A](https://csrc.nist.gov/pubs/sp/800/90/a/r1/final)
- **1.4.7 網路安全威脅與防護**　以異常登入、可疑組態變更和服務中斷為例，對照最小權限、多因素驗證、網管分區、更新和集中稽核。告警調查可交由資安和網管值班共同核實。[CISA 電信基礎設施防護指引](https://www.cisa.gov/sites/default/files/2025-01/joint-guidance-enhanced-visibility-hardening-guide-for-comms-infrastructure-508c_0.pdf)
- **1.4.8 SUPI 與 SUCI**　SUPI 是永久訂戶識別，SUCI 是依規範形成的訂戶識別表示，可透過指定保護方案降低永久識別在接取時暴露的風險。處理工單時依任務所需選擇可見的識別資訊。[3GPP TS 33.501](https://www.etsi.org/deliver/etsi_ts/133500_133599/133501/16.17.00_60/ts_133501v161700p.pdf)
