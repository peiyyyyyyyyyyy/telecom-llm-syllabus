# 附錄 C　對應方法與規則

## 規則分配（整科）

| GSMA 科目 | 分到 | 理由 |
|---|---|---|
| TeleTables | 2.3 表格與參數 | 整科都在查規格表格 |

| TeleLogs | 6.1 根因的類型 | 整科都在找降速根因 |
| ORANBench | 1.5 開放與虛擬化 | 整科都是 O-RAN 規格 |
| TeleMath | 第 3 章（由模型挑細項） | 整科都是計算題 |

## 模型逐題標記（TeleQnA、srsRANBench、TeleMath 的細項）

- 標記模型：本機 gpt-oss-120b（資料不出機房），溫度 0。
- 判斷規則：「照題目要模型『具備什麼知識或做什麼事』，標到最能接住它的一個細項；一題只標一個最主要的細項。」
- 第一輪接不住（標 ?）的題目，第二輪強制分到最接近的細項，並在標記檔記 `forced: true`。
- 標記檔：`data/syllabus/v2/tags_goss9.jsonl`；題數表：`data/syllabus/v2/summary_goss9.md`。

## 例題怎麼挑

- 只用 GSMA **訓練集**（模擬考、正式考的題目不放進書，避免被拿去當教材）。
- 每節最多 3 題，優先挑非強制分配的題目，並輪流從不同科目挑；固定亂數種子，重新產生結果相同。
- 3GPP TSG 的題目只留文件內容；TeleLogs 題目很長，只列開頭。
