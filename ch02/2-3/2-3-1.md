# 2.3.1 查表取值

所屬：[2.3 表格與參數](../2-3.md)

## 正文

In 3GPP technical specifications, almost every numeric requirement—such as carrier frequencies, power limits, or timing parameters—is presented in tables. Engineers repeatedly “lookup” these values when designing, configuring, or testing equipment. A consistent table format reduces ambiguity, speeds up implementation, and ensures that all parties interpret the same numbers in the same way. The rules governing table creation, numbering, and presentation are therefore essential knowledge for anyone working with the standards.

### Key Definitions from the Specification

| Symbol | Meaning | Reference |
|--------|---------|-----------|
| **Table width (portrait)** | Maximum horizontal size allowed for a table displayed in portrait orientation | 17 cm (6.6.5.1) |
| **Table width (landscape)** | Maximum horizontal size allowed for a table displayed in landscape orientation | 22 cm (6.6.5.1) |
| **Column spacing** | Fixed horizontal gap between adjacent columns | 0,1 cm (6.6.5.1) |
| **Border thickness** | Line weight used to separate rows/columns | ¾ pt single line (6.6.5.1) |
| **Table number** | Sequential identifier, optionally prefixed by clause numbers | (6.6.5.2) |
| **TH style** | Paragraph style applied to the table title | (6.6.5.3) |
| **TAH, TAL, TAC, TAR** | Styles for table headings and cell alignment | (6.6.5.4) |
| **TAN style** | Paragraph style for notes placed inside the table frame | (6.6.5.6) |

No formulas are required for lookup itself; the process is purely deterministic: locate the correct table, read the cell that matches the required row and column, and respect any associated notes.

### Table Numbering and Title Layout
Tables can be numbered either globally (Table 1, Table 2, …) or hierarchically (e.g., Table 7‑1 for the first table in clause 7). The hierarchical scheme embeds the clause number(s) into the table identifier, which can be helpful when a document contains many tables across many sections (6.6.5.2). The title appears **above** the table and may optionally include a colon followed by a descriptive name. The title must use the **TH** style (6.6.5.3).

### Column Headings and Units
The first word of each column heading must start with a capital letter, and the unit of measurement is normally placed on a second line directly under the heading (6.6.5.4). Consistent use of the heading styles—**TAH** for the heading row, **TAL**, **TAC**, or **TAR** for the data cells—ensures that the table renders uniformly across all deliverables.

### Continuation Pages
When a table spans more than one printed page, the column headings must be repeated on every subsequent page (6.6.5.5). Most word‑processing tools provide a “table heading row repeat” function that automates this requirement.

### Notes Within the Table Frame
Requirements, clarifications, or exceptions that apply to the whole table are placed in a **single merged cell** at the bottom of the table and formatted with the **TAN** style (6.6.5.6). The note begins with “NOTE:” for a single entry or “NOTE 1:”, “NOTE 2:” … for multiple entries. Footnotes are **explicitly prohibited** in 3GPP specifications (6.6.5.7); therefore any supplementary information must be expressed as a note, not a footnote.

### Worked Example: Verifying Table Width

Assume you need to create a portrait‑oriented table with 4 columns. The specification requires a column spacing of 0,1 cm and a border thickness of ¾ pt (which does not affect width). You decide on the following column widths:

* Column 1: 3 cm  
* Column 2: 4 cm  
* Column 3: 3 cm  
* Column 4: 5 cm  

Calculate the total width and verify compliance with the 17 cm portrait limit.

$$
\begin{aligned}
\text{Total column width} &= 3 + 4 + 3 + 5 = 15\ \text{cm}\\
\text{Number of gaps} &= (\text{columns} - 1) = 3\\
\text{Total spacing} &= 3 \times 0.1 = 0.3\ \text{cm}\\
\text{Overall width} &= 15 + 0.3 = 15.3\ \text{cm}
\end{aligned}
$$

The resulting width (15.3 cm) is below the 17 cm maximum, so the table satisfies the size rule (6.6.5.1). If you had added a fifth column of 3 cm, the total would become:

$$
15 + 3 + (4 \times 0.1) = 18.4\ \text{cm},
$$

which would exceed the portrait limit and would therefore require either a landscape orientation (max 22 cm) or a redesign of column widths.

### Practical Tips and Common Pitfalls

| Pitfall | Why it violates the spec | Remedy |
|---------|--------------------------|--------|
| Nesting a table inside another table | “A table within a table is not permitted.” (6.6.5.1) | Keep each logical set of data in a separate, flat table. |
| Omitting column‑heading repeat on multi‑page tables | “The column headings shall be repeated on all pages after the first.” (6.6.5.5) | Use the table‑heading repeat feature in the editor. |
| Using footnotes for additional information | “Footnotes shall not be used in 3GPP TSs or 3GPP TRs.” (6.6.5.7) | Place the information in a merged‑cell note with TAN style. |
| Forgetting the required 0,1 cm column spacing | “The ‘space between columns’ is 0,1 cm.” (6.6.5.1) | Set the column spacing property explicitly; verify with a ruler or layout preview. |
| Inconsistent border thickness | “Borders should be ¾ pt single line.” (6.6.5.1) | Apply a table style that defines border weight uniformly. |

By adhering to these rules, engineers ensure that the values they extract from the specification are unambiguous, reproducible, and compliant with the formal documentation process required by 3GPP.

## 練習題

**1.** Which of the following statements about table nesting is correct according to the specification?

- A. Tables may be nested if they are in different sections.
- B. A table within a table is not permitted.
- C. Nesting is allowed only for annex tables.
- D. Nested tables are required for complex parameter sets.

<details><summary>看答案</summary>

正解：B。The spec explicitly forbids nesting tables.

</details>

**2.** What is the prescribed space between columns in a 3GPP table?

- A. 0.1 cm
- B. 0.5 cm
- C. 1 cm
- D. No spacing is defined.

<details><summary>看答案</summary>

正解：A。The standard defines a fixed column spacing of 0,1 cm.

</details>

**3.** When a table continues onto a second page, how must the column headings be handled?

- A. They are repeated on every subsequent page.
- B. They appear only on the first page.
- C. They are omitted on continuation pages.
- D. They must be placed in a footnote.

<details><summary>看答案</summary>

正解：A。The specification requires headings to be repeated on all pages after the first.

</details>

**4.** Which paragraph style should be used for notes that appear inside a table frame?

- A. TAN
- B. TH
- C. TAH
- D. TAL

<details><summary>看答案</summary>

正解：A。Notes inside tables are formatted with the TAN style.

</details>

**5.** According to 3GPP documentation rules, footnotes in tables are:

- A. Allowed if they reference external documents.
- B. Prohibited.
- C. Mandatory for every table.
- D. Optional but recommended.

<details><summary>看答案</summary>

正解：B。The spec explicitly states that footnotes must not be used.

</details>
