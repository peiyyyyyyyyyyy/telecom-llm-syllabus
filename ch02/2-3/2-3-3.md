# 2.3.3 條件與註腳

所屬：[2.3 表格與參數](../2-3.md)

## 練習題

**1.** According to TS 21.801 §6.6.5.6, how should multiple notes in the same table be designated?

- A. NOTE:
- B. NOTE 1:, NOTE 2:, NOTE 3:, etc.
- C. Footnote 1, Footnote 2
- D. NOTE A, NOTE B

<details><summary>看答案</summary>

正解：B。The specification requires sequential numbering (NOTE 1:, NOTE 2:, …) for multiple notes within a single table.

</details>

**2.** What is the required location for a note to a table?

- A. Outside the table, in the surrounding paragraph.
- B. In a separate appendix.
- C. Within the frame of the relevant table, in a merged bottom cell.
- D. As a footnote at the bottom of the page.

<details><summary>看答案</summary>

正解：C。Notes must be placed inside the table borders, merged into a single cell at the bottom.

</details>

**3.** Which of the following statements is true regarding footnotes in 3GPP TS documents?

- A. Footnotes may be used for optional parameters.
- B. Footnotes are allowed only in TRs, not TSs.
- C. Footnotes shall not be used in 3GPP TSs or 3GPP TRs.
- D. Footnotes replace notes when the table is too wide.

<details><summary>看答案</summary>

正解：C。The specification explicitly forbids the use of footnotes in both TS and TR documents.

</details>
