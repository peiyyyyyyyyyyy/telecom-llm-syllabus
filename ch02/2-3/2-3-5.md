# 2.3.5 射頻發射與接收需求表

所屬：[2.3 表格與參數](../2-3.md)

## 正文

In 5G NR base stations (BS), the **RF transmission and reception requirement tables** define the minimum and maximum power levels that a BS must meet at its connector points (antenna or TAB) and in the radiated domain (EIRP). These tables are essential for ensuring regulatory compliance, protecting neighboring equipment, and guaranteeing that user equipment (UE) can achieve the expected throughput and coverage. Engineers use the tables to dimension power amplifiers, design antenna feeds, and verify conformance during type‑approval testing.

### Key Definitions and Symbols
| Symbol | Meaning | Unit |
|--------|---------|------|
| $P_{\text{rated},c,\text{AC}}$ | Rated carrier output power at the **antenna connector** for BS type 1‑C | dBm |
| $P_{\text{rated},c,\text{sys}}$ | System‑level rated carrier output power for BS type 1‑H (sum over all TABs) | dBm |
| $P_{\text{rated},c,\text{TABC}}$ | Rated carrier output power per **TAB connector** for BS type 1‑H | dBm |
| $N_{\text{TXU,active}}$ | Number of active transmitter units in the BS | – |
| $N_{\text{cells}}$ | Minimum number of supported geographical cells (or beams) declared by the manufacturer for BS type 1‑H | – |
| $N_{\text{TXU,counted}}$ | Number of transmitter units counted for conducted‑TX emission limits | – |
| $N_{\text{TXU,counted per cell}}$ | $N_{\text{TXU,counted}}$ divided by $N_{\text{cells}}$, used for scaling basic limits | – |
| $P_{\text{max},c,\text{AC}}$ | Maximum conducted output power measured at the antenna connector (type 1‑C) | dBm |
| $P_{\text{max},c,\text{TABC}}$ | Maximum conducted output power measured at a TAB connector (type 1‑H) | dBm |
| $P_{\text{REFSENS}}$ | Reference sensitivity level – minimum mean received power at the connector for which a throughput target must be met | dBm |
| $P_{\text{rated},\text{beam EIRP}}$ | Rated beam EIRP for a declared beam direction pair (radiated domain) | dBm (EIRP) |

### Conducted Transmitter Calculations (BS type 1‑H)
The number of transmitter units that count toward the emitted power limits is limited to eight per cell:

$$
N_{\text{TXU,counted}} = \min\!\bigl(N_{\text{TXU,active}},\;8 \times N_{\text{cells}}\bigr)
$$

The per‑cell count used for scaling basic limits is

$$
N_{\text{TXU,counted per cell}} = \frac{N_{\text{TXU,counted}}}{N_{\text{cells}}}
$$

These expressions are defined in TS 38.104 §6.1 [TS 38.104 §6]​.

### Rated Output Power Limits
*For BS type 1‑C* the limits are given in Table 6.2.1‑1: Medium Range ≤ 38 dBm, Local Area ≤ 24 dBm; Wide Area has no upper limit [TS 38.104 §6.2]​.

*For BS type 1‑H* the limits depend on $N_{\text{TXU,counted}}$:

- Medium Range: $P_{\text{rated},c,\text{sys}} \le 38\text{ dBm} + 10\log_{10}(N_{\text{TXU,counted}})$, $P_{\text{rated},c,\text{TABC}} \le 38\text{ dBm}$
- Local Area: $P_{\text{rated},c,\text{sys}} \le 24\text{ dBm} + 10\log_{10}(N_{\text{TXU,counted}})$, $P_{\text{rated},c,\text{TABC}} \le 24\text{ dBm}$

Wide Area again has no upper limit [TS 38.104 §6.2]​.

### Minimum Conducted Power Accuracy
In **normal conditions** the measured maximum power must stay within ±2 dB of the rated value; in **extreme conditions** the tolerance widens to ±2.5 dB [TS 38.104 §6.2.2, 6.2.3]​.

### Reference Sensitivity (Receiver) Requirements
$P_{\text{REFSENS}}$ is the minimum mean power at the connector that must yield ≥ 95 % of the maximum reference channel throughput (as defined in Annex A.1). Table 7.2.2‑1 lists $P_{\text{REFSENS}}$ values for various channel bandwidths and sub‑carrier spacings for Wide Area BSs, e.g. –103.6 dBm for a 3 MHz, 15 kHz SC spacing configuration [TS 38.104 §7.2.2]​.

### Radiated Beam EIRP Requirements
For each declared beam, the **claimed** EIRP must be achievable within ±2.2 dB in normal conditions for any beam peak direction within the OTA peak directions set [TS 38.104 §9.2.2]​.

### Worked Example
A Medium‑Range BS type 1‑H declares support for $N_{\text{cells}} = 4$ cells. During a test the equipment has $N_{\text{TXU,active}} = 30$ active transmitter units.

1. Compute $N_{\text{TXU,counted}}$:
   $$
   N_{\text{TXU,counted}} = \min(30,\;8 \times 4) = \min(30,\;32) = 30
   $$
2. Compute the system‑level rated power limit:
   $$
   P_{\text{rated},c,\text{sys}} \le 38\text{ dBm} + 10\log_{10}(30) \approx 38\text{ dBm} + 14.8\text{ dB} = 52.8\text{ dBm}
   $$
3. The per‑TAB limit remains $38\text{ dBm}$.

If the manufacturer measures $P_{\text{max},c,\text{TABC}} = 39.5\text{ dBm}$ on a TAB connector, the deviation from the rated $38\text{ dBm}$ is $+1.5\text{ dB}$, which is within the ±2 dB normal‑condition tolerance [TS 38.104 §6.2.2]​.

### Practical Notes and Common Mistakes
- **Confusing connector types**: BS type 1‑C uses the antenna connector; BS type 1‑H uses TAB connectors. Mixing the two leads to applying the wrong power limits.
- **Ignoring the 8‑per‑cell cap**: $N_{\text{TXU,counted}}$ cannot exceed $8 \times N_{\text{cells}}$. Forgetting this cap can result in overstated rated power limits.
- **Wide‑Area BS limits**: The tables explicitly state “no upper limit” for Wide Area BSs; attempting to enforce a numeric cap is a specification error.
- **Receiver sensitivity units**: $P_{\text{REFSENS}}$ values are absolute dBm levels, not relative to noise floor. Misinterpreting them as SNR thresholds will cause test failures.
- **Beam EIRP vs. Conducted Power**: Radiated EIRP limits apply per beam direction, while conducted limits apply at the connector. Both must be verified independently.

Understanding and correctly applying these tables ensures that a base station meets both **regulatory** and **performance** objectives across all operating bands and deployment scenarios.
