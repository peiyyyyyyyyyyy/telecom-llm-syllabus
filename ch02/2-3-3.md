# 2.3.3 條件與註腳

所屬：[2.3 表格與參數](2-3.md)

## 內文

表格中的條件決定某列值在哪種設備、頻率或操作模式下適用。條件可能寫在主條文、引介表格的句子、欄首、列名或註腳。工程師在做驗收文字、參數清冊與差異比較時，應把條件跟著數值保存。規格的版面常把共用條件留在表外，表格單獨複製進試算表後，適用範圍容易遺失。 [3GPP TS 38.104 V18.12.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf) [ETSI Drafting Rules §§5.2.2、5.5.1](https://portal.etsi.org/directives/52_ETSI_directives_dec_2025.pdf)

讀表時先看引介文字如何呼叫該表，再沿著本來要引用的欄位找上標與對應註腳。先確定註腳掛在單一儲存格、整欄、整列還是全表，再判斷它是在定義術語、排除一種設備、給出附加量測條件，或把同一個欄位分成幾個數值。條文出現 unless otherwise stated 時，可先記錄一般設定，再沿同章和相關小節尋找實際涵蓋該情境的特別規定。看到小於、等於、至少等詞，應逐一確認邊界在哪一側。遇到條件分流，可以在筆記寫成一條「設備或頻率條件 → 適用值」的對照，並把表號連同註腳標記留下。正文的 NOTE 用來提供資訊，不能含要求。依 ETSI 撰寫規則，表格註腳則可以含要求。要理解有取值效果的註腳，可以回到正文的要求句，看它如何指向帶條件的表列。 [ETSI Drafting Rules §§5.2.2、5.5.1](https://portal.etsi.org/directives/52_ETSI_directives_dec_2025.pdf) [3GPP TS 38.104 V18.12.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf)

TS 38.104 V18.12.0 的表 6.5.2.2-1 列出 1-C、1-H 型基地台的 PDSCH 調變品質要求。讀到 1024QAM 時，一列出現兩個帶標記的百分比。表下注記將 2.5% 配給頻率等於或低於 4.2 GHz 的情況，將 2.8% 配給頻率高於 4.2 GHz 的情況。若設備的相關頻率恰落在 4.2 GHz，等於一詞已把它放進第一個條件。工程紀錄應留下兩個值各自的頻率適用區間，再依設備條件選一筆。§6.5.2.2 引用此表時也列有適用的發射及量測設定，因此試驗計畫還要將表前條件與腳註合起來讀。 [3GPP TS 38.104 V18.12.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf)

易混淆之處有三種。第一是看到一個數值旁有標記，卻把腳註套給相鄰的其他調變列。第二是看到一條預設規則，便漏看同一要求內明列的例外。第三是把說明性的 NOTE、附加在表值上的限定條件，以及正文中的義務句混成同一種文字。看表時應確認這些元素各自指向何處，以及規格如何連接它們。 [3GPP TS 38.104 V18.12.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf) [ETSI Drafting Rules §§5.2.2、5.5.1](https://portal.etsi.org/directives/52_ETSI_directives_dec_2025.pdf)

2.3.1 的查表流程可用來保存註腳所在的位置，2.3.5 則說明射頻要求還要結合設備類型與測試配置。把帶註腳的值寫入報告時，可接續 2.6.1 的版本與條號格式。 [3GPP TS 38.104 V18.12.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf) [3GPP TR 21.900 V19.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf)
