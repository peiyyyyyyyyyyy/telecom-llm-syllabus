# 2.2.3 規格的章節組成：範圍、參考、定義、縮寫

所屬：[2.2 規格文件的結構](2-2.md)

## 內文

技術規格的開頭提供正文的讀取條件。Scope 界定文件處理的系統、介面或功能，References 提供沿著正文追查其他規格的方法，術語、符號與縮寫則固定在本文件裡的解讀。工程師收到一份只節錄表格或一段條文的資料時，可先查回這些前置章節，確認那段資料適用於哪個版本及技術範圍，再決定是否能用來支持測試或實作判斷。 [3GPP TR 21.801 規格資料](https://portal.3gpp.org/desktopmodules/Specifications/SpecificationDetails.aspx?specificationId=552) [3GPP TS 38.215 V18.4.0 §§1–3](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.04.00_60/ts_138215v180400p.pdf)

讀法可從封面開始，記下文件題名、版次及 Release，到 Scope 確認它與待查介面、對象或協定層的關係。看到正文的方括號索引時，到 References 找完整編號及題名。若適用的參照規則區分 specific 和 non-specific，前者由日期、版次等資訊固定，應使用被指明的版本。後者依規則使用適用的新版本，引用 3GPP 文件時，常見寫法會限定在同一 Release 內取最新版。到 Definitions 或 Terms 查正文用語的意義，再確認同一術語在文件內的優先順序。到 Symbols 查公式的量、索引或符號，到 Abbreviations 核對字母組合的全名。若文獻表也指向共用詞彙文件，應先弄清該規格是否對某個詞另給在地定義。最後回到正文，檢查引文是要求的一部分、補充說明或查找背景的線索。 [3GPP TS 38.412 V18.0.0 §2](https://www.etsi.org/deliver/etsi_ts/138400_138499/138412/18.00.00_60/ts_138412v180000p.pdf) [3GPP TS 38.215 V18.4.0 §§1–3](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.04.00_60/ts_138215v180400p.pdf)

以 TS 38.412 V18.0.0 為例，先讀 §1 確認主題是 NG 信令傳輸。正文 §6 列出 IPv6 所參照的 [5]，回 §2 可看到 IETF RFC 8200 連同年月一起列出，而同一清單的 [3] 是未列版號的 3GPP TS 23.501。依本件 §2 的規則，讀 [5] 時沿用指明的文件，查 [3] 時在 Release 18 找適用版本。另開 TS 38.215 V18.4.0，§3.1 是 Terms，§3.2 是 Symbols，§3.3 是 Abbreviations，並可在 §3.1 看出它如何處理 TR 21.905 和本文件詞義的優先次序。 [3GPP TS 38.412 V18.0.0 §§1、2、6](https://www.etsi.org/deliver/etsi_ts/138400_138499/138412/18.00.00_60/ts_138412v180000p.pdf) [3GPP TS 38.215 V18.4.0 §3](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.04.00_60/ts_138215v180400p.pdf)

方括號序號的作用域是本件文件及版本，換到另一份文件時要重新查。術語定義、符號表及縮寫清單用途各異，僅查縮寫全名仍需回正文了解技術行為。文件編排也可依實際內容增減小節，查找時應以該版目錄和小節題名為準。 [3GPP TS 38.215 V18.4.0 §§2–5](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.04.00_60/ts_138215v180400p.pdf)

前置章節能提供正文的引用口徑。實際決定對照版次時接續 2.6.2，寫報告或工單時用 2.6.1 的格式，將所引用的正文條文和版本一併留下。 [3GPP TR 21.801 規格資料](https://portal.3gpp.org/desktopmodules/Specifications/SpecificationDetails.aspx?specificationId=552) [3GPP TS 38.412 V18.0.0 §2](https://www.etsi.org/deliver/etsi_ts/138400_138499/138412/18.00.00_60/ts_138412v180000p.pdf)
