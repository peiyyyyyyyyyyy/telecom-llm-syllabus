# 2.6.4 由檔名讀出版本與 Release

所屬：[2.6 引用規則](2-6.md)

## 內文

3GPP 封存檔名把文件編號與版本壓縮為短代碼。下載舊版、排查版本差異或整理回溯證據時，從檔名先分辨文件與版本，可以減少打開錯誤分支的機會。編碼適用於遵循相同命名規則的正式封存項目。入口列出的版本、原檔封面與 Release 標誌可以用來交叉核對，最後在正文引註寫出完整版本，讓讀者不必自行解碼。 [3GPP TR 21.900 V19.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [3GPP，版本編碼規則](https://www.3gpp.org/specifications-technologies/specifications-by-series/version-numbering-scheme)

3GPP TR 21.900 V19.1.0 §5A 用 aabbb-xyz.eee 交代單一分件的檔名形式。讀左段時，可把系列與三位文件序號組合成規格號，例如 38215 讀成 38.215。某些規格另有可見的分冊或子分冊標記，應照 §5A 的分件形式保留。最右的版本段對應 x.y.z 三個分量，字母用該節的表 6 換成數值，其中小寫 i 代表 18，j 代表 19。三個字符要逐一解讀。副檔名是檔案格式，從封存站取件時，外層可能是 ZIP 壓縮檔。查到一列後，先把完整檔名、還原出的版本與入口欄位放在一起，確認三者一致再開文件。再看封面所列的 Release。對工作稿、特殊歷史分支或封面標示不明的版本，查規格工作方法及官方入口，將解碼結果與 Release 歸屬各自核實。 [3GPP TR 21.900 V19.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [3GPP，版本編碼規則](https://www.3gpp.org/specifications-technologies/specifications-by-series/version-numbering-scheme)

真實例子可從 3GPP Portal 的 TS 38.215 規格頁在 Release 18 區塊找到 V18.4.0 的封存連結，其檔名為 38215-i40.zip。左段 38215 還原為 38.215，右段 i40 依序還原成 18、4、0，讀為 V18.4.0。ETSI 公開發行的同版副本叫 ts_138215v180400p.pdf，檔名形式採 ETSI 出版格式。打開後，封面可同時核對 3GPP TS 38.215、V18.4.0 與 Release 18。實務交付中可保存封存檔名及公開副本網址，再在引用欄寫全版本，日後有人從封存站或發行機構的入口查找時，都可對回同一版次。 [3GPP Portal，TS 38.215](https://portal.3gpp.org/desktopmodules/Specifications/SpecificationDetails.aspx?specificationId=3217) [ETSI／3GPP TS 38.215 V18.4.0](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.04.00_60/ts_138215v180400p.pdf) [3GPP TR 21.900 V19.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf)

有幾個容易混淆的地方。字母代表版本分量的數值，控管清單若只寫 i 版會遺失其餘分量。中段的 4 表示 y 分量，不能當成 Release 4。ETSI PDF、會議文件與其他系統的自訂檔名各自有編碼原則，對任何外部副本都可用封面或官方入口恢復原始識別。分件規格則要保留分冊號，因為同一主規格下的不同分冊可有相似的版本尾碼與不同的適用內容。 [3GPP TR 21.900 V19.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [ETSI／3GPP TS 38.215 V18.4.0](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.04.00_60/ts_138215v180400p.pdf)

本節提供解碼方法，2.6.1 說明如何將版本與條號組成可複查的引註。2.2.6 可用來理解版本分量改變與 CR 納入的關係。若任務已有驗收基線或引用規則，仍應按 2.6.2 的方法查證該版的適用性。 [3GPP TR 21.900 V19.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [ETSI／3GPP TS 21.205 V18.0.0](https://www.etsi.org/deliver/etsi_ts/121200_121299/121205/18.00.00_60/ts_121205v180000p.pdf)
