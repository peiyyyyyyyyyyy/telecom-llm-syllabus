# 2.2.5 ASN.1 與資訊元素

所屬：[2.2 規格文件的結構](../2-2.md)

## 練習題

**1.** 依照規範，當在 3GPP 文件中加入 ASN.1 程式碼時，必須如何處理？

- A. 不需要任何特別標示
- B. 必須清楚標示
- C. 必須將程式碼加密
- D. 必須刪除程式碼

<details><summary>看答案</summary>

正解：B。規範要求所有加入的程式碼必須明確標示其身分。

</details>

**2.** 以下哪一項被列為可在 3GPP TS 或 TR 中包含的程式碼範例？

- A. Java
- B. ASN.1
- C. Python
- D. HTML

<details><summary>看答案</summary>

正解：B。例子中明確提到 ASN.1 為可包含的程式碼類型之一。

</details>

**3.** 關於在 3GPP 文件中加入程式碼的政策，下列哪一敘述最符合規範？

- A. 程式碼不可加入文件中
- B. 程式碼可加入且不需標示
- C. 程式碼可加入，但必須清楚標示
- D. 只允許加入 ASN.1 程式碼

<details><summary>看答案</summary>

正解：C。規範允許加入程式碼，但強調必須清楚標示其身分。

</details>
