# 2.2.4 程序與訊息的描述方式

所屬：[2.2 規格文件的結構](../2-2.md)

## 練習題

**1.** What must the NG‑RAN node do when a PDU SESSION RESOURCE SETUP REQUEST contains several PDU Session ID IEs set to the same value?

- A. Accept the first ID and ignore the rest.
- B. Report the establishment of the corresponding PDU sessions as failed.
- C. Merge the duplicate entries into a single session.
- D. Forward the request to the core network for disambiguation.

<details><summary>看答案</summary>

正解：B。The specification mandates a failure response for duplicate session IDs.

</details>

**2.** For a GBR QoS flow, the NG‑RAN node requires which IE to avoid a failure response?

- A. Dynamic 5QI Descriptor
- B. GBR QoS Flow Information
- C. Delay Critical
- D. Maximum Data Burst Volume

<details><summary>看答案</summary>

正解：B。The presence of GBR QoS Flow Information is mandatory for GBR flows.

</details>

**3.** When the *Delay Critical* IE is set to “delay critical” but the *Maximum Data Burst Volume* IE is missing, the NG‑RAN node shall:

- A. Accept the QoS flow and use a default burst volume.
- B. Report the establishment of the corresponding QoS flow as failed.
- C. Request the UE to resend the missing IE.
- D. Ignore the *Delay Critical* setting and proceed.

<details><summary>看答案</summary>

正解：B。The specification requires a failure response for this condition.

</details>
