# 2.2.5 ASN.1 與資訊元素

所屬：[2.2 規格文件的結構](2-2.md)

## 內文

Abstract Syntax Notation One（ASN.1）是一套用於描述資料型別和結構的記法。無線或核心網控制協定可用它描述可交換的訊息以及其中的 Information Element（IE，資訊元素）。工程師核對封包解碼、實作不同版本的欄位或追查設定更新時，要讀訊息型別、欄位型別、出現條件及其程序語義，才能從收到的資料判斷設備該執行的動作。 [ITU-T X.680](https://www.itu.int/rec/T-REC-X.680/e) [3GPP TS 38.331 V17.1.0 §§6.1、6.2](https://www.etsi.org/deliver/etsi_ts/138300_138399/138331/17.01.00_60/ts_138331v170100p.pdf)

從訊息型別開始，沿名稱找到內層 IE。SEQUENCE 聚合有順序的欄位，CHOICE 提供其中一個可選分支，ENUMERATED 列舉可用值，INTEGER 後可以再宣告範圍。看到 OPTIONAL，先記下它在語法上可省略，再找欄位說明、條件註記、接收程序及適用的編碼規則。以 TS 38.331 V17.1.0 的無線資源控制協定為例，§6.1.2 表 6.1.2-1 對缺席的可選欄位給出處理指引。Need M 指在適用情形維持現有值，Need R 指釋放既存配置，Need S 要按欄位或程序指定行為處理，Need N 表達無需動作。讀到 Cond 時，回查對應條件的文字，分辨在哪個分支要求或允許欄位出現。若欄位位於另一結構裡，亦要檢查上層結構是否出現和本件定義的例外。實作測試可以成對驗證欄位出現與省略時的結果，並把前置狀態與所用版本一起記錄。 [ITU-T X.680](https://www.itu.int/rec/T-REC-X.680/e) [3GPP TS 38.331 V17.1.0 §6.1.2 表 6.1.2-1](https://www.etsi.org/deliver/etsi_ts/138300_138399/138331/17.01.00_60/ts_138331v170100p.pdf)

例如在 TS 38.331 V17.1.0 §6.2.2 找 RRCReconfiguration，再往下讀 RRCReconfiguration-IEs。radioBearerConfig 的行上可讀到 OPTIONAL 及 Need M，表示先依語法判定該欄位可省略，再依 Need code 和相關程序處理既有的無線承載配置。secondaryCellGroup 同樣有 OPTIONAL，另註 Cond SCG。查到這一列，應接著讀該訊息的 SCG 條件表，核對觸發條件及該條件限定的內容。兩個欄位在同一訊息的相鄰行，就能看見語法容許、條件和接收語義分別由哪些資料表達。 [3GPP TS 38.331 V17.1.0 §§6.1.2、6.2.2](https://www.etsi.org/deliver/etsi_ts/138300_138399/138331/17.01.00_60/ts_138331v170100p.pdf)

Need M 的 M 在這份文件中指 Maintain，應依同版 §6.1.2 及例外處理。其他協定可使用 Mandatory、Optional 或 Conditional 等 Presence 欄位，例如 TS 38.413 的 NG SETUP REQUEST。當另有 Criticality 欄時，也需按該協定的錯誤處理規則解讀。採用某個協定定義的縮寫或欄位時，以那份文件內的意義為準。 [3GPP TS 38.331 V17.1.0 §6.1.2](https://www.etsi.org/deliver/etsi_ts/138300_138399/138331/17.01.00_60/ts_138331v170100p.pdf) [3GPP TS 38.413 V18.8.0 §9.2.6.1](https://www.etsi.org/deliver/etsi_ts/138400_138499/138413/18.08.00_60/ts_138413v180800p.pdf)

回到 2.2.4 可核對訊息在哪個程序收發。引用資訊元素時，依 2.6.1 保留協定版本、訊息或欄位、適用條件，連同可能改變語義的接收程序一併定位。 [3GPP TS 38.331 V17.1.0 §§5、6](https://www.etsi.org/deliver/etsi_ts/138300_138399/138331/17.01.00_60/ts_138331v170100p.pdf)
