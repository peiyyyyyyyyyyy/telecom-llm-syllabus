# 2.1.5 3GPP 組織夥伴（ETSI 等）與引用的外部標準（IETF、IEEE）

所屬：[2.1 標準體系](2-1.md)

## 內文

3GPP 的組織夥伴（Organizational Partners）為跨區標準制定提供治理、會員與出版機制。3GPP 也會在規格中引用外部組織維護的技術，讓傳輸、橋接等既有協定能用在電信系統的特定介面。有兩條線索需要分開記錄。一條是文件由哪個夥伴轉載或發布，另一條是實作某項要求時還需要遵循哪份外部文件。追溯兩條線索都有助於在互通或採購審查時交代依據。 [3GPP Working Procedures](https://www.3gpp.org/FTP/tsg_ran/WG4_Radio/TSGR4_115/Templates/3GPP%20Working%20Procedures_2025.pdf) [3GPP Working Procedures，組織架構與組織夥伴](https://www.3gpp.org/FTP/tsg_ran/WG4_Radio/TSGR4_115/Templates/3GPP%20Working%20Procedures_2025.pdf)

3GPP Working Procedures 的會員申請樣表並列 ARIB、ATIS、CCSA、ETSI、TSDSI、TTA 與 TTC。組織夥伴在合作架構中有正式角色，個別成員參加技術工作時依其所屬夥伴與會員程序辦理。若手邊拿的是 ETSI 刊行版，先看封面標出的原 3GPP 文件號、版本與 Release，再以那些欄位比對專案的規格清單。外部引用需從規格正文回查 References，讀取該筆的機構、文件號、版本限定及文件題名。接著把外部文件交給正文段落指定的介面或功能使用，並把 3GPP 另列的取值、角色、支援義務與範圍一起記下來。Internet Engineering Task Force（IETF）的 RFC 可提供傳輸協定，IEEE 文件可提供橋接等機制，兩者在各自的發行或維護網站有獨立版本紀錄。若另一方拿不同版的同名文件，先對照正文中方括號的引用號，再決定要討論引用版本還是建議變更基線。 [3GPP Working Procedures 附錄 C](https://www.3gpp.org/FTP/tsg_ran/WG4_Radio/TSGR4_115/Templates/3GPP%20Working%20Procedures_2025.pdf) [3GPP Working Procedures，組織架構與組織夥伴](https://www.3gpp.org/FTP/tsg_ran/WG4_Radio/TSGR4_115/Templates/3GPP%20Working%20Procedures_2025.pdf) [IEEE 的 802.1Q-2022 頁面](https://standards.ieee.org/ieee/802.1q/10323/)

以 3GPP TS 38.412 V18.0.0 §7 為例，規格沿用 Stream Control Transmission Protocol（SCTP），指定它作為 NG-C 信令承載的傳輸層。從正文的引用號回到 §2，查得 [2] 為 IETF RFC 4960，接著才讀該 RFC 的協定定義。若 RFC Editor 頁面列有更新或取代文件，先保留工單所採的 3GPP 版與它明列的 RFC。另一種例子是 TS 23.501 V18.11.0 的時間敏感網路段落，引用 IEEE Std 802.1Q [98] 中的串流篩選相關條款。讀到篩選或優先級的外部欄位時，應回到該節確認 5G 系統使用它做哪項處理。 [3GPP TS 38.412 V18.0.0 §§2、7](https://www.etsi.org/deliver/etsi_ts/138400_138499/138412/18.00.00_60/ts_138412v180000p.pdf) [IETF RFC 4960](https://www.rfc-editor.org/rfc/rfc4960.html) [3GPP TS 23.501 V18.11.0](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf)

遇到兩組編號時，ETSI 封面的刊行編號與其列明的 3GPP 原文件號可以對照同一版技術內容。IETF 或 IEEE 的文件則依正文引用建立關係，保有自身版本及勘誤歷程。此外，某文件被列在 References，只能先確認文獻關係，實作範圍還要從引述它的句子找出來。 [3GPP Working Procedures，組織架構與組織夥伴](https://www.3gpp.org/FTP/tsg_ran/WG4_Radio/TSGR4_115/Templates/3GPP%20Working%20Procedures_2025.pdf) [3GPP TS 38.412 V18.0.0](https://www.etsi.org/deliver/etsi_ts/138400_138499/138412/18.00.00_60/ts_138412v180000p.pdf)

2.2.3 說明文獻表的結構，2.6.2 說明不同引用類型的版次選擇。記錄跨組織的技術判斷時，依 2.6.1 同時保留引用者的條文與被引用文件的定位資料，讓讀者能沿兩個方向查驗。 [3GPP TR 21.801 規格資料](https://portal.3gpp.org/desktopmodules/Specifications/SpecificationDetails.aspx?specificationId=552) [3GPP TS 38.412 V18.0.0](https://www.etsi.org/deliver/etsi_ts/138400_138499/138412/18.00.00_60/ts_138412v180000p.pdf)
