# 2.1.1 3GPP 組織：TSG RAN、SA、CT

所屬：[2.1 標準體系](../2-1.md)

## 練習題

**1.** Which of the following statements correctly describes the relationship between a TSG and a WG in 3GPP?

- A. A WG can approve Change Requests without involving the TSG.
- B. A WG reports to a TSG and drafts specifications under its scope.
- C. A TSG is a sub‑group of a WG.
- D. Both TSG and WG have the same authority over version numbers.

<details><summary>看答案</summary>

正解：B。A Working Group reports to its Technical Specification Group and drafts the normative text, while the TSG holds the ultimate approval authority.

</details>

**2.** In a version identifier of the form $x.y.z$, which component represents the major version according to 3GPP terminology?

- A. $y$
- B. $z$
- C. $x$
- D. The concatenation of $x$ and $y$

<details><summary>看答案</summary>

正解：C。The major version is defined as the first integer before the first dot.

</details>

**3.** What is the definition of a Change Request (CR) in the 3GPP process?

- A. An informal suggestion that does not require a formal number.
- B. A formal proposal presented on a standard form to modify a specification under change control.
- C. The final version of a specification after all corrections.
- D. A work task that belongs to a building block.

<details><summary>看答案</summary>

正解：B。A CR is a formal proposal on a standard form to modify a specification that is under change control.

</details>

**4.** Which term refers to a sub‑division of a feature that is expected to reside in a single system element?

- A. Work Item
- B. Building block
- C. Study Item
- D. Change Request

<details><summary>看答案</summary>

正解：B。A building block is defined as a sub‑division of a feature representing a coherent set of technical functionality.

</details>

**5.** When a specification status is described as “frozen,” which of the following is true?

- A. No further changes of any kind are permitted.
- B. Only essential corrections are permitted.
- C. The specification is being drafted and can be freely edited.
- D. The specification has been withdrawn from the valid set.

<details><summary>看答案</summary>

正解：B。In the frozen status, only essential corrections are allowed.

</details>
