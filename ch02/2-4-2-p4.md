Proposed prepended Selection Mechanism between CS/PS and IMS domain This contribution proposes to define (in addition to the existing domain selection mechanism) a new domain selection mechanism for MT-SMS delivery which is prepended before the existing mechanism. Outcome of the new domain selection mechanism is either “IMS domain” in which case the Short Message is delivered via the IP-SM-GW, or “CS/PS domain” in which case the Short Message is delivered according to the existing domain selection. The new domain selection mechanism shall be distributed between IP-SM-GW and HLR as follows: The IP-SM-GW when receiving the REGISTER message from the S-CSCF selects either IMS-domain in which case it registers its own address at the HLR by sending the message IP-SM-GW Register Req (MAP_ANY_TIME_MODIFICATION), or CS/PS domain in which case it does not send the message IP-SM-GW Register Req (MAP_ANY_TIME_MODIFICATION) to the HLR.
