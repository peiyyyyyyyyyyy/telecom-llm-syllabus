# 2.3.2 允許範圍與單位

所屬：[2.3 表格與參數](2-3.md)

## 內文

規格中的允許範圍描述某個量在指定條件下能取的值。下限界定至少要達到的程度，上限界定不得超出的程度，而以標稱值為中心的容差描述實際值可以偏離多少。工程師在寫驗收門檻或分析測試報告時，要一起保留數字、正負號、單位與比較方向。只抄下數字，往往無法知道它在限制輸出、誤差、頻率位置還是量測設定。 [3GPP TS 38.104 V18.12.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf)

先把表名與量名分開讀。工作頻率、通道頻寬與次載波間隔都用頻率單位，但量的意思分別對應運作位置、通道規模與相鄰次載波的間距。MHz 與 kHz 的量級不同，跨欄比較前先換到同一單位，並保留原欄名。功率欄看到 dBm 時，以相對於毫瓦基準的功率位準解讀，看到 dB 時先查它表示哪兩個量的比例，例如相鄰通道功率比。寫最小值與最大值時照原文保留是否含邊界。表格出現 ± 時，要找中心所代表的標稱值或零誤差基準，確認上下兩個方向都允許同量偏差。碰到 ppm，還要查該比例作用在哪個參考量上，記下量測週期與其他適用條件。百分比欄則先查被比較的量與分母，例如調變誤差的百分比和功率誤差的比例各有定義。輸入欄位若可能由儀器自動換算，測試紀錄仍宜保留最初讀得的單位，讓後續人員能追溯換算。 [3GPP TS 38.104 V18.12.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf) [3GPP TS 38.101-1 V18.8.0](https://www.etsi.org/deliver/etsi_TS/138100_138199/13810101/18.08.00_60/ts_13810101v180800p.pdf)

以 TS 38.104 V18.12.0 的表 6.5.1.2-1 為例，從 §6.5.1.2 得知頻率誤差是在一毫秒期間觀察的載波頻率偏差，再到表內依基地台類別取限定值。Wide Area BS 欄對應 ±0.05 ppm，Medium Range BS 及 Local Area BS 對應 ±0.1 ppm。把第一列寫成驗收紀錄時，應記錄基地台類別、正負兩側的界值、原有單位以及觀察時間。若後續要換算成 Hz，還須知道實際所指的標稱載波頻率，因為相同 ppm 掛在不同載波上，得到的 Hz 差值也會不同。單獨把 ±0.05 交給測試人員，會同時漏掉比例單位、適用設備分類和量測時間。 [3GPP TS 38.104 V18.12.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf)

常見混淆包括把允許範圍當成儀器的顯示解析度、把功率位準與相對功率比視為同一量，以及看到負的 dBm 就把比較方向反轉。工程上還常遇到 dB 量的定義方向不同，因此比較前應先找清楚誰是分子、誰是分母。同樣的數字也可能分屬通道頻寬與次載波間隔，核對時應讀出整個欄名。 [3GPP TS 38.104 V18.12.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf) [3GPP TS 38.101-1 V18.8.0](https://www.etsi.org/deliver/etsi_TS/138100_138199/13810101/18.08.00_60/ts_13810101v180800p.pdf)

轉錄數字之前可依 2.3.1 固定適用的表列。看到註記、例外和表格依據的量測設定時，接著讀 2.3.3。若該數值要判定一致性測試結果，另見 2.3.7 的測試容差。 [3GPP TS 38.104 V18.12.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/138104/18.12.00_60/ts_138104v181200p.pdf) [3GPP TS 38.141-1 V19.4.0](https://www.etsi.org/deliver/etsi_ts/138100_138199/13814101/19.04.00_60/ts_13814101v190400p.pdf)
