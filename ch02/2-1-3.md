# 2.1.3 Release 與版本演進

所屬：[2.1 標準體系](2-1.md)

## 內文

Release 是一組可共同追蹤的標準演進基線。它讓終端、網路及測試人員用相容的功能範圍討論設計，但每份規格仍有自己的版本與更新歷程。寫採購需求、測試計畫或故障報告時，可先記錄業者採用的 Release，再為關鍵條款補上個別文件的完整版本，並從 Release 及工作項目資料確認功能何時納入、目前處於哪個階段。 [3GPP TR 21.900 V19.1.0 §§4.7、4.8](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [3GPP Portal Release 資料](https://portal.3gpp.org/Releases.aspx?SubTB=659&TabId=56&language=en-US&tbid=659)

Release 15 建立 5G NR 與 5G 系統的初始規格基礎，Release 16 擴充了高可靠度低延遲通訊及整合接取與回傳等功能。Release 17 增加 NR 衛星等非地面接取支援，並持續擴展業界應用。Release 18 是首個 5G-Advanced Release，Release 19 延續這條演進路徑，工作項目包括環境物聯網、非地面網路與移動性增強。Release 20 同時有 5G-Advanced 工作與 6G 研究，Release 21 已有 6G 服務需求的規範性工作項目。各版開始與結束日期、階段凍結及測試完備日期應分欄閱讀。凍結是對該階段新增內容與變更施加管制，允許的修正仍可走相應變更程序。技術或協定凍結之後，工程師仍需確認實作所用的規格版次，避免在同一 Release 中混用不同時間點的文字。 [3GPP TR 21.915 V15.0.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121915/15.00.00_60/tr_121915v150000p.pdf) [3GPP TR 21.916 V16.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121916/16.01.00_60/tr_121916v160100p.pdf) [3GPP TR 21.917 V17.0.1](https://www.etsi.org/deliver/etsi_tr/121900_121999/121917/17.00.01_60/tr_121917v170001p.pdf) [ETSI 工作計畫中的 Release 18、19 說明](https://www.etsi.org/images/files/WorkProgramme/ETSI-Work-Programme-2024-2025.pdf) [ETSI 的 3GPP 工作計畫簡報](https://www.etsi.org/wp-content/uploads/D31_ETSI3GPP_Cano_Soveri.pdf) [3GPP TR 21.900 V19.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf)

以 3GPP Portal 的正式 Releases 清單為例，先看 Status 和 End date。查核時，Release 15 至 19 均為 Frozen，列出的結束日依序為 2019-06-07、2020-07-03、2022-06-10、2024-06-21、2025-12-12。這是入口的 Release 層級日期，記錄時保留欄名，避免當成各組 ASN.1 或測試基線的日期。Release 20 列為 Open，End date 欄列 2027-06-18 為計畫日期。Release 21 同屬 Open，表中未列 End date。要追 6G 實際進展，可開啟官方工作項目，將 Release 20 的 FS_6G_REQ 研究與 Release 21 的 6G-REQ 規範性工作分開核對。 [3GPP Portal Releases 清單](https://portal.3gpp.org/Releases.aspx?SubTB=659&TabId=56&language=en-US&tbid=659) [3GPP FS_6G_REQ 工作項目](https://portal.3gpp.org/desktopmodules/WorkItem/WorkItemDetails.aspx?workitemId=1050110) [3GPP 6G-REQ 工作項目](https://portal.3gpp.org/desktopmodules/WorkItem/WorkItemDetails.aspx?workitemId=1110085)

凍結與停止維護是不同的狀態。凍結後可能仍有修訂版，因此只寫 Release 19 仍不足以還原當次引用。個別規格的版本上升與 Release 功能基線的演進也要分開追，改動可能只是修正或編輯。最後，研究中的功能與已納入規範的功能應分別標記，兩者的適用證據不同，設備或網路也可能只支援相應 Release 中的一部分選項。 [3GPP TR 21.900 V19.1.0 §§4.7、4.8](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [3GPP Portal Release 狀態](https://portal.3gpp.org/Releases.aspx?SubTB=659&TabId=56&language=en-US&tbid=659)

2.1.7 說明工作項目如何將研究接到規範交付。查到版本並需要確認變更時，見 2.2.6 的版號及變更請求。當文件日期或版本選擇與專案基線有差異，再依 2.6.2 尋找指定版本及生效條件。 [3GPP TR 21.900 V19.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [ETSI 的 3GPP 工作計畫簡報](https://www.etsi.org/wp-content/uploads/D31_ETSI3GPP_Cano_Soveri.pdf)
