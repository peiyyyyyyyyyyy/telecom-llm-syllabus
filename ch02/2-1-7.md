# 2.1.7 研究項目（SI）與工作項目（WI）

所屬：[2.1 標準體系](2-1.md)

## 內文

3GPP 把預計推進的工作登記為 Work Item（WI），其中 Study Item（SI）用來研究可行性、方案取捨或對現有系統的影響。研究的輸出為 Technical Report（TR），具規範化目標的後續工作可制訂 Technical Specification（TS）或修改既有規格。工程師查看開發計畫或評估還在形成中的功能時，應確認資料屬於研究結論、工作計畫、待核准改文，還是已發布的規範。 [3GPP TR 21.900 V19.1.0 §§2、6](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf)

成員提交 Work Item Description（WID）時，依工作性質送相應技術群組或工作組，經相關組別完善後，再交負責的技術群組採納。Study Item description（SID）依相同表單體系記載研究項目。查提案時先讀題名、代號、主責組別、提交及版本資訊，以定位同一份提案的不同修版。接著讀目的與範圍，確認必要的跨組工作、交付文件和排程安排，並從工作計畫查最新工作項目描述及已列出的規格影響範圍。Feature 可再拆成 Building Block 與 Work Task，追蹤時應同時查看上層功能和下層交付。研究完成後，若各方決定續作，應回查規範化工作的責任組、Release 及交付物，因為研究結果可能只涵蓋其中一部分。查既有文件改文時，再從工作項目代號找已核准的變更請求及納入版次。 [3GPP TR 21.900 V19.1.0 §§6、6.1](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [3GPP 研究項目紀錄 FS_6G_REQ](https://portal.3gpp.org/desktopmodules/WorkItem/WorkItemDetails.aspx?workitemId=1050110)

在 3GPP Portal 查看 FS_6G_REQ，先用工作項目代號和 UID 1050110 確認紀錄，再讀 Latest WID version 的 SP-241391 與 Release 20，最後查該頁產出規格清單所列的 22.870。接著打開 6G-REQ 的工作紀錄，對照 UID 1110085、SP-260323、Release 21 及該頁產出規格清單中的 22.270，並留意它們各自的組別及進度欄。這樣可以追出需求研究到規範工作的跨版本接續。若要在終端相容性文件寫某項能力為必備，仍需回到所採版次的規範段落，找適用條件和規範用語。 [3GPP FS_6G_REQ](https://portal.3gpp.org/desktopmodules/WorkItem/WorkItemDetails.aspx?workitemId=1050110) [3GPP 6G-REQ](https://portal.3gpp.org/desktopmodules/WorkItem/WorkItemDetails.aspx?workitemId=1110085)

SI 是 WI 的一種類型。SID 是研究提案描述的稱呼，Portal 的 Latest WID version 欄位亦可指向研究項目的提案文件。工作項目採納、研究報告刊行、規範變更納入各有紀錄，閱讀時應逐項標明所指的工作狀態。工作計畫上可能列出多份受影響規格，應按各份文件的版次及條文驗證實際落點。 [3GPP TR 21.900 V19.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [3GPP 的研究項目紀錄](https://portal.3gpp.org/desktopmodules/WorkItem/WorkItemDetails.aspx?workitemId=1050110)

想知道工作位在哪個 Release 的時間線，見 2.1.3。想從工作項目追到已寫進規範的變更，接續 2.2.6 和 2.4.7，核對變更請求及影響條文。 [3GPP Release 入口](https://portal.3gpp.org/Releases.aspx?SubTB=659&TabId=56&language=en-US&tbid=659) [3GPP TR 21.900 V19.1.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf)
