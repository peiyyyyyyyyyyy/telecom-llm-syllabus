## 練習題（6 題）

### GSMA 練習題（6 題）

**1.** Which layers are described in the 36.300 series? [3GPP Release 17]

- A. Layer 1 and Layer 2
- B. Layer 2 and Layer 3
- C. Layer 1 and Layer 3
- D. Only Layer 1
- E. Only Layer 3

<details><summary>看答案</summary>

正解：B　（GSMA `teleqna-train-3360`）

</details>

**2.** Which TS document includes the catalog of general security assurance requirements? [3GPP Release 14]

- A. TS 23.682
- B. TS 32.277
- C. TS 33.117
- D. TS 33.116
- E. TS 33.250

<details><summary>看答案</summary>

正解：C　（GSMA `teleqna-train-1444`）

</details>

**3.** Which 3GPP technical specification document focuses on the physical channels and modulation for 5G New Radio (NR) technology?

- A. 3GPP TS 28.541 V17.9.0 (2023-01)
- B. 3GPP TS 38.211 V17.4.0 (2022-12)
- C. 3GPP TS 28.542 V17.9.0 (2023-01)
- D. 3GPP TS 38.212 V17.4.0 (2022-12)

<details><summary>看答案</summary>

正解：B　（GSMA `oranbench-train-575`）

</details>

**4.** Which 3GPP technical specification defines the requirements for the 5G system?

- A. 3GPP TS 28.530
- B. 3GPP TS 28.541
- C. 3GPP TS 22.261
- D. 3GPP TS 28.552

<details><summary>看答案</summary>

</details>
