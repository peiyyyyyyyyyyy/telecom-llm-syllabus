# 2.2.2 規格編號與系列

所屬：[2.2 規格文件的結構](2-2.md)

## 內文

3GPP 規格編號的系列可以作為技術範圍的查找入口。工程師讀到只列規格號的變更單、會議資料或測試引用，可先靠系列分流，然後以完整編號、題名、適用範圍及版本鎖定文件。系列內仍有多種文件用途，例如架構、協定、測量、測試及研究成果，讀編號的重點是建立查找路徑，並找到與當前問題相關的條文。 [3GPP TR 21.900 V19.1.0 §4.0](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf)

3GPP TR 21.900 V19.1.0 §4.0 用 aa.bbb 表示基本編號，表 1 定義系列用途，表 2 提供後三位配置指引。按系列讀，21 涵蓋通用事項，22 找業務層需求，23 常見架構與技術實現，24 常見終端到核心網的詳細訊令。25 是早期無線接取相關文件，26 管編解碼，27 管資料應用支援，28 在歷史分配表有無線子系統到核心網訊令的用途，現行 28 系列也有管理與編排文件，29 常見核心網訊令。30 可找專案管理，31 是用戶識別模組及介面，32 涵蓋計費與維運，33 是安全，34 是測試，35 是演算法，36 是 LTE 無線接取，37 是多種無線接取技術的共同議題，38 是 NR。系列表容納歷史配置，因此透過封面與 Scope 核實文件內容。若編號有連字號和後綴，也一併保留，以免選到同族的其他部分。 [3GPP TR 21.900 V19.1.0 §4.0 表 1、表 2](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [3GPP TS 28.552 V19.6.0](https://www.etsi.org/deliver/etsi_ts/128500_128599/128552/19.06.00_60/ts_128552v190600p.pdf)

有一份 5G 系統資料只寫「23.501」，可開啟 ETSI 出版的 TS 123 501 V18.11.0，從封面確認它是 3GPP TS 23.501、Release 18，並由題名確認它是系統架構。接著從 §4 查參考架構及功能的配置。若問題來自一段終端註冊交換，可另看 TS 24.501 的適用對象和訊息條文。若查 NR 實體層量測，可在 TS 38.215 V18.4.0 §1 確認範圍。這三個號碼的前段協助判斷材料會落在架構、終端核心網協定或無線量測。引用最後選中的資料時，把完整號碼、版次及實際支持結論的段落一起記下。 [3GPP TS 23.501 V18.11.0 §4](https://www.etsi.org/deliver/etsi_ts/123500_123599/123501/18.11.00_60/ts_123501v181100p.pdf) [3GPP TS 24.501 V17.17.0](https://www.etsi.org/deliver/etsi_ts/124500_124599/124501/17.17.00_60/ts_124501v171700p.pdf) [3GPP TS 38.215 V18.4.0 §1](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.04.00_60/ts_138215v180400p.pdf)

系列號和 Release 版號扮演不同角色，同一規格系列可跨多個 Release。系列標籤也可能涵蓋多個工作組的內容，例如 38 系列包含量測及無線協定。確認維護組時，應查看規格的公開紀錄。遇到封面的 ETSI 編號，對照該封面明列的 3GPP 原編號及版本即可建立對應。 [3GPP TR 21.900 V19.1.0 §4](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf) [3GPP TS 38.215 V18.4.0 封面](https://www.etsi.org/deliver/etsi_ts/138200_138299/138215/18.04.00_60/ts_138215v180400p.pdf)

2.2.1 說明文件類型，2.4.7 接著示範如何從規格及變更資訊定位負責工作組。讀到封面版本或壓縮檔名時，另按 2.2.6 和 2.6.4 的規則解讀。 [3GPP TR 21.900 V19.1.0 §4](https://www.etsi.org/deliver/etsi_tr/121900_121999/121900/19.01.00_60/tr_121900v190100p.pdf)
