# 2.6.2 新舊版衝突時用哪一版

所屬：[2.6 引用規則](../2-6.md)

## 練習題

**1.** When a non‑specific reference is used, to which version does it implicitly refer?

- A. The earliest version of the referenced document across all Releases.
- B. The latest version of the referenced document *in the same Release* as the referring document.
- C. The version explicitly mentioned in the reference clause.
- D. Any version that the author prefers.

<details><summary>看答案</summary>

正解：B。The rule states the reference points to the latest version within the same Release.

</details>

**2.** When updating a specification that contains a non‑specific reference, what happens to the reference if a newer version of the referenced TS is released within the same Release?

- A. The reference must be edited to point to the new version explicitly.
- B. The reference automatically resolves to the newer version.
- C. The reference becomes invalid and must be removed.
- D. The reference continues to point to the original version forever.

<details><summary>看答案</summary>

正解：B。Because the reference is to the latest version in the same Release, it automatically picks up newer versions.

</details>
