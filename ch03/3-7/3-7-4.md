# 3.7.4 迴旋碼與 Viterbi 解碼

所屬：[3.7 資訊理論與編碼](../3-7.md)

## 練習題

**1.** In a binary rate‑$1/2$ convolutional code with constraint length $K=4$, how many distinct trellis states exist?

- A. 4
- B. 8
- C. 16
- D. 32

<details><summary>看答案</summary>

正解：B。The number of states is $2^{K-1}=2^{3}=8$.

</details>

**2.** Which of the following branch metrics is appropriate for hard‑decision Viterbi decoding on a binary symmetric channel?

- A. Euclidean distance between soft values
- B. Log‑likelihood ratio sum
- C. Hamming distance between received and expected bits
- D. Correlation coefficient

<details><summary>看答案</summary>

正解：C。Hard decisions reduce symbols to bits, so the metric is the Hamming distance.

</details>

**3.** When zero‑tail termination is applied to a convolutional encoder with memory $m$, how many extra bits are appended to the information sequence?

- A. $m$ zeros
- B. $K$ zeros
- C. $2m$ zeros
- D. No extra bits are needed

<details><summary>看答案</summary>

正解：A。Zero‑tail adds exactly $m = K-1$ zeros to force the encoder back to the all‑zero state.

</details>

**4.** For a convolutional code with memory $m = 3$ (i.e., constraint length $K = 4$), compute the total number of trellis states.  Unit: (dimensionless)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

The number of states equals $2^{m}$.  
$m = 3$ → $2^{3} = 8$.  
$\boxed{8}$

</details>

**5.** In hard‑decision Viterbi decoding, the branch metric is the Hamming distance. Given a received pair $(r_1,r_2) = (0,1)$ and a candidate encoder output $(c_1,c_2) = (1,1)$, compute the branch metric. Unit: bits


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

Compute the bitwise differences:  
$r_1 \neq c_1$ → 1 difference,  
$r_2 = c_2$ → 0 difference.  
Metric = $1 + 0 = 1$.  
$\boxed{1}$

</details>
