# 3.7.5 LDPC 碼

所屬：[3.7 資訊理論與編碼](../3-7.md)

## 練習題

**1.** Which property of the parity‑check matrix $\mathbf{H}$ is the defining characteristic of an LDPC code?

- A. It is square and invertible.
- B. It has a low density of ones (i.e., is sparse).
- C. All rows have the same weight.
- D. It contains a systematic identity sub‑matrix.

<details><summary>看答案</summary>

正解：B。LDPC stands for *Low‑Density* Parity‑Check; sparsity of $\mathbf{H}$ is the essential feature.

</details>

**2.** In a regular $(d_v,d_c)$ LDPC code of length $n$, the number of parity checks $m$ satisfies which relation?

- A. $m = n\,\frac{d_c}{d_v}$
- B. $m = n\,\frac{d_v}{d_c}$
- C. $m = n - d_v - d_c$
- D. $m = n\,\frac{d_v+d_c}{2}$

<details><summary>看答案</summary>

正解：B。Edge count equality $n d_v = m d_c$ gives $m = n d_v/d_c$.

</details>

**3.** During belief‑propagation decoding, which operation is performed at a check node to combine incoming messages?

- A. Simple summation of LLRs.
- B. Product of probabilities.
- C. $\tanh^{-1}$ of the product of $\tanh$ of half‑messages.
- D. Maximum of the incoming LLRs.

<details><summary>看答案</summary>

正解：C。The check‑node update uses the “box‑plus” rule: $\Lambda = 2\tanh^{-1}\!\bigl(\prod \tanh(M/2)\bigr)$.

</details>

**4.** A binary LDPC code has a parity‑check matrix of size $m=120$ rows and $n=300$ columns. What is the code rate $R$? (unitless)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

The rate is $R = 1 - m/n$. Compute $m/n = 120/300 = 0.4$. Hence $R = 1 - 0.4 = 0.6$. $\boxed{0.6}$

</details>

**5.** Consider a regular LDPC ensemble with variable node degree $d_v=3$ and check node degree $d_c=6$. If the block length is $n=1200$, determine the number of parity‑check equations $m$ and the code rate $R$ (unitless).


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

For a regular code, $n d_v = m d_c$. Solve for $m$: $m = n d_v / d_c = 1200*3/6 = 600$. Then $R = 1 - m/n = 1 - 600/1200 = 0.5$. $\boxed{0.5}$

</details>
