## 練習題

**1.** In the polar encoder $G_N = B_N\,F^{\otimes n}$, the matrix $B_N$ is:

- A. The $N\times N$ identity matrix.
- B. The $N\times N$ matrix that reverses the order of the rows only.
- C. The $N\times N$ bit‑reversal permutation matrix that simultaneously permutes rows and columns.
- D. The $N\times N$ matrix that adds a cyclic prefix to the codeword.

<details><summary>看答案</summary>

正解：C。$B_N$ implements the bit‑reversal permutation on the index order; both rows and columns are permuted accordingly, and it is essential for matching the synthetic‑channel ordering.

</details>

**2.** Compared with plain successive‑cancellation (SC) decoding, SC‑list (SCL) decoding with a CRC:

- A. Has the same error‑exponent but higher latency.
- B. Is optimal (maximum‑likelihood) for any list size $L\ge 1$.
- C. Provides a performance gain that grows with $L$, and a CRC allows selection of the correct path with high probability.
- D. Requires fewer arithmetic operations than SC because the list prunes branches early.

<details><summary>看答案</summary>

正解：C。SCL keeps $L$ candidate paths; a CRC lets the decoder pick the path that satisfies the CRC, yielding near‑ML performance that improves as $L$ increases.

</details>

**3.** For a binary erasure channel with erasure probability $\varepsilon=0.3$, block length $N=4$ ($n=2$), and $K=2$ information bits, compute the SC‑decoding upper bound $P_e\le\sum_{i\in\mathcal{A}} Z(W_N^{(i)})$, where $\mathcal{A}$ contains the $K$ synthetic channels with smallest Bhattacharyya parameters. Give the bound as a decimal number.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Start with $Z_0=\varepsilon=0.3$.  
2. First polarization step:  
   $Z^{(1)} = 2Z_0-Z_0^2 = 2(0.3)-0.3^2 = 0.51$ (bad channel)  
   $Z^{(2)} = Z_0^2 = 0.09$ (good channel)  
3. Second step applied to each of the two values:  

   - From $0.51$:  
     $Z^{(1)} = 2·0.51-0.51^2 = 0.7599$  
     $Z^{(2)} = 0.51^2 = 0.2601$  

   - From $0.09$:  
     $Z^{(1)} = 2·0.09-0.09^2 = 0.1719$  
     $Z^{(2)} = 0.09^2 = 0.0081$  

   The ordered list $[Z(W_4^{(i)})]$ is $[0.7599,0.2601,0.1719,0.0081]$.  

4. Choose the two smallest values for the information set $\mathcal{A}$: $0.0081$ and $0.1719$.  

5. Upper bound: $P_e \le 0.0081 + 0.1719 = 0.1800$.  

$\boxed{0.18}$

</details>

**4.** The successive‑cancellation decoder has computational complexity $\mathcal{O}(N\log N)$. For a polar code with block length $N=1024$, compute the exact number of elementary operations implied by the leading term $N\log_2 N$. Give the result as an integer.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. $N = 1024 = 2^{10}$.  
2. $\log_2 N = 10$.  
3. Multiply: $N\log_2 N = 1024 \times 10 = 10240$.  

$\boxed{10240}$

</details>
