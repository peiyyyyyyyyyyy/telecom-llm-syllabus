## 練習題

**1.** Which of the following statements about the Kraft inequality is true for any binary prefix code?

- A. $\displaystyle\sum_{x\in\mathcal{X}} 2^{\ell(x)} = 1$
- B. $\displaystyle\sum_{x\in\mathcal{X}} 2^{-\ell(x)} \le 1$
- C. $\displaystyle\sum_{x\in\mathcal{X}} \ell(x) = |\mathcal{X}|$
- D. $\displaystyle\sum_{x\in\mathcal{X}} p(x)\,\ell(x) = H(X)$

<details><summary>看答案</summary>

正解：B。The Kraft inequality for binary prefix codes requires the sum of $2^{-\ell(x)}$ over all codewords to be at most one; equality holds for a complete code.

</details>

**2.** For a memoryless source with entropy $H(X)=2.3$ bits/symbol, which of the following guarantees that a Huffman code will have an average length $L_{\text{avg}} \le 3.3$ bits/symbol?

- A. The source must have at most $2^{2.3}$ symbols.
- B. The source probabilities must all be powers of $\tfrac12$.
- C. Huffman coding always satisfies $L_{\text{avg}} < H(X)+1$.
- D. The source must be binary.

<details><summary>看答案</summary>

正解：C。Huffman coding satisfies the bound $H(X) \le L_{\text{avg}} < H(X)+1$, so $L_{\text{avg}} < 3.3$ bits/symbol follows directly.

</details>

**3.** Using the probabilities $p(A)=0.5$, $p(B)=0.2$, $p(C)=0.2$, $p(D)=0.1$, compute the average Huffman code length for the codewords A:0, B:101, C:100, D:11.  Give the answer in bits per symbol.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. List codeword lengths: $\ell(A)=1$, $\ell(B)=3$, $\ell(C)=3$, $\ell(D)=2$.  
2. Compute weighted sum: $L_{\text{avg}} = 0.5\cdot1 + 0.2\cdot3 + 0.2\cdot3 + 0.1\cdot2$.  
3. Evaluate: $0.5 + 0.6 + 0.6 + 0.2 = 1.9$.  
$\boxed{1.9}$

</details>

**4.** For the same source, encode the symbol sequence “A B D” with arithmetic coding. Provide the lower bound of the final interval $L_n$ (the left endpoint) in decimal.  Unit: none (dimensionless).


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

CDF: $F(A)=0$, $F(B)=0.5$, $F(C)=0.7$, $F(D)=0.9$.  
Start $[0,1)$.  
- After A: $L_1=0$, $U_1=0.5$.  
- After B: range $=0.5$, $L_2 = 0 + 0.5\times0.5 = 0.25$, $U_2 = 0 + 0.5\times0.7 = 0.35$.  
- After D: range $=0.35-0.25=0.1$, $L_3 = 0.25 + 0.1\times0.9 = 0.34$, $U_3 = 0.25 + 0.1\times1 = 0.35$.  
Thus the left endpoint $L_3 = 0.34$.  
$\boxed{0.34}$

</details>
