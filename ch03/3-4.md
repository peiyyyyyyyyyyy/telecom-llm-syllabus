## GSMA 例題（訓練集）

**【TeleMath】**

> Determine the normalized throughput for configuration B in a Time Division Multiple Access (TDMA) system, given parameters N_u = 20.0, an arrival rate λ of 1.0 packet per second, and a packet transmission time t_P of 0.02 seconds.

正解：0.4

---

**【TeleQnA】**

> Which multiple access scheme is suitable for traffic with low latency requirements?
>
> A. LTE-style four-way handshaking
> B. Fast-grant multiple access (FGMA)
> C. Immediate RRC connection (IRC)
> D. Semi-persistent scheduling
> E. Grant-free multiple access (GFMA)

正解：E. Grant-free multiple access (GFMA)

---

**【srsRANBench】**

> What does the `is_sr_opportunity_slot` function check for?
>
> A. Whether the UE has a valid ul_config.
> B. Whether the UE has a valid pucch_cfg.
> C. Whether the UE has a valid sr_res_list.
> D. Whether the slot point corresponds to an SR opportunity for the UE.

正解：D. Whether the slot point corresponds to an SR opportunity for the UE.
