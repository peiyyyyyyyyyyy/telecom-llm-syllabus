# 3.7.4 迴旋碼與 Viterbi 解碼

所屬：[3.7 資訊理論與編碼](3-7.md)

## 內文

#### 為什麼要學

迴旋碼（convolutional code）不把資料切成獨立的區塊，而是讓每一組輸出位元同時取決於目前的輸入與前幾個輸入，像一個帶記憶的濾波器。它搭配 Viterbi 解碼，是 GSM、第三代與第四代行動通訊控制通道、衛星通訊與無線區域網路長期使用的通道編碼。雖然 NR 的資料通道與控制通道已改用 LDPC 碼與 Polar 碼（3.7.5、3.7.6），但格狀圖（trellis）、分支度量、路徑度量與「每個狀態只留一條存活路徑」的想法，仍是理解序列偵測、等化器與軟性解碼的基礎。這一節的目標是能由生成多項式寫出編碼輸出，並在小型格狀圖上手算 Viterbi 的路徑度量。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $k$ | 每個時刻送進編碼器的資訊位元數（本節 $k=1$） | bit |
| $n$ | 每個時刻編碼器送出的位元數 | bit |
| $R=k/n$ | 碼率 | 無 |
| $m$ | 編碼器的記憶體（移位暫存器）個數 | 個 |
| $K$ | 約束長度，本節定義為 $K=m+1$ | bit |
| $u_t$ | 時刻 $t$ 的輸入位元 | 無 |
| $v_t^{(1)},\ v_t^{(2)}$ | 時刻 $t$ 的兩個輸出位元 | 無 |
| $g^{(1)},\ g^{(2)}$ | 生成多項式（常用八進位表示） | 無 |
| 狀態 | 暫存器內容 $(u_{t-1},u_{t-2})$，共 $2^{m}$ 種 | 無 |
| BM、PM | 分支度量、路徑度量（硬式判決時為漢明距離） | bit（位置數） |
| $d_{free}$ | 自由距離：任兩條相異碼序列的最小漢明距離 | bit（位置數） |

#### 公式與推導

**約束長度的定義。** 本節採用「一個輸出位元最多受幾個輸入位元影響」的定義：目前這一個輸入加上 $m$ 個暫存器裡的舊輸入，所以 $K=m+1$。Proakis、Sklar 等通訊教科書與多數行動通訊規格採用這種寫法。也有文獻把記憶體個數 $m$ 本身，或 $n(m+1)$ 稱為約束長度，讀資料時要先確認定義，否則狀態數會差一倍。

**編碼。** 標準例子是碼率 $1/2$、$K=3$、生成多項式 $(7,5)$ 八進位的碼。$7_8=111_2$、$5_8=101_2$，由左到右依序對應 $u_t,\ u_{t-1},\ u_{t-2}$ 的接線：

$$v_t^{(1)} = u_t\oplus u_{t-1}\oplus u_{t-2},\qquad v_t^{(2)} = u_t\oplus u_{t-2}$$

暫存器有 $m=2$ 個，狀態數 $2^{m}=2^{K-1}=4$。每輸入 1 位元輸出 2 位元，碼率 $R=1/2$。為了讓解碼器知道終點狀態，通常在 $L$ 個資訊位元後面補 $m$ 個 0（尾位元），把編碼器帶回全零狀態；這時實際碼率變成

$$R_{\text{eff}}=\frac{L}{n(L+m)}$$

$L$ 很大時趨近 $1/n$。

**狀態轉移。** 把上式對四個狀態逐一代入，得到格狀圖每一段的分支（狀態寫成 $u_{t-1}u_{t-2}$）：

| 目前狀態 | 輸入 0：輸出／下一狀態 | 輸入 1：輸出／下一狀態 |
|---|---|---|
| 00 | 00／00 | 11／10 |
| 10 | 10／01 | 01／11 |
| 01 | 11／00 | 00／10 |
| 11 | 01／01 | 10／11 |

**Viterbi 解碼。** 解碼的目標是在格狀圖上找出與接收序列最接近的那一條路徑（最大概似序列）。硬式判決時，分支度量是該分支的輸出與這一段接收位元的漢明距離；路徑度量是沿途分支度量的累加。每個時刻對每個狀態做「加、比、選」：

$$PM_t(s)=\min_{s'\to s}\big[PM_{t-1}(s')+BM_t(s'\to s)\big]$$

進入同一狀態的路徑只保留度量最小的一條（存活路徑），其餘丟掉。丟掉的路徑之後不論怎麼走，都不可能比存活路徑好，所以結果仍是最佳解，而計算量只和狀態數 $2^{K-1}$ 成正比，不隨序列長度指數成長。軟式判決時把漢明距離換成歐氏距離或對數概似比的相關值，做法相同，效能較好。

**更正能力。** $(7,5)$ 碼的自由距離 $d_{free}=5$（例如輸入 $1,0,0$ 產生 $11,10,11$，重量 5，之後回到全零狀態）。只要錯誤夠分散，可更正 $\lfloor(d_{free}-1)/2\rfloor=2$ 個錯誤。

#### 算例

**算例 1（編碼）** 已知資訊位元 $1,0,1,1$，後面補 2 個尾位元 0，起始狀態 00。求輸出序列與實際碼率。

逐步代入（狀態為 $u_{t-1}u_{t-2}$）：

| $t$ | 輸入 | 目前狀態 | $v^{(1)}$ | $v^{(2)}$ | 下一狀態 |
|---|---|---|---|---|---|
| 1 | 1 | 00 | $1\oplus0\oplus0=1$ | $1\oplus0=1$ | 10 |
| 2 | 0 | 10 | $0\oplus1\oplus0=1$ | $0\oplus0=0$ | 01 |
| 3 | 1 | 01 | $1\oplus0\oplus1=0$ | $1\oplus1=0$ | 10 |
| 4 | 1 | 10 | $1\oplus1\oplus0=0$ | $1\oplus0=1$ | 11 |
| 5 | 0 | 11 | $0\oplus1\oplus1=0$ | $0\oplus1=1$ | 01 |
| 6 | 0 | 01 | $0\oplus0\oplus1=1$ | $0\oplus1=1$ | 00 |

輸出為 $11\ 10\ 00\ 01\ 01\ 11$，共 12 位元。實際碼率 $R_{\text{eff}}=4/(2\times 6)=1/3$。合理性檢查：最後回到狀態 00；每一列的輸出都和上面的狀態轉移表一致。

**算例 2（Viterbi 路徑度量）** 資訊位元 $1,0,1$ 加 2 個尾位元，依同樣方法編碼得 $11\ 10\ 00\ 10\ 11$。假設通道把第 4 個位元翻轉，收到 $11\ 11\ 00\ 10\ 11$。用硬式判決 Viterbi 解碼。

每一格寫「候選度量 ← 來自哪個狀態」，粗體為存活者；最後兩段是尾位元，只走輸入 0 的分支。

| $t$（接收） | 狀態 00 | 狀態 10 | 狀態 01 | 狀態 11 |
|---|---|---|---|---|
| 1（11） | **2**←00 | **0**←00 | — | — |
| 2（11） | **4**←00 | **2**←00 | **1**←10 | **1**←10 |
| 3（00） | 4←00、**3**←01 | 6←00、**1**←01 | 3←10、**2**←11 | 3←10、**2**←11 |
| 4（10） | 4←00、**3**←01 | — | **1**←10、4←11 | — |
| 5（11） | 5←00、**1**←01 | — | — | — |

以 $t=3$ 的狀態 10 為例：由狀態 00 輸入 1 的分支輸出 11，與接收的 00 差 2，候選 $4+2=6$；由狀態 01 輸入 1 的分支輸出 00，差 0，候選 $1+0=1$；取 1。

回溯：終點狀態 00 的存活者來自 01（$t=4$），再往前是 10（$t=3$）、01（$t=2$）、10（$t=1$）、00。狀態序列 $00\to10\to01\to10\to01\to00$ 對應輸入 $1,0,1,0,0$，去掉尾位元得 $1,0,1$，與原資訊一致。

合理性檢查：最後的路徑度量是 1，正好等於通道造成的錯誤個數；1 個錯誤小於可更正的 2 個，解碼成功是預期中的結果。

#### 常見錯誤

- 把約束長度和記憶體個數混用。$K=3$ 的碼只有 2 個暫存器、4 個狀態，不是 8 個狀態。
- 八進位轉二進位後接線方向弄反。本節的對應是最左邊接 $u_t$；$(7,5)$ 因為 $111$、$101$ 左右對稱看不出差別，換成不對稱的多項式就會算錯。
- 算碼率時忘了尾位元。短序列的實際碼率明顯低於 $1/n$（算例 1 是 $1/3$ 而不是 $1/2$）。
- Viterbi 每一步沒有對「每個狀態」各自比較，而是只留全域最小的那一條；這樣會把之後可能勝出的路徑提早丟掉。

#### 和其他小節的關係

漢明距離與更正能力的觀念來自 3.7.3。分支度量換成軟性資訊時，要用到 3.2.3 的調變與錯誤率模型。NR 以 3.7.5 的 LDPC 碼與 3.7.6 的 Polar 碼取代迴旋碼與渦輪碼；3.7.7 的 HARQ 則在解碼失敗時補救。

**3.7.4G001**　A rate-1/2 convolutional encoder has constraint length $K = 7$, where $K = m + 1$ and $m$ is the number of memory (shift-register) elements. Determine the number of states in its trellis.

\boxed{64}

**出處**　Proakis & Salehi, Digital Communications (convolutional codes; state diagram and trellis)

</details>

**3.7.4G002**　A rate-1/3 convolutional encoder with one input bit per step has constraint length $K = 9$, defined as $K = m + 1$ with $m$ memory elements. Determine the total number of branches in one full stage of its trellis (all states, all input values).

<details><summary>看答案</summary>

**答案**　512

**詳解**　$m = 9 - 1 = 8$, so there are $2^8 = 256$ states. Each state has 2 outgoing branches (input 0 or 1). Branches per stage $= 256 \times 2 = 512$.
\boxed{512}

**出處**　Proakis & Salehi, Digital Communications (trellis representation of convolutional codes)

</details>

**3.7.4G003**　A rate-1/2 convolutional code has generator polynomials 561 and 753 in octal notation. The leftmost nonzero binary digit of the longest generator taps the current input bit, and each further digit taps one older input bit. Determine the number of memory (shift-register) elements in the encoder.

<details><summary>看答案</summary>

**答案**　8

**詳解**　Convert each octal digit to 3 bits: $561_8 = 101\,110\,001$ and $753_8 = 111\,101\,011$. Both have 9 binary digits with a leading 1, so each output depends on the current input plus 8 older inputs: $K = 9$ and memory $m = K - 1 = 8$.
\boxed{8}

**出處**　Lin & Costello, Error Control Coding (convolutional codes; generator sequences)

</details>

**3.7.4G004**　A rate-2/3 convolutional encoder takes 2 input bits per step. The first input stream feeds a shift register with 2 memory elements and the second feeds a shift register with 1 memory element. The encoder state is the contents of all memory elements. Determine the number of trellis states.

<details><summary>看答案</summary>

**答案**　8

**詳解**　Total memory $\nu = 2 + 1 = 3$ bits. Number of states $= 2^{\nu} = 2^3 = 8$. (Each state has $2^2 = 4$ outgoing branches, one per pair of input bits.)
\boxed{8}

**3.7.4G005**　A reference defines the constraint length of a rate-$1/n$ convolutional code as $n_A = n(m+1)$, the number of coded bits that a single input bit can influence, where $m$ is the number of memory elements. #### 單題：Code rate and trellis termination

**3.7.4G006**　A block of 40 information bits is encoded with a rate-1/2 convolutional code with $K = 7$ ($K = m + 1$) and terminated with $m$ zero tail bits, which are also encoded. Determine the effective code rate, rounded to four decimal places.

**3.7.4G007**　A 40-bit message is encoded with a rate-1/3, $K = 7$ ($K = m + 1$) convolutional code. **3.7.4G008**　A rate-1/2 convolutional code with $K = 9$ ($K = m + 1$) is terminated with $m$ encoded zero tail bits. Determine the smallest number of information bits $L$ per block for which the effective code rate $L/[2(L + m)]$ is at least 0.49.
