# 3.4.6 多重存取：FDMA、TDMA、CDMA、OFDMA

所屬：[3.4 訊務與存取](../3-4.md)

## 正文

In a shared communication medium the central problem is *how to let many users transmit simultaneously without destroying each other’s information*. Multiple‑access (MA) techniques answer this question by partitioning the available resources—frequency, time, code, or a combination—into orthogonal or quasi‑orthogonal slices that can be assigned to individual users. The choice of MA scheme determines the achievable **spectral efficiency**, the **complexity of the radio**, and the **interference management** required in a real network (cellular, satellite, WLAN, or IoT).

Below we present the four classical MA families that dominate modern telecom standards, give the essential formulas, and illustrate their use with a short numerical example.

---

### 1. Frequency Division Multiple Access (FDMA)

*Concept*: The total spectrum of width $B_{\text{tot}}$ (Hz) is split into $N$ non‑overlapping channels, each of bandwidth $B_{\text{c}}$ (Hz). A guard band $B_{\text{g}}$ (Hz) separates adjacent channels to limit adjacent‑channel interference.

*Key formulas*  

$$
\boxed{N = \left\lfloor \frac{B_{\text{tot}}}{B_{\text{c}}+B_{\text{g}}}\right\rfloor}
\tag{1}
$$

where $\lfloor\cdot\rfloor$ denotes the integer part.  
If each user transmits at a data rate $R$ (bit s$^{-1}$), the **spectral efficiency** (bit s$^{-1}$ Hz$^{-1}$) is

$$
\boxed{\eta_{\text{FDMA}} = \frac{N\,R}{B_{\text{tot}}}}
\tag{2}
$$

*Units*: $B_{\text{tot}}, B_{\text{c}}, B_{\text{g}}$ in Hz; $R$ in bit s$^{-1}$; $\eta$ in bit s$^{-1}$ Hz$^{-1}$.

---

### 2. Time Division Multiple Access (TDMA)

*Concept*: Users share a common carrier but are assigned distinct time slots within a repeating frame of duration $T_{\text{f}}$ (s). Each slot lasts $T_{\text{s}}$ (s); the number of slots per frame is

$$
\boxed{N = \frac{T_{\text{f}}}{T_{\text{s}}}}
\tag{3}
$$

A guard time $T_{\text{g}}$ may be inserted to absorb timing jitter.

If a user transmits $b$ bits per slot, the per‑user throughput is

$$
\boxed{R = \frac{b}{T_{\text{f}}}}
\tag{4}
$$

*Units*: $T_{\text{f}}, T_{\text{s}}, T_{\text{g}}$ in seconds; $b$ in bits; $R$ in bit s$^{-1}$.

---

### 3. Code Division Multiple Access (CDMA)

*Concept*: All users occupy the *entire* bandwidth simultaneously, but each multiplies its data by a unique spreading code of length $L$. The **processing gain** is

$$
\boxed{G_{\text{p}} = \frac{W}{R}}
\tag{5}
$$

where $W$ (Hz) is the spread bandwidth and $R$ (bit s$^{-1}$) the uncoded data rate. Under the **interference‑limited** assumption, the approximate maximum number of users is

$$
\boxed{N \approx \frac{W/R}{\left(E_b/N_0\right)_{\text{req}}}}
\tag{6}
$$

with $\left(E_b/N_0\right)_{\text{req}}$ expressed as a linear ratio (not dB). Equation (6) follows from the requirement that each user’s energy‑per‑bit to interference‑plus‑noise density must exceed the target value.

*Units*: $W$ in Hz, $R$ in bit s$^{-1}$, $\left(E_b/N_0\right)_{\text{req}}$ dimensionless.

---

### 4. Orthogonal Frequency Division Multiple Access (OFDMA)

*Concept*: OFDMA is the MA extension of OFDM. The total bandwidth is divided into $K$ orthogonal sub‑carriers, each of spacing $\Delta f$ (Hz). A sub‑carrier’s bandwidth equals $\Delta f = 1/T_{\text{u}}$, where $T_{\text{u}}$ is the useful OFDM symbol duration (excluding the cyclic prefix). A user $i$ is allocated a set of $n_i$ sub‑carriers; its achievable rate is

$$
\boxed{R_i = n_i \,\Delta f \,\log_2\!\bigl(1+\mathrm{SNR}_i\bigr)}
\tag{7}
$$

If a cyclic prefix of length $T_{\text{cp}}$ is added, the *effective* symbol duration becomes $T_{\text{sym}} = T_{\text{u}}+T_{\text{cp}}$, reducing the usable fraction to $\frac{T_{\text{u}}}{T_{\text{sym}}}$.

*Units*: $\Delta f$ in Hz, $\mathrm{SNR}_i$ linear, $R_i$ in bit s$^{-1}$.

---

### Worked Example – FDMA Capacity

A narrow‑band IoT (NB‑IoT) uplink operates over a total carrier of $B_{\text{tot}} = 10\;\text{MHz}$. Each device requires a 25 kHz channel and a 5 kHz guard band on each side.

1. Compute the bandwidth per user: $B_{\text{unit}} = 25\;\text{kHz} + 5\;\text{kHz} = 30\;\text{kHz}$.  
2. Apply (1):  

$$
N = \left\lfloor \frac{10\,\text{MHz}}{30\,\text{kHz}} \right\rfloor
  = \left\lfloor \frac{10\,000\,\text{kHz}}{30\,\text{kHz}} \right\rfloor
  = \left\lfloor 333.33 \right\rfloor = 333\;\text{users}.
$$

If each user transmits at $R = 50\;\text{kbit s}^{-1}$,

$$
\eta_{\text{FDMA}} = \frac{333 \times 50\,000}{10\,000\,000}
                  = \frac{16\,650\,000}{10\,000\,000}
                  = 1.665\;\text{bit s}^{-1}\!\text{Hz}^{-1}.
$$

Thus the system can support 333 simultaneous NB‑IoT devices with a modest spectral efficiency.

---

### Practical Notes & Common Pitfalls

| Pitfall | Why it matters | Remedy |
|---------|----------------|--------|
| **Neglecting guard bands** in FDMA calculations | Overestimates the number of channels; adjacent‑channel interference spikes. | Always include a realistic guard (typically 5–20 % of the channel bandwidth). |
| **Assuming perfect orthogonality in CDMA** | Real spreading codes have non‑zero cross‑correlation, raising the effective interference. | Use a margin (e.g., 1–2 dB) on $\left(E_b/N_0\right)_{\text{req}}$ or rely on system‑level simulations. |
| **Forgetting the cyclic prefix overhead** in OFDMA | Reduces the net data rate because a portion of each OFDM symbol carries no payload. | Multiply the raw rate (7) by the factor $\frac{T_{\text{u}}}{T_{\text{u}}+T_{\text{cp}}}$. |
| **Treating TDMA slots as completely independent** | In practice, timing drift and propagation delay cause slot overlap, especially in satellite links. | Allocate a guard time $T_{\text{g}}$ and synchronize with a network‑wide timing reference. |
| **Using Shannon capacity directly for CDMA** | The linear model (6) ignores power control, near‑far effects, and multipath fading. | Apply (6) as a first‑order estimate; refine with link‑budget and simulation. |

Understanding the trade‑offs among these MA schemes enables engineers to select the appropriate technique for a given service (voice, broadband, massive IoT) and to dimension the radio resources accurately.

## 練習題

**1.** In an FDMA system the total available bandwidth is 15 MHz. Each user is assigned a 100 kHz channel and a 10 kHz guard band on each side of the channel. How many users can be supported simultaneously (ignoring any other overhead)?

- A. 125
- B. 150
- C. 136
- D. 111

<details><summary>看答案</summary>

正解：C。The bandwidth per user is 100 kHz + 10 kHz = 110 kHz. 15 MHz / 110 kHz = 136.36, so the integer number of users is ⌊136.36⌋ = 136.

</details>

**2.** An FDMA system has a total bandwidth of 20 MHz. Each channel occupies 200 kHz and a guard band of 10 kHz is placed between adjacent channels. Every user transmits at 100 kbit s⁻¹. Compute the spectral efficiency (bit s⁻¹ Hz⁻¹) of the system.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Bandwidth per user = channel + guard = 200 kHz + 10 kHz = 210 kHz.  
2. Number of users $N = \left\lfloor \dfrac{20\,\text{MHz}}{210\,\text{kHz}} \right\rfloor = \left\lfloor 95.238 \right\rfloor = 95$.  
3. Total carried bit rate = $N \times R = 95 \times 100\,000 = 9\,500\,000$ bit s⁻¹.  
4. Spectral efficiency $\eta = \dfrac{9\,500\,000}{20\,000\,000} = 0.475$ bit s⁻¹ Hz⁻¹.  
$$$\boxed{0.475}$$$

</details>

**3.** In an OFDMA system the total bandwidth is 10 MHz and the sub‑carrier spacing is 15 kHz. A user is allocated 20 sub‑carriers. The SNR on each allocated sub‑carrier is 10 dB. The useful OFDM symbol duration is $T_u = 1/\Delta f$ and the cyclic prefix length is 5 µs. Determine the achievable data rate for the user (bit s⁻¹). Ignore any higher‑layer overhead.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Sub‑carrier spacing $\Delta f = 15\,\text{kHz} = 15\,000$ Hz.  
2. Useful symbol duration $T_u = 1/\Delta f = 1/15\,000 = 66.666\;\mu\text{s}$.  
3. Effective symbol factor $\frac{T_u}{T_u+T_{cp}} = \frac{66.666}{66.666+5} = 0.930232558$.  
4. Linear SNR: $10\;\text{dB} = 10^{10/10}=10$.  
5. Per‑sub‑carrier spectral efficiency $\log_2(1+SNR) = \log_2(11) = 3.459431618$ bit/s/Hz.  
6. Rate before CP overhead: $R_{\text{raw}} = n_i \Delta f \log_2(1+SNR) = 20 \times 15\,000 \times 3.459431618 = 1\,037\,829.4856$ bit s⁻¹.  
7. Apply CP overhead: $R = R_{\text{raw}} \times 0.930232558 = 965\,422.8206$ bit s⁻¹.  
$$$\boxed{965422.8206}$$$

</details>
