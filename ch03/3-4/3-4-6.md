# 3.4.6 多重存取：FDMA、TDMA、CDMA、OFDMA

所屬：[3.4 訊務與存取](../3-4.md)

## 練習題

**1.** An FDMA system has a total bandwidth of 20 MHz. Each channel occupies 200 kHz and a guard band of 10 kHz is placed between adjacent channels. Every user transmits at 100 kbit s⁻¹. Compute the spectral efficiency (bit s⁻¹ Hz⁻¹) of the system.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Bandwidth per user = channel + guard = 200 kHz + 10 kHz = 210 kHz.  
2. Number of users $N = \left\lfloor \dfrac{20\,\text{MHz}}{210\,\text{kHz}} \right\rfloor = \left\lfloor 95.238 \right\rfloor = 95$.  
3. Total carried bit rate = $N \times R = 95 \times 100\,000 = 9\,500\,000$ bit s⁻¹.  
4. Spectral efficiency $\eta = \dfrac{9\,500\,000}{20\,000\,000} = 0.475$ bit s⁻¹ Hz⁻¹.  
$$$\boxed{0.475}$$$

</details>

**2.** In an OFDMA system the total bandwidth is 10 MHz and the sub‑carrier spacing is 15 kHz. A user is allocated 20 sub‑carriers. The SNR on each allocated sub‑carrier is 10 dB. The useful OFDM symbol duration is $T_u = 1/\Delta f$ and the cyclic prefix length is 5 µs. Determine the achievable data rate for the user (bit s⁻¹). Ignore any higher‑layer overhead.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Sub‑carrier spacing $\Delta f = 15\,\text{kHz} = 15\,000$ Hz.  
2. Useful symbol duration $T_u = 1/\Delta f = 1/15\,000 = 66.666\;\mu\text{s}$.  
3. Effective symbol factor $\frac{T_u}{T_u+T_{cp}} = \frac{66.666}{66.666+5} = 0.930232558$.  
4. Linear SNR: $10\;\text{dB} = 10^{10/10}=10$.  
5. Per‑sub‑carrier spectral efficiency $\log_2(1+SNR) = \log_2(11) = 3.459431618$ bit/s/Hz.  
6. Rate before CP overhead: $R_{\text{raw}} = n_i \Delta f \log_2(1+SNR) = 20 \times 15\,000 \times 3.459431618 = 1\,037\,829.4856$ bit s⁻¹.  
7. Apply CP overhead: $R = R_{\text{raw}} \times 0.930232558 = 965\,422.8206$ bit s⁻¹.  
$$$\boxed{965422.8206}$$$

</details>
