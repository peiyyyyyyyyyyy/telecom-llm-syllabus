# 3.4.2 Erlang B／C：阻塞機率與等待機率

所屬：[3.4 訊務與存取](../3-4.md)

## 練習題

**1.** Which of the following statements correctly describes the Erlang B model?

- A. It assumes blocked calls are placed in an infinite FIFO queue.
- B. It assumes blocked calls are cleared (lost) immediately.
- C. It requires the offered traffic $E$ to be less than the number of servers $c$.
- D. It provides the average waiting time of a call in seconds.

<details><summary>看答案</summary>

正解：B。Erlang B models a pure loss system where a call that finds all $c$ servers busy is cleared; there is no waiting.

</details>

**2.** The Erlang C formula (3) is valid only under which condition?

- A. $E > c$
- B. $E = c$
- C. $E < c$
- D. $c = 1$

<details><summary>看答案</summary>

正解：C。For a finite average waiting time the offered load must be less than the number of servers; otherwise the queue would diverge.

</details>

**3.** Which relationship correctly links Erlang B and Erlang C probabilities?

- A. $C = B \times \frac{c}{E}$
- B. $C = \frac{B}{1-\frac{E}{c}\bigl(1-B\bigr)}$
- C. $C = B^{2}$
- D. $C = 1 - B$

<details><summary>看答案</summary>

正解：B。Equation (4) shows the exact conversion from blocking probability $B$ to waiting probability $C$.

</details>

**4.** A base station receives $\lambda = 0.15$ call attempts per second. The average call holding time is $H = 120\,$s. The station has $c = 10$ voice channels. Compute the blocking probability $B$ using Erlang B. (Answer as a decimal, three‑digit precision.)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Compute traffic $E = \lambda H = 0.15 \times 120 = 18$ Erlangs.  
2. Use the recursive formula (2):  

   $B_1 = \frac{18}{1+18}=0.947368$  

   $B_2 = \frac{18 B_1}{2+18 B_1}=0.8955$  

   … continue up to $c=10$:  

   $B_{10}\approx 0.4938$.  

3. Round to three decimal places: $\boxed{0.494}$

</details>

**5.** Offered traffic is $E = 6$ Erlangs and the system provides $c = 8$ identical servers. Determine the probability that a new call must wait (Erlang C). (Answer as a decimal, three‑digit precision.)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Compute Erlang B for $E=6$, $c=8$ via recursion:  

   $B_1 = 6/7 = 0.8571$  

   $B_2 = 0.7200$  

   $B_3 = 0.5900$  

   $B_4 = 0.4690$  

   $B_5 = 0.3600$  

   $B_6 = 0.2650$  

   $B_7 = 0.1850$  

   $B_8 = 0.1220$  

2. Apply conversion (4):  

   $C = \frac{B}{1-\frac{E}{c}(1-B)} = \frac{0.122}{1-0.75(1-0.122)} \approx 0.3575$.  

3. Rounded to three decimals: $\boxed{0.358}$

</details>
