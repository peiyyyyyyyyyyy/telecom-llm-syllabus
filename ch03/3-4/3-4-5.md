## 正文

In any communication system the *quality of service* perceived by the user is largely determined by two intertwined performance metrics: **delay** (or latency) and **throughput**. Delay measures how long a packet or call spends from the instant it is generated until it is successfully delivered; throughput measures how much useful data the system can transport per unit time. Network designers must balance these quantities: a link that offers high peak throughput may suffer excessive queuing delay under heavy load, while a system engineered for low latency may sacrifice spectral efficiency.

---

### 1. Fundamental definitions  

| Symbol | Meaning | Unit |
|--------|---------|------|
| $ \lambda $ | **Arrival rate** – average number of traffic units (calls, packets) entering the system per second | s$^{-1}$ |
| $ \mu $ | **Service rate** – average number of traffic units that can be served per second by a single server | s$^{-1}$ |
| $ c $ | Number of parallel servers (e.g., channels, processors) | – |
| $ \rho $ | **Utilization** – offered load per server, $ \rho = \frac{\lambda}{c\mu} $ | – |
| $ L $ | **Average number of units in the system** (waiting + in service) | – |
| $ L_q $ | **Average number waiting in queue** (excluding those in service) | – |
| $ W $ | **Average total delay** (waiting + service) per unit | s |
| $ W_q $ | **Average waiting time** in queue (excluding service) | s |
| $ X $ | **Throughput** – effective departure rate, equal to the arrival rate for a stable system | s$^{-1}$ |
| $ K $ | System capacity (maximum number of units allowed, including those in service) | – |
| $ P_{\text{loss}} $ | **Loss probability** – probability an arriving unit is blocked because the system is full | – |

All symbols are dimensionless unless indicated; rates are expressed in **Erlangs** when the traffic unit is a voice call (1 Erlang = 1 call × hour⁻¹), but the same notation applies to packet arrivals when expressed in s$^{-1}$.

---

### 2. Little’s Law  

For any *stable* queuing system (arrival rate equals departure rate, $ \lambda = X $) the following relationship holds, regardless of the arrival or service time distribution:

$$
L = \lambda \, W ,\qquad L_q = \lambda \, W_q .
$$

Thus, once two of the three quantities are known, the third follows immediately. Little’s law is the cornerstone for linking **throughput** and **delay**.

---

### 3. Classical queueing results  

#### 3.1 M/M/1 (single‑server, exponential inter‑arrival & service)

- **Utilization:** $\displaystyle \rho = \frac{\lambda}{\mu}$, stability requires $\rho < 1$.
- **Average number in system:** $\displaystyle L = \frac{\rho}{1-\rho}$.
- **Average delay (including service):**  
  $$
  W = \frac{1}{\mu - \lambda} = \frac{1}{\mu(1-\rho)} .
  $$
- **Average waiting time in queue:** $W_q = \frac{\rho}{\mu - \lambda}$.

Throughput equals the arrival rate ($X = \lambda$) because no losses occur.

#### 3.2 M/M/c (c parallel servers)

Define the **traffic intensity** $a = \lambda / \mu$ (in Erlangs). Utilization per server is $\rho = a / c$; stability requires $\rho < 1$.

The probability that an arrival must wait (the Erlang‑C formula) is

$$
P_{\text{wait}} = \frac{\displaystyle \frac{a^{c}}{c!}\,\frac{c\mu}{c\mu-\lambda}}
{\displaystyle \sum_{k=0}^{c-1}\frac{a^{k}}{k!} + \frac{a^{c}}{c!}\,\frac{c\mu}{c\mu-\lambda}} .
$$

Average waiting time in queue:

$$
W_q = \frac{P_{\text{wait}}}{c\mu-\lambda}.
$$

Total delay $W = W_q + \frac{1}{\mu}$.

Throughput again equals $\lambda$ (lossless system).

#### 3.3 M/M/1/K (finite buffer of size $K$)

When the system can hold at most $K$ units (including the one in service), arrivals finding a full system are blocked. The **blocking probability** (also the loss probability) is given by the Erlang‑B formula:

$$
P_{\text{loss}} = \frac{\displaystyle \frac{a^{K}}{K!}}
{\displaystyle \sum_{k=0}^{K}\frac{a^{k}}{k!}} ,
\qquad a = \frac{\lambda}{\mu}.
$$

Effective throughput is reduced:

$$
X = \lambda \,(1-P_{\text{loss}}).
$$

The average number in the system $L$ is obtained from the state probabilities $P_n$; then delay follows from Little’s law:

$$
W = \frac{L}{X}.
$$

---

### 4. Worked example  

**Scenario:** A cellular base station provides $c = 3$ identical voice channels. Each channel can serve $\mu = 0.9$ calls s$^{-1}$ (average call duration 1.11 s). Calls arrive as a Poisson process at $\lambda = 2.1$ calls s$^{-1}$.

**Step 1 – Utilization per server**  
$$
a = \frac{\lambda}{\mu} = \frac{2.1}{0.9}=2.333\;\text{Erlangs},\qquad
\rho = \frac{a}{c}= \frac{2.333}{3}=0.777 < 1.
$$

**Step 2 – Compute $P_{\text{wait}}$ (Erlang‑C)**  

$$
\begin{aligned}
\text{Denominator } D &= \sum_{k=0}^{2}\frac{a^{k}}{k!} + \frac{a^{3}}{3!}\,\frac{c\mu}{c\mu-\lambda}\\
&= 1 + \frac{2.333}{1} + \frac{2.333^{2}}{2} + \frac{2.333^{3}}{6}\,\frac{2.7}{2.7-2.1}\\
&\approx 1 + 2.333 + 2.722 + 2.12 = 8.175 .
\end{aligned}
$$

$$
\text{Numerator } N = \frac{a^{3}}{3!}\,\frac{c\mu}{c\mu-\lambda}
\approx 2.12 .
$$

$$
P_{\text{wait}} = \frac{N}{D} \approx \frac{2.12}{8.175}=0.259 .
$$

**Step 3 – Average waiting time**  

$$
W_q = \frac{P_{\text{wait}}}{c\mu-\lambda}
= \frac{0.259}{2.7-2.1}
= \frac{0.259}{0.6}=0.432\;\text{s}.
$$

**Step 4 – Total delay**  

$$
W = W_q + \frac{1}{\mu}=0.432 + \frac{1}{0.9}=0.432+1.111=1.543\;\text{s}.
$$

**Step 5 – Throughput**  

Because no calls are dropped, $X = \lambda = 2.1$ calls s$^{-1}$.

**Interpretation:** On average a caller experiences 1.54 s of delay (including the 1.11 s talk time) before the call is set up. The system operates at 77.7 % utilization; a modest increase in offered load would raise $P_{\text{wait}}$ sharply, illustrating the classic *delay–throughput trade‑off*.

---

### 5. Common pitfalls and practical notes  

| Pitfall | Why it occurs | Correct practice |
|---------|---------------|------------------|
| **Confusing $\rho$ with $P_{\text{loss}}$** | Both are probabilities, but $\rho$ measures *utilization* while $P_{\text{loss}}$ measures *blocking*. | Compute each from the appropriate formula; never replace one with the other. |
| **Applying M/M/1 formulas to a multi‑server system** | The presence of $c>1$ changes the waiting‑time distribution. | Use Erlang‑C for $c$ parallel servers; verify $\rho < 1$. |
| **Ignoring finite buffer effects** | In practice, many routers have limited queue depth, causing losses that reduce throughput. | When $K$ is small, employ M/M/1/K; adjust $X = \lambda(1-P_{\text{loss}})$. |
| **Using Little’s law with an unstable system** | If $\lambda \ge \mu$ (or $\rho \ge 1$), the system never reaches steady state; $L$ and $W$ diverge. | Check stability first; if violated, redesign capacity or apply admission control. |
| **Miscalculating units** | Mixing Erlangs (calls·hour⁻¹) with s$^{-1}$ leads to factor‑3600 errors. | Convert consistently: 1 Erlang = 1/3600 calls s$^{-1}$. |

*Practical tip*: In cellular network planning, engineers often fix a target **mean call setup delay** (e.g., < 200 ms) and then back‑calculate the maximum admissible traffic per cell using the Erlang‑C formula. The same methodology applies to packet networks when targeting latency for latency‑sensitive services (e.g., URLLC).

**3.** In an M/M/3 system, $\lambda = 90$ packets s$^{-1}$, $\mu = 50$ packets s$^{-1}$ per server. Compute the average waiting time in queue $W_q$ (seconds), using the Erlang‑C formula. (Round to three decimals.)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

Compute traffic intensity $a = \lambda/\mu = 90/50 = 1.8$ Erlangs. Utilization per server $\rho = a/c = 1.8/3 = 0.6$.  

Denominator $D = \sum_{k=0}^{c-1} a^{k}/k! + a^{c}/c! \cdot c\mu/(c\mu-\lambda)$.  

Calculate terms:  
$k=0$: $1$  
$k=1$: $a = 1.8$  
$k=2$: $a^{2}/2 = (1.8^{2})/2 = 3.24/2 = 1.62$  

Sum = $1 + 1.8 + 1.62 = 4.42$  

Now $a^{c}/c! = 1.8^{3}/6 = 5.832/6 = 0.972$  

$c\mu = 3 \times 50 = 150$, $c\mu-\lambda = 150-90 = 60$  

Extra term = $0.972 \times 150/60 = 0.972 \times 2.5 = 2.43$  

Denominator $D = 4.42 + 2.43 = 6.85$  

Numerator $N = 0.972 \times 150/60 = 2.43$  

$P_{\text{wait}} = N/D = 2.43/6.85 = 0.3547$  

$W_q = P_{\text{wait}}/(c\mu-\lambda) = 0.3547/60 = 0.0059117$ s ≈ $0.0059$ s. $\boxed{0.0059}$

</details>
