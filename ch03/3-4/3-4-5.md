# 3.4.5 延遲與吞吐量分析

所屬：[3.4 訊務與存取](../3-4.md)

## 練習題

**1.** An M/M/1 queue has $\lambda = 120$ calls h$^{-1}$ and $\mu = 180$ calls h\(^{-1}$. Compute the average total delay $W$ in seconds. (Answer in seconds, rounded to two decimals.)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

Convert rates to per second: $\lambda = 120/3600 = 0.03333\,$s\(^{-1}$, $\mu = 180/3600 = 0.05\,$s$^{-1}$. Utilization $\rho = \lambda/\mu = 0.6667$. For M/M/1, $W = 1/(\mu-\lambda) = 1/(0.05-0.03333) = 1/0.01667 = 60$ s. $\boxed{60.00}$

</details>

**2.** In an M/M/3 system, $\lambda = 90$ packets s$^{-1}$, $\mu = 50$ packets s$^{-1}$ per server. Compute the average waiting time in queue $W_q$ (seconds), using the Erlang‑C formula. (Round to three decimals.)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

Compute traffic intensity $a = \lambda/\mu = 90/50 = 1.8$ Erlangs. Utilization per server $\rho = a/c = 1.8/3 = 0.6$.  

Denominator $D = \sum_{k=0}^{c-1} a^{k}/k! + a^{c}/c! \cdot c\mu/(c\mu-\lambda)$.  

Calculate terms:  
$k=0$: $1$  
$k=1$: $a = 1.8$  
$k=2$: $a^{2}/2 = (1.8^{2})/2 = 3.24/2 = 1.62$  

Sum = $1 + 1.8 + 1.62 = 4.42$  

Now $a^{c}/c! = 1.8^{3}/6 = 5.832/6 = 0.972$  

$c\mu = 3 \times 50 = 150$, $c\mu-\lambda = 150-90 = 60$  

Extra term = $0.972 \times 150/60 = 0.972 \times 2.5 = 2.43$  

Denominator $D = 4.42 + 2.43 = 6.85$  

Numerator $N = 0.972 \times 150/60 = 2.43$  

$P_{\text{wait}} = N/D = 2.43/6.85 = 0.3547$  

$W_q = P_{\text{wait}}/(c\mu-\lambda) = 0.3547/60 = 0.0059117$ s ≈ $0.0059$ s. $\boxed{0.0059}$

</details>
