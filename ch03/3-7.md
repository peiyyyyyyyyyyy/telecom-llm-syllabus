## GSMA 例題（訓練集）

**【TeleQnA】**

> What is the main objective of Blind Source Separation (BSS)?
>
> A. To estimate the mixing matrix
> B. To estimate the sources signals
> C. To estimate the demixing matrix
> D. To estimate the random vector
> E. To estimate the dimensions of the data matrix

正解：B. To estimate the sources signals

**【TeleMath】**

> Determine the efficiency of a Huffman binary code for a quaternary memoryless source with an alphabet Ax = {0, 1, 2, 3} and a probability mass distribution (PMD) given by px(0) = 0.2, px(1) = 0.2, px(2) = 0.3, px(3) = 0.3.

正解：0.9854752972273341

**【TeleQnA】**

> What is the definition of the differential entropy of a set of random variables?
>
> A. H(X1, X2, ..., Xn) = ∫f(x1, x2, ..., xn) log(f(x1, x2, ..., xn)) dx1 dx2 ... dxn
> B. H(X1, X2, ..., Xn) = -∫f(x1, x2, ..., xn) log(f(x1, x2, ..., xn)) dx1 dx2 ... dxn
> C. H(X1, X2, ..., Xn) = ∫f(x1, x2, ..., xn) log(2/f(x1, x2, ..., xn)) dx1 dx2 ... dxn
> D. H(X1, X2, ..., Xn) = -∫f(x1, x2, ..., xn) log(1/f(x1, x2, ..., xn)) dx1 dx2 ... dxn

正解：B. H(X1, X2, ..., Xn) = -∫f(x1, x2, ..., xn) log(f(x1, x2, ..., xn)) dx1 dx2 ... dxn
