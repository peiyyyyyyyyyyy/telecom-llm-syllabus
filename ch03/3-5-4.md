# 3.5.4 隨機過程：卜瓦松過程、馬可夫鏈、高斯過程

所屬：[3.5 基礎數理](3-5.md)

## 內文

#### 為什麼要學

隨機變數描述「某一刻」的不確定性，隨機過程（stochastic process）描述不確定性如何隨時間演變。電信裡最常用的有三種。卜瓦松過程描述通話或連線請求的到達，是話務理論與排隊模型的起點。馬可夫鏈（Markov chain）描述在有限個狀態之間跳動的系統，例如通道在「好」與「壞」之間切換造成成串錯誤，或用戶設備在閒置與連線狀態之間轉移；由轉移機率可以算出長期停留在各狀態的時間比例。高斯過程則是熱雜訊的模型，接收機分析中的「加成性白高斯雜訊」就是它的特例。掌握這三種過程，才能讀懂排隊、通道模型與雜訊分析的假設。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $N(t)$ | 到時刻 $t$ 為止的累計到達數 | 個 |
| $\lambda$ | 卜瓦松過程的到達率 | 個/秒（或個/分、個/時） |
| $T$ | 相鄰兩次到達的間隔時間 | 秒 |
| $X_n$ | 馬可夫鏈在第 $n$ 步的狀態 | 無單位 |
| $p_{ij}$ | 由狀態 $i$ 一步轉移到狀態 $j$ 的機率 | 無單位 |
| $\mathbf{P}$ | 轉移矩陣，第 $i$ 列第 $j$ 行是 $p_{ij}$，每列和為 1 | 無單位 |
| $\boldsymbol\pi$ | 穩態（平穩）分布，列向量 | 無單位 |
| $R_X(\tau)$ | 自相關函數 | $X$ 單位的平方 |
| $N_0/2$ | 白雜訊的雙邊功率頻譜密度 | W/Hz |

#### 公式與推導

**卜瓦松過程。** 到達率為 $\lambda$ 的卜瓦松過程滿足：不重疊時段內的到達數互相獨立；長度為 $t$ 的時段內到達數服從平均為 $\lambda t$ 的卜瓦松分布，

$$P\big(N(t) = k\big) = \frac{(\lambda t)^k e^{-\lambda t}}{k!}$$

令 $k = 0$ 得到「$t$ 時間內沒有到達」的機率 $e^{-\lambda t}$，這也就是到達間隔 $T$ 大於 $t$ 的機率，所以 $T$ 服從指數分布，平均為 $1/\lambda$。指數分布具有無記憶性：已經等了多久，不影響還要再等多久。另外兩個常用性質：獨立的卜瓦松過程合併後仍是卜瓦松過程，到達率相加；以固定機率 $p$ 獨立地篩選到達，篩出來的仍是卜瓦松過程，到達率為 $p\lambda$。這個模型適合「大量用戶各自獨立、每人發起機率很小」的情境，對突發性強的數據流量不一定適用。

**離散時間馬可夫鏈。** 馬可夫性質是指下一步的狀態只和目前狀態有關，和更早的歷史無關：$P(X_{n+1} = j\mid X_n = i,\dots) = p_{ij}$。若目前的狀態分布是列向量 $\boldsymbol\pi^{(n)}$，則下一步是 $\boldsymbol\pi^{(n+1)} = \boldsymbol\pi^{(n)}\mathbf{P}$，$m$ 步的轉移機率是 $\mathbf{P}^m$。穩態分布是轉移後不再改變的分布：

$$\boldsymbol\pi = \boldsymbol\pi\,\mathbf{P},\qquad \sum_i \pi_i = 1$$

對於狀態數有限、任兩個狀態可以互相到達（不可約）且非週期的鏈，穩態分布唯一，且不論初始狀態為何，分布都會收斂到它；$\pi_i$ 也是長期下來停留在狀態 $i$ 的時間比例。兩狀態鏈若 $p_{12} = p$、$p_{21} = q$，解平衡式 $\pi_1 p = \pi_2 q$ 得

$$\pi_1 = \frac{q}{p+q},\qquad \pi_2 = \frac{p}{p+q}$$

每一步以機率 $q$ 離開狀態 2，所以連續停留在狀態 2 的步數服從幾何分布，平均為 $1/q$ 步。

**高斯過程。** 若任取有限個時刻，過程在這些時刻的取值都服從聯合高斯分布，就稱為高斯過程。它完全由平均函數與自相關函數決定；廣義平穩（平均為常數、自相關只和時間差 $\tau$ 有關）的高斯過程同時也是嚴格平穩的；高斯過程通過線性濾波器後仍是高斯過程。白高斯雜訊的功率頻譜密度在所有頻率上為常數 $N_0/2$（雙邊），通過等效雜訊頻寬為 $B$ 的濾波器後，輸出雜訊功率是 $N_0B$。

#### 算例

**算例 1：連線請求的到達。** 已知（假設）：某細胞的連線請求為卜瓦松過程，每小時 120 次。求 1 分鐘內沒有請求的機率、相鄰兩次請求間隔超過 30 秒的機率、3 分鐘內恰好 6 次請求的機率。

1. 換單位：$\lambda = 120/60 = 2$ 次/分。
2. 1 分鐘內沒有請求：$\lambda t = 2$，$P = e^{-2} = 0.1353$。
3. 間隔超過 30 秒：$t = 0.5$ 分，$\lambda t = 1$，$P(T > 0.5) = e^{-1} = 0.3679$。
4. 3 分鐘內恰好 6 次：$\lambda t = 6$，$P = 6^6e^{-6}/6! = 46656\times0.0024788/720 = 0.1606$。

合理性檢查：平均間隔是 $1/\lambda = 0.5$ 分鐘，間隔超過平均值的機率是 $e^{-1}\approx37\%$ 而不是 50%，因為指數分布右偏。3 分鐘的平均到達數就是 6，而恰好等於平均值的機率只有 16%，標準差為 $\sqrt6\approx2.45$ 次，說明短時間的到達數波動很大。

**算例 2：兩狀態通道（Gilbert–Elliott 模型）。** 已知（假設）：通道每個時槽處於「好」或「壞」狀態；好轉壞的機率 $p = 0.1$，壞轉好的機率 $q = 0.4$；好狀態的封包錯誤率為 0.01，壞狀態為 0.5。求穩態分布、壞狀態的平均持續長度、長期平均封包錯誤率，以及由好狀態出發兩步後仍在好狀態的機率。

1. 轉移矩陣（狀態順序：好、壞）：$\mathbf{P} = \begin{bmatrix}0.9 & 0.1\\ 0.4 & 0.6\end{bmatrix}$。
2. 穩態：$\pi_{\text{好}} = q/(p+q) = 0.4/0.5 = 0.8$，$\pi_{\text{壞}} = 0.1/0.5 = 0.2$。
3. 壞狀態平均持續 $1/q = 1/0.4 = 2.5$ 個時槽。
4. 平均封包錯誤率 $= 0.8\times0.01 + 0.2\times0.5 = 0.008 + 0.100 = 0.108$。
5. 兩步後仍為好：$(\mathbf{P}^2)_{\text{好,好}} = 0.9\times0.9 + 0.1\times0.4 = 0.85$。

合理性檢查：驗算 $\boldsymbol\pi\mathbf{P}$：第一個分量 $0.8\times0.9 + 0.2\times0.4 = 0.80$，第二個分量 $0.8\times0.1 + 0.2\times0.6 = 0.20$，確實不變。由好狀態出發，停在好狀態的機率依序是 1、0.9、0.85，三步後是 $0.85\times0.9 + 0.15\times0.4 = 0.825$，逐步靠近 0.8，每步與穩態值的差距都減半（0.2、0.1、0.05、0.025）。平均錯誤率 10.8% 幾乎全部來自只佔 20% 時間的壞狀態，而且錯誤會成串出現，這是獨立錯誤模型描述不出來的。

#### 常見錯誤

- 把轉移矩陣的方向弄反。本章採用「列是目前狀態、行是下一個狀態、每列和為 1」，穩態式是 $\boldsymbol\pi\mathbf{P} = \boldsymbol\pi$（列向量乘在左邊）。
- 到達率與時間的單位沒有對齊，例如用每小時的 $\lambda$ 乘上以分鐘計的 $t$。
- 把穩態機率當成短期機率使用。剛離開某個狀態後的幾步內，分布還沒有收斂。
- 認為卜瓦松到達是「等間隔」到達。它的間隔是指數分布，會有密集的時段，也會有很長的空檔。

#### 和其他小節的關係

卜瓦松到達是 3.4.1～3.4.3 的 Erlang 公式與 M/M/1 等排隊模型的假設，也是 3.4.4 ALOHA 分析的前提；穩態向量與收斂速度的矩陣算法見 3.5.7；在馬可夫鏈上加入動作與報酬就成為 3.5.6 的馬可夫決策過程；白高斯雜訊的功率計算接到 3.1.5 與 3.1.7。
