# 3.3.4 接收靈敏度

所屬：[3.3 鏈路預算](3-3.md)

## 內文

#### 為什麼要學

鏈路預算的另一端是接收機：訊號再弱，只要還高過某個門檻，就能以要求的錯誤率或吞吐量解出來，這個門檻就是接收靈敏度（receiver sensitivity）。它決定鏈路能承受多少路徑損耗，數值每改善 1 dB，可容許的路徑損耗就多 1 dB。靈敏度不是憑空指定的數字，而是由三個物理量疊出來的：熱雜訊在接收頻寬內的總功率、接收機自己多加的雜訊（雜訊指數）、以及解調與解碼所需的訊號雜訊比。3GPP 對基地臺與終端規定的參考靈敏度（reference sensitivity）也是同一個結構，會拆這條式子，就能判斷一個靈敏度數字合不合理，以及頻寬、調變編碼方式改變時它會怎麼動。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $k$ | 波茲曼常數，$1.380649\times10^{-23}$ | J/K |
| $T$ | 參考雜訊溫度，慣例取 290 | K |
| $N_0$ | 熱雜訊功率頻譜密度，$N_0 = kT$ | W/Hz 或 dBm/Hz |
| $B$ | 接收訊號所占的雜訊頻寬 | Hz |
| $NF$ | 接收機雜訊指數（noise figure） | dB |
| $\text{SNR}_{\text{req}}$ | 達到目標錯誤率或吞吐量所需的訊號雜訊比（解調器輸入端） | dB，可為負值 |
| $N$ | 折算到接收機輸入端的等效雜訊功率 | dBm |
| $S_{\min}$ | 接收靈敏度：接收機輸入端所需的最小訊號功率 | dBm |
| $N_{\text{RB}}$ | 配置的資源區塊（resource block）數 | 個 |

#### 公式與推導

熱雜訊在頻寬 $B$ 內的功率是 $kTB$（見 3.1.5）。先算每赫茲的密度，取 $T = 290$ K：

$$N_0 = kT = 1.380649\times10^{-23}\times290 = 4.0039\times10^{-21}\ \text{W/Hz}$$

換成 dBm/Hz（1 mW $=10^{-3}$ W）：

$$N_0 = 10\log_{10}\!\left(\frac{4.0039\times10^{-21}}{10^{-3}}\right) = -173.98\ \text{dBm/Hz} \approx -174\ \text{dBm/Hz}$$

接收機內部的放大器與混頻器會再加入雜訊，效果等同把輸入端的雜訊功率放大 $F$ 倍（$NF = 10\log_{10}F$）。因此折算到輸入端的等效雜訊功率是

$$N = -174 + 10\log_{10}B + NF\quad(\text{dBm；}B\text{ 以 Hz 計})$$

要讓解調器得到至少 $\text{SNR}_{\text{req}}$，輸入訊號功率必須比 $N$ 高出這麼多（$\text{SNR}_{\text{req}}$ 為負時則是可以比 $N$ 低），於是

$$S_{\min} = -174 + 10\log_{10}B + NF + \text{SNR}_{\text{req}}\quad(\text{dBm})$$

各項的正負號與單位如下：$-174$ 是 dBm/Hz，為 $-173.98$ 的取位值，兩者只差 0.02 dB，下面的算例用 $-173.98$ 計算；$10\log_{10}B$ 是把 Hz 換成 dB 的頻寬項，恆為正，頻寬加倍多 3.01 dB；$NF$ 是正的 dB 值；$\text{SNR}_{\text{req}}$ 是 dB，低碼率搭配低階調變時可以是負值。結果是負的 dBm，**數值越負代表靈敏度越好**。

適用條件與提醒：（1）式子假設雜訊是白色的、接收機前端為線性，且天線看到的雜訊溫度接近 290 K；（2）$B$ 是訊號實際占用的頻寬，不是標稱通道頻寬，例如 NR 以 15 kHz 子載波間隔配置 $N_{\text{RB}}$ 個資源區塊時，$B = N_{\text{RB}}\times12\times15\ \text{kHz} = N_{\text{RB}}\times180$ kHz；（3）式子只考慮熱雜訊，若有干擾，要另外加干擾餘量（3.3.3）；（4）實作損失若沒有包含在 $\text{SNR}_{\text{req}}$ 內，要另加一項；多支接收天線合成帶來的增益則會使所需訊號功率下降，應另列為增益項，不要混進 $NF$。

#### 算例

**算例 1（終端下行靈敏度）**　已知：通道頻寬 20 MHz、子載波間隔 15 kHz，依 TS 38.101-1 表 5.3.2-1 最大配置為 106 個資源區塊；終端雜訊指數 7 dB（假設）；所需 SNR 為 −1 dB（假設）。

1. 頻寬：$B = 106\times180\ \text{kHz} = 19.08$ MHz，$10\log_{10}(19.08\times10^6) = 72.81$ dB。
2. 熱雜訊功率：$-173.98 + 72.81 = -101.17$ dBm。
3. 加雜訊指數：$-101.17 + 7 = -94.17$ dBm。
4. 加所需 SNR：$S_{\min} = -94.17 + (-1) = -95.17$ dBm。

換成線性：$10^{-9.517}\ \text{mW} = 3.04\times10^{-10}$ mW，約 0.30 pW。合理性檢查：若用整數 −174 計算會得到 −95.19 dBm，只差 0.02 dB；靈敏度落在熱雜訊（−101.17 dBm）之上 6 dB，正是 $NF + \text{SNR}_{\text{req}} = 7 - 1$ 的結果。

**算例 2（由 3GPP 參考靈敏度反推）**　已知：TS 38.104 表 7.2.2-1 規定廣域基地臺（Wide Area BS）在通道頻寬 5、10、15 MHz、15 kHz 子載波間隔、參考量測通道 G-FR1-A1-1 下的參考靈敏度為 −101.7 dBm；同一份規格表 A.1-1 載明該參考通道配置 25 個資源區塊、QPSK、碼率 1/3。求這個數字隱含的 $NF + \text{SNR}_{\text{req}}$。

1. 頻寬：$B = 25\times180\ \text{kHz} = 4.5$ MHz，$10\log_{10}(4.5\times10^6) = 66.53$ dB。
2. 熱雜訊功率：$-173.975 + 66.532 = -107.44$ dBm。
3. 差值：$-101.7 - (-107.44) = 5.74$ dB。

也就是說，這項最低要求相當於「雜訊指數、該參考通道所需 SNR 與實作餘量」合計約 5.7 dB。合理性檢查：QPSK、碼率 1/3 所需的 SNR 在 0 dB 上下，剩下幾 dB 留給接收機雜訊指數，量級合理。要注意規格值是測試用的最低要求，實際產品通常優於此值；規格並未在該表中把 5.7 dB 拆成各項，拆法屬於推估。

#### 常見錯誤

- **頻寬單位沒換成 Hz**：把 20 MHz 當成 20 代入，$10\log_{10}B$ 只得 13 dB，少了 60 dB。
- **用通道頻寬而不是占用頻寬**：窄頻配置（例如只配幾個資源區塊）的雜訊頻寬小得多，靈敏度會好很多；上行鏈路預算尤其要注意。
- **正負號方向弄反**：$NF$ 與正的 $\text{SNR}_{\text{req}}$ 都讓靈敏度數值變大（變差）；看到「−110 dBm 比 −100 dBm 好」要能立即反應。
- **把 −174 dBm/Hz 當成不變的常數**：它是 290 K 的值；另外 −174 是 dBm/Hz，若改用 dBW/Hz 則是 −204。

#### 和其他小節的關係

$kTB$ 與雜訊指數的定義、多級串接的總雜訊指數見 3.1.5；$\text{SNR}_{\text{req}}$ 與調變編碼方式的關係可對照 3.1.6 與 3.2 各小節。干擾存在時要搭配 3.3.3 的干擾餘量。本節的 $S_{\min}$ 會直接代入 3.3.5 的最大允許路徑損耗，並在 3.3.6 分別計算終端與基地臺兩端。
