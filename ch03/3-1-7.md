# 3.1.7 訊號與頻譜分析：傅立葉轉換、功率頻譜密度、自相關

所屬：[3.1 訊號與通道](3-1.md)

## 內文

#### 為什麼要學

通訊系統的規格幾乎都寫在頻率域：載波頻寬、頻譜遮罩、鄰頻洩漏、每赫茲的雜訊密度。頻譜分析儀上看到的也是功率隨頻率的分布。要把時間上的波形（脈衝多寬、符號多長）和頻率上的占用（主瓣多寬、旁瓣多高）對起來，靠的是傅立葉轉換（Fourier transform）；要描述雜訊這類隨機訊號在各頻率上的功率，靠的是功率頻譜密度（power spectral density, PSD）和自相關函數（autocorrelation function）。本節重點放在會算、會判讀：由脈衝寬度估頻寬、由 PSD 積分求功率、由頻譜儀讀值換算通道功率。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $x(t)$ | 時間訊號 | V（或任意振幅單位） |
| $X(f)$ | $x(t)$ 的傅立葉轉換 | V/Hz（即 V·s） |
| $f$、$t$、$\tau$ | 頻率、時間、時間差 | Hz、s、s |
| $T$ | 脈衝寬度或符號長度 | s |
| $R_x(\tau)$ | 自相關函數 | V²（功率型訊號，以 1 Ω 為基準） |
| $S_x(f)$ | 功率頻譜密度 | W/Hz（或 dBm/Hz） |
| $H(f)$ | 線性非時變系統的頻率響應 | 無因次 |
| $P$ | 平均功率 | W（或 dBm） |
| $N_0$ | 白雜訊的單邊功率頻譜密度 | W/Hz |
| $B$ | 頻寬 | Hz |
| $\text{RBW}$ | 頻譜分析儀的解析頻寬（resolution bandwidth） | Hz |
| $\text{sinc}(x)$ | $\sin(\pi x)/(\pi x)$ | 無因次 |

#### 公式與推導

**傅立葉轉換對**（本章採用以頻率 $f$ 為變數的寫法）：

$$X(f) = \int_{-\infty}^{\infty} x(t)\,e^{-j2\pi ft}\,dt,\qquad x(t) = \int_{-\infty}^{\infty} X(f)\,e^{j2\pi ft}\,df$$

計算與判讀時最常用的性質：

| 性質 | 時間域 | 頻率域 |
|---|---|---|
| 線性 | $a\,x_1(t) + b\,x_2(t)$ | $a\,X_1(f) + b\,X_2(f)$ |
| 時間平移 | $x(t - t_0)$ | $X(f)\,e^{-j2\pi ft_0}$（只改相位，不改振幅頻譜） |
| 頻率平移（調變） | $x(t)\,e^{j2\pi f_ct}$ | $X(f - f_c)$ |
| 尺度變換 | $x(at)$ | $\dfrac{1}{\lvert a\rvert}X\!\left(\dfrac{f}{a}\right)$（時間壓縮，頻譜展寬） |
| 摺積 | $x(t) * h(t)$ | $X(f)\,H(f)$ |
| 相乘 | $x(t)\,y(t)$ | $X(f) * Y(f)$ |

能量守恆（Parseval 定理）：$\int\lvert x(t)\rvert^2dt = \int\lvert X(f)\rvert^2df$。最重要的一組轉換對是寬度 $T$、高度 1 的矩形脈衝：

$$\text{rect}\!\left(\frac{t}{T}\right)\ \longleftrightarrow\ T\,\text{sinc}(fT)$$

它的頻譜在 $f = \pm1/T, \pm2/T, \dots$ 為零：脈衝越窄，頻譜越寬，時間寬度與頻寬成反比。OFDM 正是利用這一點：有效符號長度 $T_u$ 的子載波頻譜是 sinc 形，零點間隔 $1/T_u$，把子載波間隔取成 $\Delta f = 1/T_u$，每個子載波的峰值就落在其他子載波的零點上而互相正交；例如 TS 38.211 表 4.2-1 的 30 kHz 子載波間隔對應 $T_u = 1/30000 = 33.33$ μs。

**功率頻譜密度與自相關。** 對廣義穩態的隨機訊號，自相關函數 $R_x(\tau) = E[x(t)\,x(t+\tau)]$ 只和時間差有關，PSD 是它的傅立葉轉換（Wiener–Khinchin 定理）：

$$S_x(f) = \int_{-\infty}^{\infty} R_x(\tau)\,e^{-j2\pi f\tau}\,d\tau,\qquad P = R_x(0) = \int_{-\infty}^{\infty} S_x(f)\,df$$

訊號通過頻率響應為 $H(f)$ 的線性系統後，$S_y(f) = \lvert H(f)\rvert^2S_x(f)$。白雜訊的 PSD 是常數：雙邊寫法為 $N_0/2$（正負頻率都算），單邊寫法為 $N_0$（只算正頻率），兩種寫法積分出來的功率相同。白雜訊通過頻寬 $B$ 的理想低通濾波器後，功率是 $N_0B$，自相關是 $R(\tau) = N_0B\,\text{sinc}(2B\tau)$，第一個零點在 $\tau = 1/(2B)$：頻寬越寬，雜訊在時間上「記得自己」的時間越短。

**頻寬的幾種定義**要先講清楚再比較：零點到零點頻寬（主瓣寬度）、3 dB 頻寬（PSD 降到峰值一半的寬度）、占用頻寬（包含總功率某個百分比的寬度，無線電規則常用 99%，即上下各留 0.5% 在外）、等效雜訊頻寬（和實際濾波器通過相同白雜訊功率的理想矩形濾波器寬度）。同一個訊號用不同定義得到的數字可以差好幾倍。

**PSD 平坦時的功率換算**：$P(\text{dBm}) = S(\text{dBm/Hz}) + 10\log_{10}B_{\text{Hz}}$。

#### 算例

**算例 1：矩形脈衝的頻譜**

已知：寬度 $T = 1$ μs 的矩形基頻脈衝。求頻譜第一個零點、調變到載波後的零點到零點頻寬、基頻的 3 dB 點，以及第一旁瓣相對主瓣的高度。

- 第一零點：$f = 1/T = 1$ MHz。
- 調變到載波後頻譜平移到 $f_c$ 兩側，零點到零點頻寬為 $2/T = 2$ MHz。
- 3 dB 點：解 $\text{sinc}^2(fT) = 0.5$ 得 $fT = 0.443$，即 $f = 443$ kHz；調變後的 3 dB 頻寬為 $2\times443 = 886$ kHz，不到零點到零點頻寬的一半。
- 第一旁瓣：峰值出現在 $fT \approx 1.43$，$\lvert\text{sinc}(1.43)\rvert = 0.2172$，$20\log_{10}0.2172 = -13.26$ dB。
- 合理性檢查：若脈衝縮短為 0.1 μs，各頻率數字都變 10 倍（零點在 10 MHz），符合尺度變換性質；旁瓣只比主瓣低 13 dB 左右，說明未經整形的矩形脈衝頻譜洩漏嚴重，實際系統需要脈衝整形或濾波。

**算例 2：由頻譜分析儀讀值換算通道功率**

已知（假設值）：頻譜分析儀的解析頻寬為 100 kHz，在一個 20 MHz 寬、頻譜大致平坦的訊號上，游標讀到 −80 dBm。求功率頻譜密度與整個 20 MHz 的通道功率。

- PSD：$-80 - 10\log_{10}(10^5) = -80 - 50 = -130$ dBm/Hz。
- 通道功率：$-130 + 10\log_{10}(20\times10^6) = -130 + 73.01 = -56.99$ dBm。
- 另一種算法：頻寬比 $20\ \text{MHz}/100\ \text{kHz} = 200$，$10\log_{10}200 = 23.01$ dB，$-80 + 23.01 = -56.99$ dBm，一致。
- 合理性檢查：通道功率一定比單一解析頻寬內的讀值高。和 3.1.5 的熱雜訊密度 −174 dBm/Hz 相比，這個訊號的密度高出 44 dB。此換算假設頻譜平坦，並把解析頻寬當成等效雜訊頻寬，實際儀器還有濾波器形狀與檢波方式的修正量。

#### 常見錯誤

- **單邊與雙邊 PSD 混用**：雙邊密度 $N_0/2$ 要對正負頻率一起積分；用單邊 $N_0$ 卻又乘 2，功率會多 3 dB。
- **頻寬定義沒對齊**：3 dB 頻寬、零點到零點頻寬、99% 占用頻寬數字不同，比較前先確認定義。
- **把頻譜儀讀值當成總功率**：讀值是解析頻寬內的功率，改變解析頻寬，雜訊類訊號的讀值就跟著變；要換成 dBm/Hz 或積分成通道功率才能比較。
- **dBm/Hz 換成功率時用乘的**：dB 域要加 $10\log_{10}B$，而且 $B$ 用 Hz。

#### 和其他小節的關係

3.1.5 的熱雜訊密度 $N_0 = kT$ 就是本節的白雜訊 PSD，$kTB$ 是對它積分；3.1.4 的延遲擴散與同調頻寬是時間域、頻率域的一組對應；3.1.8 的取樣定理用到「時間域取樣等於頻譜週期複製」；3.2.5 的 OFDM 子載波正交性與 3.2.7 的脈衝整形、升餘弦頻寬直接建立在本節的轉換對上；自相關與穩態的機率基礎見 3.5.4。
