# 3.6.2 多步計算逐步寫出

所屬：[3.6 解題方法](3-6.md)

## 內文

#### 為什麼要學

鏈路預算、涵蓋距離、話務容量這類題目，通常要串三到五條公式才能得到答案。中間任何一步出錯，最後的數字就不對，而且只看最後的數字看不出錯在哪裡。把每一步的算式、中間值與單位都寫出來，有三個用處：自己可以逐步核對；別人審查鏈路預算表或容量規劃報告時可以重算；發現結果不合理時，可以很快定位到出錯的那一步（3.6.5）。對語言模型而言，逐步寫出也是避免「心算」跳步造成數值錯誤的主要做法。

#### 定義與符號

| 項目 | 意思 | 例子 |
|---|---|---|
| 步驟（step） | 一次只用一條公式或做一次換算的計算單位 | 「把 23 dBm 的發射功率加上天線增益得到 EIRP」 |
| 中間值（intermediate value） | 某一步的結果，會成為後面步驟的輸入 | 接收靈敏度 $-113.44$ dBm |
| 保護位數（guard digit） | 中間值比最後答案多保留的位數 | 答案要小數 1 位時，中間值保留小數 2～3 位 |
| 計算鏈（chain） | 從已知量到未知量的公式順序 | 靈敏度 → MAPL → 距離 |
| 逆向規劃 | 從未知量往回找需要哪些量，直到全部是已知量 | 要距離需要 MAPL，要 MAPL 需要靈敏度 |
| 遞迴式 | 用前一步結果算下一步的公式，每一步都是中間值 | Erlang B 的遞迴計算 |

#### 公式與推導

多步計算的做法可以整理成「先排順序、再逐步算、每步落款」。

**先排順序（逆向規劃）。** 從要求的量往回推。以「求涵蓋距離」為例：距離要由路徑損耗模型反解，所以需要最大容許路徑損耗（maximum allowable path loss, MAPL，3.3.5）；MAPL 需要 EIRP、接收增益、各項餘量與接收靈敏度（3.3.1、3.3.3、3.3.4）；靈敏度需要頻寬、雜訊指數與需求 SNR。推到每一項都是已知量或已寫明的假設為止，再把順序倒過來，就是計算鏈。

**再逐步算。** 每一步遵守四條準則：

1. 一步只做一件事：一條公式或一次單位換算，不把兩條公式合併成一行心算。
2. 先寫符號式，再寫代入數字的式子，最後寫結果。這樣別人看得出數字放在哪個位置。
3. 每個中間值都帶單位，並且取一個名字（例如 $S_{\min}$、MAPL），後面引用時用名字。
4. 中間值多留位數。答案要求小數第 $n$ 位時，中間值至少保留到小數第 $n+2$ 位（即比最終答案多保留 2 位）；線性值（由 dB 轉換而來的倍數）至少保留 4 位有效數字。取位只在最後一步做一次（3.6.4）。

**每步落款。** 每算完一步，花幾秒鐘看一下量級：dB 值是否在常見範圍、機率是否介於 0 與 1、利用率是否小於 1。這是把 3.6.5 的驗算分散到每一步，錯誤越早發現越省事。

需要區分 dB 域與線性域的地方要特別標示。dB 域裡增益與損耗用加減，線性域裡用乘除；功率相加（例如雜訊加干擾）只能在線性域做（3.1.1）。計算鏈中若需要跨域，把「轉換」本身當成獨立的一步寫出來。

遞迴式也適用同樣的寫法。3.4.2 的 Erlang B 阻塞機率可以用遞迴計算，其中 $A$ 為話務量（Erlang），$n$ 為通道數：

$$B(0, A) = 1,\qquad B(n, A) = \frac{A\,B(n-1, A)}{n + A\,B(n-1, A)}$$

每一個 $n$ 的結果都是下一步的輸入，因此每一個都要寫下來，不能只寫最後一個。

#### 算例

**算例 1（鏈路預算到涵蓋距離，5 步）** 假設一條 3.5 GHz 的上行鏈路：手機發射功率 23 dBm、天線增益 0 dBi；基地台天線增益 18 dBi、饋線損耗 2 dB、雜訊指數 5 dB；占用頻寬 360 kHz（子載波間隔 30 kHz 時的 1 個資源區塊，12 個子載波）；需求 SNR 為 0 dB；衰落與穿透餘量合計 20 dB。傳播採對數距離模型（3.1.3），路徑損耗指數 3.5，參考距離 100 m 處的損耗取自由空間值。溫度未指定，採 290 K。求涵蓋距離，取 3 位有效數字。

步驟 1，雜訊頻寬項：$10\log_{10}(360\times10^3) = 55.56$ dB。

步驟 2，接收靈敏度（3.3.4）：

$$S_{\min} = -174 + 55.56 + 5 + 0 = -113.44\ \text{dBm}$$

步驟 3，最大容許路徑損耗（3.3.5）：

$$\text{MAPL} = 23 + 0 + 18 - 2 - (-113.44) - 20 = 132.44\ \text{dB}$$

步驟 4，參考距離 $d_0 = 0.1$ km 處的自由空間損耗（3.1.2）：

$$PL(d_0) = 92.45 + 20\log_{10}(3.5) + 20\log_{10}(0.1) = 92.45 + 10.88 - 20 = 83.33\ \text{dB}$$

步驟 5，反解距離：由 $\text{MAPL} = PL(d_0) + 10 \times 3.5 \times \log_{10}(d/d_0)$，

$$\log_{10}\frac{d}{d_0} = \frac{132.44 - 83.33}{35} = \frac{49.11}{35} = 1.4031,\qquad d = 100 \times 10^{1.4031} \approx 2530\ \text{m} = 2.53\ \text{km}$$

合理性檢查：同樣的 MAPL 若改用自由空間模型，距離會是 28.5 km，明顯過於樂觀；指數 3.5 時得到 2.5 km 左右，是 3.5 GHz 大型基地台常見的量級。

**算例 2（話務到阻塞機率，逐步遞迴）** 假設某小區有 60 位用戶，忙時每人平均撥打 2 通，每通平均 90 秒，小區有 6 個話務通道。求阻塞機率與通道利用率。

步驟 1，話務量（3.4.1）：$A = 60 \times 2 \times 90 / 3600 = 3$ Erlang。

步驟 2，用遞迴式逐步計算（3.4.2），每一步保留 4 位小數：

| $n$ | 算式 | $B(n, 3)$ |
|---|---|---|
| 1 | $3\times1 / (1 + 3\times1)$ | 0.7500 |
| 2 | $3\times0.7500 / (2 + 3\times0.7500)$ | 0.5294 |
| 3 | $3\times0.5294 / (3 + 3\times0.5294)$ | 0.3462 |
| 4 | $3\times0.3462 / (4 + 3\times0.3462)$ | 0.2061 |
| 5 | $3\times0.2061 / (5 + 3\times0.2061)$ | 0.1101 |
| 6 | $3\times0.1101 / (6 + 3\times0.1101)$ | 0.0522 |

阻塞機率約 5.22%。

步驟 3，承載話務量：$A(1 - B) = 3 \times (1 - 0.0522) = 2.843$ Erlang。

步驟 4，通道利用率：$2.843 / 6 = 0.474$，即 47.4%。

合理性檢查：阻塞機率隨通道數增加而單調下降，表中每一列都比上一列小；利用率小於 1；6 個通道承載 3 Erlang 而阻塞約 5%，量級合理。

#### 常見錯誤

1. **跳步合併。** 把靈敏度與 MAPL 寫成一行長式子，正負號容易錯（特別是「減去負的靈敏度」）。
2. **中間值沒有單位或名稱。** 後面引用時分不清 132.44 是 dB 還是 dBm，也分不清是 MAPL 還是 EIRP。
3. **中間值取位太粗。** 步驟 5 的指數若只留 1.4，距離會變成 2512 m，誤差就此帶進答案。
4. **dB 域與線性域沒有分開。** 在 dB 域做了功率相加，或在線性域把增益用加的。

#### 和其他小節的關係

計算鏈的起點是 3.6.1 整理出的已知量與假設；中間值的保留位數與最後取位見 3.6.4；逐步寫出的中間值是 3.6.5 驗算與找錯的依據。算例用到 3.3.4、3.3.5、3.1.2、3.1.3 的鏈路預算公式，以及 3.4.1、3.4.2 的話務公式。
