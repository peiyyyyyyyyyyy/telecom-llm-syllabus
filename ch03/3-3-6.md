# 3.3.6 上行與下行鏈路預算比較

所屬：[3.3 鏈路預算](3-3.md)

## 內文

#### 為什麼要學

行動通訊是雙向的：下行（downlink，基地臺到終端）與上行（uplink，終端到基地臺）走同一條路徑，但兩端的發射功率、接收機品質與傳輸頻寬都不一樣。基地臺功放有幾十瓦，手機通常只有 0.2 瓦；因此兩個方向能承受的路徑損耗不相等，真正決定細胞半徑的是比較弱的那個方向。如果只用下行預算來布站，會出現「手機看得到訊號卻連不上、上傳不動」的區域。把上下行各算一份鏈路預算、找出受限方向並量化兩者的差距，是涵蓋規劃的標準步驟，也是判斷該採取哪種補強手段（提高終端功率、縮窄上行頻寬、增加基地臺接收分集等）的依據。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $\text{MAPL}_{\text{DL}}$ | 下行最大允許路徑損耗 | dB |
| $\text{MAPL}_{\text{UL}}$ | 上行最大允許路徑損耗 | dB |
| $\Delta$ | 鏈路不平衡量，$\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}}$ | dB |
| $P_{\text{BS}},\ P_{\text{UE}}$ | 基地臺、終端的發射功率 | dBm |
| $G_{\text{BS}},\ G_{\text{UE}}$ | 基地臺、終端的天線增益 | dBi |
| $L_{\text{BS}}$ | 基地臺端饋線損耗 | dB |
| $L_{\text{body}}$ | 終端側人體損耗 | dB |
| $S_{\text{BS}},\ S_{\text{UE}}$ | 基地臺、終端的接收靈敏度 | dBm |
| $M_{I,\text{DL}},\ M_{I,\text{UL}}$ | 下行、上行干擾餘量 | dB |
| $M_{\text{SF}}$ | 陰影衰落餘量 | dB |
| $L_{\text{pen}}$ | 穿透損耗 | dB |

#### 公式與推導

把 3.3.5 的 MAPL 公式分別寫給兩個方向。下行由基地臺發射、終端接收：

$$\text{MAPL}_{\text{DL}} = (P_{\text{BS}} + G_{\text{BS}} - L_{\text{BS}}) - S_{\text{UE}} + G_{\text{UE}} - L_{\text{body}} - M_{\text{SF}} - M_{I,\text{DL}} - L_{\text{pen}}$$

上行由終端發射、基地臺接收：

$$\text{MAPL}_{\text{UL}} = (P_{\text{UE}} + G_{\text{UE}} - L_{\text{body}}) - S_{\text{BS}} + G_{\text{BS}} - L_{\text{BS}} - M_{\text{SF}} - M_{I,\text{UL}} - L_{\text{pen}}$$

**受限方向**是 MAPL 較小的那一個，細胞的可用涵蓋由 $\min(\text{MAPL}_{\text{DL}},\ \text{MAPL}_{\text{UL}})$ 決定。**不平衡量**定義為

$$\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}}$$

$\Delta > 0$ 表示上行受限，$\Delta < 0$ 表示下行受限，$\Delta = 0$ 稱為鏈路平衡。使用這個量時要註明減的順序，因為也有文件用相反的定義。

若兩個方向使用相同的天線增益、饋線損耗、人體損耗、陰影衰落餘量與穿透損耗，兩式相減後這些項全部抵銷，只剩

$$\Delta = (P_{\text{BS}} - P_{\text{UE}}) - (S_{\text{UE}} - S_{\text{BS}}) - (M_{I,\text{DL}} - M_{I,\text{UL}})$$

也就是：發射功率差，扣掉兩端靈敏度的差，再扣掉干擾餘量的差。靈敏度差又可依 3.3.4 拆成頻寬、雜訊指數與所需 SNR 三項之差。這條式子說明了不平衡的來源與補救方向：基地臺功率大使 $\Delta$ 變正；但基地臺雜訊指數較低、上行配置的頻寬較窄，都讓 $S_{\text{BS}}$ 比 $S_{\text{UE}}$ 更靈敏，把差距補回一部分。

適用條件：抵銷的前提是兩個方向的路徑損耗相同。分時雙工（TDD）上下行同頻，這個假設成立；分頻雙工（FDD）上下行頻率不同，路徑損耗與穿透損耗略有差異，嚴謹的做法是各自反推距離再比較。此外，上下行的頻寬與所需 SNR 對應各自的目標速率，比較時要先講清楚兩個方向各以什麼業務速率為準；採用上下行不同的天線配置（例如基地臺接收分集）時，增益項也不會完全抵銷。

#### 算例

沿用前面的假設：頻率 3,500 MHz（TDD）；基地臺功率 46.02 dBm、天線 17 dBi、饋線損耗 2 dB；終端功率 23 dBm（TS 38.101-1 表 6.2.1-1 的功率等級 3）、天線 0 dBi、人體損耗 3 dB；陰影衰落餘量 10.25 dB；穿透損耗 12.70 dB；下行干擾餘量 3 dB、上行 3.01 dB（負載 50%）。下行占 106 個資源區塊，終端靈敏度 −95.17 dBm；上行配置 25 個資源區塊，基地臺雜訊指數 5 dB、所需 SNR −1 dB（皆為假設）。

**算例 1（上下行 MAPL、受限方向與不平衡量）**

1. 下行：已於 3.3.5 算得 $\text{MAPL}_{\text{DL}} = 127.24$ dB。
2. 基地臺靈敏度：$B = 25\times180\ \text{kHz} = 4.5$ MHz，熱雜訊 $-107.44$ dBm（3.3.4 算例 2）；$S_{\text{BS}} = -107.44 + 5 - 1 = -103.44$ dBm。
3. 上行 EIRP：$23 + 0 - 3 = 20$ dBm。
4. 上行 MAPL：$20 - (-103.44) + 17 - 2 - 10.25 - 3.01 - 12.70$。逐步：$123.44 \to 140.44 \to 138.44 \to 128.19 \to 125.18 \to$ **112.48 dB**。
5. 不平衡量：$\Delta = 127.24 - 112.48 = 14.76$ dB，為正值，**上行受限**。
6. 用抵銷後的式子驗算：功率差 $46.02 - 23 = 23.02$ dB；靈敏度差 $-95.17 - (-103.44) = 8.27$ dB（其中頻寬 $10\log_{10}(106/25) = 6.27$ dB、雜訊指數 $7 - 5 = 2$ dB）；干擾餘量差 $3 - 3.01 = -0.01$ dB。$\Delta = 23.02 - 8.27 + 0.01 = 14.76$ dB，一致。
7. 涵蓋半徑：用 3.3.5 的對數距離模型（$d_0 = 100$ m、$PL(d_0) = 83.32$ dB、$n = 3.5$，假設），上行 $d = 100\times10^{(112.48 - 83.32)/35} = 100\times10^{0.8331} = 681$ m，下行則為 1,798 m。細胞半徑應取 681 m。

合理性檢查：半徑比為 $10^{-14.76/35} = 0.379$，$1{,}798\times0.379 = 681$ m，相符；面積只剩下行涵蓋的約 14%，可見忽略上行會嚴重高估涵蓋。

**算例 2（補強上行後的不平衡量）**　把細胞邊緣終端的上行配置縮為 5 個資源區塊，並改用功率等級 2 的終端（TS 38.101-1 表 6.2.1-1，n78 頻段為 26 dBm）。

1. 頻寬縮窄的效果：$10\log_{10}(25/5) = 6.99$ dB，$S_{\text{BS}} = -103.44 - 6.99 = -110.43$ dBm。
2. 功率增加 3 dB。
3. 新的上行 MAPL：$112.48 + 6.99 + 3 = 122.47$ dB；$\Delta = 127.24 - 122.47 = 4.77$ dB，仍是上行受限但差距大幅縮小。
4. 半徑：$100\times10^{(122.47 - 83.32)/35} = 100\times10^{1.1186} = 1{,}314$ m。

合理性檢查：上行多了 9.99 dB，半徑變為 $10^{9.99/35} = 1.93$ 倍，$681\times1.93 = 1{,}314$ m，相符。代價是上行頻寬只剩五分之一，邊緣使用者的上行速率也隨之下降，這是涵蓋與速率之間的取捨。

#### 常見錯誤

- **只算下行就決定站距**：基地臺功率大，下行 MAPL 幾乎總是比較樂觀；涵蓋要取兩個方向中較小的 MAPL。
- **上下行用同一個頻寬算靈敏度**：上行常只配置少量資源區塊，雜訊頻寬較窄；沿用下行的全頻寬會把上行算得過於悲觀。
- **天線增益只算一邊**：基地臺天線增益在下行是發射增益、在上行是接收增益，兩個方向都要計入；終端天線與人體損耗也一樣。
- **不平衡量沒註明正負號定義**：$\Delta$ 是「下行減上行」還是相反，要寫清楚，否則「不平衡 10 dB」無法判斷哪一邊受限。

#### 和其他小節的關係

兩個方向的 MAPL 都用 3.3.5 的公式，輸入來自 3.3.1（EIRP）、3.3.2（天線增益）、3.3.3（損耗與餘量）與 3.3.4（兩端靈敏度）。反推半徑用 3.1.3 的對數距離模型。上行縮窄頻寬換取涵蓋、但速率下降的取捨，可對照 3.2 的容量與頻寬關係以及 3.1.6 的 SNR 計算。

**出處**　3GPP TS 38.101-1 V18.15.0 表 6.2.1-1（終端功率等級）；3GPP TS 38.104 V18.15.0 第 7.2 節（基地臺參考靈敏度的定義與表 7.2.2-1）；Holma & Toskala, *WCDMA for UMTS*，無線網路規劃一章（上下行鏈路預算）；Rappaport, *Wireless Communications: Principles and Practice*，鏈路預算的討論。

### 補充練習題（85 題）

#### 單題：Both directions' MAPL and the imbalance

**3.3.6G001**　A macro sector has base-station output power 46 dBm, antenna gain 18 dBi and feeder loss 2 dB. The terminal transmits 23 dBm, has a 0 dBi antenna and 3 dB body loss. Sensitivities: terminal −97.0 dBm, base station −106.2 dBm. Both directions use a shadow fading margin of 8 dB and an interference margin of 3 dB; there is no penetration loss. Compute the imbalance $\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}}$ in dB, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　13.80

**詳解**　$\text{MAPL}_{\text{DL}} = (46 + 18 - 2) + 97.0 + 0 - 3 - 8 - 3 = 62 + 97 - 14 = 145.0$ dB. $\text{MAPL}_{\text{UL}} = (23 + 0 - 3) + 106.2 + 18 - 2 - 8 - 3 = 20 + 106.2 + 16 - 11 = 131.2$ dB. $\Delta = 145.0 - 131.2 = 13.8$ dB, i.e. 13.80 dB (positive: uplink-limited).
\boxed{13.80}

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink and downlink link budgets); T. S. Rappaport, *Wireless Communications: Principles and Practice* (link budget).

</details>

**3.3.6G002**　An uplink budget for indoor users lists: terminal output power 23 dBm, terminal antenna gain −1 dBi, body loss 3 dB, base-station sensitivity −105.4 dBm, base-station antenna gain 17 dBi, jumper loss 0.5 dB (radio unit at the mast), shadow fading margin 9 dB, uplink interference margin 2 dB and penetration loss 14 dB. Compute the uplink MAPL in dB, rounded to one decimal place.

<details><summary>看答案</summary>

**答案**　115.9

**詳解**　UE EIRP $= 23 - 1 - 3 = 19$ dBm. $\text{MAPL}_{\text{UL}} = 19 + 105.4 + 17 - 0.5 - 9 - 2 - 14$. Step by step: $19 + 105.4 = 124.4$; $+17 = 141.4$; $-0.5 = 140.9$; $-9 = 131.9$; $-2 = 129.9$; $-14 = 115.9$ dB.
\boxed{115.9}

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink link budget).

</details>

**3.3.6G003**　A planning report defines the link imbalance the other way round, as $\Delta' = \text{MAPL}_{\text{UL}} - \text{MAPL}_{\text{DL}}$. For a cell with $\text{MAPL}_{\text{DL}} = 131.6$ dB and $\text{MAPL}_{\text{UL}} = 124.9$ dB, compute $\Delta'$ in dB, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　-6.70

**詳解**　$\Delta' = 124.9 - 131.6 = -6.7$ dB, i.e. $-6.70$ dB. With this convention a negative value means the uplink is the limiting direction.
\boxed{-6.70}

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink and downlink link budgets).

</details>

**3.3.6G004**　A base station transmits 80 W per carrier into a 17.5 dBi antenna with 2.5 dB feeder loss (the same antenna and feeder serve the uplink). The terminal transmits 23 dBm with a 0 dBi antenna and 3 dB body loss. Sensitivities: terminal −96.4 dBm, base station −104.8 dBm. Both directions use a shadow fading margin of 8.5 dB and a penetration loss of 12 dB; the interference margin is 3 dB in the downlink and 2 dB in the uplink. Compute $\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}}$ in dB, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　16.63

**詳解**　$P_{\text{BS}} = 10\log_{10}(80\,000\ \text{mW}) = 49.0309$ dBm. $\text{MAPL}_{\text{DL}} = 49.0309 + 17.5 - 2.5 + 96.4 + 0 - 3 - 8.5 - 3 - 12 = 133.9309$ dB. $\text{MAPL}_{\text{UL}} = 23 + 0 - 3 + 104.8 + 17.5 - 2.5 - 8.5 - 2 - 12 = 117.3$ dB. $\Delta = 133.9309 - 117.3 = 16.6309$ dB, which rounds to 16.63 dB.
\boxed{16.63}

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink and downlink link budgets); T. S. Rappaport, *Wireless Communications: Principles and Practice* (dBm conversion).

</details>

**3.3.6G005**　A sector's downlink MAPL is 141.3 dB. In the uplink the terminal transmits 23 dBm with a 0 dBi antenna and 3 dB body loss; the base station has single-antenna sensitivity −103.6 dBm, and four-branch receive combining adds a diversity gain of 3.0 dB that exists only in the uplink. The base-station antenna gain is 16 dBi, the feeder loss 1 dB, the shadow fading margin 7.5 dB and the uplink interference margin 2.5 dB. #### 單題：Sensitivity of each receiver from thermal noise

**3.3.6G006**　In the downlink a terminal decodes 106 resource blocks of 180 kHz each (19.08 MHz). Its noise figure is 7 dB and the required SNR is −1 dB. Using −174 dBm/Hz, compute the terminal sensitivity in dBm, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　-95.19

**詳解**　$10\log_{10}(19.08\times10^{6}) = 72.8058$ dB. $S_{\text{UE}} = -174 + 72.8058 + 7 + (-1) = -95.1942$ dBm, which rounds to $-95.19$ dBm.
\boxed{-95.19}

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (thermal noise $kTB$; receiver sensitivity).

**3.3.6G010**　A vendor quotes a base-station uplink sensitivity of −108.5 dBm for a 2.16 MHz allocation, with a receiver noise figure of 4 dB. Using −174 dBm/Hz, what SNR does this sensitivity assume? Give the answer in dB, rounded to two decimal places.

#### 單題：Imbalance from the power, sensitivity and margin differences

**3.3.6G011**　Both directions use the same antennas, feeder, body loss, shadow fading margin and penetration loss. Given $P_{\text{BS}} = 46$ dBm, $P_{\text{UE}} = 23$ dBm, $S_{\text{UE}} = -95.2$ dBm, $S_{\text{BS}} = -103.9$ dBm, downlink interference margin 3.5 dB and uplink interference margin 2.0 dB, compute $\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}}$ in dB, rounded to one decimal place.

<details><summary>看答案</summary>

**答案**　12.8

**詳解**　With the common terms cancelled, $\Delta = (P_{\text{BS}} - P_{\text{UE}}) - (S_{\text{UE}} - S_{\text{BS}}) - (M_{I,\text{DL}} - M_{I,\text{UL}})$. Power difference: $46 - 23 = 23$ dB. Sensitivity difference: $-95.2 - (-103.9) = 8.7$ dB. Margin difference: $3.5 - 2.0 = 1.5$ dB. $\Delta = 23 - 8.7 - 1.5 = 12.8$ dB.
\boxed{12.8}

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink and downlink link budgets).

</details>

**3.3.6G013**　A base station transmits 43 dBm and a terminal 23 dBm. The downlink is received over 20 MHz with terminal noise figure 7 dB and required SNR 2 dB; the uplink is received over 5 MHz with base-station noise figure 3 dB and required SNR 0 dB. All other budget terms, including the interference margins, are the same in both directions. Split the sensitivity difference into its bandwidth, noise-figure and SNR parts and compute $\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}}$ in dB, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　7.98

**詳解**　Bandwidth part: $10\log_{10}(20/5) = 6.0206$ dB. Noise-figure part: $7 - 3 = 4$ dB. SNR part: $2 - 0 = 2$ dB. $S_{\text{UE}} - S_{\text{BS}} = 6.0206 + 4 + 2 = 12.0206$ dB. $\Delta = (43 - 23) - 12.0206 = 7.9794$ dB, which rounds to 7.98 dB.
\boxed{7.98}

Both directions use a shadow fading margin of 9 dB and an indoor penetration loss of 15 dB; the interference margin is 4 dB in the downlink and 3 dB in the uplink. The path loss exponent is 3.6.

**3.3.6S006**　Compute the uplink MAPL in dB, rounded to one decimal place.

<details><summary>看答案</summary>

**答案**　118.5 dB

**詳解**　UE EIRP $= 23 + 0 - 3 = 20$ dBm. $\text{MAPL}_{\text{UL}} = 20 + 101.5 + 24 - 9 - 3 - 15 = 118.5$ dB.

</details>

**3.3.6S007**　Compute the downlink MAPL, the imbalance $\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}}$, and the ratio of the uplink range to the downlink range (three decimal places).

<details><summary>看答案</summary>

**答案**　$\text{MAPL}_{\text{DL}} = 137.2$ dB, $\Delta = 18.7$ dB, range ratio 0.302.

**詳解**　$\text{MAPL}_{\text{DL}} = 74 + 94.2 + 0 - 3 - 9 - 4 - 15 = 137.2$ dB. $\Delta = 137.2 - 118.5 = 18.7$ dB (uplink-limited). Range ratio $= 10^{-18.7/36} = 10^{-0.519444} = 0.302382$ ≈ 0.302.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (log-distance path loss model); H. Holma and A. Toskala (eds.), *LTE for UMTS* (link budgets).

</details>

**3.3.6S008**　In this cell the downlink is described by one beamformed EIRP and the uplink by one combined receive gain. Why can the simplified imbalance formula that cancels "the same antenna gain in both directions" not be applied here?

<details><summary>看答案</summary>

**答案**　Because the antenna terms are not the same in the two directions. The downlink EIRP contains the total power of all 64 transmitters plus the transmit beamforming gain, while the uplink uses a receive combining gain that depends on how many chains are combined and on the channel estimate quality for a weak terminal. The cancellation assumes one antenna gain used identically in both directions; with active arrays each direction's gain must be entered separately.

**詳解**　For example, if both gains were taken equal, the power and gain terms in the cancelled formula would wrongly suggest that only $P_{\text{BS}} - P_{\text{UE}}$ and the sensitivities matter, and the 24 dBi receive gain versus the transmit array gain would disappear from the comparison.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (link budget); E. Björnson, J. Hoydis and L. Sanguinetti, *Massive MIMO Networks* (array and beamforming gain).

</details>

**3.3.6S009**　Why can the uplink and downlink of this TDD cell be compared simply by their MAPL values, without converting each to a distance first?

<details><summary>看答案</summary>

**答案**　In TDD both directions use the same carrier frequency over the same path, so the path loss (and the penetration loss) at any location is the same both ways (reciprocity). The direction with the smaller MAPL therefore runs out of budget first at every location, and the difference in MAPL maps directly onto a range ratio through one propagation model.

**詳解**　In FDD, by contrast, the two frequencies differ, so each direction's MAPL must be converted to a distance with its own frequency-dependent model before comparing.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (TDD and FDD link budgets).

</details>

#### 情境題：Where the imbalance comes from

**Scenario | Macro cell versus indoor small cell**

An operator compares two cells. Macro: base-station power 46 dBm, base-station noise figure 3 dB, interference margins 3 dB in both directions. Indoor small cell: power 24 dBm, noise figure 7 dB, interference margin 6 dB in the downlink (many co-channel cells in the building) and 2 dB in the uplink. In both cells the terminals transmit 23 dBm and have noise figure 8 dB, the downlink is received over 40 MHz and the cell-edge uplink over 10 MHz, and the required SNR is the same in both directions. Each cell uses one antenna for both directions (macro 18 dBi, small cell 5 dBi), and losses and shadow margins are identical in both directions of each cell.

**3.3.6S016**　Compute $\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}}$ for the macro cell, in dB, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　11.98 dB

**詳解**　$\Delta = (P_{\text{BS}} - P_{\text{UE}}) - (S_{\text{UE}} - S_{\text{BS}}) - (M_{I,\text{DL}} - M_{I,\text{UL}})$. Power: $46 - 23 = 23$ dB. Sensitivity difference: bandwidth $10\log_{10}(40/10) = 6.0206$ dB plus noise figure $8 - 3 = 5$ dB, total 11.0206 dB. Margins: $3 - 3 = 0$. $\Delta = 23 - 11.0206 - 0 = 11.9794$ dB ≈ 11.98 dB (uplink-limited).

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (link budgets).

</details>

**3.3.6S017**　Compute $\Delta$ for the indoor small cell, in dB, rounded to two decimal places, and state the limiting direction.

<details><summary>看答案</summary>

**答案**　−10.02 dB; the downlink limits.

**詳解**　Power: $24 - 23 = 1$ dB. Sensitivity difference: $6.0206 + (8 - 7) = 7.0206$ dB. Margin difference: $6 - 2 = 4$ dB. $\Delta = 1 - 7.0206 - 4 = -10.0206$ dB ≈ −10.02 dB. Negative, so the downlink MAPL is the smaller one.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (link budgets).

</details>

**3.3.6S018**　The small-cell result shows that "the uplink always limits" is only a rule of thumb. Which improvements would help the small cell most, and why are they different from the usual macro remedies?

<details><summary>看答案</summary>

**答案**　The small cell is downlink-limited because its transmit power is almost the same as the terminal's while its downlink suffers heavy co-channel interference (6 dB margin). Remedies are therefore on the downlink side: more transmit power, better interference coordination between the small cells (which lowers the downlink margin) or fewer co-channel neighbours. Macro remedies such as high-power terminals, uplink receive diversity or narrower uplink allocations would only widen the gap here.

**詳解**　For example, cutting the downlink margin from 6 dB to 3 dB and raising the power by 3 dB would move $\Delta$ from −10.02 dB to −4.02 dB.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (link budgets; interference margin).

</details>

**3.3.6S019**　The macro antenna gain (18 dBi) is much larger than the small-cell antenna gain (5 dBi). Why does neither gain appear in the $\Delta$ calculations?

<details><summary>看答案</summary>

**答案**　In each cell the same antenna is used to transmit and to receive, so its gain is added once in the downlink MAPL (transmit gain) and once in the uplink MAPL (receive gain). In the difference $\text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}}$ the two cancel. The gain does affect the range of each cell, but not which direction limits.

**詳解**　$\text{MAPL}_{\text{DL}} = P_{\text{BS}} + G_{\text{BS}} - \ldots$ and $\text{MAPL}_{\text{UL}} = \ldots + G_{\text{BS}} - \ldots$; subtracting removes $G_{\text{BS}}$. The same holds for feeder loss, body loss, shadow margin and penetration loss when they are equal in both directions.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (link budgets).

</details>

#### 情境題：Closing the uplink gap

**Scenario | Power-class-2 terminals on a 3.5 GHz TDD network**

<details><summary>看答案</summary>

**答案**　10.4 dB

**詳解**　The uplink EIRP rises by $26 - 23 = 3$ dB, so $\text{MAPL}_{\text{UL}}$ rises by 3 dB and $\Delta = 13.4 - 3 = 10.4$ dB (still uplink-limited).

**出處**　3GPP TS 38.101-1, Table 6.2.1-1 (UE power classes).

<details><summary>看答案</summary>

**詳解**　Range factor $= 10^{3/36} = 10^{0.083333} = 1.211528$ ≈ 1.212. Area factor $= 1.211528^2 = 10^{6/36} = 1.467799$, i.e. +46.8%.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (log-distance path loss model).

</details>

**3.3.6S028**　Does promoting power-class-2 terminals change the downlink MAPL? What side effect on the uplink budget should the planner check?

<details><summary>看答案</summary>

**答案**　No, the downlink is untouched: base-station power, terminal sensitivity and all common terms are unchanged. The side effect is that terminals transmitting 3 dB more raise the uplink interference received in neighbouring cells, so the uplink interference margin may need to increase under load, eating part of the 3 dB gain.

**詳解**　If the uplink interference margin rose by, say, 0.5 dB, the net uplink gain would be 2.5 dB and $\Delta$ would be 10.9 dB rather than 10.4 dB.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink interference margin).

**3.3.6S029**　Why should the planner treat the full 3 dB as an upper bound on what power-class-2 terminals deliver in practice?

<details><summary>看答案</summary>

**答案**　The 26 dBm is a maximum output power class, not a guarantee in every slot: the terminal's actual power can be reduced by regulatory exposure limits, uplink duty-cycle restrictions in TDD, power back-off for higher-order modulation or wide allocations, and by the share of the terminal population that actually supports the class. The coverage gain is therefore at most 3 dB and only for capable terminals.

**詳解**　The planning budget should use the power the terminal can sustain at the cell edge; with only part of the population capable, the cell edge for the remaining terminals is unchanged.

**出處**　3GPP TS 38.101-1, clause 6.2 (UE maximum output power and power reductions).

**Scenario | Narrowing the cell-edge uplink allocation**

A cell is uplink-limited by $\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}} = 11.0$ dB when cell-edge terminals transmit on 25 resource blocks. The scheduler is changed so that cell-edge terminals transmit on only 4 resource blocks, still at their full 23 dBm and with the same required SNR. The path loss exponent is 3.5.

**3.3.6S036**　Compute the new imbalance in dB (two decimal places) and the factor by which the uplink range grows (three decimal places).

<details><summary>看答案</summary>

**答案**　$\Delta = 3.04$ dB; range ×1.688.

**詳解**　The base-station noise bandwidth falls by $25/4 = 6.25$, so $S_{\text{BS}}$ improves by $10\log_{10}(6.25) = 7.9588$ dB. $\Delta = 11.0 - 7.9588 = 3.0412$ dB ≈ 3.04 dB (still uplink-limited, so the full gain extends the range). **出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (receiver sensitivity; log-distance path loss model).

**3.3.6S037**　What is the price of this gain for the cell-edge user?

<details><summary>看答案</summary>

**答案**　The user's peak uplink rate at the edge drops roughly in proportion to the bandwidth: at the same SNR and modulation, 4 resource blocks carry about $4/25 = 16\%$ of what 25 carry. The operator trades edge throughput for coverage (the user stays connected further out but uploads more slowly).

**詳解**　Rate $\approx B \times$ spectral efficiency; with the spectral efficiency fixed by the unchanged SNR target, the rate scales with $B$.

**出處**　A. Goldsmith, *Wireless Communications* (capacity and bandwidth); H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink coverage and data rate).

**3.3.6S038**　Why does the same trick not improve the downlink MAPL when a cell-edge terminal is given fewer downlink resource blocks?

<details><summary>看答案</summary>

**答案**　In the uplink the terminal puts its full 23 dBm into the smaller allocation, so the power per hertz rises as the bandwidth shrinks. In the downlink the base station's power is spread over the whole carrier at a fixed power per resource block; giving one terminal fewer blocks lowers both the noise bandwidth and the received signal power by the same factor, so the SNR (and the MAPL) does not improve.

**詳解**　Downlink: $P_{\text{rx}} \propto B$ and $N \propto B$, so SNR is independent of $B$. Uplink: $P_{\text{rx}}$ fixed and $N \propto B$, so SNR $\propto 1/B$.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink and downlink power allocation in link budgets).

**3.3.6S049**　What does a user located 4 km from this site experience, and why is this situation harmful for the network as well as for the user?

**答案**　At 4 km the user is inside the downlink range (5.16 km) but outside the uplink range (3.26 km): the terminal decodes the cell's broadcast and control signals and may camp on it, but its uplink transmissions (access attempts, acknowledgements, data) fail. The user sees signal bars but cannot set up calls or send data, and the network sees repeated failed access attempts and dropped connections.

**詳解**　The cell's effective service area must be limited to the smaller (uplink) range; handover and cell-reselection thresholds are tuned so that terminals move to another cell before reaching the uplink edge.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink-limited coverage).

</details>

#### 情境題：Impact of the imbalance on cell range and site count

**Scenario | Site count rework after an uplink audit**

A 220 km² city area was dimensioned from the downlink budget only, with $\text{MAPL}_{\text{DL}} = 134.3$ dB. An audit computed $\text{MAPL}_{\text{UL}} = 126.8$ dB for the same service. The model is $PL = 127.5 + 36.2\log_{10} d_{\text{km}}$ (dB), and each three-sector site covers $A_{\text{site}} = 1.95R^2$.

**3.3.6S051**　How many sites did the original downlink-based plan require? Round up to a whole number.

<details><summary>看答案</summary>

**答案**　48 sites

**詳解**　$\log_{10} R_{\text{DL}} = (134.3 - 127.5)/36.2 = 6.8/36.2 = 0.187845$; $R_{\text{DL}} = 10^{0.187845} = 1.54115$ km. $A_{\text{site}} = 1.95 \times 1.54115^2 = 1.95 \times 2.37515 = 4.63154$ km². $N = 220/4.63154 = 47.50$, rounded up to 48 sites.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (path loss models); H. Holma and A. Toskala (eds.), *LTE for UMTS* (site count).

</details>

**3.3.6S052**　How many sites are needed when the uplink is taken into account? Round up to a whole number.

<details><summary>看答案</summary>

**答案**　124 sites

**詳解**　The uplink limits. $\log_{10} R_{\text{UL}} = (126.8 - 127.5)/36.2 = -0.7/36.2 = -0.019337$; $R_{\text{UL}} = 10^{-0.019337} = 0.95645$ km. $A_{\text{site}} = 1.95 \times 0.95645^2 = 1.95 \times 0.91480 = 1.78386$ km². $N = 220/1.78386 = 123.33$, rounded up to 124 sites.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (path loss models); H. Holma and A. Toskala (eds.), *LTE for UMTS* (site count).

</details>

**3.3.6S053**　Rather than building 124 sites, what are the two broad strategies to close the gap, and what does each cost?

<details><summary>看答案</summary>

**答案**　(1) Improve the uplink budget so that its range approaches the downlink range: receive diversity, tower-mounted amplifiers, higher-power terminals, narrower edge allocations or a low-band supplementary uplink; these cost equipment, terminal support or edge throughput. (2) Accept the uplink range and densify, which costs sites. Lowering the downlink power does not help coverage; it only balances the link at the smaller range. In practice a combination is chosen by cost per dB recovered.

**詳解**　Every dB recovered in the uplink reduces the site count by the factor $10^{-2/36.2} = 0.881$ (about 12% per dB) while the uplink still limits.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink coverage improvements and dimensioning).

</details>

**3.3.6S054**　The imbalance is "only" 7.5 dB. Why does it almost triple the site count?

<details><summary>看答案</summary>

**答案**　The site count scales with $1/R^2$ and $R$ depends exponentially on the MAPL, so the ratio of site counts is $10^{2\Delta/(10n)} = 10^{15/36.2} = 2.60$. A few dB of budget translate into a large factor in area because both the exponent of the path loss model and the squaring of the range act on it.

**詳解**　$10^{0.414365} = 2.5964$; $47.50 \times 2.5964 = 123.33$, consistent with the two site counts.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (log-distance path loss model).

</details>

**3.3.6S055**　A manager estimates the uplink site count quickly as follows. Find the wrong step and give the correct number of sites.

2. Site-count factor $= 10^{7.5/36.2} = 1.611$.
3. Sites $= 47.50 \times 1.611 = 76.5$, so 77 sites.

<details><summary>看答案</summary>

**答案**　Step 2 is wrong: $10^{\Delta/(10n)}$ is the range ratio; the site count scales with the area, i.e. with the square of the range ratio, $10^{2\Delta/(10n)} = 2.596$. Correct number: 124 sites.

**詳解**　$47.50 \times 2.5964 = 123.33$, rounded up to 124 sites.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (cell coverage area).

**Scenario | Narrowband IoT trackers: both directions**

A narrowband IoT carrier occupies 180 kHz. In the downlink the base station puts 43 dBm into this carrier through a 15 dBi antenna with 1 dB feeder loss; the tracker has a −3 dBi antenna, noise figure 9 dB and needs SNR −4 dB (with repetitions) over 180 kHz. In the uplink the tracker transmits 23 dBm on a single 15 kHz tone; the base station has noise figure 3 dB and needs SNR −6 dB (with repetitions) over 15 kHz. Use −174 dBm/Hz. Both directions use a 7 dB shadow fading margin, a 1 dB interference margin and a 10 dB indoor penetration loss; nobody holds the trackers.

**3.3.6S056**　Compute both sensitivities, both MAPLs and $\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}}$, giving $\Delta$ in dB rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　$\Delta = 1.21$ dB (nearly balanced, uplink slightly limiting).

**詳解**　$S_{\text{UE}} = -174 + 10\log_{10}(180\,000) + 9 - 4 = -174 + 52.5527 + 5 = -116.4473$ dBm. $S_{\text{BS}} = -174 + 10\log_{10}(15\,000) + 3 - 6 = -174 + 41.7609 - 3 = -135.2391$ dBm. $\text{MAPL}_{\text{DL}} = (43 + 15 - 1) + 116.4473 - 3 - 7 - 1 - 10 = 152.4473$ dB. $\text{MAPL}_{\text{UL}} = (23 - 3) + 135.2391 + 15 - 1 - 7 - 1 - 10 = 151.2391$ dB. $\Delta = 152.4473 - 151.2391 = 1.2082$ dB ≈ 1.21 dB.

**出處**　3GPP TR 45.820 (coverage analysis for low-throughput IoT); T. S. Rappaport, *Wireless Communications: Principles and Practice* (thermal noise; link budget).

</details>

**3.3.6S057**　Broadband carriers are often uplink-limited by 10–15 dB. Why is this narrowband IoT link almost balanced?

<details><summary>看答案</summary>

**答案**　What matters is power per hertz. The base station spreads 43 dBm over 180 kHz, about −9.6 dBm/Hz, while the tracker concentrates 23 dBm into 15 kHz, about −18.8 dBm/Hz: the 20 dB total-power gap shrinks to about 9.2 dB per hertz. The base station's lower noise figure (6 dB better) and lower required SNR (2 dB) cover most of the rest.

**詳解**　$43 - 52.5527 = -9.5527$ dBm/Hz; $23 - 41.7609 = -18.7609$ dBm/Hz; difference 9.2082 dB. $\Delta = 9.2082 - (9 - 3) - (-4 - (-6)) = 9.2082 - 6 - 2 = 1.2082$ dB.

**出處**　3GPP TR 45.820 (single-tone uplink and coverage); T. S. Rappaport, *Wireless Communications: Principles and Practice* (power spectral density).

</details>

**3.3.6S058**　The operator increases the uplink repetitions so that the base station needs 6 dB less SNR. What happens to the imbalance, and what must follow in the downlink?

<details><summary>看答案</summary>

**答案**　The uplink MAPL rises by 6 dB and $\Delta$ becomes $1.21 - 6 = -4.79$ dB: the downlink becomes the limiting direction. To gain coverage, the downlink repetitions must also be increased (or other downlink gains found); otherwise trackers beyond the downlink range still cannot be reached, so the uplink improvement is wasted at the edge.

**詳解**　The usable range follows $\min(\text{MAPL}_{\text{DL}}, \text{MAPL}_{\text{UL}})$ = 152.45 dB after the change, an improvement of only 1.21 dB over the original 151.24 dB.

**出處**　3GPP TR 45.820 (coverage enhancement by repetition).

</details>

#### 情境題：Interference margins and load

**Scenario | Uplink noise rise in the busy hour**

An OFDMA cell is uplink-limited with $\Delta = \text{MAPL}_{\text{DL}} - \text{MAPL}_{\text{UL}} = 8.4$ dB when the neighbouring cells' uplink load is 50%. The uplink interference margin is modelled as the noise rise $M_{I,\text{UL}} = 10\log_{10}\!\left(1/(1-\eta)\right)$, where $\eta$ is the neighbour load; the downlink interference margin is a fixed 3 dB. The uplink-limited range at 50% load is 1.62 km, and the path loss exponent is 3.5.

**3.3.6S061**　Compute the uplink interference margin at 75% neighbour load, in dB, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　6.02 dB

**詳解**　$M_{I,\text{UL}} = 10\log_{10}(1/(1 - 0.75)) = 10\log_{10}(4) = 6.0206$ dB ≈ 6.02 dB.

**出處**　H. Holma and A. Toskala (eds.), *WCDMA for UMTS* (noise rise and interference margin).

</details>

**3.3.6S062**　Compute the imbalance at 75% load (dB, two decimal places) and the new uplink-limited range (km, three decimal places).

<details><summary>看答案</summary>

**答案**　$\Delta = 11.41$ dB; range 1.329 km.

**詳解**　At 50% load: $M_{I,\text{UL}} = 10\log_{10}(2) = 3.0103$ dB. Increase $= 6.0206 - 3.0103 = 3.0103$ dB, which lowers $\text{MAPL}_{\text{UL}}$ by the same amount. $\Delta = 8.4 + 3.0103 = 11.4103$ dB ≈ 11.41 dB. Range factor $= 10^{-3.0103/35} = 0.820335$; range $= 1.62 \times 0.820335 = 1.32894$ km ≈ 1.329 km.

**出處**　H. Holma and A. Toskala (eds.), *WCDMA for UMTS* (noise rise); T. S. Rappaport, *Wireless Communications: Principles and Practice* (log-distance path loss model).

</details>

**3.3.6S063**　This effect is often called "cell breathing". What does the planner have to decide because of it?

<details><summary>看答案</summary>

**答案**　The uplink coverage depends on the load: as the neighbours get busier, the noise rise grows and the uplink range shrinks. The planner must decide at which load the coverage is guaranteed and put the corresponding interference margin in the budget (for example 75% busy-hour load rather than 50%); otherwise the edge users lose uplink coverage exactly when the network is busiest. Higher planned load means smaller cells and more sites.

**詳解**　From 50% to 75% load the range shrank from 1.62 km to 1.33 km (−18%) without any change in hardware or terrain.

**出處**　H. Holma and A. Toskala (eds.), *WCDMA for UMTS* (cell breathing; load and coverage).

</details>

**3.3.6S064**　Why is the noise-rise formula $10\log_{10}(1/(1-\eta))$, inherited from CDMA planning, usually conservative for an OFDMA uplink?

<details><summary>看答案</summary>

**答案**　In CDMA all users of the own cell and the neighbours share the same band, so the load of the own cell also raises the noise. In OFDMA the users within one cell are orthogonal in frequency and time, so only other-cell users on the same resource blocks interfere, and only when they are scheduled there. The actual noise rise is therefore usually lower than the formula suggests for the same nominal load, though it can still be significant at high neighbour load.

**詳解**　In OFDMA link budgets the uplink interference margin is typically taken from system simulations of other-cell interference at the planned load, rather than from the single-cell CDMA load formula.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (uplink interference margin in OFDMA link budgets).

</details>
