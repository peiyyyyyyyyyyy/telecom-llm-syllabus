# 3.5.5 線性與凸最佳化

所屬：[3.5 基礎數理](../3-5.md)

## 正文

In modern telecommunication networks, designers constantly solve resource‑allocation problems: assigning transmit power to base‑station antennas, scheduling time slots for users, selecting coding rates, or configuring beam‑forming vectors in massive MIMO. All of these tasks can be expressed as **optimization problems**, i.e. the search for a vector **x** ∈ ℝⁿ that minimizes (or maximizes) a scalar **objective function** while satisfying a set of **constraints** that model physical, regulatory, or quality‑of‑service (QoS) limits.

When the feasible region is a **convex set** and the objective is a **convex function**, any local optimum is automatically a global optimum. This property makes **convex optimization** the workhorse of network planning: efficient polynomial‑time algorithms (interior‑point, simplex, dual decomposition) can be deployed even on large‑scale problems. A special case of convex optimization is **linear programming (LP)**, where both the objective and all constraints are affine (linear plus a constant). LPs appear in routing, integer‑relaxed channel assignment, and load balancing.

---

### 1. Basic definitions

*Decision variable* **x** = (x₁, …, xₙ)ᵀ  [unit depends on the variable, e.g. Watt for power]

*Objective function* f(**x**) : ℝⁿ → ℝ  [unit of f, e.g. Watt, bit/s, or dimensionless]

*Constraint functions* gᵢ(**x**) ≤ 0, hⱼ(**x**) = 0  [i = 1,…,m ; j = 1,…,p]

*Feasible set* 𝒮 = { **x** ∈ ℝⁿ | gᵢ(**x**) ≤ 0, hⱼ(**x**) = 0 }.

A set 𝒞 ⊆ ℝⁿ is **convex** if for any **u**, **v** ∈ 𝒞 and any λ ∈ [0,1],

$$\lambda \mathbf{u} + (1-\lambda)\mathbf{v} \in \mathcal{C}.$$

A function f is **convex** on a convex domain if

$$f(\lambda \mathbf{u} + (1-\lambda)\mathbf{v}) \le \lambda f(\mathbf{u}) + (1-\lambda)f(\mathbf{v}), \qquad \forall \mathbf{u},\mathbf{v}\in\text{dom }f,\; \lambda\in[0,1].$$

If the inequality is strict for **u** ≠ **v**, the function is **strictly convex**. Linear functions (f(**x**) = **c**ᵀ**x** + d) are both convex and concave.

---

### 2. Standard forms

**Linear programming (LP) – primal form**

$$
\begin{aligned}
\text{minimize}\quad & \mathbf{c}^{\mathsf T}\mathbf{x} \\
\text{subject to}\quad & \mathbf{A}\mathbf{x} \le \mathbf{b},\\
& \mathbf{x} \ge \mathbf{0},
\end{aligned}
$$

where  

* **c** ∈ ℝⁿ (cost coefficients, unit of objective per unit of x)  
* **A** ∈ ℝ^{m×n} (constraint matrix)  
* **b** ∈ ℝ^m (right‑hand side, same unit as each row of **A** **x**)  

All inequalities are component‑wise.

**Convex optimization – generic form**

$$
\begin{aligned}
\text{minimize}\quad & f(\mathbf{x}) \\
\text{subject to}\quad & g_i(\mathbf{x}) \le 0,\; i=1,\dots,m,\\
& h_j(\mathbf{x}) = 0,\; j=1,\dots,p,
\end{aligned}
$$

with each gᵢ convex and each hⱼ affine.

---

### 3. Duality and KKT conditions

For a convex problem satisfying Slater’s condition (existence of a strictly feasible point), the **Lagrangian**

$$
\mathcal{L}(\mathbf{x},\boldsymbol{\lambda},\boldsymbol{\nu}) = f(\mathbf{x}) + \sum_{i=1}^{m}\lambda_i g_i(\mathbf{x}) + \sum_{j=1}^{p}\nu_j h_j(\mathbf{x})
$$

leads to the **dual problem**

$$
\begin{aligned}
\text{maximize}\quad & \inf_{\mathbf{x}} \mathcal{L}(\mathbf{x},\boldsymbol{\lambda},\boldsymbol{\nu})\\
\text{subject to}\quad & \lambda_i \ge 0,\; i=1,\dots,m.
\end{aligned}
$$

Optimal primal‑dual pairs satisfy the **Karush‑Kuhn‑Tucker (KKT) conditions**:

1. **Primal feasibility:** gᵢ(**x***) ≤ 0, hⱼ(**x***) = 0.  
2. **Dual feasibility:** λᵢ* ≥ 0.  
3. **Complementary slackness:** λᵢ* gᵢ(**x***) = 0.  
4. **Stationarity:** ∇f(**x***) + Σᵢ λᵢ*∇gᵢ(**x***) + Σⱼ νⱼ*∇hⱼ(**x***) = **0**.

These conditions are the basis for many distributed algorithms used in wireless networks (e.g., dual decomposition for power control).

### 4. Worked example – Power minimization with a rate constraint (water‑filling)

*Problem statement*: A single‑carrier link experiences two independent sub‑channels with gains $h_1 = 2$ and $h_2 = 1$ (dimensionless). The noise spectral density is $N_0 = 10^{-9}$ W/Hz, and the system bandwidth per sub‑channel is $B = 1$ MHz. The required total data rate is $R_{\text{req}} = 6$ Mbit/s. Find the transmit powers $p_1, p_2$ (W) that **minimize** total power $p_1 + p_2$ while satisfying the Shannon capacity constraint

$$
\sum_{k=1}^{2} B\log_2\!\bigl(1 + \frac{h_k p_k}{N_0 B}\bigr) \ge R_{\text{req}}.
$$

*Formulation* (convex because $\log(1+ax)$ is concave, and we minimize a linear function):

$$
\begin{aligned}
\min_{p_1,p_2\ge 0}\;& p_1 + p_2\\
\text{s.t.}\;& B\log_2\!\bigl(1 + \frac{2p_1}{N_0 B}\bigr) + B\log_2\!\bigl(1 + \frac{p_2}{N_0 B}\bigr) \ge 6\text{ Mbit/s}.
\end{aligned}
$$

Define the Lagrange multiplier λ ≥ 0 for the rate constraint. The KKT stationarity condition yields

$$
1 - \lambda \frac{B}{\ln 2}\frac{h_k}{N_0 B + h_k p_k}=0
\;\;\Longrightarrow\;\;
p_k = \biggl[\frac{\lambda h_k}{\ln 2} - N_0 B\biggr]^+,
$$

where $[x]^+ = \max\{0,x\}$. This is the classic **water‑filling** solution: allocate power above a common water level $\frac{\lambda}{\ln 2}$.

*Finding λ*: Substitute the expression into the rate constraint and solve for λ numerically. For this small problem an analytical solution is possible.

Let $W = \frac{\lambda}{\ln 2}$. Then

$$
p_1 = [2W - N_0 B]^+,\quad p_2 = [W - N_0 B]^+ .
$$

Because the required rate is modest, both terms will be positive. Compute $N_0 B = 10^{-9}\times10^{6}=10^{-3}$ W.

The capacity contributed by each sub‑channel is

$$
C_k = B\log_2\!\bigl(1 + \frac{h_k p_k}{N_0 B}\bigr)= B\log_2\!\bigl(1 + \frac{h_k([h_kW - N_0 B])}{N_0 B}\bigr)= B\log_2\!\bigl(\frac{h_kW}{N_0 B}\bigr).
$$

Thus total rate:

$$
R(W)= B\Bigl[\log_2\!\bigl(\frac{2W}{10^{-3}}\bigr)+\log_2\!\bigl(\frac{W}{10^{-3}}\bigr)\Bigr]
= B\log_2\!\bigl(\frac{2W^2}{10^{-6}}\bigr).
$$

Set $R(W)=6\times10^{6}$ bit/s and $B=10^{6}$ Hz:

$$
10^{6}\log_2\!\bigl(\frac{2W^2}{10^{-6}}\bigr)=6\times10^{6}
\;\Longrightarrow\;
\log_2\!\bigl(\frac{2W^2}{10^{-6}}\bigr)=6
\;\Longrightarrow\;
\frac{2W^2}{10^{-6}} = 2^{6}=64
\;\Longrightarrow\;
W^2 = \frac{64\times10^{-6}}{2}=3.2\times10^{-5}
\;\Longrightarrow\;
W = \sqrt{3.2\times10^{-5}} \approx 5.66\times10^{-3}\;\text{W}.
$$

Now compute powers:

$$
p_1 = 2W - 10^{-3} \approx 2(5.66\times10^{-3})-10^{-3}=10.32\times10^{-3}\,\text{W}=10.3\;\text{mW},
$$
$$
p_2 = W - 10^{-3} \approx 5.66\times10^{-3}-10^{-3}=4.66\times10^{-3}\,\text{W}=4.7\;\text{mW}.
$$

*Result*: The minimum total transmit power is $p_1+p_2 \approx 15.0$ mW, achieved by water‑filling the better channel (higher gain) more heavily.

### 5. Common pitfalls and practical notes

| Pitfall | Why it happens | Remedy |
|---------|----------------|--------|
| Treating a non‑convex objective (e.g., integer‑valued carrier assignment) as convex | Ignoring integrality leads to infeasible or sub‑optimal schedules | Use mixed‑integer programming or relax the problem and then apply a rounding scheme while checking feasibility |
| Forgetting units in the constraint matrix **A** or in the noise term $N_0B$ | Leads to scaling issues, causing numerical ill‑conditioning for interior‑point solvers | Normalize variables (e.g., express power in dBm, rates in bits/s/Hz) and keep a consistent unit system |
| Assuming that any local optimum is global without verifying convexity | Many network utility functions (e.g., sum‑log‑rate) are concave, but adding a non‑convex penalty (e.g., piecewise linear cost) destroys convexity | Check the Hessian or use disciplined convex programming (CVX) rules before applying convex solvers |
| Misapplying complementary slackness: setting λᵢ = 0 for all active constraints | Violates KKT, yields wrong power allocation | Remember that for an active inequality (gᵢ(**x***) = 0) the corresponding multiplier λᵢ* may be > 0; only inactive constraints have λᵢ* = 0 |
| Over‑relying on the simplex method for very large LPs | Simplex can exhibit exponential worst‑case time; large‑scale network problems often have thousands of variables | Prefer interior‑point or specialized decomposition methods (e.g., ADMM) that exploit sparsity |

In practice, telecom engineers embed these optimization kernels inside higher‑level control loops (e.g., link adaptation, self‑organizing networks). Maintaining a clear convex formulation guarantees that the inner loop converges quickly and reliably, which is essential for real‑time operation.

**1.** Which of the following statements about convex functions is **always true**?

- A. The epigraph of a convex function is a non‑convex set.
- B. The sum of two convex functions is convex.
- C. A convex function must be differentiable everywhere.
- D. The negative of a convex function is also convex.

<details><summary>看答案</summary>

正解：B。The epigraph of a convex function is convex, not non‑convex; convex functions need not be differentiable (e.g., absolute value); the negative of a convex function is concave, not convex.

</details>

**2.** In the standard primal linear program, which constraint guarantees that the decision variables are non‑negative?

- A. $\mathbf{A}\mathbf{x} \le \mathbf{b}$
- B. $\mathbf{c}^{\mathsf T}\mathbf{x}$ is minimized
- C. $\mathbf{x} \ge \mathbf{0}$
- D. $\mathbf{b} \ge \mathbf{0}$

<details><summary>看答案</summary>

正解：C。The explicit inequality $\mathbf{x} \ge \mathbf{0}$ forces each component of **x** to be non‑negative; the other constraints do not.

</details>

**3.** For a convex optimization problem satisfying Slater’s condition, which of the following is guaranteed?

- A. The primal optimal value is always larger than the dual optimal value.
- B. Strong duality holds, i.e., primal and dual optimal values are equal.
- C. There exists a unique optimal solution regardless of the objective.
- D. All Lagrange multipliers must be zero.

<details><summary>看答案</summary>

正解：B。Slater’s condition ensures zero duality gap (strong duality); the other statements are false in general.

</details>

**4.** A base station serves two users over orthogonal sub‑carriers. The channel gains are $h_1=3$ and $h_2=0.5$. Noise PSD is $N_0=2\times10^{-9}$ W/Hz, bandwidth per sub‑carrier $B=0.5$ MHz. The required sum rate is $R_{\text{req}}=4$ Mbit/s. Using the water‑filling solution derived in the text, compute the minimum total transmit power (in milliwatts, mW).


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Compute noise power per sub‑carrier: $N_0 B = 2\times10^{-9}\times5\times10^{5}=1\times10^{-3}$ W = 1 mW.  
2. Let water level $W$ satisfy  
   $$
   R(W)=B\log_2\!\bigl(\frac{h_1W}{N_0B}\bigr)+B\log_2\!\bigl(\frac{h_2W}{N_0B}\bigr)=4\times10^{6}\text{ bit/s}.
   $$  
   With $B=5\times10^{5}$ Hz, divide both sides by $B$:  
   $$
   \log_2\!\bigl(\frac{3W}{10^{-3}}\bigr)+\log_2\!\bigl(\frac{0.5W}{10^{-3}}\bigr)=8.
   $$  
   Combine logs:  
   $$
   \log_2\!\bigl(\frac{3W\cdot0.5W}{10^{-6}}\bigr)=8 \Rightarrow \frac{1.5W^{2}}{10^{-6}}=2^{8}=256.
   $$  
   Solve for $W^{2}$:  
   $$
   W^{2}= \frac{256\times10^{-6}}{1.5}=1.7067\times10^{-4}\;\Rightarrow\;W=\sqrt{1.7067\times10^{-4}}\approx1.306\times10^{-2}\text{ W}=13.06\text{ mW}.
   $$

   $p_1 = h_1W - N_0B = 3\cdot13.06\text{ mW} - 1\text{ mW}=38.18\text{ mW}$.  
   $p_2 = h_2W - N_0B = 0.5\cdot13.06\text{ mW} - 1\text{ mW}=5.53\text{ mW}$.

**5.** Consider a linear program: minimize $c_1x_1 + c_2x_2$ with $c_1=4$, $c_2=1$. Constraints: $x_1 + 2x_2 \ge 8$, $3x_1 + x_2 \le 12$, and $x_1, x_2 \ge 0$. Find the optimal objective value (in the same units as the cost coefficients).


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Convert the “≥” constraint to “≤” by multiplying by –1: $-x_1 -2x_2 \le -8$.  
2. The feasible region is the intersection of three half‑planes. Compute intersection points of the boundary lines:  

   - Intersection of $x_1 + 2x_2 = 8$ and $3x_1 + x_2 = 12$:  
     Solve: from first, $x_1 = 8 - 2x_2$. Substitute into second: $3(8-2x_2)+x_2 =12$ → $24 -6x_2 + x_2 =12$ → $-5x_2 = -12$ → $x_2 = 12/5 = 2.4$.  
     Then $x_1 = 8 - 2(2.4)=8 -4.8=3.2$.  

   - Intersection with axes:  

     * For $x_1+2x_2=8$ and $x_2=0$: $x_1=8$.  
     * For $3x_1+x_2=12$ and $x_1=0$: $x_2=12$.  

   Feasibility requires also $x_1, x_2 \ge 0$ and the two constraints. The point (8,0) violates $3x_1+x_2\le12$ (24>12). The point (0,12) violates $x_1+2x_2\ge8$ (24≥8 is true, but $3x_1+x_2=12$ is okay; however, (0,12) does not satisfy the first inequality in its original “≥” sense? It does: 0+24≥8, so feasible).  

   Check feasibility of (0,12): it satisfies both constraints, so it is a vertex.  

3. Evaluate objective at each vertex of the feasible polygon:  

   - At (3.2, 2.4): $4·3.2 + 1·2.4 = 12.8 + 2.4 = 15.2$.  
   - At (0, 12): $4·0 + 1·12 = 12$.  
   - At the intersection of $x_1+2x_2=8$ with $x_2=0$ is infeasible, so ignore.  

   The smallest objective value is **12** at (0, 12).  
$$
$\boxed{12}$
$$

</details>
