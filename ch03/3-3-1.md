# 3.3.1 發射功率與 EIRP

所屬：[3.3 鏈路預算](3-3.md)

## 內文

#### 為什麼要學

鏈路預算（link budget）是一張把「發射端送出多少功率、路上損失多少、接收端至少要收到多少」逐項列出的收支表，第一列就是發射端。基地臺的功率放大器輸出多少瓦，並不等於天線主波束方向上實際送出去的強度：中間還要扣掉饋線與接頭的損耗，再加上天線把能量集中到某個方向所帶來的增益。把這三件事合成一個數字，就是等效全向輻射功率（equivalent isotropically radiated power, EIRP）。涵蓋規劃、干擾評估、電磁波暴露評估與頻率主管機關的發射限值，多半都以 EIRP（或它的近親 ERP）為準，所以這是讀規格書、站臺資料表與法規時最先要會算的量。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $P_t$ | 發射機（功率放大器）輸出功率 | W 或 dBm、dBW |
| $L_t$ | 發射端損耗：饋線、接頭、合路器等，從功放輸出到天線輸入端 | dB（正值） |
| $G_t$ | 發射天線在指定方向的增益，相對於等向性天線 | dBi |
| $G_{t,d}$ | 發射天線在指定方向的增益，相對於半波偶極天線 | dBd |
| EIRP | 等效全向輻射功率 | W 或 dBm、dBW |
| ERP | 有效輻射功率（effective radiated power），以半波偶極為基準 | W 或 dBm、dBW |
| $S$ | 距離 $d$ 處的功率通量密度 | W/m² |
| $d$ | 與發射天線的距離（遠場） | m |

#### 公式與推導

國際電信聯合會《無線電規則》對 EIRP 的定義是：送進天線的功率，乘上天線在指定方向相對於等向性天線（isotropic antenna）的增益。送進天線的功率是功放輸出扣掉饋線損耗之後的值，因此用線性量寫成

$$\text{EIRP} = \frac{P_t\,G_t}{L_t}\quad(\text{W；}G_t\text{、}L_t\text{ 為線性倍數})$$

取對數後乘除變加減：

$$\text{EIRP (dBm)} = P_t\,(\text{dBm}) + G_t\,(\text{dBi}) - L_t\,(\text{dB})$$

功率單位的換算是 $P(\text{dBm}) = 10\log_{10}\!\big(P/1\,\text{mW}\big)$、$P(\text{dBW}) = 10\log_{10}\!\big(P/1\,\text{W}\big)$，兩者相差 30 dB（見 3.1.1）。

EIRP 的物理意義是：若把真實天線換成一支向所有方向均勻輻射的假想天線，要在「指定方向」產生同樣的場強，需要送進多少功率。因此在遠場、自由空間條件下，距離 $d$ 處的功率通量密度為

$$S = \frac{\text{EIRP}}{4\pi d^2}$$

ERP 的定義完全相同，只是比較基準改成半波偶極天線（half-wave dipole）。無損耗半波偶極本身相對於等向性天線的增益是 1.64 倍，即 $10\log_{10}(1.64) = 2.15$ dB，所以

$$\text{ERP} = \frac{\text{EIRP}}{1.64},\qquad \text{ERP (dBm)} = \text{EIRP (dBm)} - 2.15$$

同一支天線、同一個方向，EIRP 的數字永遠比 ERP 大 2.15 dB，兩者描述的是同一個實體輻射量，只是基準不同。

使用時要注意三件事。第一，EIRP 是方向的函數，沒有特別說明時指主波束最大增益方向；偏離主波束的方向要改用該方向的增益。第二，$P_t$ 必須和討論的訊號對應：整個載波的總功率、每個資源區塊或每 MHz 的功率，算出來的 EIRP 意義不同，法規常以「每若干 MHz 的 EIRP」設限。第三，多支天線元件同相合成時，若每個元件的功率固定為 $P$、共 $N$ 個元件，總功率是 $NP$，理想陣列增益又是 $N$ 倍，主波束方向的 EIRP 會隨 $N^2$ 成長（即 $20\log_{10}N$ dB）；這是理想同相合成的上限，實際值要扣掉效率與校正誤差。

#### 算例

**算例 1（由功放功率求 EIRP 與 ERP）**　已知：基地臺功放輸出 40 W；饋線與接頭損耗合計 2 dB（假設）；天線增益 17 dBi（假設）。求主波束方向的 EIRP 與 ERP。

1. 功率換成 dBm：$P_t = 10\log_{10}(40{,}000\ \text{mW}) = 46.02$ dBm。
2. 代入：$\text{EIRP} = 46.02 + 17 - 2 = 61.02$ dBm $= 31.02$ dBW。
3. 換回瓦：用未取位的 31.0206 dBW，$10^{3.10206} = 1{,}264.9$ W，約 1.26 kW（若用已取位的 31.02 會得到 1,264.7 W，差異來自取位）。
4. ERP：$61.02 - 2.15 = 58.87$ dBm，即 $1{,}264.9 / 1.64 = 771.3$ W。

合理性檢查：淨增益為 $17 - 2 = 15$ dB，約 31.6 倍，$40 \times 31.6 = 1{,}264$ W，與第 3 步一致。EIRP 遠大於功放的 40 W，並不代表能量變多，而是能量被集中到主波束。

**算例 2（由 ERP 換算 EIRP）**　已知：某站臺資料表登記 ERP 為 500 W。求 EIRP。

1. 線性：$\text{EIRP} = 500 \times 1.64 = 820$ W。
2. 以 dB 驗算：$10\log_{10}(500) = 26.99$ dBW，加 2.15 dB 得 29.14 dBW，即 59.14 dBm；$10^{2.914} = 820$ W，兩種算法一致。

#### 常見錯誤

- **把 ERP 當 EIRP 直接比較**：兩者差 2.15 dB（1.64 倍）。比較限值或不同文件的數字前，先確認基準是等向性還是半波偶極。
- **dBm 與 dBW 混用**：46 dBm 是 16 dBW，不是 46 dBW；漏掉 30 dB 相當於差一千倍。
- **損耗的正負號弄反**：$L_t$ 定義為正值並用減的；若把損耗寫成負的增益又再減一次，結果會多出兩倍的損耗量。
- **以為 EIRP 是實際輻射的總功率**：實際輻射的總功率不會超過送進天線的功率。EIRP 只在指定方向有意義，其他方向的等效值比較小。

#### 和其他小節的關係

功率單位換算用 3.1.1；$G_t$ 的來源與 dBi、dBd 的差別在 3.3.2 說明；$L_t$ 與其他損耗、餘量的整理在 3.3.3。本節算出的 EIRP 是 3.3.5 最大允許路徑損耗的起點，並在 3.3.6 分別用於上行與下行；功率通量密度與自由空間路徑損耗的關係見 3.1.2。
