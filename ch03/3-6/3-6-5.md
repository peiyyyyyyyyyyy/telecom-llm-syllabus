# 3.6.5 驗算

所屬：[3.6 解題方法](../3-6.md)

## 練習題

**1.** Which of the following is *not* a valid verification technique for a telecommunications calculation?

- A. Substituting the computed result back into the original equation
- B. Checking that all terms share the same unit system
- C. Ignoring rounding errors because they are negligible
- D. Comparing the result with a known special‑case value

<details><summary>看答案</summary>

正解：C。Ignoring rounding errors can hide significant discrepancies; proper verification must account for them.

</details>

**2.** In a free‑space link‑budget check, a residual error $R$ of $+0.8\ \text{dB}$ is observed after back‑substitution. Which tolerance is most commonly accepted for such calculations?

- A. 0 dB
- B. ±0.1 dB
- C. ±1 dB
- D. ±10 dB

<details><summary>看答案</summary>

正解：C。Engineering practice usually tolerates residuals up to about ±1 dB for link‑budget verification.

</details>

**3.** Which statement about sanity (order‑of‑magnitude) checks is correct?

- A. They replace the need for a full calculation.
- B. They are only useful for analog circuit design.
- C. They involve estimating the result using simplified formulas and comparing the magnitude.
- D. They require the exact final numeric value.

<details><summary>看答案</summary>

正解：C。Sanity checks provide a quick magnitude estimate to flag gross errors without needing the full detailed computation.

</details>

**4.** A point‑to‑point microwave link operates at $f = 12\ \text{GHz}$ over a distance $d = 15\ \text{km}$. The transmitter power is $P_{\text{tx}} = 20\ \text{dBm}$, the antenna gains are $G_t = 30\ \text{dBi}$ and $G_r = 35\ \text{dBi}$. Compute the received power $P_{\text{rx}}$ in dBm using the free‑space path‑loss model, then verify by back‑substitution. Report the verified $P_{\text{rx}}$ (rounded to one decimal place).


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Compute wavelength: $\lambda = c/f = 3.0\times10^{8}\ \text{m/s} / 12\times10^{9}\ \text{Hz} = 0.025\ \text{m}$.  
2. Compute $L_p = 20\log_{10}(4\pi d/\lambda)$.  
   $4\pi d/\lambda = 4\pi \times 15\,000\ \text{m} / 0.025\ \text{m} = 7.54\times10^{6}$.  
   $L_p = 20\log_{10}(7.54\times10^{6}) = 20 \times 6.877 = 137.5\ \text{dB}$.  
3. Link‑budget: $P_{\text{rx}} = 20 + 30 + 35 - 137.5 = -52.5\ \text{dBm}$.  
4. Verification: RHS = $20 + 30 + 35 - 137.5 = -52.5\ \text{dBm}$, same as computed, so residual $R = 0\ \text{dB}$.  
$\boxed{-52.5}$

</details>

**5.** A cellular uplink uses $P_{\text{tx}} = 5\ \text{dBm}$, $G_t = 2\ \text{dBi}$, $G_r = 0\ \text{dBi}$, $f = 900\ \text{MHz}$, and $d = 500\ \text{m}$. Compute the received power $P_{\text{rx}}$ in dBm (rounded to two decimal places) and verify by calculating the residual $R$ after back‑substitution. Provide the final $P_{\text{rx}}$ value.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. $\lambda = c/f = 3.0\times10^{8}/9.0\times10^{8}=0.3333\ \text{m}$.  
2. $4\pi d/\lambda = 4\pi \times 500 / 0.3333 = 18849.6$.  
3. $L_p = 20\log_{10}(18849.6) = 20 \times 4.275 = 85.50\ \text{dB}$.  
4. $P_{\text{rx}} = 5 + 2 + 0 - 85.50 = -78.50\ \text{dBm}$.  
5. Verification: RHS = $5 + 2 + 0 - 85.50 = -78.50\ \text{dBm}$, so $R = 0\ \text{dB}$.  
$\boxed{-78.50}$

</details>
