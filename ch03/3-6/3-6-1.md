# 3.6.1 讀題：找出已知、未知與隱含假設，再選公式

所屬：[3.6 解題方法](../3-6.md)

## 正文

In any telecommunications calculation—whether you are sizing a cellular link, estimating interference, or evaluating a coding scheme—the first step is *reading* the problem statement.  
A correct reading accomplishes three things:

1. **Extract all given quantities (knowns)** and write them with their units and, if necessary, convert them to a consistent system (e.g., SI).  
2. **Identify the quantity to be found (unknown)** and its required unit.  
3. **Spot any hidden assumptions** (line‑of‑sight, far‑field, thermal equilibrium, etc.) that dictate which theoretical model or formula is appropriate.

Skipping any of these steps leads to the wrong formula, unit mismatches, or an answer that is physically impossible. In real networks, an erroneous link‑budget, for example, can cause a base‑station to be under‑powered, resulting in coverage holes and dropped calls.

### Key Definitions and Formulas

The most common single‑step calculation in wireless planning is the **Friis transmission equation** for free‑space line‑of‑sight links.

$$
P_r = \frac{P_t\,G_t\,G_r\,\lambda^{2}}{(4\pi d)^{2}\,L}
\tag{1}
$$

| Symbol | Meaning | Unit |
|--------|---------|------|
| $P_t$ | Transmit power (average, linear) | **W** |
| $G_t$ | Transmit antenna gain (linear, referenced to isotropic) | – |
| $G_r$ | Receive antenna gain (linear) | – |
| $\lambda$ | Wavelength, $\lambda = c/f$ | **m** |
| $d$ | Separation between antennas (far‑field distance) | **m** |
| $L$ | System loss factor (cables, connectors, polarization mismatch) | – |
| $P_r$ | Received power (linear) | **W** |

The same relationship is often expressed in decibels:

$$
P_r\;[\mathrm{dBm}] = P_t\;[\mathrm{dBm}] + G_t\;[\mathrm{dBi}] + G_r\;[\mathrm{dBi}]
- L_{\text{fs}}\;[\mathrm{dB}] - L\;[\mathrm{dB}]
\tag{2}
$$

where the **free‑space path loss** is

$$
L_{\text{fs}}\;[\mathrm{dB}] = 20\log_{10}\!\bigl(4\pi d/\lambda\bigr)
= 20\log_{10}(d) + 20\log_{10}(f) + 32.44
\tag{3}
$$

with $d$ in **km**, $f$ in **MHz**, and the constant 32.44 dB accounts for the unit conversion.

*Conversion between linear and dB*:

$$
\text{Linear} = 10^{\frac{\text{dB}}{10}}, \qquad
\text{dB} = 10\log_{10}(\text{Linear})
\tag{4}
$$

### Worked Example

**Problem statement**  
A point‑to‑point microwave link operates at $f = 2.4\;\text{GHz}$ over a distance of $d = 5\;\text{km}$. The transmitter outputs $P_t = 10\;\text{W}$. The transmit antenna gain is $G_t = 3\;\text{dBi}$ and the receive antenna gain is $G_r = 6\;\text{dBi}$. System losses (cables, connectors) amount to $L = 2\;\text{dB}$. Compute the received power $P_r$ in dBm.

| Step | Action | Result |
|------|--------|--------|
| 1️⃣ | **List knowns** | $P_t = 10\;\text{W},\; G_t = 3\;\text{dBi},\; G_r = 6\;\text{dBi},\; f = 2.4\;\text{GHz},\; d = 5\;\text{km},\; L = 2\;\text{dB}$ |
| 2️⃣ | **Identify unknown** | $P_r$ (requested in dBm) |
| 3️⃣ | **Check assumptions** | Free‑space, line‑of‑sight, far‑field (distance ≫ λ), isotropic reference for gains – all satisfied. |
| 4️⃣ | **Convert gains & loss to linear** | $G_t = 10^{3/10}=1.995$, $G_r = 10^{6/10}=3.981$, $L_{\text{lin}} = 10^{2/10}=1.585$ |
| 5️⃣ | **Compute wavelength** | $\lambda = c/f = 3\times10^{8}\; \text{m/s} / 2.4\times10^{9}\; \text{Hz}=0.125\;\text{m}$ |
| 6️⃣ | **Apply Friis (1)** | $$
P_r = \frac{10 \times 1.995 \times 3.981 \times (0.125)^2}{(4\pi \times 5000)^2 \times 1.585}
      = 1.99\times10^{-10}\;\text{W}
$$ |
| 7️⃣ | **Convert to dBm** | $$
P_r\;[\text{dBm}] = 10\log_{10}\!\bigl(\frac{1.99\times10^{-10}}{10^{-3}}\bigr) = -67.0\;\text{dBm}
$$ |

$$
\boxed{-67.0}
$$

**Interpretation** – A received power of –67 dBm is typical for a high‑gain microwave link; the value confirms that the link budget is realistic under the assumed free‑space conditions.

### Common Mistakes & Practical Tips

| Mistake | Why it Happens | How to Avoid |
|---------|----------------|--------------|
| **Leaving gains in dBi** when using the linear Friis equation | dBi is a logarithmic unit; multiplying dBi with linear quantities is illegal. | Convert every dBi (or dBd) to linear using (4). |
| **Mixing distance units** (km in (3) but meters in (1)) | The constant 32.44 dB in (3) assumes km/MHz; using meters yields a 60 dB error. | Keep a unit‑consistency checklist: km for (3), m for (1). |
| **Ignoring system loss** | Problem statements often list cable loss separately; forgetting it inflates $P_r$. | Explicitly write $L_{\text{lin}} = 10^{L_{\text{dB}}/10}$ and include it in the denominator. |
| **Assuming free‑space when the environment is obstructed** | The Friis model only applies to unobstructed LOS. | Look for clues: “urban canyon”, “indoor”, “terrain” → use a different path‑loss model (e.g., Hata, COST‑231). |
| **Using the wrong reference for noise power** when later computing SNR | Noise is often expressed per Hertz; forgetting the bandwidth leads to a 10‑log‑B error. | Write $N = kTB$ explicitly before using SNR. |

A disciplined reading routine—**list‑knowns → list‑unknowns → list‑assumptions → choose‑formula**—eliminates these pitfalls and builds a solid foundation for every subsequent calculation.

## 練習題

**1.** When a problem provides antenna gains as “4 dBi” and “8 dBi”, which of the following steps is **required** before inserting the gains into the linear Friis equation?

- A. Convert the gains to watts using $P = 10^{G/10}$ W.
- B. Convert the gains to linear scale using $G_{\text{lin}} = 10^{G_{\text{dBi}}/10}$.
- C. Use the dBi values directly because the Friis equation works in dB.
- D. Divide each dBi value by 10 to obtain the linear gain.

<details><summary>看答案</summary>

正解：B。The Friis equation in linear form needs dimensionless linear gains; dBi must be converted with $10^{G/10}$.

</details>

**2.** Which implicit assumption must hold for the Friis transmission equation to be valid?

- A. The antennas are operating in the near‑field region.
- B. Multipath fading dominates the channel.
- C. The link is free‑space, line‑of‑sight, and the distance is much larger than the wavelength.
- D. The transmit power is expressed in dBm.

<details><summary>看答案</summary>

正解：C。Friis assumes free‑space, far‑field propagation with a clear line of sight.

</details>

**3.** A problem states that the free‑space path loss is “112 dB”. To use this value in the linear Friis equation, you must:

- A. Add 112 to the other dB terms.
- B. Multiply the other linear terms by 112.
- C. Convert 112 dB to a linear factor using $10^{112/10}$.
- D. Convert 112 dB to a linear factor using $10^{-112/10}$.

<details><summary>看答案</summary>

正解：D。Path loss is a reduction factor; in linear form it is $10^{-L_{\text{dB}}/10}$.

</details>

**4.** A point‑to‑point link operates at $f = 900\;\text{MHz}$ over a distance of $d = 2\;\text{km}$. The transmitter outputs $P_t = 5\;\text{W}$. Transmit antenna gain is $G_t = 9\;\text{dBi}$, receive antenna gain is $G_r = 12\;\text{dBi}$, and system loss is $L = 1\;\text{dB}$. Compute the received power $P_r$ in dBm.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Convert gains and loss to linear:  
$G_t = 10^{9/10}=7.9433$, $G_r = 10^{12/10}=15.8489$, $L_{\text{lin}} = 10^{1/10}=1.2589$.  
2. Compute wavelength: $\lambda = c/f = 3\times10^{8}/9\times10^{8}=0.3333\;\text{m}$.  
3. Compute the Friis factor: $\bigl(\lambda/(4\pi d)\bigr)^2 = \bigl(0.3333/(4\pi\times2000)\bigr)^2 = 1.761\times10^{-10}$.  
4. Apply (1):  
$P_r = \dfrac{5 \times 7.9433 \times 15.8489 \times 1.761\times10^{-10}}{1.2589}=8.81\times10^{-8}\;\text{W}$.  
5. Convert to dBm:  
$P_r\;[\text{dBm}] = 10\log_{10}(8.81\times10^{-8}/10^{-3}) = -40.55\;\text{dBm}$.  
$\boxed{-40.55}$

</details>

**5.** A communication channel has a bandwidth of $B = 20\;\text{MHz}$ and a signal‑to‑noise ratio of $\text{SNR}=15\;\text{dB}$. Using Shannon’s capacity formula, compute the maximum achievable data rate $C$ in megabits per second (Mbps).


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Convert SNR to linear: $\text{SNR}_{\text{lin}} = 10^{15/10}=31.6228$.  
2. Apply Shannon: $C = B\log_2(1+\text{SNR}_{\text{lin}})$.  
3. Compute: $C = 20\times10^{6}\times\log_2(1+31.6228) = 20\times10^{6}\times\log_2(32.6228)$.  
   $\log_2(32.6228)=\frac{\ln 32.6228}{\ln 2}=5.027$.  
4. $C = 20\times10^{6}\times5.027 = 1.0054\times10^{8}\;\text{bit/s}$.  
5. Convert to Mbps: $C = 100.54\;\text{Mbps}$.  
$\boxed{100.54}$

</details>
