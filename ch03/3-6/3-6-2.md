# 3.6.2 多步計算逐步寫出

所屬：[3.6 解題方法](../3-6.md)

## 練習題

**1.** After obtaining the received power $P_r$ from the Friis equation, which quantity must be calculated next before applying the Shannon capacity formula?

- A. Convert $P_r$ to dBm.
- B. Compute the noise power $N = kTB$.
- C. Determine the antenna gains in linear scale.
- D. Evaluate the path loss in dB.

<details><summary>看答案</summary>

正解：B。Shannon’s formula requires the signal‑to‑noise ratio, so the linear noise power must be known before forming SNR.

</details>

**2.** In the Friis transmission equation $P_r = \dfrac{P_t G_t G_r \lambda^2}{(4\pi d)^2 L}$, the factor $L$ represents:

- A. The free‑space path loss.
- B. The combined effect of cable, polarization, and other implementation losses.
- C. The antenna directivity in linear units.
- D. The receiver noise figure.

<details><summary>看答案</summary>

正解：B。$L$ is a linear loss factor that accounts for any additional attenuation not captured by the free‑space term.

</details>

**3.** Which practice best minimizes the impact of rounding errors in a multi‑step telecom calculation?

- A. Round each intermediate result to three significant figures.
- B. Keep full calculator precision until the final answer, then round.
- C. Convert all intermediate results to dB before proceeding.
- D. Use only integer values for distances and frequencies.

<details><summary>看答案</summary>

正解：B。Delaying rounding preserves accuracy; premature rounding can accumulate error.

</details>

**4.** A microwave link operates at $f = 900\,$MHz with transmit power $P_t = 5\,$W, transmit antenna gain $G_t = 12\,$dBi, receive antenna gain $G_r = 8\,$dBi, distance $d = 2\,$km, system loss $L = 1.5$, and bandwidth $B = 10\,$MHz. Assuming $T=290\,$K, compute the achievable data rate $C$ in **Mbps**. (Use $c=3\times10^{8}$ m/s, $k=1.38\times10^{-23}$ J/K.)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Convert gains: $G_t = 10^{12/10}=15.8489$, $G_r = 10^{8/10}=6.3096$.  
2. Wavelength: $\lambda = c/f = 3\times10^{8} / 9\times10^{8}=0.3333\,$m.  
3. Friis: $P_r = \dfrac{5 \times 15.8489 \times 6.3096 \times (0.3333)^2}{(4\pi \times 2000)^2 \times 1.5}=5.86\times10^{-8}\,$W.  
4. Noise power: $N = kTB = 1.38\times10^{-23}\times290\times10^{7}=4.00\times10^{-14}\,$W.  
5. SNR: $\text{SNR}=P_r/N = 5.86\times10^{-8}/4.00\times10^{-14}=1.46\times10^{6}$.  
6. Capacity: $C = B\log_2(1+\text{SNR}) = 10^{7}\,\log_2(1+1.46\times10^{6}) = 2.05\times10^{8}\,$bit/s.  
7. Convert to Mbps: $C = 205\,$Mbps.  
$\boxed{205}$

</details>

**5.** For a point‑to‑point link at $f = 2.1\,$GHz, distance $d = 3\,$km, bandwidth $B = 5\,$MHz, required capacity $C = 10\,$Mbps, transmit antenna gain $G_t = 10\,$dBi, receive antenna gain $G_r = 5\,$dBi, system loss $L = 2$, and $T=290\,$K, determine the minimum transmit power $P_t$ in **mW**. (Use $c=3\times10^{8}$ m/s, $k=1.38\times10^{-23}$ J/K.)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Convert gains: $G_t = 10^{10/10}=10$, $G_r = 10^{5/10}=3.1623$.  
2. Required SNR from Shannon: $C = B\log_2(1+\text{SNR}) \Rightarrow \text{SNR}=2^{C/B}-1 = 2^{10/5}-1 = 2^{2}-1 = 3$.  
3. Noise power: $N = kTB = 1.38\times10^{-23}\times290\times5\times10^{6}=2.001\times10^{-14}\,$W.  
4. Required receive power: $P_r = \text{SNR}\times N = 3\times2.001\times10^{-14}=6.003\times10^{-14}\,$W.  
5. Wavelength: $\lambda = c/f = 3\times10^{8}/2.1\times10^{9}=0.142857\,$m, $\lambda^{2}=0.020408$.  
6. Friis rearranged for $P_t$: $P_t = \dfrac{P_r L (4\pi d)^{2}}{G_t G_r \lambda^{2}}$.  
   Compute $(4\pi d)^{2}= (4\pi\times3000)^{2}= (37699.1)^{2}=1.420\times10^{9}$.  
   Numerator: $P_r L (4\pi d)^{2}=6.003\times10^{-14}\times2\times1.420\times10^{9}=1.706\times10^{-4}\,$W.  
   Denominator: $G_t G_r \lambda^{2}=10\times3.1623\times0.020408=0.645$.  
   Hence $P_t = 1.706\times10^{-4}/0.645 = 2.64\times10^{-4}\,$W.  
7. Convert to mW: $P_t = 0.264\,$mW.  
$\boxed{0.264}$

</details>
