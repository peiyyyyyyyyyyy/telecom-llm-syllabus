# 3.2.3 調變與錯誤率：PSK、QAM、Q 函數與 Eb/N0

所屬：[3.2 容量](3-2.md)

## 內文

#### 為什麼要學

調變決定一個符號載幾個位元：階數越高，同樣頻寬送得越多，但星座點越擠，同樣的雜訊下越容易判錯。位元錯誤率（bit error rate, BER）公式把「需要多少 $E_b/N_0$ 才能達到某個錯誤率」量化，是鏈路預算的起點：先由目標 BER 查出所需的 $E_b/N_0$ 或 SNR，再往回推接收靈敏度與可容忍的路徑損耗。基地台的鏈路調適也是同一個道理：通道好就用 64QAM、256QAM，通道差就退回 QPSK。會算 BER，才能解釋為什麼每升一階調變大約要多 4～5 dB 的訊號品質。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $M$ | 星座點數（調變階數），每符號 $\log_2 M$ 個位元 | 無單位 |
| $E_b$ | 每位元能量 | J |
| $E_s$ | 每符號能量，$E_s = E_b\log_2 M$ | J |
| $N_0$ | 單邊雜訊功率頻譜密度 | W/Hz |
| $E_b/N_0$ | 每位元訊雜比（線性值） | 無單位 |
| $P_b$ | 位元錯誤率 | 無單位 |
| $P_s$ | 符號錯誤率 | 無單位 |
| $Q(x)$ | 標準常態分布的右尾機率 | 無單位 |

#### 公式與推導

$Q$ 函數定義為

$$Q(x) = \frac{1}{\sqrt{2\pi}}\int_x^{\infty} e^{-t^2/2}\,dt = \frac{1}{2}\,\text{erfc}\!\left(\frac{x}{\sqrt{2}}\right)$$

常用值：$Q(1)=0.1587$、$Q(2)=0.02275$、$Q(3)=1.350\times10^{-3}$、$Q(4)=3.167\times10^{-5}$。$x$ 越大，$Q(x)$ 下降得越快。

以下公式都假設 AWGN 通道、同調檢測（接收端知道載波相位）、最大似然判決、未加通道編碼。

**BPSK（精確式）**：兩個星座點相距 $2\sqrt{E_b}$，雜訊在判決方向的標準差為 $\sqrt{N_0/2}$，因此

$$P_b = Q\!\left(\sqrt{\frac{2E_b}{N_0}}\right)$$

**QPSK，Gray 編碼（位元錯誤率為精確式）**：QPSK 可視為同相與正交兩路互相獨立的 BPSK，每一路的每位元能量都是 $E_b$，所以位元錯誤率和 BPSK 完全相同：$P_b = Q\!\left(\sqrt{2E_b/N_0}\right)$。符號錯誤率則是 $P_s = 2Q - Q^2$，其中 $Q = Q\!\left(\sqrt{2E_b/N_0}\right)$。QPSK 在相同 $E_b/N_0$ 下與 BPSK 同樣可靠，但頻譜效率加倍。

**方形 M-QAM，Gray 編碼（近似式）**：$M = 4, 16, 64, 256,\dots$ 時，

$$P_b \approx \frac{4}{\log_2 M}\left(1-\frac{1}{\sqrt{M}}\right)Q\!\left(\sqrt{\frac{3\log_2 M}{M-1}\cdot\frac{E_b}{N_0}}\right)$$

這條式子是近似式：只計入最近鄰星座點造成的錯誤，並假設 Gray 編碼下一個符號錯誤只造成一個位元錯誤，所以在中高 SNR（錯誤率低於約 $10^{-2}$）才準確，低 SNR 時會有偏差。代入 $M=4$ 可得係數為 1、根號內為 $2E_b/N_0$，與 QPSK 一致。16QAM 時簡化為 $P_b \approx \tfrac{3}{4}\,Q\!\left(\sqrt{0.8\,E_b/N_0}\right)$。

根號內的 $\dfrac{3\log_2 M}{M-1}$ 隨 $M$ 增大而快速變小，代表高階調變要靠更大的 $E_b/N_0$ 補回星座點間距。以目標 $P_b=10^{-5}$ 用上列公式反推所需的 $E_b/N_0$：

| 調變 | 每符號位元數 | 所需 $E_b/N_0$（$P_b=10^{-5}$，未編碼） |
|---|---|---|
| BPSK／QPSK | 1／2 | 9.59 dB |
| 16QAM | 4 | 13.43 dB |
| 64QAM | 6 | 17.79 dB |
| 256QAM | 8 | 22.50 dB |

#### 算例

**算例 1（BPSK）** 已知 $E_b/N_0 = 9.6$ dB，求未編碼 BPSK 的位元錯誤率。

1. 線性值：$10^{0.96} = 9.120$。
2. 根號內：$2\times 9.120 = 18.24$，開根號得 $x = 4.271$。
3. $P_b = Q(4.271) = 9.74\times10^{-6}$（取三位有效數字）。
4. 合理性檢查：結果略低於 $10^{-5}$，與上表「9.59 dB 對應 $10^{-5}$」一致；$Q(4)=3.17\times10^{-5}$，$x$ 稍大於 4，結果應略小於它，合理。

**算例 2（同樣的 $E_b/N_0$，比較 16QAM 與 64QAM）** 已知 $E_b/N_0 = 14$ dB，Gray 編碼，AWGN。

1. 線性值：$10^{1.4} = 25.12$。
2. 16QAM：根號內 $0.8\times 25.12 = 20.10$，$x = 4.483$，$Q(4.483) = 3.68\times10^{-6}$；$P_b \approx 0.75\times 3.68\times10^{-6} = 2.76\times10^{-6}$。
3. 64QAM：$\dfrac{3\times 6}{63} = 0.2857$，根號內 $0.2857\times 25.12 = 7.177$，$x = 2.679$，$Q(2.679) = 3.69\times10^{-3}$；係數 $\dfrac{4}{6}\left(1-\dfrac{1}{8}\right) = 0.5833$；$P_b \approx 0.5833\times 3.69\times10^{-3} = 2.15\times10^{-3}$。
4. 合理性檢查：同樣 14 dB，64QAM 的錯誤率比 16QAM 高出約 780 倍。由上表，64QAM 要達到相同錯誤率需要多約 4.4 dB，這裡 14 dB 對 16QAM 有餘、對 64QAM 明顯不足，結果合理。

#### 常見錯誤

- 把 $E_b/N_0$ 和 $E_s/N_0$ 或 SNR 混用。$E_s/N_0 = \log_2 M\times E_b/N_0$；例如 64QAM 的 $E_s/N_0$ 比 $E_b/N_0$ 高 $10\log_{10}6 = 7.78$ dB。
- 把 dB 值直接放進根號。一定要先換成線性值。
- 把符號錯誤率當成位元錯誤率。Gray 編碼、高 SNR 時 $P_b\approx P_s/\log_2 M$，兩者不相等。
- 把未編碼的 BER 公式直接套在有通道編碼的系統上。實際 4G／5G 系統有 LDPC 或 Turbo 碼，所需的 SNR 比未編碼低很多，衡量指標也改用區塊錯誤率（BLER）。
- 把 M-QAM 近似式用在很低的 SNR，得到不合理的數值。

#### 和其他小節的關係

$E_b/N_0$ 與 SNR 的換算在 3.1.6；衰落通道下錯誤率會變差，背景在 3.1.4；調變階數乘上碼率成為 3.2.4 的 MCS；每符號位元數與頻寬的關係在 3.2.7；通道編碼如何降低所需 $E_b/N_0$ 見 3.7 細項；所需 SNR 會用到 3.3 細項的接收靈敏度。
