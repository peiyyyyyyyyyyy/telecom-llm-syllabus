# 3.2.3 調變與錯誤率：PSK、QAM、Q 函數與 Eb/N0

所屬：[3.2 容量](3-2.md)

## 內文

#### 為什麼要學

調變決定一個符號載幾個位元：階數越高，同樣頻寬送得越多，但星座點越擠，同樣的雜訊下越容易判錯。位元錯誤率（bit error rate, BER）公式把「需要多少 $E_b/N_0$ 才能達到某個錯誤率」量化，是鏈路預算的起點：先由目標 BER 查出所需的 $E_b/N_0$ 或 SNR，再往回推接收靈敏度與可容忍的路徑損耗。基地台的鏈路調適也是同一個道理：通道好就用 64QAM、256QAM，通道差就退回 QPSK。以 $E_b/N_0$ 計每升一階約多 3.8～4.7 dB；以 SNR（$E_s/N_0$）計約多 6～6.9 dB。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $M$ | 星座點數（調變階數），每符號 $\log_2 M$ 個位元 | 無單位 |
| $E_b$ | 每位元能量 | J |
| $E_s$ | 每符號能量，$E_s = E_b\log_2 M$ | J |
| $N_0$ | 單邊雜訊功率頻譜密度 | W/Hz |
| $E_b/N_0$ | 每位元訊雜比（線性值） | 無單位 |
| $P_b$ | 位元錯誤率 | 無單位 |
| $P_s$ | 符號錯誤率 | 無單位 |
| $Q(x)$ | 標準常態分布的右尾機率 | 無單位 |

#### 公式與推導

$Q$ 函數定義為

$$Q(x) = \frac{1}{\sqrt{2\pi}}\int_x^{\infty} e^{-t^2/2}\,dt = \frac{1}{2}\,\text{erfc}\!\left(\frac{x}{\sqrt{2}}\right)$$

常用值：$Q(1)=0.1587$、$Q(2)=0.02275$、$Q(3)=1.350\times10^{-3}$、$Q(4)=3.167\times10^{-5}$。$x$ 越大，$Q(x)$ 下降得越快。

以下公式都假設 AWGN 通道、同調檢測（接收端知道載波相位）、最大似然判決、未加通道編碼。

**BPSK（精確式）**：兩個星座點相距 $2\sqrt{E_b}$，雜訊在判決方向的標準差為 $\sqrt{N_0/2}$，因此

$$P_b = Q\!\left(\sqrt{\frac{2E_b}{N_0}}\right)$$

**QPSK，Gray 編碼（位元錯誤率為精確式）**：QPSK 可視為同相與正交兩路互相獨立的 BPSK，每一路的每位元能量都是 $E_b$，所以位元錯誤率和 BPSK 完全相同：$P_b = Q\!\left(\sqrt{2E_b/N_0}\right)$。符號錯誤率則是 $P_s = 2Q - Q^2$，其中 $Q = Q\!\left(\sqrt{2E_b/N_0}\right)$。QPSK 在相同 $E_b/N_0$ 下與 BPSK 同樣可靠，但頻譜效率加倍。

**方形 M-QAM，Gray 編碼（近似式）**：$M = 4, 16, 64, 256,\dots$ 時，

$$P_b \approx \frac{4}{\log_2 M}\left(1-\frac{1}{\sqrt{M}}\right)Q\!\left(\sqrt{\frac{3\log_2 M}{M-1}\cdot\frac{E_b}{N_0}}\right)$$

這條式子是近似式：只計入最近鄰星座點造成的錯誤，並假設 Gray 編碼下一個符號錯誤只造成一個位元錯誤，所以在中高 SNR（錯誤率低於約 $10^{-2}$）才準確，低 SNR 時會有偏差。代入 $M=4$ 可得係數為 1、根號內為 $2E_b/N_0$，與 QPSK 一致。16QAM 時簡化為 $P_b \approx \tfrac{3}{4}\,Q\!\left(\sqrt{0.8\,E_b/N_0}\right)$。

根號內的 $\dfrac{3\log_2 M}{M-1}$ 隨 $M$ 增大而快速變小，代表高階調變要靠更大的 $E_b/N_0$ 補回星座點間距。以目標 $P_b=10^{-5}$ 用上列公式反推所需的 $E_b/N_0$：

| 調變 | 每符號位元數 | 所需 $E_b/N_0$（$P_b=10^{-5}$，未編碼） |
|---|---|---|
| BPSK／QPSK | 1／2 | 9.59 dB |
| 16QAM | 4 | 13.43 dB |
| 64QAM | 6 | 17.79 dB |
| 256QAM | 8 | 22.50 dB |

#### 算例

**算例 1（BPSK）** 已知 $E_b/N_0 = 9.6$ dB，求未編碼 BPSK 的位元錯誤率。

1. 線性值：$10^{0.96} = 9.120$。
2. 根號內：$2\times 9.120 = 18.24$，開根號得 $x = 4.271$。
3. $P_b = Q(4.271) = 9.74\times10^{-6}$（取三位有效數字）。
4. 合理性檢查：結果略低於 $10^{-5}$，與上表「9.59 dB 對應 $10^{-5}$」一致；$Q(4)=3.17\times10^{-5}$，$x$ 稍大於 4，結果應略小於它，合理。

**算例 2（同樣的 $E_b/N_0$，比較 16QAM 與 64QAM）** 已知 $E_b/N_0 = 14$ dB，Gray 編碼，AWGN。

1. 線性值：$10^{1.4} = 25.12$。
2. 16QAM：根號內 $0.8\times 25.12 = 20.10$，$x = 4.483$，$Q(4.483) = 3.68\times10^{-6}$；$P_b \approx 0.75\times 3.68\times10^{-6} = 2.76\times10^{-6}$。
3. 64QAM：$\dfrac{3\times 6}{63} = 0.2857$，根號內 $0.2857\times 25.12 = 7.177$，$x = 2.679$，$Q(2.679) = 3.69\times10^{-3}$；係數 $\dfrac{4}{6}\left(1-\dfrac{1}{8}\right) = 0.5833$；$P_b \approx 0.5833\times 3.69\times10^{-3} = 2.15\times10^{-3}$。
4. 合理性檢查：同樣 14 dB，64QAM 的錯誤率比 16QAM 高出約 780 倍。由上表，64QAM 要達到相同錯誤率需要多約 4.4 dB，這裡 14 dB 對 16QAM 有餘、對 64QAM 明顯不足，結果合理。

#### 常見錯誤

- 把 $E_b/N_0$ 和 $E_s/N_0$ 或 SNR 混用。$E_s/N_0 = \log_2 M\times E_b/N_0$；例如 64QAM 的 $E_s/N_0$ 比 $E_b/N_0$ 高 $10\log_{10}6 = 7.78$ dB。
- 把 dB 值直接放進根號。一定要先換成線性值。
- 把符號錯誤率當成位元錯誤率。Gray 編碼、高 SNR 時 $P_b\approx P_s/\log_2 M$，兩者不相等。
- 把未編碼的 BER 公式直接套在有通道編碼的系統上。實際 4G／5G 系統有 LDPC 或 Turbo 碼，所需的 SNR 比未編碼低很多，衡量指標也改用區塊錯誤率（BLER）。
- 把 M-QAM 近似式用在很低的 SNR，得到不合理的數值。

#### 和其他小節的關係

$E_b/N_0$ 與 SNR 的換算在 3.1.6；衰落通道下錯誤率會變差，背景在 3.1.4；調變階數乘上碼率成為 3.2.4 的 MCS；每符號位元數與頻寬的關係在 3.2.7；通道編碼如何降低所需 $E_b/N_0$ 見 3.7 細項；所需 SNR 會用到 3.3 細項的接收靈敏度。

**答案**　QPSK is two BPSK signals on orthogonal carriers (I and Q). With Gray coding each bit is carried by one of the two branches and decided independently; each branch receives energy Eb per bit and independent noise of the same density. Each bit therefore sees exactly the BPSK situation, so $P_b = Q(\sqrt{2E_b/N_0})$. The price of the doubled bit rate is paid in Es (twice Eb), not in BER per bit.

**詳解**　Es = 2Eb for QPSK; per-branch amplitude √Eb; per-branch noise variance N0/2 → same decision statistics as BPSK.

**出處**　B. Sklar, *Digital Communications: Fundamentals and Applications* (QPSK as two orthogonal BPSK channels).

</details>

**3.2.3S009**　A colleague says "with Gray coding Pb = Ps/2 exactly for QPSK". Is that correct?

<details><summary>看答案</summary>

**答案**　Not exactly. Ps/2 = Q − Q²/2, which is slightly less than Pb = Q. The difference comes from the event that both branches are wrong (probability Q²): the symbol goes to the diagonal neighbour and two bits flip, so that symbol error costs two bit errors, not one. At high Eb/N0 Q² is negligible and Pb ≈ Ps/2 is an excellent approximation.

**詳解**　Here Q = 3.304×10⁻⁵; Ps/2 = 3.3040×10⁻⁵ − 5.46×10⁻¹⁰, which differs from Pb only in the fifth significant digit.

**出處**　J. G. Proakis and M. Salehi, *Digital Communications* (symbol-to-bit error relation with Gray mapping).

</details>

#### 情境題：From BER to bit errors, packet errors and BER measurement

**Scenario | Factory sensor packets over QPSK**

Wireless sensors on a factory floor send 64-byte packets (1 byte = 8 bits) at 10 packets per second using uncoded, Gray-coded QPSK with coherent detection. On the worst link the channel is treated as AWGN with Eb/N0 = 7 dB, and the bit error rate is computed with the exact expression $P_b = Q\left(\sqrt{2E_b/N_0}\right)$: rounding the argument to two decimal places, Q(3.17) = 7.622×10⁻⁴. Assume bit errors are independent and there is no error correction, so a packet is lost if any bit is wrong.

**3.2.3S046**　What is the packet error rate on the worst link? Round to four decimal places.

<details><summary>看答案</summary>

**答案**　0.3232

**詳解**　Step 1: linear Eb/N0 = 5.0119; x = √10.0237 = 3.1660 → 3.17; Pb = 7.622×10⁻⁴.
Step 2: n = 64 × 8 = 512 bits.
Step 3: PER = 1 − (1 − 7.622×10⁻⁴)⁵¹² = 1 − 0.67679 = 0.32321 ≈ 0.3232.

**出處**　A. Leon-Garcia, *Probability, Statistics, and Random Processes for Electrical Engineering* (independent Bernoulli trials); B. Sklar, *Digital Communications: Fundamentals and Applications* (QPSK BER).

</details>

**3.2.3S047**　How many packets are lost per hour on that link? Round to one decimal place.

<details><summary>看答案</summary>

**答案**　11 635.6 packets per hour

**詳解**　Packets per hour = 10 × 3600 = 36 000. Lost = 36 000 × 0.32321 = 11 635.6.

**出處**　A. Leon-Garcia, *Probability, Statistics, and Random Processes for Electrical Engineering* (expected value of a binomial count).

</details>

**3.2.3S048**　The calculation assumes independent bit errors. When is this reasonable, and what happens in a factory with slow fading or impulsive interference?

<details><summary>看答案</summary>

**答案**　It is reasonable for an AWGN channel, where the noise on successive symbols is independent. With slow fading or impulsive interference errors arrive in bursts: many errors in a few packets and none in others. For the same average BER the packet error rate is then usually lower than the independent-error formula predicts, but the errors that do occur are concentrated, which matters for retransmission and coding design.

**詳解**　Under bursts, P(packet error) ≤ 1 − (1 − Pb)ⁿ is typical, because errors cluster in the same packets.

**出處**　A. Goldsmith, *Wireless Communications* (error bursts in fading channels).

</details>

**3.2.3S049**　A colleague uses the shortcut PER ≈ n·Pb. When is this valid, and is it valid here?

<details><summary>看答案</summary>

**答案**　It is valid only when n·Pb ≪ 1, where (1 − Pb)ⁿ ≈ 1 − n·Pb. Here n·Pb = 512 × 7.622×10⁻⁴ = 0.390, which is not small: the shortcut gives 0.390 instead of 0.323, an overestimate of about 21 %. (The shortcut can even exceed 1 when n·Pb > 1.)

**詳解**　n·Pb = 0.3902; exact 0.3232; 0.3902/0.3232 = 1.207.

**出處**　A. Leon-Garcia, *Probability, Statistics, and Random Processes for Electrical Engineering* (binomial probabilities and their approximations).

</details>

**3.2.3S050**　An engineer computes the packet error rate as follows. Which step is wrong, why, and what is the correct PER?

#### 情境題：Limits of the uncoded AWGN formulas

**Scenario | When the approximations break down**

A student compares exact and approximate symbol error expressions at low SNR on an AWGN channel, with Gray coding throughout. For square M-QAM the exact symbol error rate is $P_s = 1 - (1 - P_{\sqrt M})^2$ with $P_{\sqrt M} = 2\left(1 - \tfrac{1}{\sqrt M}\right)Q\left(\sqrt{\tfrac{3}{M-1}\tfrac{E_s}{N_0}}\right)$, and the common approximation is $P_s \approx 2P_{\sqrt M}$. For QPSK the exact symbol error rate is $P_s = 2Q - Q^2$ with $Q = Q(\sqrt{E_s/N_0})$. Round Q arguments to two decimal places; use Q(0.71) = 0.2389, Q(1.58) = 0.05705, Q(2.00) = 0.02275 and Q(4.47) = 3.911×10⁻⁶.

**3.2.3S061**　For 16QAM at Es/N0 = 4 dB, what is the exact symbol error rate? Round to four decimal places.

<details><summary>看答案</summary>

**答案**　0.5883

**詳解**　Step 1: linear Es/N0 = 10^0.4 = 2.5119; 3/(M − 1) = 0.2; 0.2 × 2.5119 = 0.50238; x = √0.50238 = 0.7088 → 0.71.
Step 2: $P_{\sqrt M} = 2(1 - 1/4) \times 0.2389 = 1.5 \times 0.2389 = 0.35835$.
Step 3: $P_s = 1 - (1 - 0.35835)^2 = 1 - 0.41171 = 0.58829$ ≈ 0.5883.
(The approximation 2 × 0.35835 = 0.7167 overstates it by about 22 %.)

**出處**　J. G. Proakis and M. Salehi, *Digital Communications* (exact symbol error probability of square QAM).

</details>

**3.2.3S062**　Why does the approximation $P_s \approx 2P_{\sqrt M}$ overestimate the symbol error rate, and why does the overestimate vanish at high SNR?

<details><summary>看答案</summary>

**答案**　The symbol is wrong if the I rail or the Q rail (or both) is wrong. Adding the two rail probabilities counts the "both wrong" event twice; the exact expression subtracts it once ($P_{\sqrt M}^2$). At low SNR $P_{\sqrt M}$ is large (0.36 here), so the double-counted term is significant; at high SNR it is the square of a small number and becomes negligible.

**詳解**　2P − P² vs 2P: difference P² = 0.1284 at P = 0.35835.

**出處**　J. G. Proakis and M. Salehi, *Digital Communications* (square QAM as two independent PAM rails).

</details>

**3.2.3S063**　At this low SNR, is the Gray-coding rule Pb ≈ Ps/log2 M still a good way to get the bit error rate, and why?

<details><summary>看答案</summary>

**答案**　No. The rule assumes each symbol error goes to an adjacent point and flips exactly one bit. At low SNR a symbol often lands two or more points away or wrong in both rails, flipping several bits, so the true Pb is noticeably larger than Ps/log2 M. The rule, like the nearest-neighbour BER formula, is meant for error rates around 10⁻³ and below.

**詳解**　Non-adjacent errors involve Q(3x), Q(5x), ...; with x = 0.71, Q(2.13) ≈ 0.017 is not negligible against Q(0.71) = 0.24.

**出處**　A. Goldsmith, *Wireless Communications* (validity of the nearest-neighbour approximation).

</details>

**3.2.3S064**　The student then evaluates 16QAM at Es/N0 = 20 dB. Which step is wrong, why, and what is the correct symbol error rate?
1. Es/N0 = 20 dB.
2. x = √(0.2 × 20) = 2.00, so Q = 0.02275.
3. $P_{\sqrt M}$ = 1.5 × 0.02275 = 0.03413; Ps ≈ 2 × 0.03413 = 0.0683.

<details><summary>看答案</summary>

**答案**　Step 2 is wrong: the dB value was put into the square root instead of the linear ratio (20 dB = 100). With x = √20 = 4.47, $P_{\sqrt M}$ = 5.8665×10⁻⁶ and Ps ≈ 1.173×10⁻⁵, more than three orders of magnitude lower than the wrong result. At this SNR the approximation and the exact value agree to four significant digits.

**詳解**　x = √(0.2 × 100) = 4.4721 → 4.47; Q = 3.911×10⁻⁶; $P_{\sqrt M}$ = 1.5 × 3.911×10⁻⁶ = 5.8665×10⁻⁶; Ps ≈ 2 × 5.8665×10⁻⁶ = 1.1733×10⁻⁵ (exact 1 − (1 − 5.8665×10⁻⁶)² = 1.1733×10⁻⁵).

**出處**　J. G. Proakis and M. Salehi, *Digital Communications* (square QAM symbol error probability).

</details>

**3.2.3S065**　For Gray-coded QPSK at Es/N0 = 4 dB the student writes the following. Which step is wrong, why, and what is the correct symbol error rate?
1. Linear Es/N0 = 2.5119; x = √2.5119 = 1.5849 → 1.58; Q = 0.05705.
2. Ps = 2Q + Q² = 0.11410 + 0.00325 = 0.1174.

<details><summary>看答案</summary>

**答案**　Step 2 is wrong: the "both rails wrong" term must be subtracted, not added: Ps = 1 − (1 − Q)² = 2Q − Q². The correct symbol error rate is 0.1108.

**詳解**　2 × 0.05705 − 0.05705² = 0.11410 − 0.0032547 = 0.11085 ≈ 0.1108 (to four decimal places: 0.1108).

**出處**　J. G. Proakis and M. Salehi, *Digital Communications* (exact QPSK symbol error probability).
