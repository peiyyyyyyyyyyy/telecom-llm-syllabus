# 3.5.1 基本電學：功率、阻抗匹配與傳輸線衰減

所屬：[3.5 基礎數理](3-5.md)

## 內文

#### 為什麼要學

基地台的射頻功率要經過跳線、饋線、接頭，最後才到天線。這一段路上只要有一處阻抗不連續（接頭進水、饋線壓扁、天線振子損壞），就會有一部分功率被反射回發射機，實際輻射出去的功率變少，嚴重時還會觸發功率放大器保護。維運人員在現場用天饋線分析儀量到的電壓駐波比（voltage standing wave ratio, VSWR）與回波損耗（return loss, RL），以及基地台回報的駐波告警，背後都是同一個量：反射係數。本節把功率、阻抗、反射係數、VSWR、回波損耗、失配損耗與傳輸線衰減的關係講清楚，讓讀者能從任何一個量換算到其他量，並判斷量測結果是否合理。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $V$、$I$ | 電壓、電流的有效值（rms） | V、A |
| $P$ | 功率 | W（或 dBm） |
| $R$ | 電阻 | Ω |
| $Z_0$ | 傳輸線的特性阻抗（行動通訊設備通常是 50 Ω） | Ω |
| $Z_L$ | 負載阻抗（例如天線輸入阻抗） | Ω |
| $\Gamma$ | 負載端的電壓反射係數，一般是複數 | 無單位 |
| VSWR | 電壓駐波比，線上電壓最大值與最小值的比 | 無單位（常寫成 1.5:1） |
| RL | 回波損耗，入射功率與反射功率的比 | dB |
| ML | 失配損耗（mismatch loss），因反射而沒有送進負載的功率比例 | dB |
| $\alpha$ | 傳輸線單位長度衰減 | dB/m（型錄常用 dB/100 m） |
| $\ell$ | 傳輸線長度 | m |

#### 公式與推導

直流或純電阻負載的功率是 $P = VI = I^2R = V^2/R$，交流時 $V$、$I$ 用有效值。例如 20 W 送進 50 Ω 的匹配負載，電壓有效值是 $\sqrt{20\times50}\approx31.6$ V。當訊號源內阻抗為 $Z_S$ 時，負載取 $Z_L = Z_S^*$（共軛匹配）可以得到最大功率；射頻系統把訊號源、傳輸線與負載都做成 50 Ω，就是為了同時滿足匹配與不反射。

傳輸線上的電壓可以看成入射波與反射波的疊加。在負載端，反射波與入射波的電壓比就是反射係數：

$$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$$

$Z_L = Z_0$ 時 $\Gamma = 0$（完全匹配）；負載短路時 $\Gamma = -1$，開路時 $\Gamma = +1$，兩者都是全反射。功率與電壓平方成正比，所以反射功率佔入射功率的比例是 $|\Gamma|^2$，送進負載的比例是 $1 - |\Gamma|^2$（假設傳輸線本身無損）。

入射波與反射波同相的位置電壓最大，為 $1 + |\Gamma|$ 倍；反相的位置最小，為 $1 - |\Gamma|$ 倍，兩者相除就是

$$\text{VSWR} = \frac{1 + |\Gamma|}{1 - |\Gamma|},\qquad |\Gamma| = \frac{\text{VSWR} - 1}{\text{VSWR} + 1}$$

VSWR 的範圍是 1（完全匹配）到無限大（全反射）。把反射功率比例寫成 dB，就是回波損耗與失配損耗：

$$\text{RL} = -20\log_{10}|\Gamma|\ \ \text{(dB)},\qquad \text{ML} = -10\log_{10}\left(1 - |\Gamma|^2\right)\ \ \text{(dB)}$$

RL 用 20 是因為 $\Gamma$ 是電壓比；RL 越大代表反射越小，匹配越好。ML 則是「因為失配而少送進負載的功率」，數值通常很小。

傳輸線衰減以 dB 計時和長度成正比：$L_{\text{線}} = \alpha\,\ell$。同軸電纜的衰減隨頻率升高而增加，所以型錄上的 $\alpha$ 一定要對應到使用的頻率。有損耗的線還有一個重要效應：反射波要來回各走一趟，因此在線的輸入端量到的回波損耗會比負載端的真實值大

$$\text{RL}_{\text{輸入端}} = \text{RL}_{\text{負載端}} + 2\,\alpha\,\ell$$

這條式子成立的條件是傳輸線本身的特性阻抗等於量測參考阻抗 $Z_0$，且線上沒有其他反射點。

#### 算例

**算例 1：由阻抗算四個量。** 已知：$Z_0 = 50$ Ω 的饋線誤接到 $Z_L = 75$ Ω 的負載（純電阻）。求 $\Gamma$、VSWR、RL、ML。

1. 反射係數：$\Gamma = (75 - 50)/(75 + 50) = 25/125 = 0.2$。
2. VSWR $= (1 + 0.2)/(1 - 0.2) = 1.2/0.8 = 1.5$。
3. 回波損耗：$\text{RL} = -20\log_{10}0.2 = 13.98$ dB。
4. 反射功率比例 $|\Gamma|^2 = 0.04$，即 4%；失配損耗 $\text{ML} = -10\log_{10}(1 - 0.04) = -10\log_{10}0.96 = 0.18$ dB。

合理性檢查：純電阻負載時 VSWR 等於兩個阻抗中較大者除以較小者，$75/50 = 1.5$，與第 2 步一致。4% 的功率被反射，只損失 0.18 dB，可見 VSWR 1.5 對涵蓋的影響很小。

**算例 2：天饋線現場檢查。** 已知：基地台輸出 43 dBm（約 20 W）；饋線長 30 m，假設在該頻段的衰減為 4 dB/100 m；兩端接頭合計損耗假設 0.2 dB；天線端口的 VSWR 為 1.4。求送進天線的功率、反射功率，以及在基地台端口量到的回波損耗。

1. 饋線損耗 $= 4 \times 30/100 = 1.2$ dB；單程總損耗 $= 1.2 + 0.2 = 1.4$ dB。
2. 到達天線端口的入射功率 $= 43 - 1.4 = 41.6$ dBm，換成瓦特是 $10^{41.6/10}$ mW $\approx 14.45$ W。
3. 天線端的反射係數 $|\Gamma| = (1.4 - 1)/(1.4 + 1) = 0.4/2.4 = 0.1667$；$\text{RL} = -20\log_{10}0.1667 = 15.56$ dB；$\text{ML} = -10\log_{10}(1 - 0.1667^2) = 0.12$ dB。
4. 反射功率 $= 41.6 - 15.56 = 26.04$ dBm $\approx 0.40$ W；送進天線的功率 $= 41.6 - 0.12 = 41.48$ dBm $\approx 14.05$ W。
5. 在基地台端口量到的回波損耗 $= 15.56 + 2 \times 1.4 = 18.36$ dB，換算 $|\Gamma| = 10^{-18.36/20} = 0.1207$，VSWR $= 1.1207/0.8793 = 1.27$。

合理性檢查：$14.05 + 0.40 = 14.45$ W，功率守恆。這題的重點在第 5 步：饋線損耗讓基地台端看到的 VSWR（1.27）比天線端的真實值（1.4）好看，饋線越長、越損耗，天線的問題越容易被遮住。

#### 常見錯誤

- 把回波損耗當成「損失掉的功率」。回波損耗 15.56 dB 不代表少了 15.56 dB 的功率，實際少送進負載的是失配損耗 0.12 dB。
- 回波損耗用 $10\log_{10}|\Gamma|$ 計算。$\Gamma$ 是電壓比，要用 20；用 $|\Gamma|^2$ 才是 10。
- 把 VSWR 直接代進 dB 公式，或把 VSWR 1.5 讀成「反射 50%」。VSWR 要先換成 $|\Gamma|$，1.5 對應的反射功率只有 4%。
- 忽略量測位置。在機房端量到的 VSWR 已經被饋線來回損耗「美化」，不能直接當成天線本身的 VSWR。
