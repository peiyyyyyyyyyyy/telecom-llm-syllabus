# 3.6.3 單位一致

所屬：[3.6 解題方法](3-6.md)

## 內文

#### 為什麼要學

電信的數值橫跨很多個數量級，而且同一個量常有好幾種寫法：距離用 m 或 km，頻率用 MHz 或 GHz，功率用 W、mW、dBm 或 dBW，資料量用 bit、byte、MB，速率用 kbps 或 Mbps。公式裡的常數是配著特定單位推出來的，單位放錯，結果常常差 $10^3$ 倍或 60 dB；bit 與 byte 混用則差 8 倍。這類錯誤算式看起來完全正確，所以很難靠重算發現。實務上，鏈路預算表、流量報表、計費資料來自不同系統，各用各的單位，動手計算前先把單位統一，是最便宜的防錯手段。

#### 定義與符號

| 項目 | 意思 | 例子 |
|---|---|---|
| SI 詞頭（SI prefix） | 十進位倍數：k $=10^3$、M $=10^6$、G $=10^9$；m $=10^{-3}$、μ $=10^{-6}$、n $=10^{-9}$ | 2.6 GHz $= 2600$ MHz $= 2.6\times10^9$ Hz |
| 二進位詞頭（binary prefix） | IEC 定義的二進位倍數：Ki $=2^{10}$、Mi $=2^{20}$、Gi $=2^{30}$，不屬於 SI | 1 MiB $= 1{,}048{,}576$ byte |
| bit 與 byte | 1 byte $= 8$ bit；速率通常用 bit，檔案大小通常用 byte | 8 Mbps $= 1$ MB/s（十進位） |
| 絕對功率單位 | dBm 以 1 mW 為基準，dBW 以 1 W 為基準，兩者差 30 dB | 20 W $= 43.01$ dBm $= 13.01$ dBW |
| 相對量 | dB、dBi、dBd 是比值，沒有絕對大小 | 增益 15 dBi、損耗 2 dB |
| 配對常數 | 公式中隨輸入單位改變的常數 | FSPL：32.44 配 km 與 MHz，92.45 配 km 與 GHz |
| 因次檢查（dimensional check） | 檢查等號兩邊的單位是否相同 | bit ÷ (bit/s) $=$ s |

#### 公式與推導

單位一致的做法分成四步。

**第一步：列出每個量的單位，選定一套工作單位。** 最不容易出錯的做法是全部換成基本單位（m、Hz、W、s、bit）再代入原始公式，例如自由空間路徑損耗的原式（3.1.2）：

$$\text{FSPL} = 20\log_{10}\!\left(\frac{4\pi d f}{c}\right),\quad d\ \text{用 m},\ f\ \text{用 Hz},\ c\ \text{用 m/s}$$

如果要用帶常數的簡化式，就把輸入換成常數所配的單位：

$$\text{FSPL} = 32.44 + 20\log_{10} d_{\text{km}} + 20\log_{10} f_{\text{MHz}} = 92.45 + 20\log_{10} d_{\text{km}} + 20\log_{10} f_{\text{GHz}}$$

兩個常數相差 60 dB，正好是 $20\log_{10}(1000)$。嚴格來說兩者差 60.00 dB，但習慣寫法各自取位後差了 0.01 dB，所以用兩式算同一題，結果可能有 0.01 dB 的出入，這不是計算錯誤。

**第二步：換算時把換算因子寫成「等於 1 的分數」。** 例如 $800\ \text{m} \times \dfrac{1\ \text{km}}{1000\ \text{m}} = 0.8\ \text{km}$，單位可以像代數符號一樣約掉。乘還是除不用背，看單位能不能約掉就知道。

**第三步：分清楚線性量與對數量。** 功率的換算（3.1.1）為

$$P_{\text{dBm}} = 10\log_{10}\!\left(\frac{P}{1\ \text{mW}}\right),\qquad P_{\text{dBW}} = P_{\text{dBm}} - 30$$

判斷準則：dBm 加減 dB 仍是 dBm；dBm 減 dBm 得到 dB；dBm 與 dBm 不能直接相加，W 與 dBm 也不能出現在同一個加減式裡。算式中只要出現 W，就先換成 dBm（或全部換成線性）再往下算。

**第四步：資料量與速率，先確認 bit 或 byte、十進位或二進位。** 通訊速率的 k、M、G 一律是十進位：1 kbps $=10^3$ bit/s，1 Mbps $=10^6$ bit/s。檔案大小的「MB」則有兩種用法：依 SI 是 $10^6$ byte；作業系統與部分軟體把 $2^{20}$ byte 也叫 MB，IEC 另訂 MiB 來表示後者。兩者相差

$$\frac{2^{20}}{10^6} = 1.048576,\ \text{約}\ 4.9\%$$

到 GB 與 GiB 則差約 7.4%。題目沒有說明時，採用 SI 的十進位定義（1 MB $=10^6$ byte），並在答案中寫明；題目寫 MiB 或註明 $2^{20}$ 時才用二進位。傳輸時間的基本式為

$$t = \frac{\text{檔案大小（byte）} \times 8}{\text{速率（bit/s）}}$$

最後做因次檢查：byte × (bit/byte) ÷ (bit/s) $=$ s，單位對了才代數字。

#### 算例

**算例 1（km 與 m、MHz 與 GHz、W 與 dBm）** 假設基地台發射功率 20 W，天線增益 15 dBi，頻率 2.6 GHz，手機在 800 m 處，手機天線增益 0 dBi。傳播環境未指定，採自由空間。求接收功率，以 dBm（小數第 2 位）與 W（3 位有效數字）表示。

整理單位：功率是 W，要換成 dBm；距離是 m，要換成 km；頻率是 GHz，用 92.45 的式子可直接代入，用 32.44 的式子要換成 2600 MHz。

$$P_t = 10\log_{10}(20\times10^3) = 43.01\ \text{dBm},\qquad d = 800\ \text{m} = 0.8\ \text{km}$$

用 km 與 MHz：

$$\text{FSPL} = 32.44 + 20\log_{10}(0.8) + 20\log_{10}(2600) = 32.44 - 1.94 + 68.30 = 98.80\ \text{dB}$$

用 km 與 GHz 複核：$92.45 - 1.94 + 8.30 = 98.81$ dB，兩者差 0.01 dB，來自常數取位。以下採 98.80 dB。

$$P_r = 43.01 + 15 + 0 - 98.80 = -40.79\ \text{dBm}$$

換成線性：$10^{-40.79/10} = 8.34\times10^{-5}$ mW $= 8.34\times10^{-8}$ W（約 83.4 nW；若 $P_r$ 不先取位而用 $-40.791$ dBm 換算，會得到 $8.33\times10^{-8}$ W，末位的差異來自取位）。

陷阱示範：若把 800 直接當成 km 代入，FSPL 會變成 158.80 dB，多出 60 dB；若把 2.6 代入配 MHz 的式子，FSPL 會變成 38.80 dB，少了 60 dB。若把 20 W 直接和 15 dBi 相加得到「35」，則完全沒有物理意義。

**算例 2（kbps 與 MB、bit 與 byte）** 以固定速率 2500 kbps 下載一個 150 MB 的檔案，需要多久？

整理單位：速率 2500 kbps $= 2.5\times10^6$ bit/s。檔案大小題目只寫 MB，採 SI 定義，$150\ \text{MB} = 150\times10^6$ byte。

$$t = \frac{150\times10^6 \times 8}{2.5\times10^6} = \frac{1.2\times10^9}{2.5\times10^6} = 480\ \text{s} = 8\ \text{分鐘}$$

如果檔案大小其實是作業系統顯示的 150 MiB：

$$t = \frac{150 \times 1{,}048{,}576 \times 8}{2.5\times10^6} = 503.3\ \text{s}$$

比十進位的結果多 23.3 秒，約 4.9%。

陷阱示範：忘記乘 8（把 byte 當 bit）會得到 60 秒，只有正確值的八分之一。合理性檢查：2500 kbps 相當於每秒 0.3125 MB，150 MB 需要 $150/0.3125 = 480$ 秒，兩種算法一致。

#### 常見錯誤

1. **輸入單位和常數不配。** 32.44 的式子代入 GHz 或 m；$-174$ dBm/Hz 配的是 Hz，卻把頻寬以 MHz 的數字直接取對數。
2. **bit 與 byte 混用。** Mbps 是每秒百萬 bit，MB/s 是每秒百萬 byte，差 8 倍；小寫 b 通常指 bit，大寫 B 指 byte。
3. **$10^6$ 與 $2^{20}$ 不說明。** 檔案大小沒寫採用哪種定義，結果差約 5%；通訊速率的詞頭不可以用二進位。
4. **dBm 與 dBW、W 與 mW 差 30 dB 或 1000 倍。** 靈敏度公式用 dBm/Hz 的雜訊密度，發射功率卻代 dBW。

#### 和其他小節的關係

功率單位換算的公式在 3.1.1，自由空間路徑損耗的兩組常數在 3.1.2，熱雜訊密度的單位在 3.1.5，速率與延遲的單位用在 3.4.5。3.6.1 讀題時標出的單位差異在這裡統一；3.6.5 的單位檢查是本節因次檢查的再確認。
