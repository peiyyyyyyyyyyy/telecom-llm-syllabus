# 3.2.4 編碼率與 MCS

所屬：[3.2 容量](../3-2.md)

## 正文

In a practical wireless system the raw physical layer is defined by two coupled choices: the *modulation order* (how many distinct symbols are mapped to a constellation point) and the *forward error‑correction (FEC) code rate*. The pair is conventionally called a **Modulation‑and‑Coding Scheme (MCS)**. An MCS determines how many information bits are conveyed per transmitted symbol, how much redundancy is added for error protection, and consequently how much signal‑to‑noise ratio (SNR) is required to achieve a target block error rate (BLER). Network schedulers use the MCS index to adapt the link to instantaneous channel quality, maximizing throughput while keeping the error probability within acceptable bounds. Hence, understanding coding rate and MCS is essential for capacity planning, link‑budget analysis, and the design of adaptive‑modulation algorithms.

---

### 1. Coding rate  

An FEC encoder takes **k** information bits and produces **n** coded bits ( $n \ge k$ ). The **coding rate** $R$ is the ratio  

$$
R = \frac{k}{n},\qquad 0<R\le 1,
$$

and is dimension‑less.  
- $R=1$ corresponds to *uncoded* transmission (no redundancy).  
- $R=1/2$ means that for every information bit, one parity bit is added, doubling the transmitted bit count.

The coding rate directly influences the *energy per information bit* $E_b$ relative to the *energy per transmitted (coded) bit* $E_c$:

$$
E_b = \frac{E_c}{R}.
$$

Consequently, for a given transmitted power, a lower $R$ yields a higher $E_b$, which improves the error performance at the cost of reduced net data rate.

---

### 2. Spectral efficiency of an MCS  

For a rectangular $M$‑ary constellation (e.g., $M$‑QAM or $M$‑PSK) each symbol carries  

$$
\log_2 M \quad \text{bits per symbol (bpsym)}.
$$

When an FEC code of rate $R$ is applied, only a fraction $R$ of those bits are *information* bits. The **spectral efficiency** $\eta$ (bits / second / Hz) of an MCS is therefore  

$$
\boxed{\eta = R\;\log_2 M}\tag{1}
$$

where  

* $M$ – constellation size (e.g., $M=4$ for QPSK, $M=16$ for 16‑QAM).  
* $R$ – coding rate (dimension‑less).  

Equation (1) is the bridge between the abstract MCS index and the concrete capacity of a channel measured in bits s$^{-1}$ Hz$^{-1}$.

---

### 3. Required $E_b/N_0$ for a target error probability  

For additive white Gaussian noise (AWGN) channels, the uncoded symbol error probability of $M$‑QAM can be approximated by the $Q$‑function. When coding is present, the *effective* $E_b/N_0$ that the decoder sees is increased by the coding gain $G_c$ (in dB). A convenient expression that links the required $E_b/N_0$ to the MCS parameters is  

$$
\frac{E_b}{N_0} = \frac{SNR}{R\;\log_2 M},\tag{2}
$$

where $SNR$ is the linear signal‑to‑noise ratio per *coded* bit. Equation (2) shows that, for a fixed $SNR$, a lower coding rate (more redundancy) reduces the required $E_b/N_0$ to achieve the same error performance.

---

### 4. MCS index tables  

Standardised systems (e.g., 3GPP LTE, NR) enumerate a finite set of MCS indices $i\in\{0,1,\dots\}$, each mapping to a tuple $(M_i,R_i)$. For illustration, a truncated table is reproduced below (values are typical, not exhaustive):

| MCS index $i$ | Modulation $M$ | Code rate $R$ |
|--------------|----------------|--------------|
| 0            | QPSK (4)       | 0.12         |
| 5            | QPSK (4)       | 0.48         |
| 9            | 16‑QAM (16)    | 0.60         |
| 13           | 64‑QAM (64)    | 0.78         |
| 20           | 256‑QAM (256)  | 0.93         |

The scheduler selects the highest index $i$ that the measured channel quality can support, thereby maximizing $\eta$ while keeping the BLER below a target (e.g., 10 %).  

---

### 5. Worked example  

**Problem:** A 10 MHz carrier (bandwidth $B$) is allocated to a user. The network selects MCS index 9, which corresponds to 16‑QAM ($M=16$) with a coding rate $R=0.6$. Ignoring protocol overhead, compute the *theoretical* user throughput.

**Solution:**  

1. Compute spectral efficiency using (1):  

$$
\eta = R\log_2 M = 0.6 \times \log_2 16 = 0.6 \times 4 = 2.4\;\text{bits/s/Hz}.
$$

2. Multiply by the allocated bandwidth:  

$$
\text{Throughput} = \eta \, B = 2.4\;\frac{\text{bits}}{\text{s·Hz}} \times 10\times10^{6}\;\text{Hz}
= 24\times10^{6}\;\text{bits/s}=24\;\text{Mbps}.
$$

Thus, under ideal conditions the user can receive **24 Mbps** of payload data.

---

### 6. Practical notes & common pitfalls  

| Pitfall | Why it occurs | Remedy |
|---------|---------------|--------|
| **Confusing $R$ with $\eta$** | $R$ is a *dimension‑less* fraction, while $\eta$ carries units (bits s$^{-1}$ Hz$^{-1}$). | Always apply (1) to convert $R$ and $M$ into spectral efficiency before comparing to channel capacity. |
| **Neglecting overhead** | Protocol headers, reference signals, and guard bands consume a non‑trivial portion of $B$. | Apply a realistic efficiency factor (e.g., 0.85) after the raw calculation. |
| **Assuming a single $E_b/N_0$ threshold per MCS** | The required $E_b/N_0$ depends on the target BLER and the specific code (LDPC, Turbo). | Use the link‑adaptation tables supplied by the standard, which list *required* $E_b/N_0$ for each MCS at the chosen BLER. |
| **Treating $M$ as a linear factor** | $M$ appears inside a logarithm; doubling $M$ does **not** double the bits per symbol. | Remember $\log_2 M$ grows slowly; a jump from 16‑QAM to 64‑QAM adds only 1 bpsym (4→6). |
| **Using the same code rate for all modulations** | Higher‑order constellations are more sensitive to noise; standards typically pair them with higher $R$ to keep the required $E_b/N_0$ manageable. | Follow the standard’s MCS table rather than arbitrarily mixing $M$ and $R$. |

Finally, note that modern systems employ *Hybrid Automatic Repeat Request (HARQ)*, which effectively creates a variable‑rate code by combining retransmissions. The nominal $R$ in the MCS table therefore represents the *first transmission* rate; the effective throughput may be higher or lower depending on HARQ success.  

---  

Understanding the interplay between coding rate, modulation order, and the resulting spectral efficiency is the cornerstone of link‑adaptation algorithms that drive the high data rates of contemporary cellular and Wi‑Fi networks. Mastery of these concepts enables engineers to predict capacity, design robust adaptive schemes, and interpret performance specifications found in standards documents.

## 練習題

**1.** Which of the following expressions correctly gives the spectral efficiency $\eta$ (in bits s$^{-1}$ Hz$^{-1}$) of a Modulation‑and‑Coding Scheme?

- A. $\displaystyle \eta = \frac{\log_2 M}{R}$
- B. $\displaystyle \eta = R + \log_2 M$
- C. $\displaystyle \eta = R\,\log_2 M$
- D. $\displaystyle \eta = \frac{R}{\log_2 M}$

<details><summary>看答案</summary>

正解：C。Spectral efficiency is the product of code rate and bits per symbol, i.e., $\eta = R\log_2 M$.

</details>

**2.** An MCS uses 64‑QAM ($M=64$) and a code rate of 0.5. What is its spectral efficiency?

- A. 1.5 bits/s/Hz
- B. 3 bits/s/Hz
- C. 4.5 bits/s/Hz
- D. 6 bits/s/Hz

<details><summary>看答案</summary>

正解：B。$\log_2 64 = 6$; $\eta = 0.5 \times 6 = 3$ bits/s/Hz.

</details>

**3.** For a fixed transmitted SNR, decreasing the coding rate from 0.8 to 0.4 will:

- A. Increase the required $E_b/N_0$ for a given BER.
- B. Decrease the required $E_b/N_0$ for a given BER.
- C. Leave $E_b/N_0$ unchanged.
- D. Double the spectral efficiency.

<details><summary>看答案</summary>

正解：B。Lower $R$ raises $E_b$ relative to $E_c$, reducing the $E_b/N_0$ needed for the same error probability (see Eq. 2).

</details>

**4.** A 20 MHz carrier uses MCS index 13 (64‑QAM, $R=0.78$). Assuming no overhead, compute the maximum achievable data rate in Mbps.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. $\log_2 64 = 6$ bits per symbol.  
2. Spectral efficiency $\eta = R\log_2 M = 0.78 \times 6 = 4.68$ bits/s/Hz.  
3. Throughput = $\eta \times B = 4.68 \times 20\,$MHz = $93.6$ Mbps.  
$\boxed{93.6}$

</details>

**5.** In an OFDM system a subcarrier spacing of 15 kHz yields a symbol duration of 66.7 µs (ignoring cyclic prefix). If the system employs QPSK ($M=4$) with a code rate of 0.5, what is the net bit rate per subcarrier in kbps?


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Bits per QPSK symbol = $\log_2 4 = 2$ bits.  
2. Net information bits per coded symbol = $R \times 2 = 0.5 \times 2 = 1$ bit.  
3. Symbol rate per subcarrier = $1 / T_{\text{sym}} = 1 / 66.7\;\mu\text{s} \approx 14985$ symbols/s.  
4. Net bit rate = $1 \text{ bit} \times 14985 \text{ s}^{-1} \approx 14{,}985$ bps = $14.985$ kbps.  
$\boxed{14.985}$

</details>
