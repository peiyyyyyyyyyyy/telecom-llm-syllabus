# 3.2.7 位元率、符號率、頻寬與 Nyquist 準則

所屬：[3.2 容量](../3-2.md)

## 練習題

**1.** An ideal Nyquist channel carries 16‑QAM at a symbol rate of $8\,$Msps. What is the maximum achievable net bit rate?

- A. $16\,$Mbps
- B. $32\,$Mbps
- C. $64\,$Mbps
- D. $128\,$Mbps

<details><summary>看答案</summary>

正解：B。16‑QAM carries $k=\log_2 16=4$ bits/symbol, so $R_b = 4 \times 8\,$Msps = $32\,$Mbps.

</details>

**2.** Which of the following statements about the Nyquist criterion is true?

- A. It limits the bit rate only for binary signalling.
- B. It requires a rectangular pulse shape.
- C. It gives the minimum bandwidth for zero ISI when sinc pulses are used.
- D. It is irrelevant for passband modulation.

<details><summary>看答案</summary>

正解：C。Nyquist’s first criterion states that a sinc‑shaped pulse achieves zero ISI with the minimum bandwidth $B=R_s/2$.

</details>

**3.** A QPSK system (M = 4) transmits at a symbol rate of $7\,$Msps using a raised‑cosine filter with roll‑off factor $\alpha = 0.35$. Compute the occupied bandwidth $B$ in Hz.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Determine bits per symbol: $k = \log_2 4 = 2$ (not needed for bandwidth).  
2. Apply the raised‑cosine bandwidth formula (4): $B = \frac{R_s}{2}\,(1+\alpha)$.  
3. Insert $R_s = 7\times10^{6}\,$sym/s and $\alpha = 0.35$:  
   $B = \frac{7\times10^{6}}{2}\times(1+0.35) = 3.5\times10^{6}\times1.35 = 4.725\times10^{6}\,$Hz.  
$\boxed{4725000}$

</details>

**4.** A link uses 256‑QAM ($M=256$) and occupies a $20\,$MHz channel. The pulse shaping is a raised‑cosine with roll‑off $\alpha = 0.15$. Assuming ideal Nyquist signalling, compute the maximum net bit rate $R_b$ (in bits per second) that can be carried.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Bits per symbol: $k = \log_2 256 = 8$ bits/symbol.  
2. For a baseband raised‑cosine, the relation between bandwidth and symbol rate is $B = \frac{R_s}{2}(1+\alpha)$. Solve for $R_s$: $R_s = \frac{2B}{1+\alpha}$.  
3. Insert $B = 20\times10^{6}$ Hz and $\alpha = 0.15$:  
   $R_s = \frac{2 \times 20\times10^{6}}{1.15} = \frac{40\times10^{6}}{1.15} \approx 34.7826087\times10^{6}$ sym/s.  
4. Net bit rate: $R_b = k\,R_s = 8 \times 34.7826087\times10^{6} \approx 278.2608696\times10^{6}$ bits/s.  
$\boxed{278260870}$

</details>
