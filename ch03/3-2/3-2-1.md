# 3.2.1 Shannon 通道容量

## 練習題

**1.** Compute the Shannon capacity (in Mbps) for a channel with bandwidth $B = 10\,$MHz and SNR $= 15\,$dB.  (Give the answer to one decimal place.)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Convert SNR to linear: $\gamma = 10^{15/10}=10^{1.5}=31.6227766$.
2. Apply (1): $C = 10\times10^{6}\,\log_{2}(1+\gamma)$.
3. $1+\gamma = 32.6227766$.
4. $\log_{2}(32.6227766)=\dfrac{\ln 32.6227766}{\ln 2}\approx\frac{3.485}{0.6931}=5.025$.
5. $C = 10\times10^{6}\times5.025 = 5.025\times10^{7}\,\text{bit/s}=50.25\,$Mbps.
$\boxed{50.3}$

</details>

**2.** A link has signal power $S = 5\,$mW, noise power $N = 0.5\,$mW, and allocated bandwidth $B = 2.5\,$MHz. Compute its Shannon capacity in Mbps (rounded to two decimal places).


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Linear SNR: $\gamma = S/N = 5/0.5 = 10$.
2. Use (1): $C = 2.5\times10^{6}\,\log_{2}(1+10)$.
3. $1+10 = 11$.
4. $\log_{2}(11)=\dfrac{\ln 11}{\ln 2}\approx\frac{2.3979}{0.6931}=3.45943$.
5. $C = 2.5\times10^{6}\times3.45943 = 8.648575\times10^{6}\,$bit/s = $8.648575$ Mbps.
$\boxed{8.65}$

</details>
