# 3.2.5 OFDM 與資源格

## 練習題

**1.** Which of the following statements about the resource grid is FALSE?

- A. Each resource block contains 12 sub‑carriers in frequency.
- B. A resource element is the smallest unit that can carry one modulation symbol.
- C. The number of OFDM symbols per subframe is independent of the cyclic‑prefix length.
- D. Guard sub‑carriers are typically left unused to satisfy spectral masks.

<details><summary>看答案</summary>

正解：C。The CP length changes $T_\text{sym}$, thus affecting how many symbols fit into a fixed subframe duration.

</details>

**2.** A system uses $\Delta f = 15\,$kHz, CP ratio $\alpha = 0.07$, and a subframe duration of $1\,$ms. How many complete OFDM symbols (including CP) can be transmitted in one subframe? (unitless integer)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Compute useful symbol time: $T_\text{u}=1/\Delta f = 1/15000 = 66.666\;\mu\text{s}$.  
2. CP duration: $T_\text{CP}= \alpha T_\text{u}=0.07\times66.666 = 4.6666\;\mu\text{s}$.  
3. Full symbol duration: $T_\text{sym}=T_\text{u}+T_\text{CP}=71.333\;\mu\text{s}$.  
4. Number of symbols in 1 ms: $N_\text{sym}= \left\lfloor \frac{1000\;\mu\text{s}}{71.333\;\mu\text{s}} \right\rfloor = \left\lfloor 14.02 \right\rfloor = 14$? Wait compute precisely: 1000/71.333 = 14.02, floor = 14. However earlier analysis gave 13 because CP was 5 µs; using 4.666 µs gives 14. Verify with Python.  
$\boxed{14}$

</details>

**3.** A 10 MHz channel is allocated with 15 kHz sub‑carrier spacing. After reserving a 0.5 MHz guard band on each side, how many resource blocks (12 sub‑carriers each) can be assigned for user data? (integer)


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. Effective bandwidth: $B_\text{eff}=10\text{MHz} - 2\times0.5\text{MHz}=9\text{MHz}$.  
2. Number of sub‑carriers: $N = B_\text{eff}/\Delta f = 9\times10^{6} / 15\times10^{3}=600$.  
3. Resource blocks: $N_\text{RB}= \lfloor N/12 \rfloor = \lfloor 600/12 \rfloor = 50$.  
$\boxed{50}$

</details>
