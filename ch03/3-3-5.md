# 3.3.5 最大路徑損耗與涵蓋距離

所屬：[3.3 鏈路預算](3-3.md)

## 內文

#### 為什麼要學

把發射端（3.3.1）、天線（3.3.2）、損耗與餘量（3.3.3）、接收靈敏度（3.3.4）合在一起，就能回答規劃時最實際的問題：這條鏈路最多能承受多少路徑損耗？對應到多遠的距離？前者稱為最大允許路徑損耗（maximum allowable path loss, MAPL），是鏈路預算表最後一列的結果；後者要再套一個傳播模型才能得到，而且答案對模型的選擇極為敏感。站距怎麼抓、一個區域需要幾個站、換頻段或改天線後涵蓋會縮多少，都是由 MAPL 反推距離得來的。學會這一步，也才能理解為什麼「多 3 dB」在不同環境下換來的涵蓋增加幅度差很多。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| MAPL | 最大允許路徑損耗 | dB |
| EIRP | 發射端等效全向輻射功率（3.3.1） | dBm |
| $S_{\min}$ | 接收靈敏度（3.3.4） | dBm |
| $G_r$ | 接收天線增益 | dBi |
| $L_r$ | 接收端損耗（饋線、人體等） | dB |
| $\sum M$ | 各項餘量之和（陰影衰落、干擾等） | dB |
| $\sum L_{\text{其他}}$ | 其他損耗之和（穿透損耗等） | dB |
| $f$ | 載波頻率 | MHz |
| $d$ | 發射端到接收端的距離 | km 或 m（依公式而定） |
| $d_0$ | 對數距離模型的參考距離 | m |
| $PL(d_0)$ | 參考距離處的路徑損耗 | dB |
| $n$ | 路徑損耗指數（path loss exponent） | 無因次 |

#### 公式與推導

接收功率是 EIRP 減去路徑損耗，再加上接收天線增益、扣掉接收端損耗：$P_r = \text{EIRP} - PL + G_r - L_r$。要求 $P_r$ 在扣除餘量與其他損耗後仍不低於靈敏度，令等號成立時的 $PL$ 就是 MAPL：

$$\text{MAPL} = \text{EIRP} - S_{\min} + G_r - L_r - \sum M - \sum L_{\text{其他}}$$

所有量都在 dB 域；$S_{\min}$ 是負值，減去它等於加上其絕對值。這條式子本身不涉及任何傳播模型。

**由 MAPL 反推距離**要指定模型，令模型的路徑損耗等於 MAPL 再解出 $d$。

（1）自由空間模型（3.1.2）：$PL = 32.44 + 20\log_{10}d_{\text{km}} + 20\log_{10}f_{\text{MHz}}$，常數 32.44 配 km 與 MHz。這個常數用精確光速算是 32.448、光速取 $3\times10^8$ m/s 時是 32.442，本章沿用 3.1.2 的寫法取 32.44，與 32.45 只差 0.01 dB。解出

$$d_{\text{km}} = 10^{\left(\text{MAPL} - 32.44 - 20\log_{10}f_{\text{MHz}}\right)/20}$$

只適用於視距、無遮蔽、無明顯反射的情形，例如微波回傳或衛星鏈路；用在地面行動網路會嚴重高估距離。

（2）對數距離模型（3.1.3）：$PL(d) = PL(d_0) + 10\,n\log_{10}(d/d_0)$，適用於 $d \ge d_0$。解出

$$d = d_0\times10^{\left(\text{MAPL} - PL(d_0)\right)/(10n)}$$

$PL(d_0)$ 通常取參考距離處的自由空間路徑損耗或量測值；$n$ 由環境決定，自由空間為 2，有遮蔽的都會環境較大，必須依量測或所採用的模型給定。此模型給的是中位數路徑損耗，所以 MAPL 中必須已經扣除陰影衰落餘量，算出的距離才對應到指定的邊緣涵蓋機率。

**距離對 dB 的敏感度**：由上式，MAPL 每變動 $\Delta$ dB，距離變為 $10^{\Delta/(10n)}$ 倍，涵蓋面積（與 $d^2$ 成正比）變為 $10^{2\Delta/(10n)}$ 倍。$n$ 越大，同樣的 dB 換到的距離越少。

#### 算例

以下沿用前面各小節的假設數值：頻率 3,500 MHz；下行 EIRP 61.02 dBm（3.3.1 算例 1）；終端靈敏度 −95.17 dBm（3.3.4 算例 1）；終端天線增益 0 dBi、人體損耗 3 dB（皆為假設）；陰影衰落餘量 10.25 dB、低損耗建物外牆穿透損耗 12.70 dB（3.3.3 算例）；下行干擾餘量 3 dB（假設）。

**算例 1（下行 MAPL）**

$$\text{MAPL} = 61.02 - (-95.17) + 0 - 3 - (10.25 + 3) - 12.70$$

逐步：$61.02 + 95.17 = 156.19$；減人體損耗得 153.19；減兩項餘量 13.25 得 139.94；減穿透損耗得 **127.24 dB**。

**算例 2（反推涵蓋距離）**

（a）自由空間模型：$20\log_{10}(3{,}500) = 70.88$ dB；$127.24 - 32.44 - 70.88 = 23.92$；$d = 10^{23.92/20} = 10^{1.196} = 15.70$ km。

（b）對數距離模型：取 $d_0 = 100$ m，$PL(d_0)$ 用自由空間值 $32.44 + 70.88 + 20\log_{10}(0.1) = 83.32$ dB；路徑損耗指數 $n = 3.5$（假設的都會環境值）。

$$d = 100\times10^{(127.24 - 83.32)/35} = 100\times10^{1.2549} = 1{,}798\ \text{m}$$

約 1.8 km。驗算：$83.32 + 35\log_{10}(17.98) = 127.24$ dB，與 MAPL 相符。

合理性檢查：同一個 MAPL，自由空間算出 15.7 km，$n = 3.5$ 只有 1.8 km，相差近九倍，可見傳播模型比鏈路預算中任何單一項目都更能左右結果；既然預算裡已經計入穿透損耗與陰影衰落，終端顯然不在無遮蔽的視距環境，自由空間的結果不能採用。敏感度方面，$n = 3.5$ 時 MAPL 每多 1 dB，半徑變為 $10^{1/35} = 1.068$ 倍（多 6.8%），面積多約 14%；多 3 dB 時半徑 1.218 倍、面積 1.48 倍。

#### 常見錯誤

- **靈敏度的負號處理錯**：$\text{EIRP} - S_{\min}$ 是「減去負數」，結果應比 EIRP 大；算出 MAPL 只有負幾十 dB 就是符號錯了。
- **常數與單位不配對**：32.44 配 km 與 MHz；若頻率用 GHz、距離用 km，常數要多 60 dB，寫成 92.45（精確光速的 92.448 取位；光速取 $3\times10^8$ m/s 時為 92.44）。對數距離模型中 $d$ 與 $d_0$ 必須同單位。
- **沒寫用哪個模型就報距離**：只說「涵蓋 2 km」沒有意義，必須同時說明模型、路徑損耗指數與涵蓋機率。
- **重複或遺漏陰影衰落餘量**：反推距離用的是中位數模型，餘量要在 MAPL 內扣一次，而且只扣一次。

#### 和其他小節的關係

MAPL 的四個輸入分別來自 3.3.1（EIRP）、3.3.2（天線增益）、3.3.3（損耗與餘量）、3.3.4（靈敏度）。反推距離所用的自由空間公式在 3.1.2，對數距離模型與陰影衰落在 3.1.3。本節只算了單一方向；上行與下行各算一次 MAPL、取較小者決定涵蓋，是 3.3.6 的內容。

No penetration loss applies. Using $\text{MAPL} = \text{EIRP} - S_{\min} + G_r - L_r - \sum M$, compute the maximum allowable path loss in dB, rounded to two decimal places.

**答案**　145.80

**詳解**　$\text{EIRP} - S_{\min} = 58 - (-101.5) = 159.5$ dB. Adding the receive antenna gain: $159.5 + 0 = 159.5$ dB. Subtracting the body loss: $159.5 - 3 = 156.5$ dB. Subtracting the margins: $156.5 - 8.2 - 2.5 = 145.8$ dB, i.e. 145.80 dB.

**3.3.5S003**　The propagation model already gives the typical path loss at each distance. Why does the budget still subtract a 7.8 dB shadow fading margin, and what would the range mean without it?

<details><summary>看答案</summary>

**答案**　The model predicts the median loss; at the computed edge the actual loss varies around that median because of shadowing, so without a margin only about 50% of locations at the edge would be served. **詳解**　With log-normal shadowing, $P(\text{loss} \le \text{median} + M) = 1 - Q(M/\sigma)$. For $M = 0$ this is 0.5. Subtracting $M$ from the MAPL is the same as requiring the median loss at the edge to be $M$ dB lower than the budget allows.

**3.3.5S013**　Why is the free-space model a reasonable basis for this satellite link when it would badly overestimate the range of a terrestrial macro cell?

<details><summary>看答案</summary>

**答案**　Almost the entire satellite path runs through empty space or thin atmosphere with a clear line of sight, so the spreading loss dominates and the few extra effects (atmospheric, polarisation, local clutter near the handset) can be handled as fixed dB terms, as done here. A terrestrial path runs along the ground through buildings, terrain and vegetation, which add diffraction, reflection and absorption that grow with distance; the loss then rises faster than $20\log_{10} d$ (path loss exponents of 3–4), so free space would predict far too long a range.

**詳解**　Free space corresponds to $n = 2$. For the same MAPL the range ratio between $n = 2$ and $n = 3.5$ beyond a common reference point grows exponentially with the excess loss, which is why the model choice dominates the result for ground links.

**3.3.5S038**　Why does the TMA improve the uplink budget but leave the downlink budget unchanged?

<details><summary>看答案</summary>

**答案**　The TMA is a low-noise amplifier placed at the antenna, before the feeder. On receive it amplifies the signal before the feeder loss can degrade the system noise figure, so the cascade noise figure (Friis) improves. On transmit the downlink signal bypasses the amplifier (or passes through it with a small insertion loss), so the full feeder loss and the transmit power are unchanged.

**詳解**　Without TMA the feeder loss $L$ adds directly to the receiver noise figure ($F_{\text{sys}} = L\,F_{\text{rx}}$). With a TMA of gain $G$ ahead of the feeder, $F_{\text{sys}} \approx F_{\text{TMA}} + (L F_{\text{rx}} - 1)/G$, which is close to $F_{\text{TMA}}$ when $G$ is large.

**出處**　H. T. Friis, "Noise Figures of Radio Receivers," Proc. IRE, 1944; H. Holma and A. Toskala (eds.), *WCDMA for UMTS* (tower-mounted amplifiers in link budgets).

**詳解**　$\text{MAPL} = 61 + 99 + 0 - 3 - 8 - 2 - 24 = 123$ dB. $\log_{10} R = (123 - 101.2)/33.5 = 21.8/33.5 = 0.650746$; $R = 10^{0.650746} = 4.4745$ km ≈ 4.475 km. Spacing $= 2 \times 4.4745 - 0.5 = 8.4490$ km. $N = \lceil 120/8.4490 \rceil = \lceil 14.20 \rceil = 15$ sites.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (link budget; path loss models).

</details>

**3.3.5S052**　The railway company is considering installing on-board repeaters with roof antennas. Why would this reduce the number of trackside sites so much?

<details><summary>看答案</summary>

**答案**　The repeater's roof antenna is outside the metal-coated car body, so the 24 dB car penetration loss disappears from the trackside link budget (the repeater re-radiates inside the car). Recovering 24 dB with an exponent of 3.35 multiplies the range by about $10^{24/33.5} = 5.2$, so far fewer trackside sites are needed (in practice the repeater link adds its own small losses and gains).

**詳解**　Without the penetration loss: $\log_{10} R = (147 - 101.2)/33.5 = 1.367164$, $R = 23.29$ km, compared with 4.47 km.

**出處**　H. Holma and A. Toskala (eds.), *LTE for UMTS* (link budget: vehicle penetration loss); T. S. Rappaport, *Wireless Communications: Principles and Practice* (path loss models).

</details>

**3.3.5S053**　Some sites cannot be placed next to the track and must sit 1.5 km away from it. How does this affect the stretch of track each such site can cover?

<details><summary>看答案</summary>

**答案**　The range $R$ is a radial distance from the site, so a site offset by $h$ from the track reaches only $\sqrt{R^2 - h^2}$ along the track on each side. With $R = 4.475$ km and $h = 1.5$ km this is about 4.22 km instead of 4.47 km, so the spacing must shrink (from 8.45 km to about 7.93 km).

**詳解**　$\sqrt{4.4745^2 - 1.5^2} = \sqrt{20.0212 - 2.25} = \sqrt{17.7712} = 4.2156$ km. Spacing $= 2\times4.2156 - 0.5 = 7.93$ km.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (coverage geometry).

</details>

**3.3.5S054**　A planner computes the range as follows. Find the wrong step and give the correct range in km (three decimal places).

#### 情境題：Shadow fading margin and edge coverage probability

**Scenario | Choosing the edge reliability for a suburban layer**

A suburban layer has a link budget of 141.2 dB before the shadow fading margin is subtracted. Shadowing is log-normal with standard deviation $\sigma = 8$ dB. The margin is $M = z\,\sigma$, where $z = Q^{-1}(1 - P_{\text{edge}})$; use $z = 1.2816$ for 90% and $z = 1.6449$ for 95% cell-edge coverage probability. The median model is $PL(d) = 81.0 + 36\log_{10}(d/100\ \text{m})$ dB.

**3.3.5S056**　Compute the shadow fading margin for 90% edge coverage probability, in dB, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　10.25 dB

**詳解**　$M = 1.2816 \times 8 = 10.2528$ dB ≈ 10.25 dB.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (log-normal shadowing, coverage probability).

</details>

**3.3.5S057**　Compute the cell range for 95% edge coverage probability, in metres, rounded to the nearest metre.

<details><summary>看答案</summary>

**答案**　2026 m

**詳解**　$M = 1.6449 \times 8 = 13.1592$ dB. $\text{MAPL} = 141.2 - 13.1592 = 128.0408$ dB. $\log_{10}(d/100) = (128.0408 - 81.0)/36 = 47.0408/36 = 1.306689$. $d = 100\times10^{1.306689} = 2026.23$ m ≈ 2026 m (compared with 2440 m for 90%).

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (log-normal shadowing; log-distance path loss model).

</details>

**3.3.5S058**　A cell planned for 90% coverage probability at the cell edge is said to give "about 97% area coverage". Is that a contradiction?

<details><summary>看答案</summary>

**答案**　No. The 90% applies only on the cell boundary, the worst place. Users closer to the site have a lower median loss and therefore an extra margin, so their coverage probability is higher; averaged over the whole cell area, the location probability is higher than the edge value. How much higher depends on $\sigma$ and $n$ (Jakes' area-coverage formula).

**詳解**　Area coverage integrates the location probability $P(r)$ over the disc of radius $R$; since $P(r) \ge P(R)$ for $r < R$, the average exceeds $P(R) = 0.90$.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (percentage of coverage area); W. C. Jakes, *Microwave Mobile Communications*.

</details>

**3.3.5S059**　In the dense town centre the shadowing standard deviation is 10 dB instead of 8 dB. With the same 95% target, does the range in the town centre shrink only because of the larger exponent there?

<details><summary>看答案</summary>

**答案**　No. A larger $\sigma$ also needs a larger margin: $1.6449 \times 10 = 16.45$ dB instead of 13.16 dB, i.e. 3.29 dB less MAPL. The range therefore shrinks both because of the higher exponent and because of the higher margin for the same reliability.

**詳解**　$\Delta M = 16.449 - 13.159 = 3.29$ dB. With $n = 3.6$ alone this would cut the range by $10^{-3.29/36} = 0.81$.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (log-normal shadowing).

</details>

**3.3.5S060**　A planner sizes the 95% case as follows. Find the wrong step and give the correct range in metres (nearest metre).
1. For 95% coverage, $z = 1.96$.
2. $M = 1.96 \times 8 = 15.68$ dB; $\text{MAPL} = 141.2 - 15.68 = 125.52$ dB.
3. $d = 100\times10^{(125.52 - 81.0)/36} = 1725$ m.

<details><summary>看答案</summary>

**答案**　Step 1 is wrong: 1.96 is the two-sided 95% value. The edge requirement is one-sided (the loss must not exceed the budget), so $z = Q^{-1}(0.05) = 1.6449$. Correct range: 2026 m.

**詳解**　$M = 13.1592$ dB, $\text{MAPL} = 128.0408$ dB, $\log_{10}(d/100) = 47.0408/36 = 1.306689$, $d = 2026.23$ m ≈ 2026 m. The two-sided value would actually correspond to 97.5% edge coverage.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (Q function; coverage probability).

</details>

#### 情境題：Millimetre-wave fixed wireless access

**Scenario | 28 GHz fixed wireless access to suburban homes**

A 28 GHz fixed wireless access cell serves outdoor-mounted customer premises equipment (CPE). The base station's beamformed EIRP is 55 dBm. The CPE uses a 20 dBi antenna array, a 400 MHz channel, a noise figure of 8 dB and a required SNR of 0 dB; use −174 dBm/Hz. The budget subtracts 8 dB for rain and 15 dB for foliage along the path. The model is the close-in reference form $PL = 32.4 + 20\log_{10} f_{\text{GHz}} + 10n\log_{10} d_{\text{m}}$ with $n = 2.1$.

**3.3.5S061**　Compute the CPE sensitivity and the MAPL, in dBm and dB, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　Sensitivity −79.98 dBm; MAPL 131.98 dB.

**詳解**　$10\log_{10}(400\times10^{6}) = 86.0206$ dB. $S = -174 + 86.0206 + 8 + 0 = -79.9794$ dBm ≈ −79.98 dBm. $\text{MAPL} = 55 + 79.9794 + 20 - 8 - 15 = 131.9794$ dB ≈ 131.98 dB.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (thermal noise; link budget).

</details>

**3.3.5S062**　Compute the maximum CPE distance in metres, rounded to the nearest metre.

<details><summary>看答案</summary>

**答案**　2310 m

**詳解**　$20\log_{10}(28) = 28.9432$ dB. $10n\log_{10} d = 131.9794 - 32.4 - 28.9432 = 70.6362$ dB. $\log_{10} d = 70.6362/21 = 3.363630$. $d = 10^{3.363630} = 2310.10$ m ≈ 2310 m.

**出處**　T. S. Rappaport et al., "Wideband Millimeter-Wave Propagation Measurements and Channel Models for Future Wireless Communication System Design," IEEE Trans. Commun., 2015 (close-in free-space reference distance model).

</details>

**3.3.5S063**　In this model the only frequency-dependent term is $20\log_{10} f_{\text{GHz}}$ in the 1 m intercept. Does that mean a 28 GHz link must always reach much less far than a 3.5 GHz link with the same transmit power?

<details><summary>看答案</summary>

**答案**　Not necessarily. The higher intercept ($20\log_{10}(28/3.5) = 18.1$ dB more at 1 m) reflects the smaller effective aperture of an antenna with a given gain. For a fixed physical antenna size, the gain grows as $f^2$ at each end, so high-gain arrays at both ends can recover all of it and more; that is why the scenario relies on beamforming at the base station and a 20 dBi CPE array. What remains frequency-specific are blockage, foliage and rain losses, which are much larger at 28 GHz.

**詳解**　Gain of an aperture of area $A$: $G = 4\pi A/\lambda^2$, so for a fixed $A$, $G \propto f^2$, i.e. +18.1 dB per end from 3.5 to 28 GHz, versus the 18.1 dB higher free-space intercept.

**出處**　T. S. Rappaport, *Wireless Communications: Principles and Practice* (antenna gain and effective aperture; Friis equation).

</details>

**3.3.5S064**　The operator wants the links to stay up during heavier rain. What does increasing the 8 dB rain margin do to the coverage, and what quantity sets how large the margin must be?

<details><summary>看答案</summary>

**答案**　A larger rain margin lowers the MAPL dB for dB and shrinks the maximum CPE distance (each extra dB costs $10^{-1/21}$, about 10% of range). The required margin is set by the target link availability (percentage of time) together with the local rain-rate statistics and the path length, which give the rain attenuation exceeded for the allowed fraction of time.

**詳解**　For example, +4 dB of margin multiplies the range by $10^{-4/21} = 0.645$, from 2310 m to about 1490 m.

**出處**　ITU-R Recommendation P.530 (propagation data for terrestrial line-of-sight systems, rain attenuation); ITU-R Recommendation P.838 (specific attenuation model for rain).

</details>
