# 3.6.5 驗算

所屬：[3.6 解題方法](3-6.md)

## 內文

#### 為什麼要學

算出答案不等於算對。電信計算常見的錯誤有固定的「指紋」：單位錯會差 30 dB 或 60 dB，bit 與 byte 錯會差 8 倍，功率比與電壓比弄混會差 2 倍的 dB 值，線性值當 dB 用則差得毫無規律。這些錯誤重算一次往往還是同樣的結果，因為重算走的是同一條路。驗算的意思是換一條路檢查：用粗略的量級估計、把答案代回原式、看極端情況下公式的行為、核對單位。實務上，鏈路預算審查、容量規劃覆核、告警門檻設定都靠這種快速檢查來攔住離譜的數字；對語言模型而言，這也是在輸出答案前自我檢查的主要手段。

#### 定義與符號

| 項目 | 意思 | 例子 |
|---|---|---|
| 量級估計（order-of-magnitude estimate） | 用好記的近似值快速算出答案的大概範圍 | 距離每增為 10 倍，自由空間損耗加 20 dB |
| 反推代回（back-substitution） | 把答案當作已知，倒著算回題目給的條件 | 由路徑損耗反推距離，看是否等於題目的距離 |
| 極端情況（limiting case） | 讓某個變數趨近 0、無限大或臨界值，看公式的結果是否合理 | M/M/1 的到達率趨近 0 時，停留時間應趨近服務時間 |
| 界限檢查（bound check） | 答案是否落在理論上必須滿足的範圍內 | 機率在 0 與 1 之間；效率不超過 100% |
| 單位檢查 | 答案的單位是否由算式自然得出，並且是題目要的 | bit ÷ (bit/s) 得到 s |
| 錯誤指紋 | 特定錯誤造成的固定偏差量 | 差 60 dB 多半是 km 與 m 或 MHz 與 GHz 弄錯 |
| 獨立路徑 | 用另一條公式或另一組單位重算同一個量 | FSPL 用原式 $20\log_{10}(4\pi d/\lambda)$ 複核 |

#### 公式與推導

驗算有四種檢查，建議依下列順序進行，由快到慢。

**一、單位與界限檢查（幾秒鐘）。** 先看答案的單位是不是題目要的，再看數值是否違反基本界限：機率與利用率在 0 與 1 之間；被動元件的損耗為正；接收功率不會大於發射功率加上天線增益；可達速率不會超過 3.2.1 的 Shannon 容量；編碼效率不超過 100%（3.7.2）；穩態排隊系統要有 $\rho < 1$（3.4.3）。違反任何一條，答案一定有錯。

**二、量級估計。** 用幾個好記的參考值，心算出答案應該落在哪裡：

- dB 的心算：3 dB 約 2 倍、10 dB 是 10 倍，其餘用這兩個組合（3.1.1）。
- 自由空間損耗：距離或頻率每增為 10 倍加 20 dB，加倍加 6 dB（3.1.2）。可以先算 1 m 處的損耗 $20\log_{10}(4\pi/\lambda)$，再加上距離項。
- 熱雜訊：$-174$ dBm/Hz，1 MHz 頻寬為 $-114$ dBm，頻寬每增為 10 倍加 10 dB（3.1.5）。
- Shannon 容量：高 SNR 時每多 3 dB，頻譜效率約多 1 bit/s/Hz（3.2.1）。

估計值與答案差在 1～2 dB 或幾個百分點之內屬於正常；差到 3 dB、10 dB、30 dB、60 dB 或 8 倍，就對照錯誤指紋去找原因。常見的指紋如下：

| 偏差 | 可能原因 |
|---|---|
| 30 dB 或 1000 倍 | dBm 與 dBW、W 與 mW、km 與 m（一次方）、kHz 與 MHz（頻寬） |
| 60 dB | FSPL 中 km 與 m、MHz 與 GHz 弄錯（20log 使 1000 倍變成 60 dB） |
| 8 倍 | bit 與 byte |
| dB 值差 2 倍 | $10\log_{10}$ 與 $20\log_{10}$ 用錯（功率比與電壓比） |
| 約 2.3 倍或 0.43 倍 | $\ln$ 與 $\log_{10}$ 用錯 |
| 約 4.9% 或 7.4% | $10^6$ 與 $2^{20}$、$10^9$ 與 $2^{30}$ |

**三、反推代回。** 把算出的答案當成已知，從公式的另一端倒著算，看能不能得回題目的條件。反推的價值在於它會把錯誤「翻譯」成一個看得懂的量，例如反推出來的距離是 0.2 m 而不是 200 m，馬上知道錯在 1000 倍。另一種做法是用獨立的關係式交叉檢查，例如排隊問題用 Little 定理 $N = \lambda T$（3.4.3）核對平均人數與平均時間是否一致。

**四、極端情況。** 把某個輸入推到極端，看公式的行為是否合乎直覺：距離趨近無限大時接收功率應趨近零；SNR 趨近 0 時容量應趨近 0；到達率趨近服務率時等待時間應趨近無限大；通道數增加時阻塞機率應下降。如果自己用的公式在極端情況下給出不合理的結果，表示公式選錯或記錯。

四種檢查都通過，不能證明答案完全正確，但可以排除絕大多數的大錯。

#### 算例

**算例 1（量級估計加反推：找出 60 dB 的錯誤）** 題目：求 28 GHz、距離 200 m 的自由空間路徑損耗。有人算得 47.40 dB，請檢查。

量級估計：28 GHz 的波長 $\lambda = 3\times10^8 / (28\times10^9) = 0.01071$ m。1 m 處的損耗為

$$20\log_{10}\!\left(\frac{4\pi}{0.01071}\right) = 61.38\ \text{dB}$$

200 m 再加 $20\log_{10}(200) = 46.02$ dB，合計約 107.4 dB。答案 47.40 dB 比 1 m 處的損耗還小，不可能正確，而且與估計值差 60 dB。

反推：把 47.40 dB 代回配 km 與 GHz 的式子，求對應的距離：

$$20\log_{10} d_{\text{km}} = 47.40 - 92.45 - 20\log_{10}(28) = 47.40 - 92.45 - 28.94 = -73.99$$

$$d = 10^{-73.99/20} = 10^{-3.6995}\ \text{km} = 2.0\times10^{-4}\ \text{km} = 0.2\ \text{m}$$

反推得到 0.2 m，是題目距離的千分之一。對照錯誤指紋，60 dB 來自單位與常數不配：原計算把頻率 28（GHz）代入了配 MHz 的常數 32.44，即 $32.44 + 20\log_{10}(0.2) + 20\log_{10}(28) = 32.44 - 13.98 + 28.94 = 47.40$ dB。

改正：

$$\text{FSPL} = 92.45 + 20\log_{10}(0.2) + 20\log_{10}(28) = 92.45 - 13.98 + 28.94 = 107.41\ \text{dB}$$

與量級估計的 107.4 dB 相符。

**算例 2（極端情況加反推：找出公式用錯）** 題目：某路由器輸出埠可視為 M/M/1 佇列，封包到達率 800 封包/秒，服務率 1000 封包/秒。求封包在系統中的平均停留時間（含服務）。有人算得 0.8 ms，請檢查。

界限檢查：平均服務時間為 $1/\mu = 1/1000 = 1$ ms。停留時間包含等待與服務，不可能小於服務時間，0.8 ms 小於 1 ms，一定有錯。

極端情況：錯誤答案等於 $\rho/\mu = 0.8/1000$ 秒。若公式真是 $\rho/\mu$，到達率趨近 0 時停留時間會趨近 0，但實際上即使沒有人排隊，封包也要花 1 ms 被服務；到達率趨近服務率時結果只會趨近 1 ms，但實際上佇列應該無限增長。兩個極端都不合理，表示公式用錯。

反推：用 Little 定理，$N = \lambda T = 800 \times 0.0008 = 0.64$ 個封包；但 M/M/1 的平均系統人數是 $\rho/(1-\rho) = 0.8/0.2 = 4$ 個封包，兩者不一致。

改正（3.4.3，條件 $\rho = 0.8 < 1$ 成立）：

$$T = \frac{1}{\mu - \lambda} = \frac{1}{1000 - 800} = 0.005\ \text{s} = 5\ \text{ms}$$

複核：$N = \lambda T = 800 \times 0.005 = 4$ 個封包，與 $\rho/(1-\rho)$ 一致；其中等待時間為 $5 - 1 = 4$ ms。極端情況：$\lambda \to 0$ 時 $T \to 1/\mu = 1$ ms，$\lambda \to \mu$ 時 $T \to \infty$，都合理。

#### 常見錯誤

1. **用同一個方法重算一次當作驗算。** 同樣的單位錯誤或公式錯誤會重現，要換一條路徑檢查。
2. **只看數字不看量級。** 47.40 dB 看起來像個正常的 dB 值，不和參考值比較就看不出差了 60 dB。
3. **把取位差異當成錯誤，或把大偏差當成取位差異。** 差 0.01～0.03 dB 多半來自常數取位（3.6.4）；差 3 dB 以上就不是取位問題。
4. **忽略公式的前提。** 例如 $\rho \ge 1$ 時仍套用穩態公式，得到負的等待時間卻沒有察覺。

#### 和其他小節的關係

驗算要靠 3.6.2 留下的中間值才能定位錯在哪一步；單位檢查對應 3.6.3，取位差異的判斷對應 3.6.4。量級估計用到的參考值來自 3.1.1、3.1.2、3.1.5 與 3.2.1；算例用到 3.1.2 的自由空間路徑損耗與 3.4.3 的 M/M/1 與 Little 定理；界限檢查用到 3.2.1、3.4.2、3.7.2 的理論界限。

**出處**　自由空間衰減公式見 ITU-R 建議書 P.525（Calculation of free-space attenuation）；M/M/1 平均停留時間與 Little 定理見 Kleinrock, *Queueing Systems, Volume 1: Theory* 與 Bertsekas & Gallager, *Data Networks*（延遲模型一章）；回顧與檢查解答的方法見 G. Pólya, *How to Solve It*。
