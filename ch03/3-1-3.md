# 3.1.3 傳播模型與陰影衰落

所屬：[3.1 訊號與通道](3-1.md)

## 內文

#### 為什麼要學

真實的行動網路很少是自由空間：訊號會被建築物擋住、繞射、穿牆，平均損耗隨距離增加的速度比自由空間快；而且同樣距離的不同位置，因為遮蔽物不一樣，收到的功率會上下起伏好幾 dB。規劃基地臺涵蓋時，需要一個簡單的模型描述「平均損耗隨距離怎麼變」，再用統計方式處理起伏，才能回答「細胞邊緣有多少比例的位置訊號夠強」以及「要留多少衰落餘量（fade margin）」這類問題。對數距離路徑損耗模型加上對數常態陰影衰落，就是最常用的做法。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $d$ | 收發距離 | m 或 km |
| $d_0$ | 參考距離（在天線遠場內，通常取 1 m、100 m 或 1 km） | 與 $d$ 相同 |
| $\overline{PL}(d)$ | 距離 $d$ 上的平均路徑損耗 | dB |
| $n$ | 路徑損耗指數（path loss exponent） | 無因次 |
| $X_\sigma$ | 陰影衰落（shadow fading），平均為 0 的高斯隨機變數（以 dB 計） | dB |
| $\sigma$ | 陰影衰落的標準差 | dB |
| $P_r(d)$ | 距離 $d$ 上的接收功率 | dBm |
| $\gamma$ | 接收功率門檻（例如接收靈敏度） | dBm |
| $Q(x)$ | 標準常態分布的右尾機率 | 無因次 |
| $M$ | 陰影衰落餘量 | dB |

#### 公式與推導

**對數距離路徑損耗模型**（log-distance path loss model）假設平均損耗和距離的 $n$ 次方成正比，用 dB 寫成

$$\overline{PL}(d) = \overline{PL}(d_0) + 10\,n\log_{10}\frac{d}{d_0}$$

$\overline{PL}(d_0)$ 可以用量測值，或用 3.1.2 的自由空間公式算。$n = 2$ 就回到自由空間；教科書常見的整理是：市區蜂巢環境約 2.7～3.5，有遮蔽的市區約 3～5，建築物內有視距時約 1.6～1.8（走廊的波導效應使它比 2 還小），建築物內被隔間遮蔽時約 4～6。距離每增加 10 倍，損耗增加 $10n$ dB；距離加倍增加 $10n\log_{10}2 = 3.01n$ dB。

**對數常態陰影**（log-normal shadowing）：同樣距離的不同位置，損耗在平均值上下起伏，量測顯示這個起伏用 dB 表示時接近常態分布，所以

$$PL(d) = \overline{PL}(d) + X_\sigma,\qquad X_\sigma \sim \mathcal N(0,\sigma^2)$$

$\sigma$ 在戶外巨細胞環境常見的量級是數 dB 到十幾 dB。3GPP TR 38.901 的各種場景模型（都會巨細胞、都會微細胞、鄉村、室內等）也是「距離與頻率的對數式＋對數常態陰影」這個形式，只是係數依場景分別給定，實際規劃時應查該報告的路徑損耗表。

**涵蓋機率**：令平均接收功率 $\overline{P_r}(d) = P_t + G_t + G_r - \overline{PL}(d)$（dB 系列單位），則接收功率 $P_r(d)$ 是平均為 $\overline{P_r}(d)$、標準差為 $\sigma$ 的常態隨機變數，超過門檻 $\gamma$ 的機率是

$$\Pr[P_r(d) > \gamma] = Q\!\left(\frac{\gamma - \overline{P_r}(d)}{\sigma}\right),\qquad Q(x) = \frac{1}{\sqrt{2\pi}}\int_x^\infty e^{-t^2/2}\,dt$$

$Q$ 函數的性質：$Q(0) = 0.5$，$Q(-x) = 1 - Q(x)$，並可用互補誤差函數表示為 $Q(x) = \tfrac12\,\mathrm{erfc}(x/\sqrt2)$。常用值：

| $x$ | 0 | 0.5 | 1 | 1.2816 | 1.645 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| $Q(x)$ | 0.5000 | 0.3085 | 0.1587 | 0.1000 | 0.0500 | 0.02275 | 0.00135 |

反過來，若要求細胞邊緣的涵蓋機率為 $p$，平均接收功率必須比門檻高出一個餘量 $M$：

$$M = \sigma\,Q^{-1}(1-p)$$

例如 $p = 90\%$ 時 $Q^{-1}(0.1) = 1.2816$，$M = 1.28\sigma$；$p = 95\%$ 時 $M = 1.645\sigma$。這裡算的是「細胞邊緣那一圈」的涵蓋機率；整個細胞面積的涵蓋機率會比邊緣高，因為靠近基地臺的位置訊號更強。

#### 算例

**算例 1：平均路徑損耗與邊緣涵蓋機率**

已知（皆為假設值）：頻率 3500 MHz；參考距離 $d_0 = 100$ m，該處損耗用自由空間公式；路徑損耗指數 $n = 3.5$；$\sigma = 8$ dB；基地臺 EIRP 為 40 dBm，接收天線增益 0 dBi；接收門檻 $\gamma = -100$ dBm。求 $d = 3$ km 處的平均路徑損耗，以及該處接收功率超過門檻的機率。

- 參考損耗：$\overline{PL}(d_0) = 32.44 + 20\log_{10}0.1 + 20\log_{10}3500 = 32.44 - 20 + 70.88 = 83.32$ dB。
- 距離項：$10\times3.5\times\log_{10}(3000/100) = 35\times1.4771 = 51.70$ dB。
- 平均路徑損耗：$83.32 + 51.70 = 135.02$ dB。
- 平均接收功率：$40 + 0 - 135.02 = -95.02$ dBm。
- 標準化：$(\gamma - \overline{P_r})/\sigma = (-100 + 95.02)/8 = -0.6225$。
- 涵蓋機率：$Q(-0.6225) = 1 - Q(0.6225) = 1 - 0.267 = 0.733$，約 73%。
- 合理性檢查：平均值比門檻高 4.98 dB，所以機率應大於 50%；但只高出 0.62 個標準差，離 90% 還很遠，73% 合理。對照自由空間，3 km 的 FSPL 只有 $83.32 + 20\log_{10}30 = 112.86$ dB，$n = 3.5$ 的模型多了 22.16 dB。

**算例 2：衰落餘量與涵蓋半徑**

沿用上題參數，若要求邊緣涵蓋機率 90%，求所需餘量與對應的最大距離。

- 餘量：$M = 1.2816\times8 = 10.25$ dB。
- 邊緣的平均接收功率要達到 $-100 + 10.25 = -89.75$ dBm，最大容許平均路徑損耗為 $40 - (-89.75) = 129.75$ dB。
- 解距離：$10\times3.5\times\log_{10}(d/100) = 129.75 - 83.32 = 46.43$，$\log_{10}(d/100) = 1.3266$，$d = 100\times10^{1.3266} = 2121$ m，約 2.1 km。
- 若要求 95%：$M = 1.645\times8 = 13.16$ dB，最大損耗 126.84 dB，$d = 100\times10^{43.52/35} = 1752$ m，約 1.75 km。
- 合理性檢查：2.1 km 小於算例 1 的 3 km（那裡只有 73%），可靠度要求越高，半徑越小，方向正確。

#### 常見錯誤

- **距離項寫成 $20\log_{10}$**：對數距離模型是 $10n\log_{10}(d/d_0)$，只有 $n = 2$ 時才等於 $20\log_{10}$。
- **$d$ 與 $d_0$ 單位不一致**：比值 $d/d_0$ 要用同一個單位。
- **$Q$ 函數的正負號弄反**：平均值高於門檻時，$Q$ 的引數是負的，機率大於 0.5；算出小於 0.5 就是減反了。
- **把 $\sigma$ 當線性量**：陰影衰落是在 dB 域呈常態分布，$\sigma$ 的單位是 dB，餘量直接用 dB 相加。

#### 和其他小節的關係

參考距離上的損耗來自 3.1.2；本節處理的是大尺度的平均損耗與陰影，小尺度的多路徑衰落在 3.1.4。本節算出的衰落餘量是 3.3.3 各項損耗與餘量的一項，3.3.5 用最大容許路徑損耗反推涵蓋半徑時就是算例 2 的做法。$Q$ 函數會在 3.2.3 的錯誤率公式再次出現，常態分布的基礎在 3.5.2。
