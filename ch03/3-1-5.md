# 3.1.5 雜訊、雜訊指數、雜訊溫度與串接（Friis 公式）

所屬：[3.1 訊號與通道](3-1.md)

## 內文

#### 為什麼要學

接收機能收到多弱的訊號，不是由訊號本身決定，而是由雜訊決定。任何有溫度的導體都會產生熱雜訊（thermal noise），頻寬越寬收進來的雜訊越多；接收機裡的放大器、混頻器、饋線又會再加進自己的雜訊。把這些量化的工具就是 $kTB$、雜訊指數（noise figure, NF）、等效雜訊溫度（equivalent noise temperature）和多級串接的 Friis 公式。基地臺與手機的接收靈敏度、塔頂放大器要不要裝、低雜訊放大器該放在饋線前面還是後面、衛星地面站的 G/T，都靠這一節的計算。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $k$ | 波茲曼常數，$1.380649\times10^{-23}$ | J/K |
| $T$ | 絕對溫度 | K |
| $T_0$ | 標準參考溫度，290 | K |
| $B$ | 雜訊頻寬 | Hz |
| $N$ | 雜訊功率 | W（或 dBm） |
| $N_0$ | 雜訊功率頻譜密度，$N_0 = kT$ | W/Hz（或 dBm/Hz） |
| $F$ | 雜訊因子（noise factor，線性值） | 無因次 |
| $\text{NF}$ | 雜訊指數，$\text{NF} = 10\log_{10}F$ | dB |
| $T_e$ | 等效輸入雜訊溫度 | K |
| $G_i$、$F_i$ | 第 $i$ 級的功率增益、雜訊因子（都是線性值） | 無因次 |
| $L$ | 被動元件的損耗（線性值，$L \ge 1$） | 無因次 |

#### 公式與推導

**熱雜訊功率。** 溫度 $T$ 的電阻在匹配條件下可以送出的雜訊功率為

$$N = kTB$$

和電阻值無關，在一般無線頻率範圍內頻譜是平的（白雜訊）。每赫茲的雜訊密度 $N_0 = kT$，在 $T_0 = 290$ K 時

$$N_0 = 1.380649\times10^{-23}\times290 = 4.004\times10^{-21}\ \text{W/Hz}$$

換成 dB：$10\log_{10}(4.004\times10^{-21}) = -203.98$ dBW/Hz，加 30 得 $-173.98$ dBm/Hz，工程上記成 **−174 dBm/Hz**。於是 290 K 下頻寬 $B$ 的熱雜訊底是

$$N(\text{dBm}) = -174 + 10\log_{10}B_{\text{Hz}}$$

**雜訊因子與雜訊指數。** 雜訊因子定義為輸入端 SNR 與輸出端 SNR 的比值，而且規定輸入端的雜訊是 290 K 的熱雜訊：

$$F = \frac{\text{SNR}_{\text{in}}}{\text{SNR}_{\text{out}}}\ \Big|_{T_{\text{in}} = T_0},\qquad \text{NF} = 10\log_{10}F$$

元件會加入雜訊，所以 $F \ge 1$、$\text{NF} \ge 0$ dB。接收機本身的雜訊折算回輸入端後，雜訊底變成

$$N(\text{dBm}) = -174 + 10\log_{10}B_{\text{Hz}} + \text{NF}$$

**等效雜訊溫度。** 把元件內部產生的雜訊想成「輸入端多接了一個溫度 $T_e$ 的雜訊源」，則輸出雜訊是 $Gk(T_0 + T_e)B$，和無雜訊元件的 $GkT_0B$ 相比就是 $F$：

$$F = 1 + \frac{T_e}{T_0}\qquad\Longleftrightarrow\qquad T_e = T_0\,(F - 1)$$

雜訊很低的元件（例如衛星用的低雜訊放大器）用 $T_e$ 表示比較有鑑別度。

**串接（Friis 雜訊公式）。** 多級串接時，後面各級的雜訊折算回輸入端要除以它前面所有級的增益：

$$F_{\text{total}} = F_1 + \frac{F_2 - 1}{G_1} + \frac{F_3 - 1}{G_1G_2} + \cdots,\qquad T_{e,\text{total}} = T_{e1} + \frac{T_{e2}}{G_1} + \frac{T_{e3}}{G_1G_2} + \cdots$$

公式裡的 $F$ 和 $G$ **全部是線性值**。第一級的雜訊因子原封不動進入總值，而且第一級增益越大，後級的影響越小，所以低雜訊放大器要盡量靠近天線。對於實體溫度為 $T_0$ 的被動損耗元件（饋線、衰減器、濾波器），增益是 $1/L$、雜訊因子就是 $L$，也就是「損耗幾 dB，雜訊指數就是幾 dB」；元件溫度不是 290 K 時這個簡化不成立。

#### 算例

**算例 1：熱雜訊底**

已知：溫度 290 K，接收頻寬 20 MHz。求熱雜訊功率（dBm）。

- $10\log_{10}(20\times10^6) = 73.01$ dB。
- $N = -174 + 73.01 = -100.99$ dBm。
- 檢查：直接算 $kTB = 4.004\times10^{-21}\times2\times10^7 = 8.008\times10^{-14}$ W $= 8.008\times10^{-11}$ mW，換成 dBm 是 $-100.96$ dBm；和用 −174 的結果差 0.03 dB，來自把 −173.98 進位成 −174。

**算例 2：三級串接與順序的影響**

已知（假設值）：低雜訊放大器（LNA）增益 15 dB、雜訊指數 1.5 dB；饋線損耗 3 dB（溫度 290 K）；接收機雜訊指數 8 dB。分別求「LNA 在饋線前」與「饋線在 LNA 前」的總雜訊指數。

- 換線性：$F_{\text{LNA}} = 10^{0.15} = 1.4125$，$G_{\text{LNA}} = 10^{1.5} = 31.62$；饋線 $F = L = 10^{0.3} = 1.9953$，$G = 1/L = 0.5012$；接收機 $F = 10^{0.8} = 6.3096$。
- **LNA 在前**（天線 → LNA → 饋線 → 接收機）：
  $F = 1.4125 + \dfrac{1.9953 - 1}{31.62} + \dfrac{6.3096 - 1}{31.62\times0.5012} = 1.4125 + 0.0315 + 0.3350 = 1.7790$，
  $\text{NF} = 10\log_{10}1.7790 = 2.50$ dB，$T_e = 290\times(1.7790 - 1) = 225.9$ K。
- **饋線在前**（天線 → 饋線 → LNA → 接收機）：
  $F = 1.9953 + \dfrac{1.4125 - 1}{0.5012} + \dfrac{6.3096 - 1}{0.5012\times31.62} = 1.9953 + 0.8231 + 0.3350 = 3.1534$，
  $\text{NF} = 10\log_{10}3.1534 = 4.99$ dB。
- 判讀與檢查：兩種接法用的是同樣三個元件，總雜訊指數卻差 $4.99 - 2.50 = 2.49$ dB，等於接收靈敏度差 2.49 dB。饋線在前時，饋線的 3 dB 損耗直接加在 LNA 的 1.5 dB 之上（合計 4.5 dB），再加上後級的貢獻，接近 5 dB，合理；LNA 在前時總值只比 LNA 自己的 1.5 dB 多 1 dB。這就是塔頂放大器的道理。以 20 MHz 頻寬來說，LNA 在前時的雜訊底是 $-174 + 73.01 + 2.50 = -98.49$ dBm。

#### 常見錯誤

- **把 dB 值直接代入 Friis 公式**：$F$、$G$ 都要先換成線性值，算完再取 $10\log_{10}$。
- **各級雜訊指數直接相加**：只有「被動損耗緊接在某一級前面」時，dB 值相加才剛好成立；一般情況要用公式。
- **頻寬單位錯**：$10\log_{10}B$ 的 $B$ 要用 Hz；20 MHz 是 73.01 dB，不是 13.01 dB。
- **忘了 −174 dBm/Hz 的前提是 290 K**：溫度不同時要重算 $kT$；另外 dBm/Hz 和 dBW/Hz 差 30 dB，別混用。

#### 和其他小節的關係

本節的雜訊底是 3.1.6 計算 SNR 與 SINR 的分母，也是 3.3.4 接收靈敏度公式（$-174 + 10\log_{10}B + \text{NF} + \text{SNR}_{\text{req}}$）的前三項；$N_0$ 會用在 3.1.6 的 $E_b/N_0$ 與 3.2.1 的 Shannon 容量；白雜訊的功率頻譜密度概念在 3.1.7 說明；dB 與線性的換算規則來自 3.1.1；饋線損耗的電學基礎見 3.5.1。

**3.1.5G020**　Two amplifiers are available: amplifier A (gain 12 dB, noise figure 1.0 dB) and amplifier B (gain 20 dB, noise figure 3.0 dB), both referenced to 290 K. Compute the cascade noise figure for the order A→B and for the order B→A, and give the amount by which the A→B order is better, in dB, rounded to two decimal places.

**詳解**　$F_A = 10^{0.1} = 1.258925$, $G_A = 10^{1.2} = 15.84893$, $F_B = 10^{0.3} = 1.995262$, $G_B = 100$.

**3.1.5S008**　The engineer reduces the RBW from 10 kHz to 1 kHz. How do the displayed noise level and the displayed level of an unmodulated (CW) interferer change, and what does that do to the visibility of the interferer?

**3.1.5S009**　The preamplifier adds noise of its own, yet the measurement becomes more sensitive. Explain why, and state the best noise figure this arrangement could ever reach if the preamplifier gain were increased without limit.

<details><summary>看答案</summary>

**答案**　0.878 dB

**3.1.5S018**　Suppose a manufacturer quoted noise figures against a reference temperature of 300 K instead of 290 K. For the same physical amplifiers, which of the two quantities, $T_e$ or noise figure, would change, and in which direction?

<details><summary>看答案</summary>

**答案**　$T_e$ would not change: it describes the noise the device adds, independent of any reference. The noise figure would change, because $F = 1 + T_e/T_{ref}$ compares that added noise with the noise of a source at the reference temperature. With a hotter reference the added noise looks relatively smaller, so the quoted noise figure would be lower (LNA Y: 0.852 dB instead of 0.878 dB). This is why the reference $T_0$ = 290 K is standardized.

**詳解**　$10\log_{10}(1 + 65/300) = 0.8517$ dB versus $10\log_{10}(1 + 65/290) = 0.8783$ dB.

**出處**　H. T. Friis, "Noise Figures of Radio Receivers," Proceedings of the IRE, 1944 (definition of noise figure with a 290 K source).

</details>

**3.1.5S019**　A sales brochure for a third amplifier claims "noise figure −0.2 dB". Can a linear two-port have a negative noise figure in dB? What does the limiting case correspond to in terms of $T_e$?

<details><summary>看答案</summary>

**答案**　No. The noise factor is $F = 1 + T_e/T_0$ and the added noise temperature $T_e$ cannot be negative, so $F \ge 1$ and the noise figure is at least 0 dB. $F = 1$ (0 dB) is the ideal noiseless device with $T_e$ = 0 K. A negative figure would mean the device removes source noise without removing signal, i.e. output SNR better than input SNR, which a linear two-port cannot do.

**詳解**　$F = \mathrm{SNR}_{in}/\mathrm{SNR}_{out} \ge 1$ for a source at $T_0$; $NF = 10\log_{10}F \ge 0$ dB.

**出處**　D. M. Pozar, Microwave Engineering (chapter on noise and nonlinear distortion), definition of noise figure.

</details>

**3.1.5S022**　The amplifier is swapped for one with 32 dB gain and the same 3.5 dB noise figure. Does the signal-to-noise ratio at the amplifier output change? Is there any noise benefit at all from the extra gain?

<details><summary>看答案</summary>

**答案**　The output SNR of this single stage does not change: signal and noise (source noise plus the amplifier's input-referred added noise) are both multiplied by the same gain, so SNR_out = SNR_in − 3.5 dB regardless of gain. The benefit appears only when further stages follow: by the Friis formula their noise contributions are divided by the first-stage gain, so 10 dB more gain makes them ten times smaller.

**詳解**　$\mathrm{SNR}_{out} = G S_{in}/(G k T_0 B F) = S_{in}/(kT_0BF)$, independent of $G$.

A base-station receiver has a switchable attenuator directly at its antenna port, used to protect the front end when a nearby transmitter is very strong. **3.1.5S033**　Suppose the same 10 dB attenuator were placed between the LNA and the back end instead of in front of the LNA. Would the noise figure penalty be larger or smaller than 10 dB, and why?

**答案**　Much smaller. After the LNA, the attenuator's own noise and the back-end noise are both divided by the 20 dB LNA gain. **3.1.5S034**　With the 10 dB attenuator switched in (antenna treated as a 290 K source), a technician measures the thermal noise power arriving at the LNA input and finds it unchanged compared with the bypassed state. Yet the SNR has dropped by 10 dB. Explain both observations.

<details><summary>看答案</summary>

**答案**　A matched attenuator at 290 K fed by a 290 K source is in thermal equilibrium: it attenuates the source noise by 10 dB but adds exactly enough noise of its own that its output is again $kT_0B$. Signal down 10 dB with noise unchanged means SNR down 10 dB, which is exactly what the 10 dB increase of input-referred noise figure expresses.

**詳解**　$T_{out} = T_0/L + T_0(1-1/L) = T_0$; $S_{out} = S_{in}/L$.

**Scenario | Same receiver in orbit and on the ground**

The same receiver design, with a noise figure of 2.0 dB referenced to 290 K, is used at both ends of a satellite link. On the satellite, the receive antenna looks at the warm Earth and its noise temperature is taken as 290 K. <details><summary>看答案</summary>

**答案**　3.73 dB

**詳解**　$F = 10^{0.2} = 1.584893$; $T_e = 290\times0.584893 = 169.6190$ K.

**3.1.5S052**　For which of the two installations is the statement "the receiver degrades the SNR by exactly its noise figure, 2.0 dB" true, and why not for the other?

<details><summary>看答案</summary>

**答案**　It is true on the satellite, because there the source (antenna) noise temperature is 290 K, the reference condition under which noise figure is defined: degradation $= 1 + T_e/T_a = 1 + 169.6/290 = F$. At the ground station the source is at 25 K, so the same added noise is compared with much less source noise: degradation $= 1 + 169.6/25 = 7.78$, i.e. 8.91 dB.

**詳解**　$10\log_{10}(1 + 169.619/25) = 10\log_{10}(7.78476) = 8.91$ dB.

**Scenario | Rain over a Ku-band receive-only terminal**

A Ku-band receive-only terminal has an antenna gain of 37 dBi and an LNB with an equivalent noise temperature of 60 K; feed loss is neglected. In clear sky the antenna noise temperature is 40 K. During a storm the rain attenuation on the path is 3 dB, and the rain is modelled as an absorbing medium with an effective temperature of 275 K, so that the antenna noise temperature becomes $T_{a,rain} = T_{a,clear}/A + T_m(1 - 1/A)$, where $A$ is the rain attenuation as a linear ratio and $T_m$ = 275 K.

**3.1.5S056**　Find the antenna noise temperature during the storm, in kelvin, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　157.22 K

**詳解**　$A = 10^{0.3} = 1.995262$, $1/A = 0.501187$.
Attenuated clear-sky part: $40\times0.501187 = 20.0475$ K.
Emission of the rain: $275\times(1 - 0.501187) = 275\times0.498813 = 137.1735$ K.
$T_{a,rain} = 20.0475 + 137.1735 = 157.2210$ K, which rounds to 157.22 K.

**出處**　Recommendation ITU-R P.618 (propagation data for Earth-space systems), increase of sky noise temperature due to attenuation; G. Maral and M. Bousquet, Satellite Communications Systems.

</details>

**3.1.5S057**　By how many dB does the terminal's G/T fall during the storm compared with clear sky? Round to two decimal places.

<details><summary>看答案</summary>

**答案**　3.37 dB

**詳解**　Storm antenna temperature: $40/1.995262 + 275\times(1 - 1/1.995262) = 20.0475 + 137.1735 = 157.2210$ K.
Clear sky: $T_{sys} = 40 + 60 = 100$ K. Storm: $T_{sys} = 157.221 + 60 = 217.221$ K.
The antenna gain is unchanged, so the G/T change is $10\log_{10}(217.221/100) = 3.3690$ dB, which rounds to 3.37 dB.

**出處**　G. Maral and M. Bousquet, Satellite Communications Systems (figure of merit G/T; system noise temperature).

</details>

**3.1.5S058**　The rain attenuation is 3 dB. Is the drop in downlink $C/N_0$ during the storm equal to 3 dB? Explain using the results above.

<details><summary>看答案</summary>

**答案**　No, it is larger: about 6.37 dB. Rain hurts twice. It attenuates the carrier by 3 dB, and because an absorbing medium also emits thermal noise, it raises the antenna temperature and hence the system temperature, which lowers G/T by a further 3.37 dB. The two effects add in dB. This double penalty is strongest for low-noise terminals, where the clear-sky system temperature is small.

**詳解**　$\Delta(C/N_0) = 3 + 3.3690 = 6.369$ dB.

**出處**　Recommendation ITU-R P.618 (propagation data for Earth-space systems); G. Maral and M. Bousquet, Satellite Communications Systems.

</details>

**3.1.5S059**　As the rain becomes heavier and heavier, what value does the antenna noise temperature approach in this model, and does the G/T degradation keep growing without limit like the attenuation does?

<details><summary>看答案</summary>

**答案**　As $A$ grows, $1/A \to 0$ and the antenna temperature tends to the medium temperature $T_m$ = 275 K: the antenna then sees only the rain, which behaves like a matched load at 275 K. The system temperature therefore saturates at $275 + 60 = 335$ K, and the G/T degradation saturates at $10\log_{10}(335/100) = 5.25$ dB. The carrier attenuation, by contrast, keeps increasing without limit, so in very heavy rain the attenuation dominates the loss of $C/N_0$.

**詳解**　$\lim_{A\to\infty} T_{a,rain} = T_m$; $10\log_{10}(3.35) = 5.2504$ dB.

**出處**　Recommendation ITU-R P.618 (propagation data for Earth-space systems), sky noise temperature model.

</details>

<details><summary>看答案</summary>
