# 3.2.6 MIMO 容量

所屬：[3.2 容量](3-2.md)

## 內文

#### 為什麼要學

多輸入多輸出（multiple-input multiple-output, MIMO）是 4G、5G 在不加頻寬、不加總功率的前提下把速率往上推的主要手段。基地台與終端各裝多支天線後，通道從一個數字變成一個矩陣，同一個時頻資源上可以同時送好幾路獨立的資料，稱為空間多工（spatial multiplexing）；3GPP 把這些並行的資料路數稱為層（layer）。3.2.5 峰值速率公式裡的 $v_{Layers}$ 就是這個量。同樣的多天線也可以不拿來加速，而是用來對抗衰落，稱為分集（diversity）。會算 MIMO 容量，才能判斷某個通道能撐幾層、加天線到底是讓速率倍增還是只讓鏈路變穩，也才看得懂終端回報的秩指示（rank indicator）為什麼在室內高、在空曠的直視環境反而低。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $N_t$、$N_r$ | 發射天線數、接收天線數 | 個 |
| $\mathbf{H}$ | $N_r\times N_t$ 通道矩陣，$h_{ij}$ 是第 $j$ 支發射天線到第 $i$ 支接收天線的複數增益 | 無單位 |
| $\mathbf{H}^H$ | $\mathbf{H}$ 的共軛轉置 | 無單位 |
| $\rho$ | 每支接收天線的平均 SNR（總發射功率除以雜訊功率，通道增益正規化後；線性值） | 無單位 |
| $\sigma_i$ | $\mathbf{H}$ 的第 $i$ 個奇異值 | 無單位 |
| $\lambda_i$ | $\mathbf{H}\mathbf{H}^H$ 的第 $i$ 個特徵值，$\lambda_i=\sigma_i^2$ | 無單位 |
| $r$ | $\mathbf{H}$ 的秩，$r\le\min(N_t,N_r)$ | 無單位 |
| $C$ | 容量（這裡以每 Hz 表示） | bit/s/Hz |
| $d$ | 分集階數（diversity order） | 無單位 |
| $\bar\gamma$、$\gamma_{th}$ | 每個分支的平均 SNR、中斷門檻 SNR（線性值） | 無單位 |

#### 公式與推導

**訊號模型。** 窄頻、平坦衰落下，$\mathbf{y} = \mathbf{H}\mathbf{x} + \mathbf{n}$，其中 $\mathbf{x}$ 是 $N_t$ 維的發射向量，$\mathbf{n}$ 是各分量獨立、功率相同的高斯雜訊。OFDM 系統中每個子載波各自符合這個模型。

**容量公式（接收端已知通道、發射端未知通道）。** 假設接收端完全知道 $\mathbf{H}$，發射端不知道，因此把總功率平均分給 $N_t$ 支天線、各天線送互相獨立的高斯訊號。對一個固定的 $\mathbf{H}$，

$$C = \log_2\det\!\left(\mathbf{I}_{N_r}+\frac{\rho}{N_t}\mathbf{H}\mathbf{H}^H\right)\quad[\text{bit/s/Hz}]$$

把 $\mathbf{H}$ 做奇異值分解，行列式可拆成各特徵值的乘積：

$$C = \sum_{i=1}^{r}\log_2\!\left(1+\frac{\rho}{N_t}\lambda_i\right),\qquad \lambda_i=\sigma_i^2$$

這表示 MIMO 通道等效於 $r$ 條互不干擾的並行子通道，每條的增益是 $\lambda_i$。能用的層數上限是秩 $r$，而秩最多是 $\min(N_t,N_r)$。

**層數與容量的關係。** 高 SNR 時每一項近似 $\log_2\rho$ 加常數，所以 $C\approx r\log_2\rho+\text{常數}$：SNR 每加 3 dB，容量多 $r$ bit/s/Hz，而單天線只多 1。$r$ 稱為多工增益。但這有兩個條件。第一，通道要夠「豐富」：若各 $h_{ij}$ 是獨立同分布的 Rayleigh 衰落（多散射、天線間距夠大），$\mathbf{H}$ 幾乎必然滿秩，平均（遍歷）容量約隨 $\min(N_t,N_r)$ 線性成長；若是強直視或天線高度相關，$\mathbf{H}$ 接近秩 1，只剩一條可用的子通道。第二，SNR 要夠高：低 SNR 時較弱的特徵值幾乎沒有貢獻，多送幾層並不划算。

**發射端也知道通道時**，可以沿著 $\mathbf{H}$ 的右奇異向量預編碼，並用注水法（見 3.5.5）把功率多分給強的子通道，容量不低於等功率分配；兩者在高 SNR 且滿秩時差距很小，在低 SNR 或秩不足時差距明顯。NR 的碼簿預編碼與通道狀態回報就是為了逼近這種情形。

**分集增益。** 分集是讓同一份資料經過多條獨立衰落的路徑，只有全部同時衰落才會出錯。在 Rayleigh 衰落下，高 SNR 的錯誤率或中斷機率大致隨 $\text{SNR}^{-d}$ 下降，$d$ 就是分集階數；$N_t\times N_r$ 的獨立同分布通道最多可得 $d=N_tN_r$。以最簡單的選擇合併（selection combining）為例，$L$ 個獨立同分布的 Rayleigh 分支取 SNR 最大的一個，SNR 低於門檻的中斷機率為

$$P_{out} = \left(1-e^{-\gamma_{th}/\bar\gamma}\right)^{L}\approx\left(\frac{\gamma_{th}}{\bar\gamma}\right)^{L}\quad(\bar\gamma\gg\gamma_{th})$$

除了分集增益，多支接收天線做最大比合併還有陣列增益（array gain）：合併後的平均 SNR 是各分支的總和，$N_r$ 支天線約多 $10\log_{10}N_r$ dB。陣列增益把曲線往左平移，分集增益則改變曲線的斜率，兩者不同。同一組天線不能同時拿到最大的多工增益與最大的分集增益，兩者之間有取捨：層數開得越多，留給分集的自由度越少。

#### 算例

**算例 1（2×2 固定通道的容量）** 已知 $\mathbf{H} = \begin{bmatrix}1 & 0.5\\ 0.5 & 1\end{bmatrix}$，$\rho = 20$ dB，接收端已知通道、發射端未知、等功率分配。求容量，並與單天線、以及秩 1 的通道比較。

1. $\rho = 100$，$\rho/N_t = 50$。
2. $\mathbf{H}\mathbf{H}^H = \begin{bmatrix}1.25 & 1\\ 1 & 1.25\end{bmatrix}$，特徵值 $\lambda_1 = 1.25+1 = 2.25$、$\lambda_2 = 1.25-1 = 0.25$（奇異值 1.5 與 0.5）。
3. $C = \log_2(1+50\times2.25)+\log_2(1+50\times0.25) = \log_2(113.5)+\log_2(13.5) = 6.827+3.755 = 10.58$ bit/s/Hz（取到小數第 2 位）。
4. 用行列式驗算：$\det\begin{bmatrix}63.5 & 50\\ 50 & 63.5\end{bmatrix} = 4032.25-2500 = 1532.25$，$\log_2(1532.25) = 10.58$，一致。
5. 比較：同樣 $\rho$ 的單天線通道（增益 1）為 $\log_2(101) = 6.66$ bit/s/Hz；理想的 $\mathbf{H}=\mathbf{I}$ 為 $2\log_2(51) = 11.34$ bit/s/Hz；若 $\mathbf{H} = \begin{bmatrix}1&1\\1&1\end{bmatrix}$（秩 1，特徵值 4 與 0），$C = \log_2(1+50\times4) = \log_2(201) = 7.65$ bit/s/Hz。
6. 合理性檢查：兩條子通道一強一弱，第二層只貢獻 3.755 bit/s/Hz，所以總容量沒有到單天線的兩倍；秩 1 通道雖然元素比較大，卻只比單天線多 1 bit/s/Hz 左右，那是陣列增益，不是多工增益。

**算例 2（分集階數）** 假設各分支為獨立同分布的 Rayleigh 衰落，平均 SNR $\bar\gamma = 20$ dB，中斷門檻 $\gamma_{th} = 5$ dB，採選擇合併。求 1、2、4 個分支的中斷機率；平均 SNR 提高到 30 dB 時又是多少？

1. $\bar\gamma = 100$，$\gamma_{th} = 10^{0.5} = 3.162$，$\gamma_{th}/\bar\gamma = 0.03162$。
2. 單一分支：$1-e^{-0.03162} = 0.03113$。
3. 兩個分支：$0.03113^2 = 9.69\times10^{-4}$；四個分支：$0.03113^4 = 9.39\times10^{-7}$。
4. $\bar\gamma = 1000$ 時：單一分支 $1-e^{-0.003162} = 3.157\times10^{-3}$；兩個分支 $9.97\times10^{-6}$。
5. 合理性檢查：SNR 加 10 dB，單一分支的中斷機率約降為 1/10（斜率 1），兩個分支約降為 1/100（斜率 2），正好對應分集階數 1 與 2。

#### 常見錯誤

- 以為 $N_t\times N_r$ 的天線一定能送 $\min(N_t,N_r)$ 層。層數受通道秩與各特徵值大小限制，直視或高相關的通道可能只能送 1 層。
- 忘了把功率除以 $N_t$。公式裡是 $\rho/N_t$，總發射功率固定；漏掉會高估容量。
- 把陣列增益、分集增益、多工增益混為一談。陣列增益提高平均 SNR，分集增益改變錯誤率曲線的斜率，多工增益增加並行的資料路數。
- 把 dB 值代入行列式或 $\log_2(1+\cdot)$，或把奇異值 $\sigma_i$ 直接當成 $\lambda_i$ 而沒有平方。
- 把固定通道的容量和衰落通道的平均容量混用；後者要對 $\mathbf{H}$ 的分布取期望值。
