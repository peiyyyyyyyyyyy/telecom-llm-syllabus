# 3.6.1 讀題：找出已知、未知與隱含假設，再選公式

所屬：[3.6 解題方法](3-6.md)

## 內文

#### 為什麼要學

電信的計算題很少只考一條公式。實務上遇到的問題是用文字描述的：「某基地台發射 40 W，兩公里外的手機收到多少功率？」這句話沒有說傳播環境、沒有說溫度、沒有說極化是否匹配，但要算出數字，這些條件都必須先定下來。網路規劃、鏈路預算（link budget）審查、KPI 判讀時，算錯的原因多半不是公式背錯，而是把題目的量認錯、漏掉單位，或是用了題目條件不支持的公式。讀題就是在動筆計算之前，把題目文字整理成一張「已知、未知、假設、公式」的清單，後面每一步才有依據。

#### 定義與符號

| 項目 | 意思 | 例子 |
|---|---|---|
| 已知量（given） | 題目直接給的數值，要連同單位與「是線性值還是 dB 值」一起記下 | 發射功率 40 W（線性）、天線增益 17 dBi（dB） |
| 未知量（unknown） | 題目要求的量，要記下要求的單位與取位方式 | 接收功率，單位 dBm，四捨五入至小數第 2 位 |
| 隱含假設（implicit assumption） | 題目沒寫、但計算一定要用到的條件；採用常見的預設值，並在答案中寫明這是假設 | 沒說傳播環境時採自由空間；沒說溫度時採 290 K |
| 多餘資訊（distractor） | 題目給了、但這一問用不到的數值 | 只問路徑損耗時，接收機雜訊指數用不到 |
| 適用條件 | 公式成立的前提，要和題目條件對得上 | Shannon 容量公式假設加成性白高斯雜訊通道 |
| 參考點 | 功率或增益是在哪一點量的 | 發射功率是在功率放大器輸出端，還是在天線埠 |

#### 公式與推導

讀題沒有公式，但有固定的步驟。建議每一題都照下面四步做，並把結果寫在算式之前。

**第一步：圈出已知量與單位。** 逐句讀題，每遇到一個數字就記下三件事：數值、單位、是線性值還是對數值。例如「40 W」是線性功率，「17 dBi」是相對於等向性天線的對數增益，「2 dB 饋線損耗」是對數比值。同一類的量如果單位不同（例如一個功率用 W、另一個用 dBm），先標出來，留到 3.6.3 的單位換算處理。

**第二步：找出要求的量。** 看清楚問的是哪一個量、在哪一個參考點、要什麼單位。「接收功率」和「接收訊號雜訊比」差一個雜訊功率；「路徑損耗」和「最大容許路徑損耗」差一整套鏈路預算。題目若指定取位，也在這一步記下。

**第三步：補上隱含假設。** 從未知量往回推：要算出它需要哪些量？把需要的量和第一步的已知量對照，缺的就是要補的假設。常見的預設如下，採用時一律寫明「題目未指定，假設……」：

- 沒說傳播環境：採自由空間（free space），用 3.1.2 的自由空間路徑損耗公式。
- 沒說溫度：採參考溫度 $T_0 = 290$ K，熱雜訊密度 $10\log_{10}(kT_0/1\,\text{mW}) = -173.98$ dBm/Hz，一般取 $-174$ dBm/Hz（3.1.5）。
- 沒說干擾：只考慮熱雜訊，SINR 等於 SNR（3.1.6）。
- 沒說接收天線增益或其他損耗：增益取 0 dBi，其他損耗取 0 dB。
- 沒說光速取值：取 $c = 3\times10^8$ m/s（精確值為 299,792,458 m/s）。

預設值不是事實，只是讓題目可以算下去的約定。如果題目的情境明顯和預設衝突（例如室內穿牆、市區非視線），就不能套自由空間，要改用 3.1.3 的傳播模型，或說明條件不足。

**第四步：選公式。** 以「未知量」和「已知量加假設」為兩端，找能把兩端接起來的公式，並逐一檢查適用條件：變數是線性值還是 dB 值、常數配哪一組單位、公式有沒有前提（穩態、$\rho<1$、獨立同分布等）。需要多條公式時，先排好順序再計算（見 3.6.2）。判斷準則是：每一個已知量不是被用到，就是被判定為多餘資訊；每一個公式輸入不是來自已知量，就是來自寫明的假設。兩者都對得上，讀題才算完成。

#### 算例

**算例 1（鏈路預算）** 題目：「某 3.5 GHz 基地台的發射功率為 40 W，天線增益 17 dBi，饋線損耗 2 dB。距離 2 km 處的手機，接收功率是多少 dBm？取至小數第 2 位。」

已知：$P_t = 40$ W（線性）、$G_t = 17$ dBi、$L_f = 2$ dB、$f = 3.5$ GHz、$d = 2$ km。未知：$P_r$（dBm）。

隱含假設（題目未指定）：傳播環境採自由空間；手機天線增益 $G_r = 0$ dBi；沒有穿透、人體等其他損耗。

選公式：先用 3.1.1 把 W 換成 dBm，再用 3.3.1 求 EIRP，用 3.1.2 求自由空間路徑損耗（距離 km、頻率 GHz，常數 92.45），最後相減。

$$P_t = 10\log_{10}(40\times10^3) = 46.02\ \text{dBm}$$

$$\text{EIRP} = 46.02 + 17 - 2 = 61.02\ \text{dBm}$$

$$\text{FSPL} = 92.45 + 20\log_{10}(3.5) + 20\log_{10}(2) = 92.45 + 10.88 + 6.02 = 109.35\ \text{dB}$$

$$P_r = 61.02 + 0 - 109.35 = -48.33\ \text{dBm}$$

合理性檢查：2 km 外收到約 $-48$ dBm，比一般手機的接收靈敏度高出數十 dB，符合「自由空間、無遮蔽」這個樂觀假設。答案要附註：此值建立在自由空間假設上，實際市區環境會低很多。

**算例 2（容量）** 題目：「接收機頻寬 10 MHz、雜訊指數 5 dB，收到的訊號功率為 $-90$ dBm。這條鏈路的容量上限是多少 Mbps？取 3 位有效數字。」

已知：$B = 10$ MHz、$\text{NF} = 5$ dB、$S = -90$ dBm。未知：容量 $C$。

隱含假設：題目沒給溫度，採 290 K，熱雜訊密度取 $-174$ dBm/Hz；沒提干擾，只計熱雜訊；「容量上限」指 3.2.1 的 Shannon 容量，通道視為加成性白高斯雜訊通道。

選公式：3.1.5 求雜訊功率，3.1.6 求 SNR，3.2.1 求容量。

$$N = -174 + 10\log_{10}(10^7) + 5 = -174 + 70 + 5 = -99\ \text{dBm}$$

$$\text{SNR} = -90 - (-99) = 9\ \text{dB} \Rightarrow 10^{0.9} = 7.943$$

$$C = 10^7 \times \log_2(1 + 7.943) = 10^7 \times 3.1608 = 3.16\times10^7\ \text{bit/s} = 31.6\ \text{Mbps}$$

合理性檢查：頻譜效率 3.16 bit/s/Hz，SNR 9 dB 時落在合理範圍；Shannon 公式要用線性 SNR，若誤把 9 直接代入會得到 $\log_2 10 = 3.32$，數字相近但做法是錯的，換一組數字就會差很多。

#### 常見錯誤

1. **沒寫假設就直接算。** 用了自由空間或 290 K 卻沒有說明，讀者無法判斷答案的適用範圍；題目若其實給了別的條件，也不容易發現自己漏看。
2. **把多餘資訊硬塞進公式。** 題目給的數字不一定每個都用得到，例如只問路徑損耗時把雜訊指數也減進去。
3. **看錯要求的量。** 問的是 SNR 卻只算到接收功率，或問的是 dBm 卻以 W 作答。
4. **預設值用在不該用的地方。** 題目寫了「室內」「市區」「非視線」仍套自由空間公式；題目給了雜訊溫度仍用 $-174$ dBm/Hz。

#### 和其他小節的關係

讀題整理出的已知量與假設，交給 3.6.2 排成多步計算；單位不一致的地方由 3.6.3 處理；題目要求的取位由 3.6.4 處理。常用的預設值分別來自 3.1.2（自由空間）、3.1.5（290 K 與 $-174$ dBm/Hz）與 3.1.6（只計熱雜訊）。
