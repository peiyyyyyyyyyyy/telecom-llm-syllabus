# 3.3.3 各項損耗與餘量

所屬：[3.3 鏈路預算](../3-3.md)

## 正文

In any wireless system the power that finally arrives at the receiver is the result of a delicate balance between **gains** (primarily the antenna gains) and **losses** (everything that reduces the signal level).  The collection of all these reductions is called *system loss* and the excess power that remains after the receiver’s minimum required level is called the **link margin**.  A realistic link budget must therefore enumerate every loss mechanism that can be expected in the deployment and then compare the received power with the receiver sensitivity.  The margin tells the designer whether the link will survive normal variations (temperature, aging, rain, interference) and still meet the required quality‑of‑service.

### Definitions and Units

| Symbol | Meaning | Unit |
|--------|---------|------|
| $P_{\text{TX}}$ | Transmitter output power (before feeder) | dBm |
| $L_{\text{f}}$ | Feeder (cable, waveguide) loss between transmitter and antenna | dB |
| $G_{\text{TX}}$ | Transmit antenna gain (relative to isotropic) | dBi |
| $L_{\text{c}}$ | Connector loss (each connector) | dB |
| $L_{\text{pol}}$ | Polarization mismatch loss (e.g., cross‑polarization) | dB |
| $L_{\text{atm}}$ | Atmospheric attenuation (gases, humidity) | dB |
| $L_{\text{rain}}$ | Rain‑fade loss (frequency‑dependent) | dB |
| $L_{\text{FS}}$ | Free‑space path loss (or any other propagation loss) | dB |
| $L_{\text{tot}}$ | Sum of all *additional* losses (connector, polarization, rain, etc.) | dB |
| $S_{\text{RX}}$ | Receiver sensitivity (minimum detectable power for a given BER) | dBm |
| $M$ | **Link margin** – excess received power over sensitivity | dB |
| $P_{\text{RX}}$ | Received power at the input of the receiver | dBm |
| $P_{\text{EIRP}}$ | Equivalent isotropically radiated power | dBm |

All quantities are expressed in **decibels** because they linearly add and subtract, which simplifies the bookkeeping.

### Core Formulas

1. **Effective Isotropic Radiated Power (EIRP)**  

   $$P_{\text{EIRP}} = P_{\text{TX}} - L_{\text{f}} + G_{\text{TX}} \quad\text{[dBm]}$$  

   The feeder loss is subtracted **before** the antenna gain is applied, because the loss occurs *before* the radiating element.

2. **Total Additional Losses**  

   $$L_{\text{tot}} = \sum_{i} L_{i} = L_{\text{c}} + L_{\text{pol}} + L_{\text{atm}} + L_{\text{rain}} + \dots$$  

3. **Received Power**  

   $$P_{\text{RX}} = P_{\text{EIRP}} - L_{\text{FS}} - L_{\text{tot}} \quad\text{[dBm]}$$  

4. **Link Margin**  

   $$M = P_{\text{RX}} - S_{\text{RX}} \quad\text{[dB]}$$  

   A *positive* margin means the link meets the design requirement; a *negative* margin indicates a shortfall that must be remedied (increase power, improve antenna, reduce losses, etc.).

### Worked Example

| Parameter | Value |
|-----------|-------|
| $P_{\text{TX}}$ | $30\ \text{dBm}$ |
| $L_{\text{f}}$ | $2\ \text{dB}$ |
| $G_{\text{TX}}$ | $15\ \text{dBi}$ |
| $L_{\text{c}}$ | $0.5\ \text{dB}$ |
| $L_{\text{pol}}$ | $3\ \text{dB}$ |
| $L_{\text{FS}}$ | $120\ \text{dB}$ |
| $S_{\text{RX}}$ | $-95\ \text{dBm}$ |

1. **EIRP**  

   $$P_{\text{EIRP}} = 30 - 2 + 15 = 43\ \text{dBm}$$

2. **Additional losses**  

   $$L_{\text{tot}} = 0.5 + 3 = 3.5\ \text{dB}$$

3. **Received power**  

   $$P_{\text{RX}} = 43 - 120 - 3.5 = -80.5\ \text{dBm}$$

4. **Link margin**  

   $$M = -80.5 - (-95) = 14.5\ \text{dB}$$

The link therefore enjoys a comfortable 14.5 dB margin, sufficient to absorb typical variations (e.g., temperature drift, moderate rain).

### Practical Notes & Common Pitfalls

| Pitfall | Why it hurts | Remedy |
|---------|--------------|--------|
| **Omitting feeder loss before antenna gain** | Leads to an *over‑optimistic* EIRP because the loss is mistakenly treated as a gain. | Always subtract $L_{\text{f}}$ *first*, then add $G_{\text{TX}}$. |
| **Double‑counting a loss** (e.g., counting connector loss both in $L_{\text{f}}$ and $L_{\text{tot}}$) | Inflates total loss, potentially causing an unnecessary redesign. | Keep a clear inventory: feeder loss = cable + waveguide; connector loss belongs to $L_{\text{tot}}$. |
| **Mixing linear and dB units** | Adding linear powers to dB quantities is mathematically invalid. | Convert all quantities to dB (or dBm) before summation; use $10\log_{10}(\cdot)$ or $20\log_{10}(\cdot)$ as appropriate. |
| **Neglecting polarization mismatch** | In many point‑to‑point microwave links the two antennas are not perfectly co‑polarized, incurring 3–6 dB loss. | Include $L_{\text{pol}}$ when the antenna orientations differ or when dual‑polarized equipment is used. |
| **Assuming free‑space loss for all environments** | Urban, suburban, and especially rainy tropical paths have excess loss beyond the free‑space value. | Add environment‑specific terms ($L_{\text{atm}}$, $L_{\text{rain}}$, clutter loss) based on measurements or standard models. |
| **Using receiver sensitivity that already includes implementation loss** | Sensitivity is defined at the *input* of the receiver; adding an extra implementation loss double‑counts. | Verify that $S_{\text{RX}}$ already accounts for the receiver’s noise figure and required SNR; do not subtract additional “receiver loss”. |

A well‑structured link budget is a living document: once the system is deployed, real‑world measurements often reveal additional loss contributors (e.g., unexpected building blockage). Maintaining a margin of **5–10 dB** for terrestrial microwave links and **10–20 dB** for satellite links is a common engineering rule of thumb, providing robustness against unforeseen degradations.

## 練習題

**1.** Which of the following is *not* typically treated as a loss in a terrestrial microwave link budget?

- A. Rain attenuation
- B. Antenna gain
- C. Waveguide connector loss
- D. Polarization mismatch

<details><summary>看答案</summary>

正解：B。Antenna gain adds power to the link; all other items subtract power and are therefore losses.

</details>

**2.** In link‑budget terminology, “link margin” is defined as:

- A. The difference between transmitter power and receiver sensitivity.
- B. The sum of all propagation losses.
- C. The excess received power over the minimum required (receiver sensitivity).
- D. The product of the transmit and receive antenna gains.

<details><summary>看答案</summary>

正解：C。Margin quantifies how much higher the actual received power is compared with the sensitivity threshold.

</details>

**3.** A system has an EIRP of 40 dBm, a total path loss of 120 dB, and a receiver sensitivity of –100 dBm. What is the link margin?

- A. –20 dB
- B. 0 dB
- C. 20 dB
- D. 40 dB

<details><summary>看答案</summary>

正解：C。Received power = 40 dBm – 120 dB = –80 dBm; margin = –80 – (–100) = 20 dB.

</details>

**4.** Given: $P_{\text{TX}}=20\ \text{dBm}$, feeder loss $L_{\text{f}}=1.5\ \text{dB}$, transmit antenna gain $G_{\text{TX}}=12\ \text{dBi}$, connector loss $L_{\text{c}}=0.3\ \text{dB}$, polarization loss $L_{\text{pol}}=2\ \text{dB}$, free‑space path loss $L_{\text{FS}}=115\ \text{dB}$, receiver sensitivity $S_{\text{RX}}=-92\ \text{dBm}$. Compute the link margin $M$ (in dB).


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. EIRP = $P_{\text{TX}} - L_{\text{f}} + G_{\text{TX}} = 20 - 1.5 + 12 = 30.5\ \text{dBm}$  
2. Additional losses $L_{\text{tot}} = L_{\text{c}} + L_{\text{pol}} = 0.3 + 2 = 2.3\ \text{dB}$  
3. Total loss = $L_{\text{FS}} + L_{\text{tot}} = 115 + 2.3 = 117.3\ \text{dB}$  
4. Received power $P_{\text{RX}} = P_{\text{EIRP}} - \text{total loss} = 30.5 - 117.3 = -86.8\ \text{dBm}$  
5. Margin $M = P_{\text{RX}} - S_{\text{RX}} = -86.8 - (-92) = 5.2\ \text{dB}$  
$\boxed{5.2}$

</details>

**5.** Given: $P_{\text{TX}}=33\ \text{dBm}$, feeder loss $L_{\text{f}}=2\ \text{dB}$, antenna gain $G_{\text{TX}}=18\ \text{dBi}$, connector loss $L_{\text{c}}=0.5\ \text{dB}$, rain attenuation $L_{\text{rain}}=4\ \text{dB}$, free‑space path loss $L_{\text{FS}}=122\ \text{dB}$, receiver sensitivity $S_{\text{RX}}=-100\ \text{dBm}$. Compute the link margin $M$ (in dB).


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. EIRP = $33 - 2 + 18 = 49\ \text{dBm}$  
2. Additional losses $L_{\text{tot}} = L_{\text{c}} + L_{\text{rain}} = 0.5 + 4 = 4.5\ \text{dB}$  
3. Total loss = $122 + 4.5 = 126.5\ \text{dB}$  
4. Received power $P_{\text{RX}} = 49 - 126.5 = -77.5\ \text{dBm}$  
5. Margin $M = -77.5 - (-100) = 22.5\ \text{dB}$  
$\boxed{22.5}$

</details>
