# 3.3.5 最大路徑損耗與涵蓋距離

所屬：[3.3 鏈路預算](../3-3.md)

## 練習題

**1.** What does the term *maximum permissible path loss* represent in a link budget?

- A. The smallest loss that can be tolerated before the link fails.
- B. The total loss of the propagation medium only, ignoring antenna gains.
- C. The highest attenuation the link can sustain while still meeting sensitivity and margin requirements.
- D. The loss introduced by the transmitter’s power amplifier.

<details><summary>看答案</summary>

正解：C。It is defined as $L_{\max}=EIRP-(S_{\text{min}}+M)$, i.e., the largest loss allowable while still satisfying the receiver’s sensitivity plus design margin.

</details>

**2.** In the free‑space path‑loss formula $L_{\text{FS}}(d)=32.44+20\log_{10}(d)+20\log_{10}(f)$, what are the assumed units for $d$ and $f$?

- A. $d$ in meters, $f$ in Hz
- B. $d$ in kilometers, $f$ in MHz
- C. $d$ in miles, $f$ in GHz
- D. $d$ in meters, $f$ in MHz

<details><summary>看答案</summary>

正解：B。The constant 32.44 is derived for $d$ in km and $f$ in MHz; using other units would require a different constant.

</details>

**3.** Using the parameters from the worked example ( $P_{\text{t}}=30\ \text{dBm}$, $G_{\text{t}}=15\ \text{dBi}$, $L_{\text{c,t}}=2\ \text{dB}$, $S_{\text{min}}=-95\ \text{dBm}$, $M=10\ \text{dB}$, $f=2000\ \text{MHz}$ ), compute the maximum coverage distance in kilometers with the free‑space model. Provide the answer in km with one decimal place.


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. $EIRP = 30 + 15 - 2 = 43\ \text{dBm}$  
2. $L_{\max}=43 - (-95+10)=43 - (-85)=128\ \text{dB}$  
3. Free‑space equation: $128 = 32.44 + 20\log_{10}(d) + 20\log_{10}(2000)$  
   $20\log_{10}(2000)=66.02$ → $20\log_{10}(d)=128-32.44-66.02=29.54$  
   $\log_{10}(d)=29.54/20=1.477$ → $d=10^{1.477}=30.0\ \text{km}$  
$\boxed{30.0}$

</details>

**4.** A point‑to‑point link operates at $f=900\ \text{MHz}$. Transmit power $P_{\text{t}}=20\ \text{dBm}$, $G_{\text{t}}=10\ \text{dBi}$, $L_{\text{c,t}}=1\ \text{dB}$. Receiver side: $G_{\text{r}}=8\ \text{dBi}$, $L_{\text{c,r}}=1\ \text{dB}$, $L_{\text{other}}=3\ \text{dB}$, $S_{\text{min}}=-90\ \text{dBm}$, margin $M=5\ \text{dB}$. Using the Hata‑type model $L(d)=32.4+20\log_{10}(f)+10n\log_{10}(d)-28$ with $n=3$, compute the maximum coverage distance $d$ in km (two‑decimal precision).


<details><summary>看答案</summary>

詳解（式號指本頁正文的公式）：

1. $EIRP = 20 + 10 - 1 = 29\ \text{dBm}$  
2. $L_{\max}=29 - (-90+5)=29 - (-85)=114\ \text{dB}$  
3. Compute constant parts: $20\log_{10}(f)=20\log_{10}(900)=59.08\ \text{dB}$  
   $C = 32.4 + 59.08 - 28 = 63.48\ \text{dB}$  
4. Set $L_{\max}=C + 10n\log_{10}(d)$ → $114 = 63.48 + 30\log_{10}(d)$  
   $30\log_{10}(d)=114-63.48 = 50.52$  
   $\log_{10}(d)=50.52/30 = 1.684$ → $d = 10^{1.684}=48.4\ \text{km}$? Wait check: we used $n=3$, so $10n =30$. Calculation gives $d\approx 48.4\ \text{km}$. However the Hata model is usually expressed in km; the result is $d\approx 5.6\ \text{km}$ if we mistakenly omitted the “‑28” term. Re‑evaluate with correct formula: $L(d)=32.4+20\log_{10}(f)+10n\log_{10}(d)-28$ → $C=32.4+59.08-28=63.48$ (as above). Solve $30\log_{10}(d)=114-63.48=50.52$, $\log_{10}(d)=1.684$, $d=10^{1.684}=48.4\ \text{km}$. This is the final answer.  
$\boxed{48.40}$

</details>
