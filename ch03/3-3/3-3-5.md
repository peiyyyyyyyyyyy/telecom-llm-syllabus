# 3.3.5 最大路徑損耗與涵蓋距離

所屬：[3.3 鏈路預算](../3-3.md)

## 正文

In a cellular or point‑to‑point system the *maximum permissible path loss* (often abbreviated as **max‑PL**) tells the planner how much attenuation the radio link can sustain while still meeting the required quality of service. Once the max‑PL is known, a propagation model (free‑space, Hata, COST‑231, etc.) can be inverted to obtain the **coverage distance** – the farthest point at which the received signal remains above the receiver’s sensitivity plus any design margin. These two quantities are the bridge between the link‑budget numbers (transmit power, antenna gains, losses) and the geographic size of the cell or the reach of a backhaul link.

---

### 1. Key definitions  

| Symbol | Meaning | Unit |
|--------|---------|------|
| $P_{\text{t}}$ | Transmit power (output of the PA) | dBm |
| $G_{\text{t}}$, $G_{\text{r}}$ | Transmit / receive antenna gain (relative to isotropic) | dBi |
| $L_{\text{c,t}}$, $L_{\text{c,r}}$ | Cable / connector loss on Tx / Rx side | dB |
| $L_{\text{other}}$ | All other deterministic losses (e.g., filter, duplexer) | dB |
| $EIRP$ | Equivalent isotropically radiated power = $P_{\text{t}}+G_{\text{t}}-L_{\text{c,t}}$ | dBm |
| $S_{\text{min}}$ | Receiver sensitivity (minimum detectable power) | dBm |
| $M$ | Link margin (design safety, fading, implementation loss) | dB |
| $L_{\max}$ | Maximum allowable path loss = $EIRP - (S_{\text{min}}+M)$ | dB |
| $L(d)$ | Path‑loss model as a function of distance $d$ | dB |
| $d$ | Separation between Tx and Rx (often expressed in km) | km (or m) |
| $f$ | Carrier frequency | MHz (or Hz) |
| $n$ | Path‑loss exponent (environment‑dependent) | – |

---

### 2. Fundamental formula  

The **maximum path loss** is obtained directly from the link‑budget balance:

$$
\boxed{L_{\max}=EIRP-\bigl(S_{\text{min}}+M\bigr)}
$$

where  

$$
EIRP = P_{\text{t}} + G_{\text{t}} - L_{\text{c,t}}
$$

and the total receiver‑side loss is included in $S_{\text{min}}$ (the sensitivity already accounts for $G_{\text{r}}$, $L_{\text{c,r}}$, and $L_{\text{other}}$).

Once $L_{\max}$ is known, the chosen propagation model $L(d)$ is solved for $d$:

$$
L(d)=L_{\max}\quad\Longrightarrow\quad d = L^{-1}\!\bigl(L_{\max}\bigr)
$$

For the **free‑space model** (distance in km, frequency in MHz):

$$
L_{\text{FS}}(d)=32.44 + 20\log_{10}(d) + 20\log_{10}(f)
\tag{1}
$$

For a more realistic urban environment the **Hata model** (valid for $150\ \text{MHz}\le f \le 1500\ \text{MHz}$) is often used:

$$
L_{\text{Hata}}(d)=32.4 + 20\log_{10}(f) + 10n\log_{10}(d) - 28\ \text{dB}
\tag{2}
$$

where $n$ is an empirical exponent (typically $2\le n\le4$).

---

### 3. Worked example  

| Parameter | Value |
|-----------|-------|
| $P_{\text{t}}$ | $30\ \text{dBm}$ |
| $G_{\text{t}}$ | $15\ \text{dBi}$ |
| $L_{\text{c,t}}$ | $2\ \text{dB}$ |
| $G_{\text{r}}$ | $12\ \text{dBi}$ |
| $L_{\text{c,r}}$ | $2\ \text{dB}$ |
| $L_{\text{other}}$ | $5\ \text{dB}$ |
| $S_{\text{min}}$ | $-95\ \text{dBm}$ |
| $M$ | $10\ \text{dB}$ |
| $f$ | $2\ \text{GHz}=2000\ \text{MHz}$ |

1. **EIRP**  

$$
EIRP = 30 + 15 - 2 = 43\ \text{dBm}
$$

2. **Maximum allowable path loss**  

$$
L_{\max}= 43 - \bigl(-95 + 10\bigr)= 43 - (-85)=128\ \text{dB}
$$

3. **Coverage distance using free‑space (1)**  

$$
128 = 32.44 + 20\log_{10}(d_{\text{km}}) + 20\log_{10}(2000)
$$

$$
20\log_{10}(2000)=66.02\ \text{dB}
$$

$$
20\log_{10}(d_{\text{km}})=128 - 32.44 - 66.02 = 29.54
$$

$$
\log_{10}(d_{\text{km}})=\frac{29.54}{20}=1.477\;\Longrightarrow\; d_{\text{km}}\approx 10^{1.477}=30\ \text{km}
$$

Hence the link can reliably serve a cell radius of roughly **30 km** under ideal free‑space conditions.

---

### 4. Practical notes & common pitfalls  

| Pitfall | Why it matters | Remedy |
|---------|----------------|--------|
| **Neglecting cable loss** | $L_{\text{c}}$ can be several dB, directly reducing $EIRP$ or effective sensitivity. | Always subtract measured connector / feeder loss from the respective side before using $EIRP$ or $S_{\text{min}}$. |
| **Mismatched distance units** | The constant term in (1) assumes *km*; using meters yields a 60 dB error. | Verify the unit convention of the model you employ; convert $d$ accordingly. |
| **Omitting link margin** | Fading, rain, or hardware aging can push the link below the required SNR. | Add a margin (typically 6–10 dB) to $S_{\text{min}}$ before computing $L_{\max}$. |
| **Using free‑space for dense urban** | Path‑loss exponent $n$ is larger; coverage will be over‑estimated. | Select a model (Hata, COST‑231, ITU‑R P.452) that matches the environment. |
| **Confusing dBi and dBd** | Gains referenced to isotropic vs. dipole differ by 2.15 dB. | Keep a consistent reference; convert if necessary. |

By carefully accounting for every loss term, applying the correct propagation model, and respecting unit conventions, the calculated max‑PL and coverage distance become reliable design guides.

## 練習題

**1.** What does the term *maximum permissible path loss* represent in a link budget?

- A. The smallest loss that can be tolerated before the link fails.
- B. The total loss of the propagation medium only, ignoring antenna gains.
- C. The highest attenuation the link can sustain while still meeting sensitivity and margin requirements.
- D. The loss introduced by the transmitter’s power amplifier.

<details><summary>看答案</summary>

正解：C。It is defined as $L_{\max}=EIRP-(S_{\text{min}}+M)$, i.e., the largest loss allowable while still satisfying the receiver’s sensitivity plus design margin.

</details>

**2.** In the free‑space path‑loss formula $L_{\text{FS}}(d)=32.44+20\log_{10}(d)+20\log_{10}(f)$, what are the assumed units for $d$ and $f$?

- A. $d$ in meters, $f$ in Hz
- B. $d$ in kilometers, $f$ in MHz
- C. $d$ in miles, $f$ in GHz
- D. $d$ in meters, $f$ in MHz

<details><summary>看答案</summary>

正解：B。The constant 32.44 is derived for $d$ in km and $f$ in MHz; using other units would require a different constant.

</details>

**3.** Using the parameters from the worked example ( $P_{\text{t}}=30\ \text{dBm}$, $G_{\text{t}}=15\ \text{dBi}$, $L_{\text{c,t}}=2\ \text{dB}$, $S_{\text{min}}=-95\ \text{dBm}$, $M=10\ \text{dB}$, $f=2000\ \text{MHz}$ ), compute the maximum coverage distance in kilometers with the free‑space model. Provide the answer in km with one decimal place.


<details><summary>看答案</summary>

詳解：

1. $EIRP = 30 + 15 - 2 = 43\ \text{dBm}$  
2. $L_{\max}=43 - (-95+10)=43 - (-85)=128\ \text{dB}$  
3. Free‑space equation: $128 = 32.44 + 20\log_{10}(d) + 20\log_{10}(2000)$  
   $20\log_{10}(2000)=66.02$ → $20\log_{10}(d)=128-32.44-66.02=29.54$  
   $\log_{10}(d)=29.54/20=1.477$ → $d=10^{1.477}=30.0\ \text{km}$  
\boxed{30.0}

</details>

**4.** A point‑to‑point link operates at $f=900\ \text{MHz}$. Transmit power $P_{\text{t}}=20\ \text{dBm}$, $G_{\text{t}}=10\ \text{dBi}$, $L_{\text{c,t}}=1\ \text{dB}$. Using the Hata‑type model $L(d)=32.4+20\log_{10}(f)+10n\log_{10}(d)-28$ with $n=3$, compute the maximum coverage distance $d$ in km (two‑decimal precision).

詳解：

   $C = 32.4 + 59.08 - 28 = 63.48\ \text{dB}$

   $30\log_{10}(d)=114-63.48 = 50.52$  
   $\log_{10}(d)=50.52/30 = 1.684$ → $d = 10^{1.684}=48.4\ \text{km}$? Wait check: we used $n=3$, so $10n =30$. Calculation gives $d\approx 48.4\ \text{km}$. Solve $30\log_{10}(d)=114-63.48=50.52$, $\log_{10}(d)=1.684$, $d=10^{1.684}=48.4\ \text{km}$. This is the final answer.
