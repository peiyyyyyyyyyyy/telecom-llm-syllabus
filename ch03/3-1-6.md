# 3.1.6 訊號雜訊比與 SINR

所屬：[3.1 訊號與通道](3-1.md)

## 內文

#### 為什麼要學

一條鏈路能跑多快、錯誤率多高，取決於想要的訊號相對於「不想要的東西」有多強。只考慮熱雜訊時用訊號雜訊比（signal-to-noise ratio, SNR）；行動網路裡鄰近細胞用同樣的頻率，干擾常常比雜訊還大，所以要用訊號對干擾加雜訊比（signal-to-interference-plus-noise ratio, SINR）。SINR 是調變編碼等級的選擇、吞吐量估算、換手判斷與網路最佳化最核心的指標。另外，比較不同調變方式的效能時，要用和頻寬、速率無關的每位元能量對雜訊密度比 $E_b/N_0$，三者之間的換算是基本功。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $S$ | 想要訊號的接收功率 | W 或 mW（或 dBm） |
| $N$ | 雜訊功率，$N = N_0B$（含接收機雜訊指數） | W 或 mW（或 dBm） |
| $I_i$ | 第 $i$ 個干擾源的接收功率 | W 或 mW（或 dBm） |
| $I$ | 干擾總功率，$I = \sum_i I_i$ | W 或 mW（或 dBm） |
| $\text{SNR}$、$\text{SIR}$、$\text{SINR}$ | 訊號對雜訊、對干擾、對干擾加雜訊的比值 | 無因次，或 dB |
| $B$ | 計算雜訊所用的頻寬 | Hz |
| $R_b$ | 資訊位元率 | bit/s |
| $E_b$ | 每個位元的能量，$E_b = S/R_b$ | J |
| $N_0$ | 雜訊功率頻譜密度 | W/Hz |
| $C/N_0$ | 載波功率對雜訊密度比 | Hz（或 dB-Hz） |

#### 公式與推導

三個比值的線性定義：

$$\text{SNR} = \frac{S}{N},\qquad \text{SIR} = \frac{S}{I},\qquad \text{SINR} = \frac{S}{I + N} = \frac{S}{\sum_i I_i + N}$$

用 dB 表示時是相減：$\text{SNR(dB)} = S(\text{dBm}) - N(\text{dBm})$。但 **分母裡的干擾和雜訊是功率相加**，必須先把每一項換成 mW 加總，再換回 dBm，最後才和 $S$ 相減。這裡假設各干擾源和雜訊互不相關，所以功率可以直接相加；而且把干擾當成像雜訊一樣處理。

把 SINR 的倒數拆開可以得到一個很有用的關係：

$$\frac{1}{\text{SINR}} = \frac{1}{\text{SNR}} + \frac{1}{\text{SIR}}$$

所以 SINR 一定比 SNR 和 SIR 都小，並且由比較小的那個主導。$I \ll N$ 時 $\text{SINR} \approx \text{SNR}$，稱為雜訊受限（noise-limited），常見於涵蓋邊緣或鄉村，加大發射功率有幫助；$I \gg N$ 時 $\text{SINR} \approx \text{SIR}$，稱為干擾受限（interference-limited），常見於密集市區，所有基地臺一起加大功率並不會改善 SINR，要靠天線傾角、干擾協調或波束成形。SNR 與 SIR 剛好相等時，SINR 比它們低 3.01 dB。

**$E_b/N_0$ 與 SNR 的換算。** 訊號功率是每秒送出的能量，$S = E_bR_b$；雜訊功率 $N = N_0B$，所以

$$\text{SNR} = \frac{E_b}{N_0}\cdot\frac{R_b}{B}\qquad\Longleftrightarrow\qquad \frac{E_b}{N_0}(\text{dB}) = \text{SNR(dB)} + 10\log_{10}\frac{B}{R_b}$$

$R_b/B$ 就是頻譜效率（bit/s/Hz）。$E_b/N_0$ 是無因次量，和選用的頻寬無關，適合比較不同調變與編碼；SNR 則會隨量測頻寬改變。同理，$C/N_0 = \text{SNR}\times B$，用 dB 表示是 $\text{SNR(dB)} + 10\log_{10}B$，單位 dB-Hz，例如 1 MHz 頻寬內 SNR 為 10 dB 相當於 $C/N_0 = 70$ dB-Hz。

#### 算例

**算例 1：兩個干擾源加雜訊的 SINR**

已知（假設值）：服務細胞訊號 $S = -85$ dBm；兩個鄰近細胞的干擾分別為 −95 dBm、−100 dBm；頻寬 20 MHz，接收機雜訊指數 7 dB，溫度 290 K。求 SNR、SIR、SINR（dB，取到小數第 2 位）。

- 雜訊：$N = -174 + 10\log_{10}(20\times10^6) + 7 = -174 + 73.01 + 7 = -93.99$ dBm，線性值 $10^{-9.399} = 3.991\times10^{-10}$ mW。
- 干擾：$10^{-9.5} = 3.162\times10^{-10}$ mW，$10^{-10} = 1.000\times10^{-10}$ mW，合計 $4.162\times10^{-10}$ mW，即 $-93.81$ dBm。
- 干擾加雜訊：$4.162\times10^{-10} + 3.991\times10^{-10} = 8.153\times10^{-10}$ mW，即 $-90.89$ dBm。
- $\text{SNR} = -85 - (-93.99) = 8.99$ dB；$\text{SIR} = -85 - (-93.81) = 8.81$ dB；$\text{SINR} = -85 - (-90.89) = 5.89$ dB（線性值 3.88）。
- 合理性檢查：干擾和雜訊幾乎一樣大（差 0.18 dB），所以 SINR 應該比 SNR、SIR 低大約 3 dB；$8.99 - 5.89 = 3.10$ dB、$8.81 - 5.89 = 2.92$ dB，吻合。用倒數關係驗算：$1/10^{0.899} + 1/10^{0.881} = 0.1262 + 0.1315 = 0.2577$，倒數為 3.88，一致。

**算例 2：SNR 與 $E_b/N_0$ 互換**

已知：頻寬 10 MHz 內量到 SNR＝3 dB，資訊位元率 2 Mbit/s。求 $E_b/N_0$。

- $B/R_b = 10\times10^6/(2\times10^6) = 5$，$10\log_{10}5 = 6.99$ dB。
- $E_b/N_0 = 3 + 6.99 = 9.99$ dB。
- 檢查：頻譜效率只有 0.2 bit/s/Hz，每個位元分到的能量多，所以 $E_b/N_0$ 比 SNR 高，方向正確。反過來，若在 1 MHz 內傳 2 Mbit/s（頻譜效率 2 bit/s/Hz）且 SNR＝10 dB，則 $E_b/N_0 = 10 + 10\log_{10}0.5 = 10 - 3.01 = 6.99$ dB，比 SNR 低。

#### 常見錯誤

- **把干擾和雜訊的 dBm 值直接相加，或取其中最大的就算數**：一定要換成線性功率加總。
- **線性與 dB 混用**：例如把 $\text{SINR} = 5.89$ dB 直接代進需要線性值的公式（如 Shannon 容量），正確要代 3.88。
- **$E_b/N_0$ 換算方向弄反**：$E_b/N_0 = \text{SNR}\times B/R_b$；頻寬大於位元率時 $E_b/N_0$ 比 SNR 高。
- **雜訊頻寬和訊號頻寬不一致**：算 $N$ 用的 $B$ 要和量 $S$ 的頻寬相同（例如都是整個載波，或都是單一資源區塊）。

#### 和其他小節的關係

分母的雜訊來自 3.1.5 的 $kTB$ 與雜訊指數；功率加總與 dB 換算的規則來自 3.1.1；訊號與干擾的強度由 3.1.2、3.1.3 的路徑損耗決定。本節算出的 SNR、SINR 會代入 3.2.1 的 Shannon 容量、3.2.4 的編碼率與 MCS 選擇；$E_b/N_0$ 是 3.2.3 錯誤率公式的自變數；3.3.3 的干擾餘量與 3.3.4 的接收靈敏度也建立在本節之上。
