# 3.4.1 話務量（Erlang）

所屬：[3.4 訊務與存取](3-4.md)

## 內文

#### 為什麼要學

網路資源（語音通道、中繼線、信令通道、客服座席、封包排程的時槽）永遠比用戶數少，因為不是所有人同時使用。要決定「該準備多少資源」，第一步是把需求量化，這個量就是話務量（traffic intensity），單位是厄蘭（Erlang, Erl）。細胞的語音通道數、交換機之間的中繼線數、VoLTE／VoNR 的同時通話容量、忙時 KPI 報表，都以 Erlang 為共同語言。先把話務量算對，才能接著用 3.4.2 的 Erlang B／C 換算成需要的通道數。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $A$ | 提供話務量（offered traffic） | Erl |
| $A_c$ | 承載話務量（carried traffic） | Erl |
| $A_l$ | 損失話務量（lost traffic） | Erl |
| $\lambda$ | 呼叫到達率（單位時間內的平均呼叫次數） | 次/秒 或 次/小時 |
| $h$ | 平均佔用時間（mean holding time） | 秒 或 小時 |
| $n$ | 觀察時間 $T$ 內的呼叫次數 | 次 |
| $T$ | 觀察時間（通常取忙時 1 小時） | 秒 或 小時 |
| $N_u$ | 用戶數 | 人 |
| $a$ | 每個用戶的平均話務量 | Erl/用戶（常寫成 mErl） |
| $B$ | 阻塞機率（被拒絕的呼叫比例） | 無因次 |

#### 公式與推導

話務量是「到達率乘以平均佔用時間」：

$$A = \lambda h = \frac{n\,h}{T}$$

$\lambda$ 和 $h$ 必須用同一個時間單位，乘起來時間單位互相消掉，所以 Erlang 是無因次量。它有兩個等價的直觀意義：第一，$A$ 是「平均同時被佔用的資源數」；第二，$A$ 是「在一段平均佔用時間內到達的平均呼叫數」。1 Erl 相當於一條通道在整個觀察時間內被連續佔滿。一條通道最多只能承載 1 Erl，所以 $N$ 條通道的承載話務量不會超過 $N$ Erl。

另一個等價的算法是把所有通話的佔用時間加總，再除以觀察時間：

$$A = \frac{\sum_i t_i}{T}$$

例如 1 小時內的通話總時間是 3,000 分鐘，話務量就是 $3000/60 = 50$ Erl。

提供、承載、損失三種話務量要分清楚。提供話務量是「如果資源無限多，會被承載的量」，它是需求面的量；承載話務量是實際被服務的量，也就是量測得到的平均佔用通道數。在呼叫被拒絕就直接離開（不重撥、不排隊）的假設下：

$$A_c = A(1-B),\qquad A_l = A\,B$$

網路統計量到的是 $A_c$；做容量規劃要用的是 $A$。阻塞率很低時兩者幾乎相等，阻塞嚴重時 $A_c$ 會明顯低估需求。

把用戶數帶進來：若每個用戶在忙時平均撥打 $c$ 次、每次平均 $h$，則每用戶話務量 $a = c\,h/T$，整個區域的話務量是

$$A = N_u\,a$$

忙時（busy hour）是一天當中話務量最高的連續 1 小時。規劃用忙時而不用全日平均，因為資源要撐得住尖峰。北美的舊單位 CCS（hundred call seconds，百秒呼）和 Erlang 的關係是 1 Erl＝3,600 秒÷100 秒＝36 CCS。

這些公式只是平均值的定義，不需要假設到達過程的分布；只有進一步算阻塞機率（3.4.2）時，才需要卜瓦松到達等假設。

#### 算例

**算例 1：由呼叫次數與平均時長求話務量**

已知：某細胞在忙時 1 小時內共有 1,200 次通話嘗試，平均通話時長 150 秒（假設值）。求提供話務量。

- 選公式：$A = n\,h/T$，時間全部換成秒，$T = 3600$ 秒。
- 代入：$A = 1200\times150/3600 = 180000/3600 = 50$ Erl。
- 換算：$50\times36 = 1800$ CCS；總通話時間 $1200\times150 = 180{,}000$ 秒＝3,000 分鐘。
- 若量測到的阻塞率是 2%（假設），承載話務量 $A_c = 50\times(1-0.02) = 49$ Erl，損失 1 Erl。
- 合理性檢查：50 Erl 表示平均同時有 50 通電話在進行，所以通道數一定要多於 50 條才有可能維持低阻塞率；如果這個細胞只有 40 條通道，承載量不可能超過 40 Erl，題目的 2% 阻塞率就不可能成立。

**算例 2：由用戶數推估話務量**

已知：某區域有 3,000 個用戶，每人在忙時平均撥打 1.5 次、每次 120 秒（假設值）。求每用戶話務量與總話務量。

- 每用戶：$a = 1.5\times120/3600 = 180/3600 = 0.05$ Erl＝50 mErl。
- 總量：$A = 3000\times0.05 = 150$ Erl。
- 合理性檢查：50 mErl 表示每個用戶在忙時有 5% 的時間在通話，也就是 60 分鐘裡 3 分鐘，和「1.5 次×2 分鐘＝3 分鐘」一致。

#### 常見錯誤

1. **時間單位沒有統一**：到達率用「次/小時」、佔用時間用「秒」直接相乘，會得到大 3,600 倍的數字。先全部換成秒或全部換成小時。
2. **把 Erlang 當成通話次數或用戶數**：50 Erl 不是 50 通電話，也不是 50 個用戶，而是平均同時佔用 50 條通道。
3. **把承載話務量當成提供話務量**：統計報表上的佔用量是 $A_c$。阻塞率高時要用 $A = A_c/(1-B)$ 還原需求，不然會低估要擴充的通道數。
4. **用全日平均代替忙時**：全日平均話務量遠低於忙時值，拿來規劃會在尖峰時段大量阻塞。

#### 和其他小節的關係

本節算出的 $A$ 是 3.4.2 Erlang B／C 的輸入，用來換算通道數與阻塞機率。$A=\lambda h$ 和 3.4.3 排隊模型的 $\lambda/\mu$ 是同一個量（$h = 1/\mu$）。3.4.6 算出的每細胞通道數則是 Erlang B 的另一個輸入。
