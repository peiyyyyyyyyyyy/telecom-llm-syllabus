# 3.2.1 Shannon 通道容量

所屬：[3.2 容量](3-2.md)

## 內文

#### 為什麼要學

Shannon 通道容量（channel capacity）回答一個最根本的問題：給定頻寬與訊號雜訊比，一條鏈路最多能可靠傳多少位元。電信網路裡，它是所有速率估算的上限參考：做鏈路預算時，用它把接收端的 SNR 換成「最多可能的速率」；評估新頻段或載波聚合時，用它判斷加頻寬划不划算；看基地台的調變與編碼方案（MCS）選得保不保守時，也是拿實際頻譜效率和 Shannon 上限相比。它同時說明了兩種完全不同的系統設計方向：頻寬不夠時要靠提高 SNR 與高階調變，功率不夠時則要靠加大頻寬與低碼率編碼。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $C$ | 通道容量，可靠傳輸速率的上限 | bit/s |
| $B$ | 通道頻寬 | Hz |
| $S$（或 $P$） | 接收到的平均訊號功率 | W |
| $N_0$ | 單邊雜訊功率頻譜密度 | W/Hz |
| $N = N_0 B$ | 頻寬 $B$ 內的雜訊功率 | W |
| $\text{SNR} = S/N$ | 訊號雜訊比（線性值，不是 dB） | 無單位 |
| $E_b$ | 每個資訊位元的接收能量，$E_b = S/R$ | J |
| $R$ | 實際資訊速率 | bit/s |
| $\eta = R/B$ | 頻譜效率 | bit/s/Hz |

#### 公式與推導

對於頻寬受限、平均功率受限的加成性白高斯雜訊（additive white Gaussian noise, AWGN）通道，容量為

$$C = B\log_2\!\left(1+\frac{S}{N}\right) = B\log_2\!\left(1+\frac{S}{N_0 B}\right)$$

這條公式的前提要記清楚：雜訊是白色高斯雜訊、通道增益固定且已知、發射訊號平均功率受限、輸入採高斯分布、而且允許任意長的編碼。它是「速率低於 $C$ 時錯誤率可以任意小」的界線，不是任何一種實際調變的速率公式。公式裡的 SNR 一定要用線性值。

依 SNR 的大小可分成兩個區域：

- **頻寬受限區**（$\text{SNR}\gg 1$）：$C \approx B\log_2(\text{SNR})$。SNR 每增加 3 dB（功率加倍），每 Hz 只多 1 bit/s；頻寬加倍則容量近乎加倍。這時頻寬是稀缺資源。
- **功率受限區**（$\text{SNR}\ll 1$）：利用 $\ln(1+x)\approx x$，得 $C \approx \dfrac{S}{N_0 \ln 2} \approx 1.4427\,\dfrac{S}{N_0}$。容量和功率成正比，幾乎和頻寬無關；頻寬趨近無限大時，容量收斂到這個有限值。

**Shannon 極限**：令速率等於容量 $R=C$，並把 $S = E_b R$ 代入，得 $\eta = \log_2\!\left(1+\eta\,E_b/N_0\right)$，也就是

$$\frac{E_b}{N_0} = \frac{2^{\eta}-1}{\eta}$$

這是在頻譜效率 $\eta$ 下可靠通訊所需的最小 $E_b/N_0$。當 $\eta\to 0$（頻寬無限大）時，$2^{\eta}-1 \approx \eta\ln 2$，所以

$$\left.\frac{E_b}{N_0}\right|_{\min} = \ln 2 = 0.6931,\qquad 10\log_{10}(0.6931) = -1.59\ \text{dB}$$

不論用多大的頻寬、多強的編碼，$E_b/N_0$ 低於 −1.59 dB 就不可能可靠傳輸。$\eta$ 越高，所需的 $E_b/N_0$ 越大：$\eta=1$ 時為 0 dB，$\eta=2$ 時為 $1.5$（1.76 dB），$\eta=6$ 時為 $10.5$（10.21 dB）。

#### 算例

**算例 1（頻寬受限區）** 已知頻寬 $B=20$ MHz，接收 SNR 為 15 dB，求容量。

1. SNR 換成線性：$10^{15/10} = 31.62$。
2. 代入：$\log_2(1+31.62) = \log_2(32.62) = 5.028$ bit/s/Hz。
3. $C = 20\times10^{6}\times 5.028 = 1.0056\times10^{8}$ bit/s，約 100.6 Mbps（取到小數第 1 位）。
4. 合理性檢查：SNR 接近 32，$\log_2 32 = 5$，結果略大於 5 bit/s/Hz，合理。實際系統因為編碼長度有限、參考訊號與控制通道占用資源，單層速率會明顯低於這個值。

**算例 2（功率受限區與頻寬的效益）** 假設接收功率 $S=-100$ dBm，雜訊密度 $N_0=-174$ dBm/Hz。比較頻寬 1 MHz 與 100 MHz 的容量，並求頻寬無限大時的極限。

1. $S/N_0 = -100-(-174) = 74$ dB·Hz，線性值 $10^{7.4} = 2.512\times10^{7}$ Hz。
2. $B=1$ MHz：$\text{SNR} = 2.512\times10^{7}/10^{6} = 25.12$（14 dB），$C = 10^{6}\times\log_2(26.12) = 4.707$ Mbps。
3. $B=100$ MHz：$\text{SNR} = 0.2512$（−6 dB），$C = 10^{8}\times\log_2(1.2512) = 32.33$ Mbps。
4. 極限：$C_\infty = 2.512\times10^{7}/0.6931 = 3.624\times10^{7}$ bit/s，即 36.24 Mbps。
5. 合理性檢查：頻寬放大 100 倍，容量只變成 $32.33/4.707 = 6.87$ 倍，而且已經達到極限值的 89%；再加頻寬幾乎沒有好處，這時該做的是提高接收功率。

#### 常見錯誤

- 把 dB 值直接代進 $\log_2(1+\text{SNR})$。15 dB 要先換成 31.62，不能代 15。
- 把 $\log_2$ 算成 $\log_{10}$ 或 $\ln$。換底：$\log_2 x = \ln x/\ln 2 = \log_{10}x/0.30103$。
- 以為頻寬加倍、容量一定加倍。接收功率固定時，頻寬加倍會讓雜訊功率也加倍、SNR 減半；只有在高 SNR 區才近似加倍。
- 把 −1.59 dB 當成 SNR 的下限。它是 $E_b/N_0$ 的下限；展頻或低碼率系統的 SNR 可以遠低於 0 dB 仍正常運作。

#### 和其他小節的關係

公式用到的 SNR 與 $E_b/N_0$ 換算在 3.1.6，雜訊功率 $N_0B$ 在 3.1.5。把容量除以頻寬就是 3.2.2 的頻譜效率上限；3.2.3、3.2.4 的調變與 MCS 是逼近這個上限的實際手段；3.2.6 把公式推廣到多天線；3.7 細項則從資訊理論說明容量的由來。
