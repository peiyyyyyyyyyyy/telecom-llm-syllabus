# 3.1.8 取樣、量化與 PCM

所屬：[3.1 訊號與通道](3-1.md)

## 內文

#### 為什麼要學

語音、影像、無線電波形本來都是連續的類比訊號，要進入數位網路就得經過取樣（sampling）、量化（quantization）、編碼三個步驟，合起來稱為脈波編碼調變（pulse code modulation, PCM）。取樣率太低會發生混疊（aliasing），訊號無法還原；量化位元數太少，量化雜訊就大。這兩個參數相乘就是位元率，直接決定傳輸線路與儲存空間的需求：傳統電話網路的 64 kbit/s 語音通道、基地臺射頻單元與基頻單元之間傳送取樣資料所需的前傳容量、類比數位轉換器（ADC）該選幾位元，都是這一節的計算。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $f_{\max}$（或 $W$） | 訊號的最高頻率（基頻訊號的頻寬） | Hz |
| $f_s$ | 取樣率 | Hz（樣本／秒） |
| $T_s$ | 取樣間隔，$T_s = 1/f_s$ | s |
| $f_a$ | 混疊後出現的頻率 | Hz |
| $N$ | 每個樣本的量化位元數 | bit |
| $L$ | 量化階數，$L = 2^N$ | 無因次 |
| $V$ | 量化器的滿刻度峰值（輸入範圍 $-V \sim +V$） | V |
| $\Delta$ | 量化間隔（step size） | V |
| $\sigma_q^2$ | 量化雜訊功率 | V² |
| $\sigma_x^2$ | 訊號功率 | V² |
| $\text{SQNR}$ | 訊號對量化雜訊比 | 無因次，或 dB |
| $R_b$ | PCM 位元率 | bit/s |

#### 公式與推導

**取樣定理。** 最高頻率為 $f_{\max}$ 的帶限基頻訊號，只要取樣率滿足

$$f_s > 2f_{\max}$$

就能由樣本完整重建；$2f_{\max}$ 稱為 Nyquist 取樣率，$f_s/2$ 稱為 Nyquist 頻率。道理是：在時間域每隔 $T_s$ 取樣，等於把頻譜以 $f_s$ 為週期重複排列；$f_s$ 夠大時各份頻譜不重疊，用低通濾波器就能取回原訊號。取樣率不夠時相鄰的頻譜重疊，高於 $f_s/2$ 的成分會「摺回」低頻，出現在

$$f_a = \lvert f - m f_s\rvert\quad(m\ \text{為使}\ f_a \le f_s/2\ \text{的整數})$$

這就是混疊，事後無法分離，所以取樣前一定要先用抗混疊濾波器把超過 $f_s/2$ 的成分濾掉。實際濾波器不是理想的，取樣率要比 $2f_{\max}$ 再高一些，留出過渡帶。

**均勻量化。** 把 $-V$ 到 $+V$ 的範圍等分成 $L = 2^N$ 階，量化間隔

$$\Delta = \frac{2V}{L} = \frac{2V}{2^N}$$

當階數夠多、輸入沒有超出範圍時，量化誤差可視為在 $\pm\Delta/2$ 之間均勻分布、和訊號無關的雜訊，功率為

$$\sigma_q^2 = \frac{1}{\Delta}\int_{-\Delta/2}^{\Delta/2}e^2\,de = \frac{\Delta^2}{12}$$

**SQNR。** 輸入為剛好打滿刻度的正弦波（振幅 $V$）時，訊號功率是 $V^2/2$，所以

$$\text{SQNR} = \frac{V^2/2}{\Delta^2/12} = \frac{V^2/2}{(2V/2^N)^2/12} = \frac{3}{2}\cdot2^{2N}$$

$$\text{SQNR(dB)} = 10\log_{10}1.5 + 20N\log_{10}2 = 1.76 + 6.02N$$

這個式子的前提是三件事：**均勻量化、輸入是滿刻度正弦波、量化誤差可視為均勻分布的白雜訊**。每多 1 個位元，SQNR 增加 6.02 dB，這一點對一般訊號都成立；但常數項 1.76 dB 只屬於滿刻度正弦波。一般情況可以寫成 $\text{SQNR(dB)} = 6.02N + 4.77 - 20\log_{10}(V/\sigma_x)$，其中 $V/\sigma_x$ 是滿刻度峰值對訊號方均根值的比：正弦波時 $V/\sigma_x = \sqrt2$（3.01 dB）就回到 1.76；輸入位準比滿刻度低幾 dB，SQNR 就少幾 dB；峰均比高的訊號（例如 OFDM）要預留更多餘裕，SQNR 也更低。

**PCM 位元率。** 每秒 $f_s$ 個樣本、每個樣本 $N$ 位元：

$$R_b = f_s \times N$$

多聲道或多路訊號再乘上路數。

#### 算例

**算例 1：電話語音的 PCM**

已知：ITU-T G.711 的語音 PCM 取樣率為 8,000 樣本／秒，每個樣本 8 位元；電話語音頻帶上限取 3.4 kHz。求 Nyquist 取樣率、位元率、一分鐘的資料量，以及若有一個 5 kHz 的單音沒被濾掉會混疊到哪裡。

- Nyquist 取樣率：$2\times3.4 = 6.8$ kHz；實際取 8 kHz，Nyquist 頻率 4 kHz，留有 0.6 kHz 的過渡帶給抗混疊濾波器。
- 位元率：$R_b = 8000\times8 = 64{,}000$ bit/s＝64 kbit/s。
- 一分鐘資料量：$64{,}000\times60 = 3{,}840{,}000$ bit，除以 8 得 480,000 byte。
- 混疊：$f_a = \lvert5 - 8\rvert = 3$ kHz，落在語音頻帶內，聽起來是一個原本不存在的 3 kHz 聲音。
- 合理性檢查：64 kbit/s 正是傳統數位電話一個話路的速率。要注意 G.711 用的是非均勻量化（A 律或 μ 律壓擴），讓小訊號也有足夠的 SQNR，所以不能把 $6.02\times8 + 1.76 = 49.92$ dB 直接當成它的效能。

**算例 2：ADC 位元數與 SQNR**

已知：12 位元均勻量化的 ADC，輸入範圍 ±1 V，輸入為滿刻度正弦波。求量化間隔、量化雜訊方均根值與 SQNR；若要求 SQNR 至少 70 dB，最少需要幾位元。

- $\Delta = 2\times1/2^{12} = 2/4096 = 0.4883$ mV。
- 量化雜訊功率：$\Delta^2/12 = (4.883\times10^{-4})^2/12 = 1.987\times10^{-8}$ V²，方均根值 $\Delta/\sqrt{12} = 0.141$ mV。
- 訊號功率：$1^2/2 = 0.5$ V²。$\text{SQNR} = 0.5/(1.987\times10^{-8}) = 2.517\times10^7$，即 74.01 dB。
- 用公式核對：$6.02\times12 + 1.76 = 74.00$ dB，一致（0.01 的差來自 6.02 與 1.76 的取位）。
- 最少位元數：$6.02N + 1.76 \ge 70$，$N \ge 68.24/6.02 = 11.34$，取整數為 12 位元。
- 合理性檢查：11 位元只有 $6.02\times11 + 1.76 = 67.98$ dB，不足 70 dB；12 位元有 74 dB，夠用。若輸入比滿刻度低 12 dB，SQNR 會降到約 62 dB，就不夠了，所以選位元數時還要考慮輸入位準的餘裕。

#### 常見錯誤

- **取樣率只取到「等於」$2f_{\max}$ 或拿訊號的中心頻率來算**：基頻訊號看最高頻率，而且實務上要高於 2 倍並搭配抗混疊濾波器。
- **把 $6.02N + 1.76$ 套到任何訊號**：常數 1.76 dB 只對滿刻度正弦波、均勻量化成立；輸入位準降低或訊號峰均比高時都要扣。
- **階數與位元數弄混**：$L = 2^N$，256 階是 8 位元，不是 256 位元；$\Delta = 2V/L$ 的分子是峰對峰範圍。
- **bit 與 byte、k 與 M 沒換**：64 kbit/s 等於每秒 8,000 byte；算儲存空間時要除以 8。

#### 和其他小節的關係

取樣定理的頻譜解釋來自 3.1.7 的傅立葉轉換性質；量化雜訊和 3.1.5 的熱雜訊一樣可視為加成性雜訊，在 3.1.6 的 SNR 計算裡與其他雜訊以線性功率相加。本節的 PCM 位元率接到 3.2.7 的位元率、符號率與所需頻寬，以及 3.4.5 的吞吐量分析；Nyquist 取樣率與 3.2.7 的 Nyquist 無符號間干擾準則名稱相近但講的是不同的事。量化誤差的均勻分布與變異數計算用到 3.5.2。

#### 單題：Nyquist rate and aliasing

**3.1.8G001**　A test signal is $x(t) = 3\cos(2\pi \cdot 1800\,t) + 2\cos(2\pi \cdot 4200\,t) + \cos(2\pi \cdot 6500\,t)$ with $t$ in seconds. Determine the Nyquist rate (the minimum sampling rate that avoids aliasing) in kHz, rounded to one decimal place.

<details><summary>看答案</summary>

**答案**　13.0

**詳解**　The components are at 1800 Hz, 4200 Hz and 6500 Hz, so the highest frequency is $f_{max} = 6500$ Hz. Nyquist rate $= 2 f_{max} = 2 \times 6500 = 13000$ Hz $= 13.0$ kHz.
\boxed{13.0}

**出處**　Oppenheim & Schafer, Discrete-Time Signal Processing (Nyquist–Shannon sampling theorem)

</details>

**3.1.8G002**　A 17.5 kHz sinusoid is sampled by an ideal sampler at 24 kHz with no anti-aliasing filter. Determine the frequency, in kHz, at which this tone appears in the baseband from 0 to $f_s/2$, rounded to one decimal place.

<details><summary>看答案</summary>

**答案**　6.5

**詳解**　$f_s/2 = 12$ kHz, and 17.5 kHz > 12 kHz, so the tone aliases. The apparent frequency is $|f - k f_s|$ for the integer $k$ that brings it into 0–12 kHz. With $k = 1$: $|17.5 - 24| = 6.5$ kHz, which is below 12 kHz.
\boxed{6.5}

**出處**　Oppenheim & Schafer, Discrete-Time Signal Processing (aliasing in periodic sampling)

</details>

**3.1.8G003**　The signal $m(t) = \cos(2\pi \cdot 3000\,t)\cdot\cos(2\pi \cdot 11000\,t)$, with $t$ in seconds, is to be sampled. Determine the Nyquist rate in kHz, rounded to one decimal place.

<details><summary>看答案</summary>

**答案**　28.0

**詳解**　Product-to-sum: $\cos A \cos B = \tfrac12[\cos(A-B) + \cos(A+B)]$. The components are at $11000 - 3000 = 8000$ Hz and $11000 + 3000 = 14000$ Hz. Highest frequency $= 14$ kHz. Nyquist rate $= 2 \times 14 = 28.0$ kHz.
\boxed{28.0}

**出處**　Haykin, Communication Systems (sampling theorem); trigonometric product-to-sum identity

</details>

**3.1.8G004**　An interfering carrier at 143 kHz reaches an analog-to-digital converter that samples at 40 kHz with no anti-aliasing filter. Determine the apparent frequency of the interferer within 0 to $f_s/2$, in kHz, rounded to one decimal place.

<details><summary>看答案</summary>

**答案**　17.0

**詳解**　Remove whole multiples of $f_s$: $143 - 3 \times 40 = 23$ kHz. This is above $f_s/2 = 20$ kHz, so it folds: $40 - 23 = 17$ kHz. (Equivalently $|143 - 4 \times 40| = 17$ kHz.)
\boxed{17.0}

**出處**　Oppenheim & Schafer, Discrete-Time Signal Processing (aliasing / frequency folding)

</details>

**3.1.8G005**　Two baseband signals are multiplied: $y(t) = x_1(t)\,x_2(t)$, where $x_1(t)$ is strictly band-limited to 4 kHz and $x_2(t)$ is strictly band-limited to 6.5 kHz. Determine the largest sampling interval that still allows $y(t)$ to be sampled without aliasing, in microseconds, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　47.62

**詳解**　Multiplication in time is convolution in frequency, so the bandwidth of $y(t)$ is $4 + 6.5 = 10.5$ kHz. Nyquist rate $= 2 \times 10.5 = 21$ kHz. Largest sampling interval $T_s = 1/21000 = 4.7619 \times 10^{-5}$ s $= 47.62$ µs.
\boxed{47.62}

**出處**　Oppenheim & Schafer, Discrete-Time Signal Processing (sampling theorem; multiplication–convolution property)

#### 單題：Guard band, oversampling and anti-aliasing filter

**3.1.8G006**　An audio signal band-limited to 20 kHz is sampled at 44.1 kHz. Determine the guard band between the upper edge of the baseband spectrum and the lower edge of the first spectral image (the image centred at $f_s$), in kHz, rounded to one decimal place.

Determine the attenuation, in dB, at the lowest input frequency that aliases back into the 0–3.4 kHz band, rounded to two decimal places.

<details><summary>看答案</summary>

**3.1.8G009**　An ideal 12-bit uniform quantizer is driven by a full-scale sinusoid and is oversampled with an oversampling ratio $f_s/(2W) = 16$. Assume the quantization noise is white and uniformly spread from 0 to $f_s/2$, that no noise shaping is used, and that an ideal digital low-pass filter keeps only the band 0 to $W$. Using $\mathrm{SQNR} = 6.02N + 1.76$ dB for the full Nyquist band, determine the in-band SQNR in dB, rounded to two decimal places.

**3.1.8G010**　An anti-aliasing filter has a flat passband up to 20 kHz and reaches its full stopband attenuation at 28 kHz and above. Components between 20 kHz and 28 kHz are only partly attenuated and must not alias into the 0–20 kHz passband, although they may alias into the region above 20 kHz. Determine the minimum sampling rate in kHz, rounded to one decimal place.

**3.1.8G012**　A 12-bit uniform analog-to-digital converter has an input range of 0 V to 3.3 V. Assuming the quantization error is uniformly distributed over one step, determine the rms quantization noise voltage in µV, rounded to one decimal place.

<details><summary>看答案</summary>

#### 情境題：Sampling rate and aliasing

**Scenario | Vibration sensor on a microwave antenna mast**

A vibration sensor on a microwave antenna mast produces a signal whose useful content extends up to 1.2 kHz. The data logger samples it at 3.2 kHz. A cooling fan in the equipment cabinet couples a 2.9 kHz tone into the sensor cable, and the logger has no anti-aliasing filter.

**3.1.8S001**　By what percentage does the logger's sampling rate exceed the Nyquist rate of the useful signal? Give the answer in percent, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　33.33 %

**詳解**　Nyquist rate $= 2 \times 1.2 = 2.4$ kHz. Ratio $= 3.2/2.4 = 1.3333$. Excess $= (1.3333 - 1) \times 100 = 33.33\%$.

**出處**　Oppenheim & Schafer, Discrete-Time Signal Processing (Nyquist–Shannon sampling theorem)

</details>

**3.1.8S002**　At what frequency does the fan tone appear in the sampled data (within 0 to $f_s/2$)? Give the answer in Hz, rounded to the nearest integer.

<details><summary>看答案</summary>

**答案**　300 Hz

**詳解**　$f_s/2 = 1.6$ kHz. The tone at 2.9 kHz is above 1.6 kHz, so it aliases. Apparent frequency $= |2.9 - 1 \times 3.2| = 0.3$ kHz $= 300$ Hz, which lies inside 0–1.6 kHz (and inside the 0–1.2 kHz useful band).

**出處**　Oppenheim & Schafer, Discrete-Time Signal Processing (aliasing in periodic sampling)

</details>

**3.1.8S003**　An engineer proposes to keep the 3.2 kHz sampling rate and remove the fan tone afterwards with a digital filter in the logger software. Can this work without damaging the useful signal? Explain.

<details><summary>看答案</summary>

**答案**　No. After sampling, the aliased tone cannot be separated from real 300 Hz content; it must be filtered out before the sampler (or the sampling rate must be raised).

**詳解**　No. After sampling, the 2.9 kHz tone is indistinguishable from a genuine 300 Hz vibration component: both give exactly the same sample values. A digital notch at 300 Hz would also remove real vibration content at 300 Hz, and nothing in the samples says which part is the alias. Aliasing must be prevented before the sampler, with an analog low-pass (anti-aliasing) filter that attenuates everything above $f_s - W = 3.2 - 1.2 = 2.0$ kHz, or by sampling faster.

**出處**　Oppenheim & Schafer, Discrete-Time Signal Processing (aliasing; anti-aliasing prefilter)

</details>

**3.1.8S004**　Suppose the sampling rate is raised to 8 kHz, still with no analog filter. Where does the fan tone now appear, and can it then be removed digitally?

<details><summary>看答案</summary>

**答案**　It appears at its true frequency, 2.9 kHz, outside the useful band, so a digital low-pass filter can then remove it.

**詳解**　With $f_s = 8$ kHz, $f_s/2 = 4$ kHz, so the 2.9 kHz tone is below half the sampling rate and appears at its true frequency, 2.9 kHz. That is outside the 0–1.2 kHz useful band, so a digital low-pass filter with a cutoff between 1.2 kHz and 2.9 kHz removes it without touching the useful signal. Raising the sampling rate turns an in-band alias into an out-of-band component that digital filtering can separate.

**出處**　Oppenheim & Schafer, Discrete-Time Signal Processing (oversampling and digital filtering)

</details>

**3.1.8S005**　A second interferer at 7.1 kHz is found on the same cable. A technician computes where it appears with $f_s = 3.2$ kHz:
1. $f_s/2 = 1.6$ kHz.
2. Remove whole multiples of $f_s$: $7.1 - 2 \times 3.2 = 0.7$ kHz.
3. Fold about $f_s$: $3.2 - 0.7 = 2.5$ kHz.
4. The interferer appears at 2.5 kHz, outside the 1.2 kHz useful band.

Which step is wrong, and what is the correct result?

<details><summary>看答案</summary>

**答案**　Step 3 is wrong. Folding ($f_s - f$) is applied only when the remainder is above $f_s/2$. Here the remainder 0.7 kHz is already below 1.6 kHz, so it is the apparent frequency. (A result of 2.5 kHz is impossible anyway, because no sampled component can appear above $f_s/2 = 1.6$ kHz.) Correct result: the interferer appears at 0.7 kHz, inside the useful band.

**詳解**　$7.1 - 2 \times 3.2 = 0.7$ kHz; $0.7 < 1.6$, so no folding. Apparent frequency $= 0.7$ kHz $= 700$ Hz, which is below 1.2 kHz and therefore corrupts the useful signal.

**出處**　Oppenheim & Schafer, Discrete-Time Signal Processing (aliasing / frequency folding)

</details>

**答案**　Because the 10 MHz band lies entirely inside one Nyquist zone (56 MHz to 84 MHz), its spectral copies do not overlap; alias-free sampling depends on the occupied band, not only on the highest frequency.

**詳解**　What must not happen is overlap between the shifted copies of the spectrum. For a band-pass signal this depends on the occupied bandwidth and its position, not on the highest frequency alone. **3.1.8S018**　The amplifier output power is held constant for several minutes, so the detector voltage is an almost perfectly constant DC value. Does the $\Delta^2/12$ noise model still describe the quantization error, and will averaging many readings reduce the error?

<details><summary>看答案</summary>

**答案**　No to both: for a constant input the error is a fixed offset, not random noise, so the model does not apply and averaging identical readings does not reduce it.

**詳解**　No to both. The $\Delta^2/12$ model assumes the input moves across many quantization levels so that the error is spread uniformly over $\pm\Delta/2$ and is uncorrelated from sample to sample. For a constant input every sample has the same error (anywhere between $-\Delta/2$ and $+\Delta/2$): it is a fixed offset, not noise, and averaging identical readings does not reduce it. Averaging helps only if the input, or added noise (dither) of at least about one step, moves the signal across several levels.

**3.1.8S019**　The 10-bit ADC is replaced by a 12-bit ADC with the same 0–2.048 V range. By what factors do the step size, the rms quantization error and the quantization noise power change?

<details><summary>看答案</summary>

**答案**　They differ only by the rounding of the constants (6.0206 and 1.7609 rounded to 6.02 and 1.76); a problem statement must say which form to use.

**詳解**　They are the same formula with different rounding. $10\log_{10}(\tfrac32 \cdot 2^{2N}) = N \times 20\log_{10}2 + 10\log_{10}1.5 = 6.0206N + 1.7609$ dB. **3.1.8S029**　List the conditions under which $\mathrm{SQNR} = 6.02N + 1.76$ dB is valid, and say which part of the formula changes when the test signal is not a full-scale sinusoid.

<details><summary>看答案</summary>

**答案**　It needs a uniform quantizer, a full-scale sinusoid with no overload, an error uniformly distributed over one step (noise power $\Delta^2/12$), and noise counted over the whole Nyquist band. For other signals or levels the constant 1.76 dB changes; the $6.02N$ term stays.

**詳解**　Conditions: (1) uniform quantizer with $2^N$ equal steps; (2) sinusoidal input whose peaks just reach the ends of the range (full scale, no overload); (3) enough levels and enough signal activity that the error is uniformly distributed over one step and uncorrelated with the signal, giving noise power $\Delta^2/12$; (4) all of the quantization noise in 0 to $f_s/2$ is counted (no oversampling gain or noise shaping). **答案**　2.0 kbit/s

**詳解**　Frame duration $= 1/8000 = 125$ µs. Multiframe duration $= 16 \times 125$ µs $= 2$ ms. Each channel gets 4 bits per multiframe: $4/(2 \times 10^{-3}) = 2000$ bit/s $= 2.0$ kbit/s.

**出處**　ITU-T Recommendation G.704 (multiframe structure for channel-associated signalling in timeslot 16)

</details>

**3.1.8S053**　Why must the E1 frame repeat exactly 8000 times per second, rather than at some other convenient rate?

<details><summary>看答案</summary>

**答案**　Because each frame carries one sample of every channel, the frame rate must equal the 8 kHz sampling rate of the voice channels (one frame every 125 microseconds).

**詳解**　Each frame carries exactly one 8-bit sample of every voice channel. Each channel produces a new sample every $1/8000$ s $= 125$ µs (the G.711 sampling rate), so the multiplexer must offer each channel one timeslot every 125 µs. A slower frame rate would drop samples, and a faster one would have timeslots with no new sample to carry. The frame rate of a synchronous TDM system equals the sampling rate of the channels it carries.

**出處**　ITU-T Recommendation G.704; Haykin, Communication Systems (time-division multiplexing of PCM signals)

</details>

**3.1.8S054**　The line carries an unbroken stream of bits with no gaps between timeslots. What would happen to the 30 voice channels if the receiver did not know where a frame starts, and which part of the frame prevents this?

<details><summary>看答案</summary>

**答案**　All channels would be decoded from wrongly grouped bits and deliver wrong samples; the frame alignment signal in timeslot 0 prevents this.

**詳解**　The receiver separates channels only by counting bits from the start of the frame. If its count is offset, every 8-bit group it extracts is made of bits from two neighbouring timeslots or belongs to another channel, so all 30 channels deliver wrong sample values (noise or crosstalk) at once. The frame alignment signal, a fixed bit pattern sent in timeslot 0, lets the receiver find and continuously check the frame boundary; that is why one timeslot of capacity is spent on it.

**出處**　ITU-T Recommendation G.704 (frame alignment signal in timeslot 0)

</details>

**3.1.8S055**　A planner estimates how much data an E1 line carries in one hour (1 MB = $10^6$ bytes):
1. Line rate $= 2.048$ Mbit/s.
2. So the line carries 2.048 MB every second.
3. In one hour: $2.048 \times 3600 = 7372.8$ MB.

Which step is wrong, and what is the correct result?

<details><summary>看答案</summary>

**答案**　Step 2 is wrong: megabits were treated as megabytes. One byte is 8 bits, so 2.048 Mbit/s $= 0.256$ MB/s. Correct result: $0.256 \times 3600 = 921.6$ MB per hour.

**詳解**　$2.048 \times 10^{6}/8 = 256000$ bytes/s $= 0.256$ MB/s. $0.256 \times 3600 = 921.6$ MB.

**出處**　ITU-T Recommendation G.704 (2048 kbit/s); SI decimal prefixes (IEC 80000-13)

</details>

#### 情境題：Storage of PCM recordings

**Scenario | Call-recording archive of a contact centre**

A contact centre records every call and stores both directions of the conversation as separate G.711 PCM streams of 64 kbit/s each (8 kHz × 8 bits, taken here as given), with no compression. On an average day 1500 call-hours are recorded. File headers and file-system overhead are ignored, 1 kbit = 1000 bits, 1 MB = $10^6$ bytes and 1 GB = $10^9$ bytes.

**3.1.8S061**　Determine the storage needed for one average day of recordings in GB (1 GB = $10^9$ bytes), rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　86.40 GB

**詳解**　Per call, both directions: $2 \times 64000 = 128000$ bit/s $= 16000$ bytes/s. Per call-hour: $16000 \times 3600 = 5.76 \times 10^{7}$ bytes $= 57.6$ MB. Per day: $57.6 \times 1500 = 86400$ MB $= 86.40$ GB.

**出處**　ITU-T Recommendation G.711 (64 kbit/s PCM); SI decimal prefixes (IEC 80000-13)

</details>

**3.1.8S062**　The operating system of the storage server reports the same day of recordings as about 80.47 "GB". Has any data been lost? Explain the discrepancy.

<details><summary>看答案</summary>

**答案**　No data is lost. The system reports binary gigabytes (GiB, $2^{30}$ bytes), which are about 7.4 % larger than $10^9$ bytes, so the same number of bytes gives a smaller figure.

**詳解**　Nothing is lost. The operating system is counting in binary units: 1 GiB $= 2^{30} = 1\,073\,741\,824$ bytes, about 7.4 % larger than the decimal gigabyte of $10^9$ bytes. $86.4 \times 10^{9}$ bytes divided by $2^{30}$ is 80.47 GiB. The number of bytes is identical; only the size of the unit differs. Capacity planning must use one convention on both sides (recording volume and disk size) and name it.

**出處**　IEC 80000-13 (decimal prefixes and binary prefixes)

</details>

**3.1.8S063**　The centre plans to move to wideband recording with uncompressed linear PCM at 16 kHz and 16 bits per sample per direction. Without doing the full calculation, by what factor does the storage requirement change, and why?

<details><summary>看答案</summary>

**答案**　By a factor of 4: the sampling rate doubles and the bits per sample double, so each stream goes from 64 kbit/s to 256 kbit/s (345.6 GB per day).

**詳解**　By a factor of 4. Storage is proportional to the bit rate $f_s \times N$ for a fixed duration and number of streams. The sampling rate doubles (8 kHz to 16 kHz) and the bits per sample double (8 to 16), so each stream goes from 64 kbit/s to 256 kbit/s. One day of recordings would need $4 \times 86.4 = 345.6$ GB.

**出處**　Haykin, Communication Systems (PCM bit rate $R_b = N f_s$)

</details>

**3.1.8S064**　A technician computes the storage for one hour of one direction of a call (1 MB = $10^6$ bytes):
1. Bit rate $= 64$ kbit/s $= 64000$ bit/s.
2. In one hour: $64000 \times 3600 = 230\,400\,000$.
3. Size $= 230\,400\,000/10^{6} = 230.4$ MB.

Which step is wrong, and what is the correct result?

<details><summary>看答案</summary>

**答案**　Step 3 is wrong. The number from step 2 is in bits, and it was divided by $10^6$ as if it were bytes. It must first be divided by 8: $230\,400\,000/8 = 28\,800\,000$ bytes $= 28.8$ MB.

**詳解**　$64000 \times 3600 = 2.304 \times 10^{8}$ bits. $2.304 \times 10^{8}/8 = 2.88 \times 10^{7}$ bytes. $2.88 \times 10^{7}/10^{6} = 28.8$ MB.

**出處**　ITU-T Recommendation G.711 (64 kbit/s PCM); SI decimal prefixes (IEC 80000-13)

</details>

**3.1.8S065**　Another technician repeats the calculation for one hour of one direction (1 MB = $10^6$ bytes):
1. Bit rate $= 64$ kbit/s $= 64 \times 1024 = 65536$ bit/s.
2. Bytes per second $= 65536/8 = 8192$.
3. In one hour: $8192 \times 3600 = 29\,491\,200$ bytes $= 29.49$ MB.

Which step is wrong, and what is the correct result?

<details><summary>看答案</summary>

**答案**　Step 1 is wrong. In transmission rates the prefix kilo is decimal: 64 kbit/s is exactly 64000 bit/s ($8000$ samples/s $\times$ 8 bits), not $64 \times 1024$. Correct: $64000/8 = 8000$ bytes/s, and one hour is $8000 \times 3600 = 28\,800\,000$ bytes $= 28.80$ MB.

**詳解**　$8000 \times 8 = 64000$ bit/s. $64000/8 = 8000$ bytes/s. $8000 \times 3600 = 2.88 \times 10^{7}$ bytes $= 28.80$ MB.

**出處**　ITU-T Recommendation G.711 (8000 samples/s, 8 bits per sample); SI decimal prefixes (IEC 80000-13)

</details>
