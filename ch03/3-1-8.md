# 3.1.8 取樣、量化與 PCM

所屬：[3.1 訊號與通道](3-1.md)

## 內文

#### 為什麼要學

語音、影像、無線電波形本來都是連續的類比訊號，要進入數位網路就得經過取樣（sampling）、量化（quantization）、編碼三個步驟，合起來稱為脈波編碼調變（pulse code modulation, PCM）。取樣率太低會發生混疊（aliasing），訊號無法還原；量化位元數太少，量化雜訊就大。這兩個參數相乘就是位元率，直接決定傳輸線路與儲存空間的需求：傳統電話網路的 64 kbit/s 語音通道、基地臺射頻單元與基頻單元之間傳送取樣資料所需的前傳容量、類比數位轉換器（ADC）該選幾位元，都是這一節的計算。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $f_{\max}$（或 $W$） | 訊號的最高頻率（基頻訊號的頻寬） | Hz |
| $f_s$ | 取樣率 | Hz（樣本／秒） |
| $T_s$ | 取樣間隔，$T_s = 1/f_s$ | s |
| $f_a$ | 混疊後出現的頻率 | Hz |
| $N$ | 每個樣本的量化位元數 | bit |
| $L$ | 量化階數，$L = 2^N$ | 無因次 |
| $V$ | 量化器的滿刻度峰值（輸入範圍 $-V \sim +V$） | V |
| $\Delta$ | 量化間隔（step size） | V |
| $\sigma_q^2$ | 量化雜訊功率 | V² |
| $\sigma_x^2$ | 訊號功率 | V² |
| $\text{SQNR}$ | 訊號對量化雜訊比 | 無因次，或 dB |
| $R_b$ | PCM 位元率 | bit/s |

#### 公式與推導

**取樣定理。** 最高頻率為 $f_{\max}$ 的帶限基頻訊號，只要取樣率滿足

$$f_s > 2f_{\max}$$

就能由樣本完整重建；$2f_{\max}$ 稱為 Nyquist 取樣率，$f_s/2$ 稱為 Nyquist 頻率。道理是：在時間域每隔 $T_s$ 取樣，等於把頻譜以 $f_s$ 為週期重複排列；$f_s$ 夠大時各份頻譜不重疊，用低通濾波器就能取回原訊號。取樣率不夠時相鄰的頻譜重疊，高於 $f_s/2$ 的成分會「摺回」低頻，出現在

$$f_a = \lvert f - m f_s\rvert\quad(m\ \text{為使}\ f_a \le f_s/2\ \text{的整數})$$

這就是混疊，事後無法分離，所以取樣前一定要先用抗混疊濾波器把超過 $f_s/2$ 的成分濾掉。實際濾波器不是理想的，取樣率要比 $2f_{\max}$ 再高一些，留出過渡帶。

**均勻量化。** 把 $-V$ 到 $+V$ 的範圍等分成 $L = 2^N$ 階，量化間隔

$$\Delta = \frac{2V}{L} = \frac{2V}{2^N}$$

當階數夠多、輸入沒有超出範圍時，量化誤差可視為在 $\pm\Delta/2$ 之間均勻分布、和訊號無關的雜訊，功率為

$$\sigma_q^2 = \frac{1}{\Delta}\int_{-\Delta/2}^{\Delta/2}e^2\,de = \frac{\Delta^2}{12}$$

**SQNR。** 輸入為剛好打滿刻度的正弦波（振幅 $V$）時，訊號功率是 $V^2/2$，所以

$$\text{SQNR} = \frac{V^2/2}{\Delta^2/12} = \frac{V^2/2}{(2V/2^N)^2/12} = \frac{3}{2}\cdot2^{2N}$$

$$\text{SQNR(dB)} = 10\log_{10}1.5 + 20N\log_{10}2 = 1.76 + 6.02N$$

這個式子的前提是三件事：**均勻量化、輸入是滿刻度正弦波、量化誤差可視為均勻分布的白雜訊**。每多 1 個位元，SQNR 增加 6.02 dB，這一點對一般訊號都成立；但常數項 1.76 dB 只屬於滿刻度正弦波。一般情況可以寫成 $\text{SQNR(dB)} = 6.02N + 4.77 - 20\log_{10}(V/\sigma_x)$，其中 $V/\sigma_x$ 是滿刻度峰值對訊號方均根值的比：正弦波時 $V/\sigma_x = \sqrt2$（3.01 dB）就回到 1.76；輸入位準比滿刻度低幾 dB，SQNR 就少幾 dB；峰均比高的訊號（例如 OFDM）要預留更多餘裕，SQNR 也更低。

**PCM 位元率。** 每秒 $f_s$ 個樣本、每個樣本 $N$ 位元：

$$R_b = f_s \times N$$

多聲道或多路訊號再乘上路數。

#### 算例

**算例 1：電話語音的 PCM**

已知：ITU-T G.711 的語音 PCM 取樣率為 8,000 樣本／秒，每個樣本 8 位元；電話語音頻帶上限取 3.4 kHz。求 Nyquist 取樣率、位元率、一分鐘的資料量，以及若有一個 5 kHz 的單音沒被濾掉會混疊到哪裡。

- Nyquist 取樣率：$2\times3.4 = 6.8$ kHz；實際取 8 kHz，Nyquist 頻率 4 kHz，留有 0.6 kHz 的過渡帶給抗混疊濾波器。
- 位元率：$R_b = 8000\times8 = 64{,}000$ bit/s＝64 kbit/s。
- 一分鐘資料量：$64{,}000\times60 = 3{,}840{,}000$ bit，除以 8 得 480,000 byte。
- 混疊：$f_a = \lvert5 - 8\rvert = 3$ kHz，落在語音頻帶內，聽起來是一個原本不存在的 3 kHz 聲音。
- 合理性檢查：64 kbit/s 正是傳統數位電話一個話路的速率。要注意 G.711 用的是非均勻量化（A 律或 μ 律壓擴），讓小訊號也有足夠的 SQNR，所以不能把 $6.02\times8 + 1.76 = 49.92$ dB 直接當成它的效能。

**算例 2：ADC 位元數與 SQNR**

已知：12 位元均勻量化的 ADC，輸入範圍 ±1 V，輸入為滿刻度正弦波。求量化間隔、量化雜訊方均根值與 SQNR；若要求 SQNR 至少 70 dB，最少需要幾位元。

- $\Delta = 2\times1/2^{12} = 2/4096 = 0.4883$ mV。
- 量化雜訊功率：$\Delta^2/12 = (4.883\times10^{-4})^2/12 = 1.987\times10^{-8}$ V²，方均根值 $\Delta/\sqrt{12} = 0.141$ mV。
- 訊號功率：$1^2/2 = 0.5$ V²。$\text{SQNR} = 0.5/(1.987\times10^{-8}) = 2.517\times10^7$，即 74.01 dB。
- 用公式核對：$6.02\times12 + 1.76 = 74.00$ dB，一致（0.01 的差來自 6.02 與 1.76 的取位）。
- 最少位元數：$6.02N + 1.76 \ge 70$，$N \ge 68.24/6.02 = 11.34$，取整數為 12 位元。
- 合理性檢查：11 位元只有 $6.02\times11 + 1.76 = 67.98$ dB，不足 70 dB；12 位元有 74 dB，夠用。若輸入比滿刻度低 12 dB，SQNR 會降到約 62 dB，就不夠了，所以選位元數時還要考慮輸入位準的餘裕。

#### 常見錯誤

- **取樣率只取到「等於」$2f_{\max}$ 或拿訊號的中心頻率來算**：基頻訊號看最高頻率，而且實務上要高於 2 倍並搭配抗混疊濾波器。
- **把 $6.02N + 1.76$ 套到任何訊號**：常數 1.76 dB 只對滿刻度正弦波、均勻量化成立；輸入位準降低或訊號峰均比高時都要扣。
- **階數與位元數弄混**：$L = 2^N$，256 階是 8 位元，不是 256 位元；$\Delta = 2V/L$ 的分子是峰對峰範圍。
- **bit 與 byte、k 與 M 沒換**：64 kbit/s 等於每秒 8,000 byte；算儲存空間時要除以 8。

#### 和其他小節的關係

取樣定理的頻譜解釋來自 3.1.7 的傅立葉轉換性質；量化雜訊和 3.1.5 的熱雜訊一樣可視為加成性雜訊，在 3.1.6 的 SNR 計算裡與其他雜訊以線性功率相加。本節的 PCM 位元率接到 3.2.7 的位元率、符號率與所需頻寬，以及 3.4.5 的吞吐量分析；Nyquist 取樣率與 3.2.7 的 Nyquist 無符號間干擾準則名稱相近但講的是不同的事。量化誤差的均勻分布與變異數計算用到 3.5.2。
