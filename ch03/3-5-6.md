# 3.5.6 馬可夫決策過程

所屬：[3.5 基礎數理](3-5.md)

## 內文

#### 為什麼要學

許多網路控制問題不是做一次決定就結束，而是每個時槽都要決定，而且現在的決定會影響之後的狀態。例如基地台在低負載時關閉部分載波可以省電，但流量回升時可能來不及應付而造成壅塞；排程器現在把資源給了某個用戶，其他用戶的佇列就會變長。馬可夫決策過程（Markov decision process, MDP）就是描述這類「逐步決策、結果帶有隨機性」問題的標準模型，也是強化學習（reinforcement learning）的數學基礎，近年用於節能、排程、換手參數調整與切片資源管理的研究。本節說明 MDP 的組成、貝爾曼方程式（Bellman equation），以及用價值迭代（value iteration）求最佳策略的做法。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $s$、$s'$ | 目前狀態、下一個狀態 | 無單位 |
| $a$ | 動作 | 無單位 |
| $P(s'\mid s,a)$ | 在狀態 $s$ 採取動作 $a$ 後轉移到 $s'$ 的機率 | 無單位 |
| $R(s,a)$ | 在狀態 $s$ 採取動作 $a$ 的即時報酬（期望值） | 報酬單位 |
| $\gamma$ | 折扣因子，$0\le\gamma<1$ | 無單位 |
| $\pi$ | 策略：每個狀態要採取哪個動作 | 無單位 |
| $V^\pi(s)$ | 依策略 $\pi$ 由狀態 $s$ 出發的期望折扣總報酬 | 報酬單位 |
| $V^*(s)$ | 最佳價值函數 | 報酬單位 |
| $Q(s,a)$ | 動作價值：先做 $a$、之後照既定方式行動的價值 | 報酬單位 |
| $V_k(s)$ | 價值迭代第 $k$ 步的估計值 | 報酬單位 |

#### 公式與推導

一個 MDP 由狀態集合、動作集合、轉移機率 $P(s'\mid s,a)$、報酬 $R(s,a)$ 與折扣因子 $\gamma$ 組成。「馬可夫」的意思是下一個狀態與報酬只取決於目前的狀態與動作。若固定一個策略，MDP 就退化成 3.5.4 的馬可夫鏈。

目標是讓折扣總報酬的期望值最大：

$$G = r_0 + \gamma r_1 + \gamma^2 r_2 + \cdots = \sum_{t=0}^{\infty}\gamma^t r_t$$

$\gamma$ 越接近 1 越重視長期，越接近 0 越短視。若每一步的報酬都是常數 $r$，則 $G = r/(1-\gamma)$；因此只要報酬的絕對值不超過 $R_{\max}$，任何價值都落在 $\pm R_{\max}/(1-\gamma)$ 之內，可用來檢查答案。

把總報酬拆成「這一步的報酬」加上「折扣後的後續價值」，就得到貝爾曼最佳方程式：

$$V^*(s) = \max_a\left[R(s,a) + \gamma\sum_{s'}P(s'\mid s,a)\,V^*(s')\right]$$

價值迭代把這條式子當成更新規則反覆套用。從任意初值（通常取 $V_0 = 0$）開始：

$$Q_{k+1}(s,a) = R(s,a) + \gamma\sum_{s'}P(s'\mid s,a)\,V_k(s'),\qquad V_{k+1}(s) = \max_a Q_{k+1}(s,a)$$

每次更新都用上一輪的 $V_k$ 計算所有狀態（同步更新）。對有限的狀態與動作且 $\gamma<1$，每迭代一次，與 $V^*$ 的最大誤差至少縮小為 $\gamma$ 倍，所以一定收斂。收斂後在每個狀態選擇讓 $Q$ 最大的動作，就是最佳策略。$V_k$ 的意義也很直觀：它是「只剩 $k$ 步可以決策」時的最佳期望報酬。

如果只想評估某個固定策略 $\pi$，把 $\max$ 拿掉即可：$V^\pi(s) = R(s,\pi(s)) + \gamma\sum_{s'}P(s'\mid s,\pi(s))\,V^\pi(s')$，這是一組線性方程式，狀態少時可以直接解。

#### 算例

**算例 1：節能決策的價值迭代兩步。** 已知（假設）：某細胞有兩個狀態，「順暢」（N）與「壅塞」（C）；每個時槽可選「省電」（關閉部分載波）或「全開」。折扣因子 $\gamma = 0.9$，初值 $V_0(\text{N}) = V_0(\text{C}) = 0$。報酬與轉移機率如下表。

| 狀態 | 動作 | 即時報酬 | 轉到 N 的機率 | 轉到 C 的機率 |
|---|---|---|---|---|
| N | 省電 | $+2$ | 0.6 | 0.4 |
| N | 全開 | $+1$ | 0.9 | 0.1 |
| C | 省電 | $-3$ | 0.2 | 0.8 |
| C | 全開 | $-1$ | 0.7 | 0.3 |

第 1 步（$V_0$ 全為 0，所以 $Q_1$ 就是即時報酬）：

- $V_1(\text{N}) = \max(2,\ 1) = 2$（省電）
- $V_1(\text{C}) = \max(-3,\ -1) = -1$（全開）

第 2 步（用 $V_1(\text{N}) = 2$、$V_1(\text{C}) = -1$）：

- $Q_2(\text{N},\text{省電}) = 2 + 0.9\,(0.6\times2 + 0.4\times(-1)) = 2 + 0.9\times0.8 = 2.72$
- $Q_2(\text{N},\text{全開}) = 1 + 0.9\,(0.9\times2 + 0.1\times(-1)) = 1 + 0.9\times1.7 = 2.53$
- $Q_2(\text{C},\text{省電}) = -3 + 0.9\,(0.2\times2 + 0.8\times(-1)) = -3 + 0.9\times(-0.4) = -3.36$
- $Q_2(\text{C},\text{全開}) = -1 + 0.9\,(0.7\times2 + 0.3\times(-1)) = -1 + 0.9\times1.1 = -0.01$

所以 $V_2(\text{N}) = 2.72$（省電）、$V_2(\text{C}) = -0.01$（全開）。

合理性檢查：每列的兩個轉移機率相加都是 1。考慮了後續影響之後，順暢狀態下「省電」領先「全開」的幅度由第 1 步的 1.00 縮小到 0.19，因為省電比較容易掉進壅塞；壅塞狀態下「全開」的優勢則由 2.00 擴大到 3.35。

**算例 2：再迭代一步並和收斂值比較。** 沿用上題，用 $V_2$ 再算第 3 步，並檢查「N 省電、C 全開」這個策略的長期價值。

1. $Q_3(\text{N},\text{省電}) = 2 + 0.9\,(0.6\times2.72 + 0.4\times(-0.01)) = 2 + 0.9\times1.628 = 3.4652$
2. $Q_3(\text{N},\text{全開}) = 1 + 0.9\,(0.9\times2.72 + 0.1\times(-0.01)) = 1 + 0.9\times2.447 = 3.2023$
3. $Q_3(\text{C},\text{省電}) = -3 + 0.9\,(0.2\times2.72 + 0.8\times(-0.01)) = -3 + 0.9\times0.536 = -2.5176$
4. $Q_3(\text{C},\text{全開}) = -1 + 0.9\,(0.7\times2.72 + 0.3\times(-0.01)) = -1 + 0.9\times1.901 = 0.7109$
5. $V_3(\text{N}) = 3.4652$（省電）、$V_3(\text{C}) = 0.7109$（全開），策略沒有改變。
6. 固定此策略解線性方程式：$V(\text{N}) = 2 + 0.9\,(0.6V(\text{N}) + 0.4V(\text{C}))$、$V(\text{C}) = -1 + 0.9\,(0.7V(\text{N}) + 0.3V(\text{C}))$，整理為 $0.46V(\text{N}) - 0.36V(\text{C}) = 2$ 與 $-0.63V(\text{N}) + 0.73V(\text{C}) = -1$，解得 $V(\text{N}) = 10.09$、$V(\text{C}) = 7.34$（取到小數第二位）。

合理性檢查：報酬的絕對值最大為 3，價值的上限是 $3/(1-0.9) = 30$，10.09 與 7.34 都在範圍內。$V_3$ 離收斂值還很遠（3.47 對 10.09），因為 $\gamma = 0.9$ 時誤差每步只縮小一成左右；但最佳動作在第 1 步就已經確定，之後沒有再變。在這個例子裡把收斂值代回貝爾曼方程式，N 狀態「省電」為 10.09、「全開」為 9.83，C 狀態「全開」為 7.34、「省電」為 4.10，確認此策略最佳。

#### 常見錯誤

- 更新 $V_{k+1}$ 時混用新舊值，例如算 $V_2(\text{C})$ 時用了剛算好的 $V_2(\text{N})$。同步更新要一律使用上一輪的 $V_k$。
- 把折扣因子乘到即時報酬上，或忘記乘在後續價值上。正確形式是 $R + \gamma\sum P\,V$。
- 只比較即時報酬就決定動作（等於只做第 1 步）。本例兩者結論相同只是巧合，報酬或轉移機率改變時就可能不同。
- 把迭代一兩步的 $V_k$ 當成最佳價值 $V^*$。$V_k$ 是只看 $k$ 步的結果，$\gamma$ 越接近 1 收斂越慢。

#### 和其他小節的關係

固定策略後的 MDP 就是 3.5.4 的馬可夫鏈，轉移機率的運算用到 3.5.7 的矩陣乘法；$\max$ 運算與策略評估的線性方程式和 3.5.5 的最佳化相關；狀態中的佇列長度、延遲等量來自 3.4.3 與 3.4.5 的排隊與延遲分析。
