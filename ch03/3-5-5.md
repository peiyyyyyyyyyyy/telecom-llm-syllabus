# 3.5.5 線性與凸最佳化

所屬：[3.5 基礎數理](3-5.md)

## 內文

#### 為什麼要學

無線資源永遠不夠用：資源區塊、發射功率、回傳容量都有上限，網路要在這些限制下讓吞吐量或營收最大。這類問題寫成數學就是最佳化（optimization）：一個目標函數加上一組限制式。目標與限制都是一次式時稱為線性規劃（linear programming, LP），常用於切片或業務之間的資源配置；目標是凹函數（例如 Shannon 容量的對數形式）且限制為線性時屬於凸最佳化（convex optimization），可以用拉格朗日乘數（Lagrange multiplier）求出解析解。其中最有名的結果是注水法（water-filling）：把固定的總功率分給多個平行通道（OFDM 的子載波、MIMO 的特徵通道）時，好通道多給、太差的通道乾脆不給。本節用小例子把這三種工具各算一次。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $\mathbf{x}$ | 決策變數向量（例如各業務分到的資源量） | 視情境而定 |
| $\mathbf{c}^{\mathsf T}\mathbf{x}$ | 線性目標函數 | 視情境而定 |
| $\mathbf{A}\mathbf{x}\le\mathbf{b}$ | 線性限制式 | 視情境而定 |
| $\mathcal{L}$ | 拉格朗日函數 | 與目標函數相同 |
| $\nu$ | 拉格朗日乘數（對應總功率限制） | 目標單位／限制單位 |
| $P$ | 總功率上限 | W |
| $p_i$ | 分給第 $i$ 個通道的功率 | W |
| $n_i$ | 第 $i$ 個通道的等效雜訊，$n_i = N_i/g_i$（雜訊功率除以通道功率增益） | W |
| $\mu$ | 水位（water level） | W |
| $(x)^+$ | $\max(x, 0)$ | 與 $x$ 相同 |

#### 公式與推導

**線性規劃。** 標準寫法是

$$\max_{\mathbf{x}}\ \mathbf{c}^{\mathsf T}\mathbf{x}\quad\text{受限於}\quad \mathbf{A}\mathbf{x}\le\mathbf{b},\ \ \mathbf{x}\ge\mathbf{0}$$

限制式圍出的可行區域是一個凸多面體。如果最佳值存在且有限，一定可以在某個頂點取得，所以只有兩個變數的小問題可以把所有頂點列出來逐一比較。每條限制式對應一個對偶變數（影子價格），代表該資源多一單位時目標值能增加多少；在最佳解上，原問題與對偶問題的目標值相等，可用來驗算。

**拉格朗日乘數。** 要在等式限制 $g(\mathbf{x}) = c$ 下求 $f(\mathbf{x})$ 的極值，建立 $\mathcal{L}(\mathbf{x},\nu) = f(\mathbf{x}) - \nu\,\big(g(\mathbf{x}) - c\big)$，令它對每個變數的偏微分為零，再和限制式聯立。若還有 $x_i\ge0$ 這類不等式限制，則改用 KKT（Karush–Kuhn–Tucker）條件：變數為正時偏微分為零，變數被壓在 0 時偏微分不大於零。對凸問題（最大化凹函數、限制為線性），滿足 KKT 條件的點就是全域最佳解。

**注水法。** 有 $K$ 個互不干擾的平行通道，第 $i$ 個通道的訊雜比是 $p_i/n_i$，每單位頻寬的總速率是

$$\max_{p_1,\dots,p_K}\ \sum_{i=1}^K \log_2\!\left(1 + \frac{p_i}{n_i}\right)\quad\text{受限於}\quad \sum_{i=1}^K p_i = P,\ \ p_i\ge0$$

對 $p_i$ 微分：$\dfrac{1}{\ln2}\cdot\dfrac{1}{n_i + p_i} = \nu$。這表示凡是分到功率的通道，$n_i + p_i$ 都等於同一個常數 $\mu = 1/(\nu\ln2)$；若某通道的 $n_i$ 已經高於 $\mu$，它的功率就是 0。因此

$$p_i = (\mu - n_i)^+,\qquad \mu\ \text{由}\ \sum_{i=1}^K(\mu - n_i)^+ = P\ \text{決定}$$

想像一個底部高低不平的容器，第 $i$ 格的底部高度是 $n_i$，倒入總量為 $P$ 的水，水面高度就是 $\mu$，各格的水深就是功率；底部高出水面的格子沒有水。實作步驟：把通道依 $n_i$ 由小到大排序，先假設全部都用，算 $\mu = (P + \sum n_i)/K$；若最差的通道 $n_i\ge\mu$，就把它剔除再重算，直到所有留下的通道都滿足 $n_i < \mu$。這個結果的前提是發射端知道各通道的 $n_i$、通道之間互不干擾，且只有總功率限制。

#### 算例

**算例 1：兩種業務的資源配置（線性規劃）。** 已知（假設）：某細胞要把資源區塊分給業務 A 與業務 B，$x_1$、$x_2$ 為各自分到的資源區塊數。每個資源區塊的收益 A 為 3 單位、B 為 2 單位。限制：資源區塊總數 $x_1 + x_2\le100$；A 每個資源區塊耗用 2 單位功率、B 耗用 1 單位，功率預算 $2x_1 + x_2\le150$；$x_1, x_2\ge0$。求最大收益。

1. 列出可行區域的頂點：$(0,0)$、$(75,0)$（功率限制與橫軸的交點）、$(0,100)$（資源限制與縱軸的交點），以及兩條限制式的交點。
2. 交點：兩式相減得 $x_1 = 50$，代回得 $x_2 = 50$。
3. 各頂點的收益 $3x_1 + 2x_2$：$(0,0)\to0$；$(75,0)\to225$；$(0,100)\to200$；$(50,50)\to250$。
4. 最佳解是 $x_1 = x_2 = 50$，收益 250 單位。

合理性檢查：在 $(50,50)$，資源用量 $50 + 50 = 100$、功率用量 $100 + 50 = 150$，兩個限制都剛好用滿。對偶驗算：設兩個限制的影子價格為 $y_1$、$y_2$，解 $y_1 + 2y_2 = 3$、$y_1 + y_2 = 2$ 得 $y_1 = y_2 = 1$，對偶目標 $100y_1 + 150y_2 = 250$，與原問題相等。只做收益較高的 A（225）或只做省功率的 B（200）都不如混合配置。

**算例 2：三個平行通道的注水功率分配。** 已知（假設）：三個通道的等效雜訊 $n_1 = 0.1$ W、$n_2 = 0.5$ W、$n_3 = 2.0$ W，總功率 $P = 1$ W。求各通道功率與總速率。

1. 先假設三個通道都用：$\mu = (1 + 0.1 + 0.5 + 2.0)/3 = 1.2$ W。但 $n_3 = 2.0 > 1.2$，通道 3 會得到負功率，不可行，剔除。
2. 只用通道 1、2：$\mu = (1 + 0.1 + 0.5)/2 = 0.8$ W。$n_2 = 0.5 < 0.8$，可行；且 $n_3 = 2.0 > 0.8$，確認通道 3 不用。
3. 功率：$p_1 = 0.8 - 0.1 = 0.7$ W，$p_2 = 0.8 - 0.5 = 0.3$ W，$p_3 = 0$ W。
4. 檢查總和：$0.7 + 0.3 + 0 = 1.0$ W，等於 $P$。
5. 速率：通道 1 為 $\log_2(1 + 0.7/0.1) = \log_28 = 3.000$；通道 2 為 $\log_2(1 + 0.3/0.5) = \log_21.6 = 0.678$；合計 3.678 bit/s/Hz。

合理性檢查：若改成三個通道各分 $1/3$ W，速率是 $\log_2(4.333) + \log_2(1.667) + \log_2(1.167) = 2.115 + 0.737 + 0.222 = 3.075$ bit/s/Hz，比注水法少約 0.60 bit/s/Hz。注水法把最差的通道關掉、把功率集中到好通道，總速率反而較高。

#### 常見錯誤

- 算出負的功率就直接採用，或只把負值改成 0 而沒有重算水位。剔除通道後必須用剩下的通道重新求 $\mu$，否則功率總和不等於 $P$。
- 用線性的 $n_i$ 推導，卻代入 dB 值。注水法的 $n_i$、$p_i$、$\mu$ 都是線性功率。
- 以為「通道越差越要多給功率來補」。那是讓各通道速率相等的做法（通道反轉），不是讓總速率最大的做法。
- 線性規劃只檢查一個頂點，或漏掉兩條限制式的交點，就宣稱找到最佳解。

#### 和其他小節的關係

注水法的目標函數來自 3.2.1 的 Shannon 容量；平行通道在 3.2.5 是 OFDM 子載波，在 3.2.6 是 MIMO 的特徵通道，其增益由 3.5.7 的奇異值決定。線性規劃可用於 3.4.6 多重存取的資源配置；會隨時間演變的決策問題則交給 3.5.6。
