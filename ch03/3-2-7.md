# 3.2.7 位元率、符號率、頻寬與 Nyquist 準則

所屬：[3.2 容量](3-2.md)

## 內文

#### 為什麼要學

一條數位鏈路有三個常被混在一起的量：位元率（每秒幾個位元）、符號率（每秒幾個調變符號）與占用頻寬（幾 Hz）。調變階數把位元率和符號率連起來，脈波成形濾波器的滾降係數把符號率和頻寬連起來。微波回傳、衛星鏈路、有線電視與光傳輸的規劃，都是在固定的頻道頻寬裡決定符號率，再由調變與碼率決定淨速率；頻譜分析儀上看到的訊號寬度，也是由符號率與滾降係數決定。Nyquist 準則則說明了在有限頻寬內，符號最快能送多快而不產生符號間干擾（intersymbol interference, ISI），是這些換算的理論底線。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $R_b$ | 位元率（這裡指調變器輸入的編碼後位元率） | bit/s |
| $R_s$ | 符號率（鮑率），$R_s=1/T$ | 符號/s（baud） |
| $T$ | 符號週期 | s |
| $M$ | 調變階數（星座點數），每符號 $\log_2M$ 個位元 | 無單位 |
| $\alpha$ | 升餘弦濾波器的滾降係數（roll-off factor），$0\le\alpha\le1$ | 無單位 |
| $W$ | 基頻通道頻寬（單邊，0 到 $W$） | Hz |
| $B$ | 訊號占用頻寬（基頻指單邊，帶通指載波兩側合計） | Hz |
| $R_c$ | 通道編碼的碼率 | 無單位 |
| $\eta$ | 頻譜效率 | bit/s/Hz |

#### 公式與推導

**位元率與符號率。** 每個符號載 $\log_2M$ 個位元，所以

$$R_s = \frac{R_b}{\log_2 M},\qquad R_b = R_s\log_2 M$$

若有通道編碼，資訊位元率是 $R_b\times R_c$。頻寬由符號率決定，不是由位元率決定：同樣的頻寬，提高 $M$ 可以多送位元，代價是 3.2.3 所說的更高 $E_b/N_0$ 需求。

**Nyquist 無符號間干擾準則。** 接收端每隔 $T$ 取樣一次。若整體脈波（發射濾波器、通道、接收濾波器合起來）$p(t)$ 在取樣點滿足 $p(0)=1$、$p(kT)=0$（$k\ne0$），相鄰符號就不會互相干擾。換到頻域，這個條件等於脈波頻譜以 $1/T$ 為間隔平移後疊加起來是常數：

$$\sum_{k=-\infty}^{\infty}P\!\left(f+\frac{k}{T}\right) = T$$

由此可知，基頻頻寬 $W$ 的通道最多只能以 $R_s = 2W$ 的符號率傳送而沒有符號間干擾；反過來說，符號率 $R_s$ 所需的**最小基頻頻寬**是

$$B_{\min} = \frac{R_s}{2} = \frac{1}{2T}$$

這個最小頻寬稱為 Nyquist 頻寬，對應的脈波是 sinc 函數（理想矩形頻譜）。但 sinc 脈波的尾巴衰減很慢，取樣時間稍有偏差就產生很大的干擾，濾波器也做不出來，所以實際系統會多用一點頻寬。

**升餘弦（raised cosine）頻譜。** 最常用的折衷是升餘弦脈波，頻譜在 $|f|\le\frac{1-\alpha}{2T}$ 內是平的，在 $\frac{1-\alpha}{2T}<|f|\le\frac{1+\alpha}{2T}$ 之間以半個餘弦波形平滑降到零，之外為零。它滿足 Nyquist 準則，占用的頻寬是

$$B_{\text{基頻}} = \frac{R_s}{2}(1+\alpha),\qquad B_{\text{帶通}} = R_s(1+\alpha)$$

$\alpha$ 是超出 Nyquist 頻寬的比例：$\alpha=0$ 退化成理想 sinc，$\alpha=1$ 時頻寬加倍。$\alpha$ 越大，脈波尾巴衰減越快、對取樣時間誤差越不敏感，但越占頻寬。實作上通常把升餘弦拆成兩個根升餘弦（root raised cosine）濾波器，發射端與接收端各一個，合起來是升餘弦，接收端那一個同時也是匹配濾波器。

**基頻與帶通的區別。** 基頻訊號的頻譜從 $-B$ 到 $+B$，習慣上只算正頻率那一半，所以是 $\frac{R_s}{2}(1+\alpha)$。把它調變到載波上（例如 QAM、PSK）後，正負兩半都搬到載波兩側，占用的射頻頻寬是兩倍，即 $R_s(1+\alpha)$。因此帶通線性調變的頻譜效率為

$$\eta = \frac{R_b}{B_{\text{帶通}}} = \frac{\log_2 M}{1+\alpha}\quad[\text{bit/s/Hz}]$$

上限是 $\alpha=0$ 時的 $\log_2M$。帶通訊號雖然頻寬加倍，但同相與正交兩路各載一個實數符號，所以每 Hz 可送的實數符號數和基頻相同，都是每秒每 Hz 2 個，並沒有浪費。這些式子適用於單載波線性調變；OFDM 的頻寬由子載波數與子載波間隔決定（見 3.2.5），不套用滾降係數的算法。

#### 算例

**算例 1（由位元率求頻寬）** 已知調變器輸入位元率 $R_b=10$ Mbit/s，採 16QAM，升餘弦滾降係數 $\alpha=0.25$。求符號率、射頻占用頻寬與頻譜效率。

1. 每符號位元數：$\log_2 16 = 4$。
2. 符號率：$R_s = 10/4 = 2.5$ Msym/s。
3. 射頻（帶通）頻寬：$B = 2.5\times(1+0.25) = 3.125$ MHz。同相或正交任一路的基頻頻寬是它的一半，$1.5625$ MHz。
4. 頻譜效率：$10/3.125 = 3.2$ bit/s/Hz，等於 $4/1.25$。
5. 合理性檢查：$\alpha=0$ 的理論最小射頻頻寬是 2.5 MHz，3.125 MHz 比它多 25%，正是滾降係數的意思。若改用 64QAM，符號率降為 $10/6 = 1.667$ Msym/s，頻寬 2.083 MHz，但所需 $E_b/N_0$ 更高。

**算例 2（由頻道頻寬求速率）** 假設一個 36 MHz 的衛星轉頻器頻道全部給單一載波使用，滾降係數 $\alpha=0.2$（假設）。求可用的最大符號率；若採 8PSK、碼率 2/3，資訊位元率是多少？改用 QPSK、碼率 3/4 呢？

1. 由 $B = R_s(1+\alpha)$：$R_s = 36/1.2 = 30$ Msym/s。
2. 8PSK（每符號 3 位元）、碼率 2/3：$30\times3\times\dfrac{2}{3} = 60$ Mbit/s。
3. QPSK（每符號 2 位元）、碼率 3/4：$30\times2\times\dfrac{3}{4} = 45$ Mbit/s。
4. 合理性檢查：若滾降係數是 0.35，符號率只剩 $36/1.35 = 26.67$ Msym/s，速率等比例下降約 11%；兩種組合的頻譜效率分別為 $60/36 = 1.67$ 與 $45/36 = 1.25$ bit/s/Hz，都低於 $\log_2M/(1+\alpha)$，因為還乘了碼率。這裡沒有計入訊框標頭與導引符號的開銷。

#### 常見錯誤

- 把位元率當成符號率來算頻寬。頻寬看的是符號率；10 Mbit/s 的 16QAM 只需要 2.5 Msym/s 的頻寬。
- 把基頻公式 $\frac{R_s}{2}(1+\alpha)$ 用在射頻訊號上，頻寬少算一半；或反過來把帶通公式用在基頻。
- 把 Nyquist 的兩個結果混在一起：取樣定理說取樣率至少是訊號最高頻率的兩倍（3.1.8）；無符號間干擾準則說頻寬 $W$ 的基頻通道最多每秒送 $2W$ 個符號。兩者都有「2 倍」，但講的是不同的事。
- 以為滾降係數越小越好。$\alpha$ 小雖然省頻寬，但脈波尾巴長，對時序誤差敏感，濾波器也需要更多階數。
- 計算淨速率時忘了乘碼率，或把碼率乘了兩次（已經用資訊位元率算符號率時就不必再乘）。

#### 和其他小節的關係

每符號位元數與錯誤率的取捨在 3.2.3；乘上碼率就是 3.2.4 的頻譜效率，並受 3.2.1 的 Shannon 上限限制；取樣定理在 3.1.8，頻譜與頻寬的定義在 3.1.7；OFDM 改用子載波間隔與資源區塊決定頻寬，見 3.2.5；占用頻寬決定雜訊功率，會用在 3.3.4 的接收靈敏度。

#### 單題：Nyquist ISI-free criterion and minimum bandwidth

**3.2.7G006**　An ideal low-pass (baseband) channel passes frequencies from 0 to 1.25 MHz and blocks everything above. Determine the maximum symbol rate that can be sent without intersymbol interference, in Msym/s, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　2.50

**詳解**　By the Nyquist ISI-free criterion, a baseband channel of bandwidth $W$ supports at most $R_s = 2W$ symbols per second (with ideal sinc pulses). $R_s = 2\times1.25 = 2.50$ Msym/s.
\boxed{2.50}

**3.2.7G010**　An ideal Nyquist (sinc) baseband pulse has its zero crossings spaced 0.4 µs apart, and the symbol period equals this spacing. Determine the baseband bandwidth occupied by the pulse, in kHz, rounded to one decimal place.

<details><summary>看答案</summary>

<details><summary>看答案</summary>

**答案**　33.33 %

**詳解**　4096-QAM: $25\times12 = 300$ Mbit/s. 256-QAM: $25\times\log_2 256 = 25\times8 = 200$ Mbit/s. Reduction $= (300-200)/300\times100 = 33.33\%$. (The ratio depends only on bits per symbol, $8/12$, because the symbol rate is fixed.)

**3.2.7S003**　When the radio steps down from 4096-QAM to QPSK, does the occupied RF bandwidth change? Explain.

<details><summary>看答案</summary>

**答案**　No. The occupied bandwidth $R_s(1+\alpha) = 28$ MHz depends on the symbol rate and roll-off, not on $M$; only the bit rate drops (to 50 Mbit/s with QPSK).

**詳解**　The spectrum of a linearly modulated signal is set by the pulse shape and the symbol rate: every symbol, whatever constellation point it carries, is the same raised-cosine-shaped pulse at the same rate. Changing $M$ changes only how many bits each pulse carries ($12 \to 2$), so the bit rate falls from 300 to $25\times2 = 50$ Mbit/s while the channel stays 28 MHz wide. This is why adaptive modulation can operate inside a fixed licensed channel.

**3.2.7S004**　With constant transmit power and constant symbol rate, how does the energy per bit $E_b$ change when the radio goes from 256-QAM to 4096-QAM? Give the change in dB and say why it matters.

<details><summary>看答案</summary>

**答案**　$E_b$ falls by $10\log_{10}(8/12) = -1.76$ dB, because the same symbol energy is shared by 12 bits instead of 8; together with the denser constellation this is why 4096-QAM needs a much higher SNR.

**詳解**　Symbol energy $E_s = P/R_s$ is unchanged (same power, same symbol rate). $E_b = E_s/\log_2 M$, so $E_b$ scales by $8/12 = 0.6667$, i.e. $10\log_{10}(0.6667) = -1.76$ dB. At the same time the constellation points are much closer together for a given $E_s$, so the error rate at a given $E_b/N_0$ is much worse. Both effects mean higher-order modulation is used only when the received SNR is high.

#### 情境題：Nyquist ISI-free criterion and minimum bandwidth

**Scenario | Short copper pair as an ideal low-pass channel**

A short copper pair inside a building is modelled as an ideal low-pass (baseband) channel that passes 0 to 1.5 MHz with flat response and blocks everything above. A designer wants to send a baseband PAM signal over it without intersymbol interference (ISI).

**3.2.7S011**　What is the maximum ISI-free symbol rate this channel can support, in theory? Give the answer in Msym/s, rounded to one decimal place.

<details><summary>看答案</summary>

**答案**　3.0 Msym/s

**詳解**　Nyquist ISI-free criterion: a baseband channel of bandwidth $W$ supports at most $R_s = 2W$. $R_s = 2\times1.5 = 3.0$ Msym/s (achieved only with ideal sinc pulses, roll-off 0).

**出處**　H. Nyquist, "Certain Topics in Telegraph Transmission Theory," Trans. AIEE, 1928; Proakis & Salehi, Digital Communications (Nyquist criterion for zero ISI)

</details>

**3.2.7S012**　The designer chooses 4-PAM with raised-cosine pulses of roll-off 0.25 and makes the baseband occupied bandwidth $R_s(1+\alpha)/2$ equal to the channel bandwidth. What bit rate results? Give the answer in Mbit/s, rounded to one decimal place.

<details><summary>看答案</summary>

**答案**　4.8 Mbit/s

**詳解**　Baseband: $R_s = 2W/(1+\alpha) = 2\times1.5/1.25 = 2.4$ Msym/s. Bits per symbol $= \log_2 4 = 2$. $R_b = 2.4\times2 = 4.8$ Mbit/s.

**出處**　Haykin, Communication Systems (raised-cosine spectrum, baseband pulse transmission)

</details>

**3.2.7S013**　Why does the designer not simply use sinc pulses (roll-off 0) to reach the full 3.0 Msym/s?

<details><summary>看答案</summary>

**答案**　Because the ideal sinc pulse requires a brick-wall filter that is non-causal and infinitely long, and its tails decay only as $1/t$, so any timing error produces large ISI; a non-zero roll-off trades some bandwidth for realizable filters and timing tolerance.

**詳解**　The sinc pulse corresponds to a perfectly rectangular spectrum. That spectrum needs a filter with infinite length and an infinitely steep edge, which cannot be built. In the time domain the sinc tails decay as $1/t$; if the sampling instant is slightly off, the sum of many neighbouring tails can become large (it can even diverge in the worst case). A raised-cosine pulse with $\alpha > 0$ has tails that decay as $1/t^3$, so it tolerates timing errors and can be approximated by finite filters, at the cost of $\alpha$ extra bandwidth.

**出處**　Proakis & Salehi, Digital Communications (signal design for band-limited channels; raised-cosine pulses)

</details>

**3.2.7S014**　A colleague says: "The factor 2 here is just the sampling theorem again." Are the Nyquist sampling theorem and the Nyquist ISI criterion the same statement? Explain the difference.

<details><summary>看答案</summary>

**答案**　No. The sampling theorem says a signal band-limited to $W$ must be sampled at least at $2W$ to be reconstructed; the ISI criterion says a channel of bandwidth $W$ can carry at most $2W$ independent symbols per second without ISI. Both have a factor 2 but they answer different questions.

**詳解**　The sampling theorem concerns representing an analog waveform by samples (how fast to sample a given signal). The ISI criterion concerns pulse design for data transmission: how fast independent symbols can be sent through a band-limited channel so that each sample at the receiver depends on only one symbol. They are mathematically related (sinc interpolation appears in both), but one gives a lower bound on a sampling rate and the other an upper bound on a signalling rate.

**出處**　Haykin, Communication Systems (sampling theorem; Nyquist criterion for distortionless baseband transmission)

</details>

**3.2.7S015**　Another designer computes the bit rate for 4-PAM with roll-off 0.25 on this channel:

**Scenario | Checking zero-ISI pulses on a test bench**

On a test bench, a baseband transmit–receive filter chain is driven by a single isolated symbol. The measured overall pulse at the receiver output is close to a raised-cosine pulse with roll-off 0.5 whose zero crossings are spaced 50 ns apart, so it was designed for 20 Msym/s. The raised-cosine pulse is $p(t) = \mathrm{sinc}(t/T)\,\cos(\pi\alpha t/T)/[1-(2\alpha t/T)^2]$, with $\mathrm{sinc}(x) = \sin(\pi x)/(\pi x)$.

**3.2.7S016**　What is the Nyquist minimum baseband bandwidth for a 20 Msym/s signal? Give the answer in MHz, rounded to one decimal place.

<details><summary>看答案</summary>

**答案**　10.0 MHz

**詳解**　$B_{min} = R_s/2 = 20/2 = 10.0$ MHz (baseband, roll-off 0).

**3.2.7S017**　A manager wants to run the same filter chain at 25 Msym/s to gain throughput. What happens to the received samples, and why?

<details><summary>看答案</summary>

**答案**　ISI appears. The pulse's zeros are still spaced 50 ns apart, but the symbols are now 40 ns apart, so neighbouring pulses are no longer zero at the sampling instants and leak into each other.

**詳解**　Zero ISI requires $p(kT) = 0$ for all $k \ne 0$, where $T$ is the actual symbol spacing. The pulse has zeros at multiples of 50 ns. At 25 Msym/s the sampling instants of neighbouring symbols are at 40 ns, 80 ns, 120 ns, ... from the pulse peak, which are not zeros of the pulse (except where they coincide with a multiple of 50 ns, e.g. 200 ns). The pulse shaping must be redesigned for the new symbol rate, and its bandwidth increases to $25\times1.5/2 = 18.75$ MHz.

**出處**　Proakis & Salehi, Digital Communications (Nyquist criterion for zero ISI)

**3.2.7S018**　At 20 Msym/s the receiver samples 10% of a symbol period early. The preceding symbol's pulse peak is then $0.9T$ before the sampling instant, so it contributes $p(0.9T)$ (relative to a peak value of 1). Calculate $p(0.9T)$ for $\alpha = 0.5$, rounded to four decimal places.

<details><summary>看答案</summary>

**答案**　0.0900

**詳解**　$\mathrm{sinc}(0.9) = \sin(0.9\pi)/(0.9\pi) = 0.309017/2.827433 = 0.109292$. $\cos(\pi\times0.5\times0.9) = \cos(0.45\pi) = 0.156434$. Denominator $= 1-(2\times0.5\times0.9)^2 = 1-0.81 = 0.19$. $p(0.9T) = 0.109292\times0.156434/0.19 = 0.017097/0.19 = 0.089985 \approx 0.0900$. (For comparison, an ideal sinc pulse would give 0.1093 from this single neighbour, and its slowly decaying tails add much more from further neighbours.)

**出處**　Proakis & Salehi, Digital Communications (raised-cosine pulse in the time domain)

**3.2.7S019**　In the frequency domain, the zero-ISI condition says that the pulse spectrum $P(f)$, shifted by all multiples of $1/T$ and added, must be a constant. Would an ideal brick-wall low-pass response with bandwidth 12 MHz (wider than 10 MHz) satisfy this for $T = 50$ ns? Why does a raised cosine with any $\alpha$ satisfy it?

<details><summary>看答案</summary>

**答案**　No. Copies of a 12 MHz brick-wall spectrum spaced 20 MHz apart overlap between 8 and 12 MHz, where the sum doubles, so the sum is not constant. The raised cosine's roll-off is antisymmetric about $1/(2T) = 10$ MHz, so overlapping copies always add to a constant.

**詳解**　With $1/T = 20$ MHz, the copy centred at 20 MHz covers 8 to 32 MHz and overlaps the original (−12 to 12 MHz) between 8 and 12 MHz; there the sum is 2 while elsewhere it is 1, so the condition fails and ISI results. In the raised cosine, the roll-off region of one copy falls by exactly as much as the next copy rises (odd symmetry about the Nyquist frequency $1/(2T)$), so the folded spectrum is flat for every $0 \le \alpha \le 1$.

**出處**　Proakis & Salehi, Digital Communications (Nyquist pulse-shaping criterion in the frequency domain)

</details>

**3.2.7S020**　An engineer checks whether this 20 Msym/s signal with roll-off 0.25 fits a 12 MHz baseband channel:

**3.2.7S022**　How much passband bandwidth is freed by reducing the roll-off to 0.05 at the same symbol rate? Give the answer in MHz, rounded to three decimal places.

<details><summary>看答案</summary>

**答案**　4.125 MHz

**詳解**　New bandwidth $= 27.5\times1.05 = 28.875$ MHz. Freed $= 33.000 - 28.875 = 4.125$ MHz (equivalently $27.5\times0.15$).

**出處**　Proakis & Salehi, Digital Communications (raised-cosine spectrum)

**3.2.7S023**　On the spectrum analyzer, at what offset from the carrier does the power spectral density fall to half (−3 dB) of its in-band level, and does this depend on the roll-off? What can the operator infer from it?

<details><summary>看答案</summary>

**答案**　At $\pm R_s/2 = \pm13.75$ MHz for any roll-off, so the −3 dB bandwidth equals the symbol rate (27.5 MHz); the operator can read the symbol rate directly from it.

**詳解**　The transmitted PSD follows the square of the transmit RRC response, i.e. the raised-cosine shape, which equals one half of its flat value at $|f| = 1/(2T)$ for every $\alpha$ (the roll-off is symmetric about that point). In passband this is at $\pm R_s/2$ from the carrier, so the −3 dB width is $R_s = 27.5$ MHz both before and after the roll-off change; only the skirts outside it get steeper.

**3.2.7S024**　What does the operator give up by reducing the roll-off from 0.20 to 0.05?

<details><summary>看答案</summary>

**答案**　The pulse tails become longer, so the system is more sensitive to timing error and needs longer (more complex) RRC filters; the signal peak-to-average power ratio also rises somewhat, so the amplifier may need more back-off.

**詳解**　A smaller $\alpha$ makes the raised-cosine pulse closer to a sinc: its time-domain tails decay more slowly, so a given sampling-time offset produces more ISI and synchronization is harder. A sharper spectrum needs a longer filter impulse response (more taps). The slower-decaying pulses also overlap more, which increases the peaks of the transmitted waveform relative to its average power. The bandwidth saving (4.125 MHz here) is traded against these costs.

The raised-cosine magnitude, normalized to 1 at DC, is $\frac{1}{2}\left[1+\cos\!\left(\frac{\pi}{\alpha R_s}\left(|f| - \frac{(1-\alpha)R_s}{2}\right)\right)\right]$ in the roll-off region, and the RRC magnitude is its square root.

<details><summary>看答案</summary>

**答案**　5.20 MHz

**詳解**　Baseband: $B = R_s(1+\alpha)/2 = 8\times1.3/2 = 5.20$ MHz.

</details>

**3.2.7S027**　What is the RRC filter's amplitude response at $f = 5.0$ MHz relative to DC, $20\log_{10}|H_{RRC}(f)|$? Give the answer in dB, rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　−17.69 dB

**詳解**　Flat edge $= (1-0.3)\times8/2 = 2.8$ MHz; outer edge $= 5.2$ MHz, so 5.0 MHz is in the roll-off region. $\alpha R_s = 2.4$ MHz. Argument $= \pi(5.0-2.8)/2.4 = 0.91667\pi$; $\cos(0.91667\pi) = -0.965926$. Raised cosine $= 0.5\times(1-0.965926) = 0.017037$. **3.2.7S028**　Why is the raised-cosine response split into two RRC filters, one at each end, instead of putting the whole raised-cosine filter in the transmitter and a plain wide low-pass filter in the receiver?

<details><summary>看答案</summary>

**答案**　Because the receive RRC is then the matched filter to the transmit pulse, maximizing SNR at the sampling instant, while the cascade of the two is still a raised cosine and therefore ISI-free; a wide receive filter would let in more noise.

**詳解**　For an AWGN channel the optimum receive filter is matched to the transmitted pulse. If the transmit pulse is RRC, the matched filter is also RRC, and RRC × RRC = raised cosine, which satisfies the Nyquist zero-ISI criterion. Putting the full raised cosine at the transmitter and a wide low-pass at the receiver gives zero ISI but admits noise over a wider bandwidth than necessary, lowering the SNR. Note that an RRC pulse on its own is not ISI-free; only the cascade is.

**出處**　Proakis & Salehi, Digital Communications (optimum transmit and receive filters for band-limited channels)

**3.2.7S029**　After quadrature up-conversion, the RF signal occupies twice the I-branch bandwidth. Does this mean passband transmission wastes half of the spectrum compared with baseband? Explain.

**答案**　Because real signals are not ideal: truncated RRC filters leave sidelobes, the high-power amplifier's nonlinearity causes spectral regrowth, and carrier frequency errors shift spectra, so some spacing is needed to keep adjacent-channel interference low.

**答案**　The symbol rate and the bit rate both halve (to 2.56 Msym/s and 13.06 Mbit/s of information); the in-channel noise power (for white noise) also halves, so the SNR improves by about 3 dB.

Noise power $N_0B$ is proportional to the bandwidth, so it drops by $10\log_{10}2 = 3.01$ dB while the signal power stays the same. The SNR gain could allow keeping 64-QAM under worse ingress, or a narrower channel can be moved away from a narrowband interferer.

**出處**　Proakis & Salehi, Digital Communications (raised-cosine spectrum; noise power in a bandwidth)

</details>

**3.2.7S055**　A planner computes the symbol rate:
1. Channel width 6.4 MHz, roll-off 0.25.
2. $R_s = 2B/(1+\alpha) = 2\times6.4/1.25 = 10.24$ Msym/s.
3. With 64-QAM: $10.24\times6 = 61.44$ Mbit/s gross.

Which step is wrong, and what is the correct result?

<details><summary>看答案</summary>

**答案**　Step 2 is wrong. It uses the baseband relation $B = R_s(1+\alpha)/2$ for an RF (passband) channel. Correct: $R_s = 6.4/1.25 = 5.12$ Msym/s and the gross bit rate is $5.12\times6 = 30.72$ Mbit/s.

**詳解**　Passband: $R_s = B/(1+\alpha) = 5.12$ Msym/s; $R_b = 30.72$ Mbit/s gross. The wrong value would occupy 12.8 MHz of RF spectrum, twice the channel.

**出處**　Proakis & Salehi, Digital Communications (band-pass signals and their lowpass equivalents)

</details>

#### 情境題：Bandwidth efficiency

**Scenario | Comparing two satellite carrier configurations**

An operator compares two single-carrier configurations, both measured against occupied passband bandwidth $R_s(1+\alpha)$. Configuration A: QPSK, code rate 4/5, roll-off 0.35, 20 Msym/s. Configuration B: 16APSK, code rate 2/3, roll-off 0.10, 24 Msym/s. Overhead other than the code is ignored.

**3.2.7S056**　By what factor is the information bandwidth efficiency of configuration B higher than that of configuration A? Give the factor rounded to two decimal places.

<details><summary>看答案</summary>

**答案**　2.05

**詳解**　A: $\eta_A = 2\times0.8/1.35 = 1.6/1.35 = 1.18519$ bit/s/Hz. B: $\eta_B = 4\times(2/3)/1.10 = 2.66667/1.10 = 2.42424$ bit/s/Hz. Factor $= 2.42424/1.18519 = 2.0455 \approx 2.05$.

**出處**　Proakis & Salehi, Digital Communications (spectral efficiency of band-pass linear modulation); Sklar, Digital Communications: Fundamentals and Applications (bandwidth efficiency)

</details>

**3.2.7S057**　Configuration B is about twice as bandwidth-efficient. Why would an operator still choose configuration A for some links?

<details><summary>看答案</summary>

**答案**　Because B needs a considerably higher $E_s/N_0$ (denser 16APSK constellation, weaker code), so on links with small antennas, rain fade or limited power, only A closes the link; bandwidth efficiency is bought with power efficiency.

**詳解**　Higher-order modulation packs points closer together at the same average power, and a higher code rate provides less error-correction redundancy; both raise the required SNR. A power-limited link (small terminals, edge of beam, heavy rain) is better served by robust QPSK with a low code rate, even though it uses more bandwidth per bit. This is the bandwidth–power trade-off bounded by the Shannon limit.

**出處**　Sklar, Digital Communications: Fundamentals and Applications (bandwidth–power trade-off)

</details>

**3.2.7S058**　A vendor brochure quotes configuration B as "2.67 bit/s/Hz", while the operator's figure is 2.42 bit/s/Hz. Both are computed correctly. What different bandwidth definitions could explain this, and which figure should be used for transponder planning?

<details><summary>看答案</summary>

**答案**　The brochure divides by the Nyquist bandwidth $R_s$ (roll-off ignored: $2.6667/1 = 2.67$), the operator by the occupied bandwidth $R_s(1+\alpha)$ (2.42). For planning, use the occupied bandwidth, or even the allocated bandwidth including guard bands, which gives a still lower figure.

**詳解**　Information bits per symbol $= 4\times2/3 = 2.6667$. Per Nyquist bandwidth ($\alpha = 0$): 2.67 bit/s/Hz. Per occupied bandwidth: $2.6667/1.10 = 2.42$ bit/s/Hz. If carriers are spaced with an extra guard, e.g. 1.2$R_s$ per carrier, the efficiency per allocated MHz falls to $2.6667/1.2 = 2.22$ bit/s/Hz. Efficiency figures are comparable only when they use the same bandwidth definition.

**出處**　Sklar, Digital Communications: Fundamentals and Applications (bandwidth efficiency and bandwidth definitions)

</details>

**3.2.7S059**　An analyst computes the efficiency of configuration B:
1. Information bits per symbol $= 4\times2/3 = 2.6667$.
2. Bandwidth per unit symbol rate $= (1+\alpha)/2 = 1.10/2 = 0.55$.
3. $\eta_B = 2.6667/0.55 = 4.85$ bit/s/Hz.

Which step is wrong, and what is the correct result?

<details><summary>看答案</summary>

**答案**　Step 2 is wrong. $(1+\alpha)/2$ is the baseband (one-sided) relation; a 16APSK satellite carrier is a passband signal occupying $R_s(1+\alpha)$. Correct: $\eta_B = 2.6667/1.10 = 2.42$ bit/s/Hz.

**詳解**　$\eta_B = 2.66667/1.10 = 2.42424 \approx 2.42$ bit/s/Hz. The wrong value exceeds even the uncoded limit $\log_2 16 = 4$ bit/s/Hz, which flags the error.

**出處**　Proakis & Salehi, Digital Communications (spectral efficiency of band-pass linear modulation)

</details>

**3.2.7S060**　Another analyst computes the efficiency of configuration B from its rates:
1. Information bit rate $= 24\times4\times2/3 = 64$ Mbit/s.
2. Roll-off 0.10 means the spectrum is 10% narrower than the symbol rate: $B = 24\times0.90 = 21.6$ MHz.
3. $\eta_B = 64/21.6 = 2.96$ bit/s/Hz.

Which step is wrong, and what is the correct result?

<details><summary>看答案</summary>

**答案**　Step 2 is wrong. The roll-off is the excess bandwidth above the Nyquist bandwidth, so the passband bandwidth is $R_s(1+\alpha) = 24\times1.10 = 26.4$ MHz. Correct: $\eta_B = 64/26.4 = 2.42$ bit/s/Hz.

**詳解**　$B = 26.4$ MHz; $\eta_B = 64/26.4 = 2.42424 \approx 2.42$ bit/s/Hz, matching $\log_2 M\cdot R_c/(1+\alpha)$. No raised-cosine spectrum is narrower than the Nyquist bandwidth ($R_s$ in passband).

**出處**　Proakis & Salehi, Digital Communications (raised-cosine spectrum)

</details>
