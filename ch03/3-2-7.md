# 3.2.7 位元率、符號率、頻寬與 Nyquist 準則

所屬：[3.2 容量](3-2.md)

## 內文

#### 為什麼要學

一條數位鏈路有三個常被混在一起的量：位元率（每秒幾個位元）、符號率（每秒幾個調變符號）與占用頻寬（幾 Hz）。調變階數把位元率和符號率連起來，脈波成形濾波器的滾降係數把符號率和頻寬連起來。微波回傳、衛星鏈路、有線電視與光傳輸的規劃，都是在固定的頻道頻寬裡決定符號率，再由調變與碼率決定淨速率；頻譜分析儀上看到的訊號寬度，也是由符號率與滾降係數決定。Nyquist 準則則說明了在有限頻寬內，符號最快能送多快而不產生符號間干擾（intersymbol interference, ISI），是這些換算的理論底線。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $R_b$ | 位元率（這裡指調變器輸入的編碼後位元率） | bit/s |
| $R_s$ | 符號率（鮑率），$R_s=1/T$ | 符號/s（baud） |
| $T$ | 符號週期 | s |
| $M$ | 調變階數（星座點數），每符號 $\log_2M$ 個位元 | 無單位 |
| $\alpha$ | 升餘弦濾波器的滾降係數（roll-off factor），$0\le\alpha\le1$ | 無單位 |
| $W$ | 基頻通道頻寬（單邊，0 到 $W$） | Hz |
| $B$ | 訊號占用頻寬（基頻指單邊，帶通指載波兩側合計） | Hz |
| $R_c$ | 通道編碼的碼率 | 無單位 |
| $\eta$ | 頻譜效率 | bit/s/Hz |

#### 公式與推導

**位元率與符號率。** 每個符號載 $\log_2M$ 個位元，所以

$$R_s = \frac{R_b}{\log_2 M},\qquad R_b = R_s\log_2 M$$

若有通道編碼，資訊位元率是 $R_b\times R_c$。頻寬由符號率決定，不是由位元率決定：同樣的頻寬，提高 $M$ 可以多送位元，代價是 3.2.3 所說的更高 $E_b/N_0$ 需求。

**Nyquist 無符號間干擾準則。** 接收端每隔 $T$ 取樣一次。若整體脈波（發射濾波器、通道、接收濾波器合起來）$p(t)$ 在取樣點滿足 $p(0)=1$、$p(kT)=0$（$k\ne0$），相鄰符號就不會互相干擾。換到頻域，這個條件等於脈波頻譜以 $1/T$ 為間隔平移後疊加起來是常數：

$$\sum_{k=-\infty}^{\infty}P\!\left(f+\frac{k}{T}\right) = T$$

由此可知，基頻頻寬 $W$ 的通道最多只能以 $R_s = 2W$ 的符號率傳送而沒有符號間干擾；反過來說，符號率 $R_s$ 所需的**最小基頻頻寬**是

$$B_{\min} = \frac{R_s}{2} = \frac{1}{2T}$$

這個最小頻寬稱為 Nyquist 頻寬，對應的脈波是 sinc 函數（理想矩形頻譜）。但 sinc 脈波的尾巴衰減很慢，取樣時間稍有偏差就產生很大的干擾，濾波器也做不出來，所以實際系統會多用一點頻寬。

**升餘弦（raised cosine）頻譜。** 最常用的折衷是升餘弦脈波，頻譜在 $|f|\le\frac{1-\alpha}{2T}$ 內是平的，在 $\frac{1-\alpha}{2T}<|f|\le\frac{1+\alpha}{2T}$ 之間以半個餘弦波形平滑降到零，之外為零。它滿足 Nyquist 準則，占用的頻寬是

$$B_{\text{基頻}} = \frac{R_s}{2}(1+\alpha),\qquad B_{\text{帶通}} = R_s(1+\alpha)$$

$\alpha$ 是超出 Nyquist 頻寬的比例：$\alpha=0$ 退化成理想 sinc，$\alpha=1$ 時頻寬加倍。$\alpha$ 越大，脈波尾巴衰減越快、對取樣時間誤差越不敏感，但越占頻寬。實作上通常把升餘弦拆成兩個根升餘弦（root raised cosine）濾波器，發射端與接收端各一個，合起來是升餘弦，接收端那一個同時也是匹配濾波器。

**基頻與帶通的區別。** 基頻訊號的頻譜從 $-B$ 到 $+B$，習慣上只算正頻率那一半，所以是 $\frac{R_s}{2}(1+\alpha)$。把它調變到載波上（例如 QAM、PSK）後，正負兩半都搬到載波兩側，占用的射頻頻寬是兩倍，即 $R_s(1+\alpha)$。因此帶通線性調變的頻譜效率為

$$\eta = \frac{R_b}{B_{\text{帶通}}} = \frac{\log_2 M}{1+\alpha}\quad[\text{bit/s/Hz}]$$

上限是 $\alpha=0$ 時的 $\log_2M$。帶通訊號雖然頻寬加倍，但同相與正交兩路各載一個實數符號，所以每 Hz 可送的實數符號數和基頻相同，都是每秒每 Hz 2 個，並沒有浪費。這些式子適用於單載波線性調變；OFDM 的頻寬由子載波數與子載波間隔決定（見 3.2.5），不套用滾降係數的算法。

#### 算例

**算例 1（由位元率求頻寬）** 已知調變器輸入位元率 $R_b=10$ Mbit/s，採 16QAM，升餘弦滾降係數 $\alpha=0.25$。求符號率、射頻占用頻寬與頻譜效率。

1. 每符號位元數：$\log_2 16 = 4$。
2. 符號率：$R_s = 10/4 = 2.5$ Msym/s。
3. 射頻（帶通）頻寬：$B = 2.5\times(1+0.25) = 3.125$ MHz。同相或正交任一路的基頻頻寬是它的一半，$1.5625$ MHz。
4. 頻譜效率：$10/3.125 = 3.2$ bit/s/Hz，等於 $4/1.25$。
5. 合理性檢查：$\alpha=0$ 的理論最小射頻頻寬是 2.5 MHz，3.125 MHz 比它多 25%，正是滾降係數的意思。若改用 64QAM，符號率降為 $10/6 = 1.667$ Msym/s，頻寬 2.083 MHz，但所需 $E_b/N_0$ 更高。

**算例 2（由頻道頻寬求速率）** 假設一個 36 MHz 的衛星轉頻器頻道全部給單一載波使用，滾降係數 $\alpha=0.2$（假設）。求可用的最大符號率；若採 8PSK、碼率 2/3，資訊位元率是多少？改用 QPSK、碼率 3/4 呢？

1. 由 $B = R_s(1+\alpha)$：$R_s = 36/1.2 = 30$ Msym/s。
2. 8PSK（每符號 3 位元）、碼率 2/3：$30\times3\times\dfrac{2}{3} = 60$ Mbit/s。
3. QPSK（每符號 2 位元）、碼率 3/4：$30\times2\times\dfrac{3}{4} = 45$ Mbit/s。
4. 合理性檢查：若滾降係數是 0.35，符號率只剩 $36/1.35 = 26.67$ Msym/s，速率等比例下降約 11%；兩種組合的頻譜效率分別為 $60/36 = 1.67$ 與 $45/36 = 1.25$ bit/s/Hz，都低於 $\log_2M/(1+\alpha)$，因為還乘了碼率。這裡沒有計入訊框標頭與導引符號的開銷。

#### 常見錯誤

- 把位元率當成符號率來算頻寬。頻寬看的是符號率；10 Mbit/s 的 16QAM 只需要 2.5 Msym/s 的頻寬。
- 把基頻公式 $\frac{R_s}{2}(1+\alpha)$ 用在射頻訊號上，頻寬少算一半；或反過來把帶通公式用在基頻。
- 把 Nyquist 的兩個結果混在一起：取樣定理說取樣率至少是訊號最高頻率的兩倍（3.1.8）；無符號間干擾準則說頻寬 $W$ 的基頻通道最多每秒送 $2W$ 個符號。兩者都有「2 倍」，但講的是不同的事。
- 以為滾降係數越小越好。$\alpha$ 小雖然省頻寬，但脈波尾巴長，對時序誤差敏感，濾波器也需要更多階數。
- 計算淨速率時忘了乘碼率，或把碼率乘了兩次（已經用資訊位元率算符號率時就不必再乘）。

#### 和其他小節的關係

每符號位元數與錯誤率的取捨在 3.2.3；乘上碼率就是 3.2.4 的頻譜效率，並受 3.2.1 的 Shannon 上限限制；取樣定理在 3.1.8，頻譜與頻寬的定義在 3.1.7；OFDM 改用子載波間隔與資源區塊決定頻寬，見 3.2.5；占用頻寬決定雜訊功率，會用在 3.3.4 的接收靈敏度。
