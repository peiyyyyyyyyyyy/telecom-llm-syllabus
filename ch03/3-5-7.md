# 3.5.7 線性代數與矩陣：轉移矩陣、穩態向量、MIMO 通道矩陣

所屬：[3.5 基礎數理](3-5.md)

## 內文

#### 為什麼要學

只要系統有多個輸入與多個輸出，就要用矩陣描述。多輸入多輸出（multiple-input multiple-output, MIMO）系統把每一對發射與接收天線之間的通道增益排成通道矩陣 $\mathbf{H}$，它的秩（rank）決定最多能同時傳幾條獨立的資料流，奇異值決定每條資料流的強弱；終端回報的秩指示與基地台的預編碼都建立在這些量上。馬可夫鏈的轉移機率排成轉移矩陣，長期行為由它的特徵值（eigenvalue）與特徵向量決定：穩態分布就是對應特徵值 1 的左特徵向量，第二大的特徵值決定收斂有多快。本節複習矩陣乘法、穩態向量、特徵值與秩的計算，全部用 2×2 或 3×3 的小矩陣實算。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $\mathbf{A}$、$a_{ij}$ | 矩陣與其第 $i$ 列第 $j$ 行的元素 | 視情境而定 |
| $\mathbf{A}^{\mathsf T}$、$\mathbf{A}^{\mathsf H}$ | 轉置、共軛轉置 | 同 $\mathbf{A}$ |
| $\det\mathbf{A}$、$\mathrm{tr}\,\mathbf{A}$ | 行列式、跡（對角線元素和） | 視情境而定 |
| $\lambda$ | 特徵值 | 視情境而定 |
| $\mathbf{v}$ | 特徵向量 | 無單位 |
| $\mathrm{rank}(\mathbf{A})$ | 秩，線性獨立的列（或行）的個數 | 個 |
| $\sigma_i$ | 奇異值 | 與 $\mathbf{A}$ 的元素相同 |
| $\mathbf{H}$ | MIMO 通道矩陣，大小為 $N_r\times N_t$ | 無單位（電壓增益） |
| $\mathbf{P}$、$\boldsymbol\pi$ | 轉移矩陣、穩態列向量 | 無單位 |
| $\rho$ | 總發射功率對應的接收訊雜比（線性值） | 無單位 |

#### 公式與推導

**矩陣乘法。** $m\times n$ 的 $\mathbf{A}$ 乘上 $n\times r$ 的 $\mathbf{B}$ 得到 $m\times r$ 的矩陣，元素為 $(\mathbf{AB})_{ij} = \sum_k a_{ik}b_{kj}$；前者的行數必須等於後者的列數。矩陣乘法一般不可交換，$\mathbf{AB}\ne\mathbf{BA}$。MIMO 的接收訊號寫成 $\mathbf{y} = \mathbf{H}\mathbf{x} + \mathbf{n}$，其中 $\mathbf{x}$ 是 $N_t$ 維的發射向量，$\mathbf{y}$ 與雜訊 $\mathbf{n}$ 是 $N_r$ 維；馬可夫鏈的狀態分布則以列向量乘在左邊，$\boldsymbol\pi^{(n+1)} = \boldsymbol\pi^{(n)}\mathbf{P}$。

**特徵值與特徵向量。** 若非零向量 $\mathbf{v}$ 滿足 $\mathbf{A}\mathbf{v} = \lambda\mathbf{v}$，則 $\lambda$ 是特徵值、$\mathbf{v}$ 是特徵向量。特徵值由特徵方程式 $\det(\mathbf{A} - \lambda\mathbf{I}) = 0$ 求得；2×2 矩陣可直接寫成

$$\lambda^2 - (\mathrm{tr}\,\mathbf{A})\,\lambda + \det\mathbf{A} = 0$$

所有特徵值的和等於跡，乘積等於行列式，可用來驗算。

**轉移矩陣的穩態向量。** 轉移矩陣每列和為 1，所以一定有特徵值 1。穩態向量滿足 $\boldsymbol\pi\mathbf{P} = \boldsymbol\pi$ 且 $\sum_i\pi_i = 1$，也就是對應特徵值 1 的左特徵向量。$\boldsymbol\pi\mathbf{P} = \boldsymbol\pi$ 的各條方程式並不獨立（全部相加是恆等式），所以要捨去其中一條，換成正規化條件。其餘特徵值的絕對值都不超過 1；對不可約且非週期的鏈，它們嚴格小於 1，其中絕對值最大者決定與穩態的差距每步縮小的比例。

**秩與奇異值。** 秩是矩陣中線性獨立的列數，也等於線性獨立的行數，因此 $\mathrm{rank}(\mathbf{H})\le\min(N_t, N_r)$。方陣的行列式不為零時為滿秩。奇異值是 $\mathbf{H}\mathbf{H}^{\mathsf H}$ 的特徵值的正平方根，$\sigma_i = \sqrt{\lambda_i(\mathbf{H}\mathbf{H}^{\mathsf H})}$，非零奇異值的個數就是秩。透過奇異值分解，MIMO 通道可以拆成 $\mathrm{rank}(\mathbf{H})$ 條互不干擾的平行通道，第 $i$ 條的功率增益是 $\sigma_i^2$。若發射端不知道通道、把功率平均分給 $N_t$ 支天線，且接收端雜訊為獨立同分布的高斯雜訊，容量為

$$C = \sum_{i=1}^{\mathrm{rank}(\mathbf{H})}\log_2\!\left(1 + \frac{\rho}{N_t}\,\sigma_i^2\right)\quad\text{(bit/s/Hz)}$$

#### 算例

**算例 1：用戶狀態的穩態向量（3×3）。** NR 的用戶設備有 RRC_IDLE、RRC_INACTIVE、RRC_CONNECTED 三種無線資源控制狀態。假設以固定長度的時槽觀察，狀態依序為 I、N、C，轉移矩陣（數值為假設）是

$$\mathbf{P} = \begin{bmatrix}0.8 & 0 & 0.2\\ 0.1 & 0.6 & 0.3\\ 0.1 & 0.3 & 0.6\end{bmatrix}$$

求穩態向量 $\boldsymbol\pi = (\pi_I, \pi_N, \pi_C)$。

1. 寫出 $\boldsymbol\pi\mathbf{P} = \boldsymbol\pi$ 的第一行：$\pi_I = 0.8\pi_I + 0.1\pi_N + 0.1\pi_C$，即 $0.2\pi_I = 0.1(\pi_N + \pi_C)$。
2. 代入 $\pi_N + \pi_C = 1 - \pi_I$：$0.2\pi_I = 0.1(1 - \pi_I)$，得 $\pi_I = 1/3$。
3. 第二行：$\pi_N = 0.6\pi_N + 0.3\pi_C$，即 $0.4\pi_N = 0.3\pi_C$，$\pi_N = 0.75\pi_C$。
4. $\pi_N + \pi_C = 2/3$，所以 $1.75\pi_C = 2/3$，$\pi_C = 8/21$，$\pi_N = 6/21$。
5. $\boldsymbol\pi = (7/21,\ 6/21,\ 8/21)\approx(0.333,\ 0.286,\ 0.381)$。

合理性檢查：三個分量的和是 $21/21 = 1$。用沒有用到的第三行驗算：$0.2\times\tfrac{7}{21} + 0.3\times\tfrac{6}{21} + 0.6\times\tfrac{8}{21} = \tfrac{1.4 + 1.8 + 4.8}{21} = \tfrac{8}{21}$，等於 $\pi_C$，所以 $\boldsymbol\pi\mathbf{P} = \boldsymbol\pi$ 成立。矩陣中 I 到 N 的機率為 0，符合用戶設備必須先進入連線狀態才可能被暫停到 RRC_INACTIVE 的事實。

**算例 2：2×2 通道矩陣的特徵值、秩與容量。** 已知（假設）兩個 2×2 實數通道矩陣

$$\mathbf{H}_1 = \begin{bmatrix}1 & 0.5\\ 0.5 & 1\end{bmatrix},\qquad \mathbf{H}_2 = \begin{bmatrix}1 & 1\\ 1 & 1\end{bmatrix}$$

總訊雜比 $\rho = 10$（即 10 dB），功率平均分給兩支發射天線。求兩者的秩、奇異值與容量。

1. $\mathbf{H}_1\mathbf{H}_1^{\mathsf T} = \begin{bmatrix}1.25 & 1\\ 1 & 1.25\end{bmatrix}$（例如左上角 $1\times1 + 0.5\times0.5 = 1.25$，右上角 $1\times0.5 + 0.5\times1 = 1$）。
2. 跡為 2.5，行列式為 $1.25^2 - 1^2 = 0.5625$。特徵方程式 $\lambda^2 - 2.5\lambda + 0.5625 = 0$，$\lambda = (2.5\pm\sqrt{6.25 - 2.25})/2 = (2.5\pm2)/2$，得 $\lambda = 2.25$ 與 $0.25$。
3. 奇異值 $\sigma_1 = \sqrt{2.25} = 1.5$、$\sigma_2 = \sqrt{0.25} = 0.5$，兩個都不為零，秩為 2。
4. 容量 $C_1 = \log_2(1 + 5\times2.25) + \log_2(1 + 5\times0.25) = \log_212.25 + \log_22.25 = 3.615 + 1.170 = 4.785$ bit/s/Hz。
5. $\mathbf{H}_2$ 的兩列完全相同，$\det\mathbf{H}_2 = 0$，秩為 1。$\mathbf{H}_2\mathbf{H}_2^{\mathsf T} = \begin{bmatrix}2 & 2\\ 2 & 2\end{bmatrix}$，跡為 4、行列式為 0，特徵值為 4 與 0，奇異值為 2 與 0。
6. 容量 $C_2 = \log_2(1 + 5\times4) = \log_221 = 4.392$ bit/s/Hz。

合理性檢查：$\mathbf{H}_1$ 的行列式是 $1 - 0.25 = 0.75$，等於奇異值的乘積 $1.5\times0.5$；特徵值的和 $2.25 + 0.25 = 2.5$ 等於跡。$\mathbf{H}_2$ 的總通道增益（所有元素平方和為 4）比 $\mathbf{H}_1$（2.5）大，容量卻較低，因為它只能支援一條資料流；訊雜比越高，秩的差異影響越大。

#### 常見錯誤

- 解穩態向量時用 $\mathbf{P}\boldsymbol\pi = \boldsymbol\pi$（行向量乘在右邊）。在「每列和為 1」的慣例下，這樣解出來的是各分量相等的向量，不是穩態分布。
- 忘記加上 $\sum_i\pi_i = 1$，得到只差一個比例的解；或把三條平衡式全部當成獨立方程式。
- 把通道矩陣 $\mathbf{H}$ 本身的特徵值當成奇異值。奇異值要由 $\mathbf{H}\mathbf{H}^{\mathsf H}$ 的特徵值開根號得到，兩者只有在 $\mathbf{H}$ 是對稱（厄米特）且半正定時才相同。
- 以為天線數就是可傳的資料流數。資料流數的上限是秩，天線之間高度相關（例如視線通道）時秩可能只有 1。

#### 和其他小節的關係

穩態向量的意義與兩狀態公式在 3.5.4；3.5.4 算例中每步差距減半，正是因為該轉移矩陣的特徵值為 1 與 0.5。秩與奇異值是 3.2.6 MIMO 容量的基礎；拆出的平行通道若要依增益分配功率，就用 3.5.5 的注水法。3.5.6 的價值迭代也以矩陣向量乘法實作。
