# 3.7.1 熵與互資訊

所屬：[3.7 資訊理論與編碼](3-7.md)

## 內文

#### 為什麼要學

電信網路裡所有「能壓多小」和「能傳多快」的問題，最後都回到熵（entropy）與互資訊（mutual information）。語音與影像編碼器能把位元率壓到多低，下限是信源的熵；一條通道在給定雜訊下最多能可靠傳送多少位元，上限是輸入與輸出之間互資訊的最大值，也就是通道容量。調變編碼方案（MCS）的碼率設計、鏈路自適應的目標頻譜效率，以及近年用互資訊當指標來評估接收機效能的做法，都以這兩個量為基礎。學會用機率表直接算出熵、條件熵與互資訊，後面談信源編碼、通道編碼與容量時才有共同的語言。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $X, Y$ | 離散隨機變數（例如通道的輸入與輸出） | 無 |
| $p(x)$ | $X$ 取值 $x$ 的機率 | 無（0～1） |
| $p(x,y)$ | $X=x$ 且 $Y=y$ 的聯合機率 | 無 |
| $p(y\mid x)$ | 已知 $X=x$ 時 $Y=y$ 的條件機率 | 無 |
| $H(X)$ | $X$ 的熵 | bit（以 $\log_2$ 計算時） |
| $H(X,Y)$ | 聯合熵 | bit |
| $H(Y\mid X)$ | 已知 $X$ 時 $Y$ 的條件熵 | bit |
| $I(X;Y)$ | $X$ 與 $Y$ 的互資訊 | bit |
| $H_b(p)$ | 二元熵函數 | bit |

#### 公式與推導

熵是「平均而言，知道一個符號的結果能得到多少資訊」：

$$H(X) = -\sum_{x} p(x)\log_2 p(x)$$

約定 $0\log_2 0 = 0$。若 $X$ 有 $M$ 種可能的取值，則 $0 \le H(X) \le \log_2 M$；完全確定時為 0，各取值機率相等時達到上限。只有兩種取值、機率為 $p$ 與 $1-p$ 時，熵寫成二元熵函數：

$$H_b(p) = -p\log_2 p-(1-p)\log_2(1-p)$$

兩個變數一起看時，聯合熵與條件熵為

$$H(X,Y) = -\sum_{x,y} p(x,y)\log_2 p(x,y),\qquad H(Y\mid X) = -\sum_{x,y} p(x,y)\log_2 p(y\mid x)$$

兩者滿足連鎖律 $H(X,Y)=H(X)+H(Y\mid X)$。這條式子可以直接由 $p(x,y)=p(x)\,p(y\mid x)$ 取對數後求期望值得到。

互資訊是「知道 $Y$ 之後，$X$ 的不確定性減少了多少」：

$$I(X;Y) = H(X)-H(X\mid Y) = H(Y)-H(Y\mid X) = H(X)+H(Y)-H(X,Y)$$

三種寫法等價，計算時挑手上資料最好算的那一個。互資訊恆不為負，而且對 $X$、$Y$ 對稱；兩者獨立時為 0，$Y$ 完全決定 $X$ 時等於 $H(X)$。由 $I(X;Y)\ge 0$ 可以得到「取條件不會讓熵變大」：$H(X\mid Y)\le H(X)$。

適用條件：以上是離散隨機變數的定義，對數取 2 為底時單位是 bit，取自然對數時單位是 nat（1 nat $=1/\ln 2\approx 1.4427$ bit）。連續變數要改用微分熵，性質不完全相同（例如可以為負），不能直接套用這裡的界限。

#### 算例

**算例 1（信源的熵）** 已知某信源有四種符號，機率為 $0.5,\ 0.25,\ 0.125,\ 0.125$。求熵。

選公式 $H(X)=-\sum p\log_2 p$。代入：

$$H = 0.5\times 1 + 0.25\times 2 + 0.125\times 3 + 0.125\times 3 = 0.5+0.5+0.375+0.375 = 1.75\ \text{bit}$$

合理性檢查：四種符號的上限是 $\log_2 4 = 2$ bit，機率不均勻所以低於 2，合理。

**算例 2（通道兩端的互資訊）** 已知輸入 $X$ 為二元，$P(X=0)=0.7$、$P(X=1)=0.3$；通道把每個位元以機率 0.1 翻轉。求 $H(X)$、$H(Y)$、$H(Y\mid X)$、$I(X;Y)$ 與 $H(X\mid Y)$。

1. 輸入的熵：$H(X)=H_b(0.7) = 0.3602+0.5211 = 0.8813$ bit。
2. 輸出分布：$P(Y=0)=0.7\times 0.9+0.3\times 0.1 = 0.66$，所以 $H(Y)=H_b(0.66)=0.3956+0.5292=0.9248$ bit。
3. 條件熵：不論送 0 或 1，輸出的不確定性都來自那 0.1 的翻轉，$H(Y\mid X)=H_b(0.1)=0.3322+0.1368=0.4690$ bit。
4. 互資訊：$I(X;Y)=H(Y)-H(Y\mid X)=0.9248-0.4690=0.4558$ bit。
5. $H(X\mid Y)=H(X)-I(X;Y)=0.8813-0.4558=0.4255$ bit。

合理性檢查：用聯合機率 $0.63,\ 0.07,\ 0.03,\ 0.27$ 直接算聯合熵得 $H(X,Y)=1.3503$ bit，與 $H(X)+H(Y\mid X)=0.8813+0.4690=1.3503$ 一致。另外，若輸入改成各 0.5，互資訊會升到 $1-H_b(0.1)=0.5310$ bit，比 0.4558 大，這正是 3.7.9 要談的容量。（以上取到小數第 4 位。）

#### 常見錯誤

- 對數底用錯：用 $\log_{10}$ 或 $\ln$ 算完卻標 bit。以 2 為底才是 bit；用計算機時可用 $\log_2 x=\ln x/\ln 2$ 換算。
- 把 $H(Y\mid X)$ 和 $H(X\mid Y)$ 當成同一個量。兩者一般不相等，只有互資訊是對稱的。
- 機率沒有先確認總和為 1，或把條件機率直接當聯合機率代入聯合熵公式。
- 以為互資訊只跟通道有關。互資訊同時取決於輸入分布與通道；對輸入分布取最大值之後才是通道容量。

#### 和其他小節的關係

本節的熵是 3.7.2 信源編碼平均碼長的下限；互資訊對輸入分布取最大值就是 3.7.9 的離散通道容量。連續通道的對應結果是 3.2 的 Shannon 容量公式。3.5 的機率基礎（條件機率、期望值）是本節計算的前提。

**出處**　C. E. Shannon, "A Mathematical Theory of Communication," Bell System Technical Journal, 1948；Cover & Thomas, Elements of Information Theory（熵、相對熵與互資訊一章）。

#### 單題：Entropy of a discrete source

**3.7.1G001**　Over one hour, a 5G cell scheduler is observed to use QPSK, 16QAM, 64QAM and 256QAM on 35 %, 30 %, 25 % and 10 % of its transport blocks. Treat the modulation choice of a transport block as a memoryless discrete random variable with these probabilities. Determine its entropy in bits (base-2 logarithm), rounded to four decimal places.

<details><summary>看答案</summary>

**答案**　1.8834

**詳解**　$H = -\sum p_i\log_2 p_i$.
$-0.35\log_2 0.35 = 0.5301$; $-0.30\log_2 0.30 = 0.5211$; $-0.25\log_2 0.25 = 0.5000$; $-0.10\log_2 0.10 = 0.3322$.
$H = 0.5301 + 0.5211 + 0.5000 + 0.3322 = 1.8834$ bit.
\boxed{1.8834}

$H(X,Y) = 0.5184 + 0.2161 + 0.3322 + 0.5288 = 1.5955$ bit.
\boxed{1.5955}

**3.7.1G007**　A random variable $X \in \{0,1\}$ (indoor/outdoor user) and $Y \in \{a,b,c\}$ (serving band) have joint probabilities $p(0,a) = 0.30$, $p(0,b) = 0.10$, $p(0,c) = 0.05$, $p(1,a) = 0.05$, $p(1,b) = 0.15$, $p(1,c) = 0.35$. <details><summary>看答案</summary>

**答案**　1.2333

**詳解**　Joint entropy: terms 0.5211, 0.3322, 0.2161, 0.2161, 0.4105, 0.5301, so $H(X,Y) = 2.22612$ bit.

**3.7.1G008**　A test transmitter picks one of 4 beams uniformly at random, and independently of the beam it inserts a marker bit that equals 1 with probability 0.2. Determine the joint entropy of (beam index, marker bit) in bits (base-2 logarithm), rounded to four decimal places.

**3.7.1G009**　The number of retransmissions $X$ of a packet takes the values 0, 1, 2, 3 with probabilities 0.1, 0.2, 0.3, 0.4. A monitoring probe records only whether $X$ is even or odd, $Y = X \bmod 2$. Determine $H(X \mid Y)$ in bits (base-2 logarithm), rounded to four decimal places.

<details><summary>看答案</summary>

**詳解**　Since $Y$ is a function of $X$, $H(X,Y) = H(X)$, so $H(X \mid Y) = H(X) - H(Y)$.
$H(X)$: terms 0.3322, 0.4644, 0.5211, 0.5288, so $H(X) = 1.84644$ bit.
$P(Y=0) = P(X=0)+P(X=2) = 0.1+0.3 = 0.4$, so $H(Y) = H_b(0.4) = 0.97095$ bit.
$H(X \mid Y) = 1.84644 - 0.97095 = 0.87549$ bit $\approx 0.8755$ bit.
\boxed{0.8755}

**出處**　Cover & Thomas, Elements of Information Theory (chain rule; entropy of a function of a random variable)

#### 單題：Conditional entropy of channel outputs and inputs

**3.7.1G011**　A binary symmetric channel (BSC) flips each bit with probability 0.05. The input is 0 with probability 0.6. Determine the conditional entropy $H(Y \mid X)$ of the output given the input, in bits (base-2 logarithm), rounded to four decimal places.

<details><summary>看答案</summary>

**答案**　0.2864

**詳解**　For a BSC, whichever input is sent, the output is uncertain only through the flip, so $H(Y \mid X) = H_b(0.05)$, independent of the input distribution.
$H_b(0.05) = -0.05\log_2 0.05 - 0.95\log_2 0.95 = 0.21610 + 0.07030 = 0.28640$ bit.
\boxed{0.2864}

**出處**　Cover & Thomas, Elements of Information Theory (conditional entropy; binary symmetric channel)

#### 單題：Mutual information from a joint probability table

**3.7.1G021**　The transmitted bit $X$ and the detected bit $Y$ of a noisy link have the joint distribution $p(0,0) = 0.4$, $p(0,1) = 0.1$, $p(1,0) = 0.1$, $p(1,1) = 0.4$. Determine $I(X;Y)$ in bits (base-2 logarithm), rounded to four decimal places.

<details><summary>看答案</summary>

**答案**　0.2781

**詳解**　Marginals: $P(X=0) = P(Y=0) = 0.5$, so $H(X) = H(Y) = 1$ bit.
$H(X,Y) = 2 \times (-0.4\log_2 0.4) + 2 \times (-0.1\log_2 0.1) = 2 \times 0.52877 + 2 \times 0.33219 = 1.72193$ bit.
$I(X;Y) = H(X) + H(Y) - H(X,Y) = 2 - 1.72193 = 0.27807$ bit $\approx 0.2781$ bit.
\boxed{0.2781}

**出處**　Cover & Thomas, Elements of Information Theory (mutual information)

</details>

**答案**　No. The rule $H(Y \mid X) \le H(Y)$ holds for the average over $X$, not for every individual value $x$; a particular condition can make $Y$ more uncertain. Here the average 1.4491 bit is indeed below 1.5161 bit.

**詳解**　$H(Y \mid X) = \sum_x P(x) H(Y \mid X{=}x)$ is the quantity bounded by $H(Y)$, because $H(Y) - H(Y \mid X) = I(X;Y) \ge 0$. Single terms $H(Y \mid X{=}x)$ can exceed $H(Y)$: the night mix is closer to uniform than the overall mix. The daytime term (1.3610 bit) is well below $H(Y)$, and the weighted average stays below.

**出處**　Cover & Thomas, Elements of Information Theory (conditioning reduces entropy on average)

</details>

**3.7.1S019**　The operator also wants to know how uncertain the period is when only the service type of a session is seen, $H(X \mid Y)$. Is a new measurement campaign needed?

<details><summary>看答案</summary>

**答案**　No. The given numbers determine the full joint distribution, so $H(X \mid Y) = H(X,Y) - H(Y) = 2.4200 - 1.5161 = 0.9039$ bit can be computed directly.

**詳解**　$P(x)$ and $P(y \mid x)$ give $p(x,y) = P(x)P(y \mid x)$ for every cell, and from that every entropy and conditional entropy follows. By the chain rule in the other order, $H(X,Y) = H(Y) + H(X \mid Y)$, so $H(X \mid Y) = 2.42005 - 1.51615 = 0.90390$ bit. It is only slightly below $H(X) = 0.97095$ bit: the service type says little about the period ($I = 0.0671$ bit).

**出處**　Cover & Thomas, Elements of Information Theory (chain rule; Bayes' rule)

</details>

**3.7.1S020**　A report computes the joint entropy of period and service as follows:
1. $H(X) = H_b(0.6) = 0.9710$ bit.
2. Overall service mix (0.44, 0.36, 0.20), so $H(Y) = 1.5161$ bit.
3. $H(X,Y) = H(X) + H(Y) = 0.9710 + 1.5161 = 2.4871$ bit.

Which step is wrong, and what is the correct result?

<details><summary>看答案</summary>

**答案**　Step 3 is wrong: $H(X,Y) = H(X) + H(Y)$ holds only if $X$ and $Y$ are independent, which they are not (the service mix depends on the period). The chain rule gives $H(X,Y) = H(X) + H(Y \mid X) = 0.9710 + 1.4491 = 2.4200$ bit.

**詳解**　The overstatement $2.4871 - 2.4200 = 0.0671$ bit is exactly the mutual information $I(X;Y)$ that the incorrect step ignores.

**出處**　Cover & Thomas, Elements of Information Theory (chain rule for entropy)

</details>

#### 情境題：Mutual information over binary channels

**Scenario | Intensity-modulated fibre link**

A 10 Gbit/s intensity-modulated fibre link is modelled, after hard decisions, as a binary symmetric channel (BSC) with bit-flip probability 0.03 (a deliberately degraded test condition). The line code makes the transmitted bits independent and equiprobable.

**3.7.1S021**　What is the mutual information between transmitted and detected bit, per channel use? Give the answer in bits (base-2 logarithm), rounded to four decimal places.

**答案**　0.8056 bit

**詳解**　$H_b(0.03) = -0.03\log_2 0.03 - 0.97\log_2 0.97 = 0.15177 + 0.04263 = 0.19439$ bit.
With equiprobable input, $I = 1 - H_b(0.03) = 1 - 0.19439 = 0.80561$ bit $\approx 0.8056$ bit.

**出處**　Cover & Thomas, Elements of Information Theory (binary symmetric channel)

</details>

**3.7.1S022**　What is the corresponding mutual-information rate of the link? Give the answer in Gbit/s, rounded to three decimal places.

<details><summary>看答案</summary>

**答案**　8.056 Gbit/s

**詳解**　One channel use per line bit: $10 \times 10^9$ uses/s. Rate $= 0.80561 \times 10 = 8.0561$ Gbit/s $\approx 8.056$ Gbit/s.

**出處**　Cover & Thomas, Elements of Information Theory (mutual information; channel capacity)

</details>

**3.7.1S023**　If a faulty scrambler made the transmitted bits equal 1 only 20 % of the time, would the mutual information per bit rise or fall? Why?

<details><summary>看答案</summary>

**答案**　It would fall (to about 0.5621 bit), because for a BSC the mutual information is maximised by equiprobable inputs; a biased input lowers $H(Y)$ while $H(Y \mid X) = H_b(0.03)$ is unchanged.

**詳解**　$I = H(Y) - H(Y \mid X)$, and $H(Y \mid X) = H_b(p)$ does not depend on the input distribution. With $P(X=1) = 0.2$, $P(Y=1) = 0.2 \times 0.97 + 0.8 \times 0.03 = 0.218$, and $H(Y) = H_b(0.218) = 0.7565$ bit, so $I = 0.7565 - 0.1944 = 0.5621$ bit. The input distribution and the channel together determine $I$.

**出處**　Cover & Thomas, Elements of Information Theory (mutual information depends on input distribution)

</details>

**3.7.1S024**　What would the mutual information be if the bit-flip probability rose to 0.5? And if, through a polarity inversion, it were 0.97?

<details><summary>看答案</summary>

**答案**　At 0.5 it is zero: the output is independent of the input. At 0.97 it is again 0.8056 bit, because $H_b(0.97) = H_b(0.03)$; the receiver simply inverts every decision.

**詳解**　$I = 1 - H_b(p)$ for equiprobable input. $H_b(0.5) = 1$, so $I = 0$. $H_b$ is symmetric about 0.5, so a channel that almost always flips is as informative as one that almost never flips, as long as the receiver knows the polarity.

**出處**　Cover & Thomas, Elements of Information Theory (binary entropy function; BSC)

</details>

**3.7.1S025**　A technician estimates the information rate:

2. $I = 1 - 0.2 = 0.8$ bit per bit.

**出處**　Cover & Thomas, Elements of Information Theory (binary symmetric channel)

**Scenario | Erasures on a low-power wide-area link**

An IoT uplink uses a code whose decoder either delivers a bit correctly or flags it as erased; it never delivers a wrong bit. **3.7.1S026**　What is the mutual information $I(X;Y)$ per channel use? Give the answer in bits (base-2 logarithm), rounded to four decimal places.

<details><summary>看答案</summary>

**答案**　0.8739 bit

**詳解**　$H(X) = H_b(0.4) = 0.52877 + 0.44218 = 0.97095$ bit.
For a BEC, $I = (1 - \varepsilon) H(X) = 0.9 \times 0.97095 = 0.87386$ bit $\approx 0.8739$ bit.

**出處**　Cover & Thomas, Elements of Information Theory (binary erasure channel)

</details>

**3.7.1S027**　What is the remaining uncertainty about the transmitted bit after the output is seen, $H(X \mid Y)$? Give the answer in bits, rounded to four decimal places.

<details><summary>看答案</summary>

**答案**　0.0971 bit

**詳解**　$H(X \mid Y) = \varepsilon H(X) = 0.1 \times 0.97095 = 0.09710$ bit $\approx 0.0971$ bit. (Check: $H(X) - I = 0.97095 - 0.87386 = 0.09710$ bit.)

**3.7.1S028**　Why does an erased output leave the receiver with exactly the prior uncertainty $H(X)$ about that bit, rather than some reduced amount?

<details><summary>看答案</summary>

**答案**　Because an erasure occurs with the same probability whatever bit was sent, so observing it does not change the probabilities of 0 and 1: the posterior equals the prior (0.6, 0.4).

**詳解**　$P(X=1 \mid Y=e) = P(Y=e \mid X=1)P(X=1)/P(Y=e) = 0.1 \times 0.4/0.1 = 0.4$. The erasure event is independent of $X$, so it carries no information about $X$, and $H(X \mid Y=e) = H(X)$. Unerased outputs remove all uncertainty, so $H(X \mid Y) = P(e) H(X)$.

**出處**　Cover & Thomas, Elements of Information Theory (binary erasure channel; Bayes' rule)

</details>

**3.7.1S029**　With equiprobable inputs, which carries more information per use: a BEC with erasure probability 0.1 or a BSC with flip probability 0.1? Why?

<details><summary>看答案</summary>

**答案**　The BEC: 0.9 bit versus $1 - H_b(0.1) = 0.531$ bit for the BSC. In the BEC the receiver knows which bits are unreliable; in the BSC errors are hidden among correct bits.

**詳解**　BEC: $I = 1 - 0.1 = 0.9$ bit. BSC: $I = 1 - H_b(0.1) = 1 - 0.469 = 0.531$ bit. Knowledge of the error positions is valuable: correcting an erasure needs less redundancy than finding and correcting an unknown error.

**3.7.1S030**　An engineer computes the mutual information of the IoT link:

**3.7.1S031**　With equiprobable input bits, what is the mutual information per channel use? Give the answer in bits (base-2 logarithm), rounded to four decimal places.

**3.7.1S032**　If pulses are sent only 40 % of the time ($P(X=1) = 0.4$), what is the mutual information per channel use? Give the answer in bits, rounded to four decimal places.

**3.7.1S033**　Sending fewer pulses increased the mutual information (0.5568 bit against 0.5488 bit). Why can a non-uniform input be better here, when for a BSC the uniform input is best?

<details><summary>看答案</summary>

**答案**　The Z-channel is asymmetric: only the 1s are corrupted. Using 1s less often reduces the noise term $P(X=1)H_b(0.25)$ faster than it reduces $H(Y)$, so the optimum input has $P(X=1)$ below 0.5 (about 0.43 for this channel).

**詳解**　$I(p_1) = H_b(0.75 p_1) - p_1 H_b(0.25)$. For a symmetric channel the uniform input maximises $I$ by symmetry, but here the noise is only on one input symbol. **3.7.1S034**　When the receiver counts a photon ($Y = 1$), how uncertain is the transmitted bit? What about when it counts none ($Y = 0$)?

<details><summary>看答案</summary>

**答案**　$Y = 1$ leaves no uncertainty: only a pulse can produce a count, so $X = 1$ for sure. $Y = 0$ is ambiguous: it can be a 0 or a missed pulse, so all of $H(X \mid Y)$ comes from the $Y = 0$ outcomes.

**詳解**　$P(X=1 \mid Y=1) = 1$, so $H(X \mid Y=1) = 0$. With equiprobable input, $P(Y=0) = 0.625$ and $P(X=1 \mid Y=0) = 0.125/0.625 = 0.2$, so $H(X \mid Y=0) = H_b(0.2) = 0.7219$ bit and $H(X \mid Y) = 0.625 \times 0.7219 = 0.4512$ bit (consistent with $H(X) - I = 1 - 0.5488$).

**3.7.1S035**　A designer computes the mutual information with equiprobable inputs:

#### 情境題：Mutual information from joint probabilities

**Scenario | One-bit channel-state feedback**

A channel state $S$ takes three levels, poor, medium and good, with probabilities 0.2, 0.5 and 0.3. To save signalling, the terminal sends a 1-bit report $R$: $R = 0$ if the state is poor and $R = 1$ if it is medium or good. The mapping is deterministic and the report is received without error.

**3.7.1S041**　What is the entropy of the channel state $H(S)$? Give the answer in bits (base-2 logarithm), rounded to four decimal places.

<details><summary>看答案</summary>

**答案**　1.4855 bit

**詳解**　Terms: $0.2 \to 0.46439$, $0.5 \to 0.50000$, $0.3 \to 0.52109$. $H(S) = 1.48548$ bit $\approx 1.4855$ bit.

**出處**　Cover & Thomas, Elements of Information Theory (entropy)

</details>

**3.7.1S042**　What is the mutual information $I(S;R)$ between the state and the report? Give the answer in bits, rounded to four decimal places.

<details><summary>看答案</summary>

**答案**　0.7219 bit

**詳解**　$R$ is a function of $S$, so $H(R \mid S) = 0$ and $I(S;R) = H(R) - H(R \mid S) = H(R)$. $P(R=0) = 0.2$, so $I = H_b(0.2) = 0.46439 + 0.25754 = 0.72193$ bit $\approx 0.7219$ bit.

**出處**　Cover & Thomas, Elements of Information Theory (mutual information; function of a random variable)

</details>

**3.7.1S043**　Why is $I(S;R)$ exactly equal to $H(R)$ here, and what would change if the report link had errors?

<details><summary>看答案</summary>

**答案**　Because the report is a deterministic function of the state, it has no uncertainty given $S$; all its entropy is information about $S$. With report errors, $H(R \mid S) > 0$ and $I(S;R)$ would drop below $H(R)$.

**詳解**　$I(S;R) = H(R) - H(R \mid S)$. A deterministic mapping gives $H(R \mid S) = 0$. Any randomness added between $S$ and $R$ (channel errors, noisy measurement) contributes to $H(R \mid S)$ without adding information about $S$.

**出處**　Cover & Thomas, Elements of Information Theory (mutual information)

</details>

**3.7.1S044**　Keeping a 1-bit report, which grouping of the three states maximises $I(S;R)$, and how large is the maximum?

<details><summary>看答案</summary>

**答案**　The grouping whose two halves are closest to probability 0.5: {medium} versus {poor, good}, which gives $P(R=0) = 0.5$ and $I = H_b(0.5) = 1$ bit, the maximum possible for a 1-bit report.

**詳解**　For a deterministic 1-bit report $I = H_b(P(R=0))$, which grows as $P(R=0)$ approaches 0.5. The options are $H_b(0.2) = 0.722$ bit ({poor}), $H_b(0.3) = 0.881$ bit ({good}) and $H_b(0.5) = 1$ bit ({medium}). Whether this grouping is useful for scheduling is a separate question: maximum information is not the same as the most useful distinction.

**出處**　Cover & Thomas, Elements of Information Theory (entropy bounds); quantizer design for feedback

</details>

**3.7.1S045**　An analyst computes the uncertainty about the state that remains after the report, $H(S \mid R)$:

**3.7.1S048**　The entropy calculation assumed that consecutive reports from the same meter are independent. In reality a meter usually repeats its previous state. How does this affect the true minimum average number of bits per report?

<details><summary>看答案</summary>

**答案**　It lowers it. With memory, the relevant limit is the entropy rate $H(X_n \mid X_{n-1}, \ldots)$, which is at most the single-report entropy of 1.918 bit; a coder that exploits the dependence (for example coding only changes) can go below 1.918 bit per report.

**答案**　The bound becomes 5.2 bit per symbol (3.604 nat). The number of labels (6 bits) no longer limits $I$; the input entropy $H(X) = 5.2$ bit does.

**詳解**　$I(X;Y) \le H(X)$ and $H(X) = 5.2$ bit for the shaped constellation. In nats, $5.2 \times \ln 2 = 3.6043$ nat. Shaping trades some input entropy for a gain in mutual information at a given SNR; it never allows $I$ to exceed $H(X)$.

#### 情境題：Entropy rate of sources with memory

**Scenario | Gilbert–Elliott channel state sequence**

A slow-fading radio link is modelled by a two-state Gilbert–Elliott chain with one state per slot. From the good state the link moves to the bad state with probability 0.02 per slot; from the bad state it returns to the good state with probability 0.2 per slot. The chain is stationary.

**3.7.1S056**　What is the entropy rate of the state sequence, $H(X_n \mid X_{n-1})$? Give the answer in bits per slot (base-2 logarithm), rounded to four decimal places.

<details><summary>看答案</summary>

**答案**　0.1942 bit per slot

**詳解**　Stationary probabilities: $\pi_G = 0.2/(0.02 + 0.2) = 0.909091$, $\pi_B = 0.02/0.22 = 0.090909$.
$H_b(0.02) = 0.14144$ bit; $H_b(0.2) = 0.72193$ bit.
Entropy rate $= 0.909091 \times 0.14144 + 0.090909 \times 0.72193 = 0.12858 + 0.06563 = 0.19421$ bit/slot $\approx 0.1942$ bit/slot.

**出處**　Cover & Thomas, Elements of Information Theory (entropy rate of a Markov chain)

</details>

**3.7.1S057**　The single-slot entropy of the state, $H_b(\pi_B) = H_b(0.0909)$, is 0.4395 bit. Why is the entropy rate (0.1942 bit) so much smaller?

<details><summary>看答案</summary>

**答案**　Because the states are strongly correlated from slot to slot: knowing the current state makes the next one very predictable (the good state persists with probability 0.98). The entropy rate counts only the new uncertainty per slot.

**詳解**　$H(X_n \mid X_{n-1}) \le H(X_n)$, with equality only if successive states are independent. With long sojourns in each state, the previous state removes most of the uncertainty. A coder that exploits this memory (for example run-length coding of state changes) can describe the state sequence with about 0.19 bit per slot instead of 0.44.

**出處**　Cover & Thomas, Elements of Information Theory (entropy rate; conditioning reduces entropy)

</details>

**3.7.1S058**　Under what transition probabilities would the entropy rate equal the single-slot entropy $H(\pi)$, keeping $P(G \to B) = 0.02$?

<details><summary>看答案</summary>

**答案**　When the next state does not depend on the current one, i.e. both rows of the transition matrix are equal: $P(B \mid B) = P(B \mid G) = 0.02$, so $P(B \to G) = 0.98$. The chain is then an i.i.d. sequence with $\pi_B = 0.02$.

**詳解**　Equality $H(X_n \mid X_{n-1}) = H(X_n)$ requires $X_n$ independent of $X_{n-1}$. Then each slot is bad with probability 0.02 regardless of the past, $\pi_B = 0.02/(0.02 + 0.98) = 0.02$, and the entropy rate equals $H_b(0.02) = 0.1414$ bit (a different value from before, because $\pi$ has changed).

**出處**　Cover & Thomas, Elements of Information Theory (entropy rate of Markov chains)

</details>

**3.7.1S059**　A student computes the entropy rate:
1. $\pi_G = 0.2/0.22 = 0.9091$, $\pi_B = 0.0909$.
2. $H_b(0.02) = 0.1414$ bit (row of the good state), $H_b(0.2) = 0.7219$ bit (row of the bad state).
3. Entropy rate $= 0.0909 \times 0.1414 + 0.9091 \times 0.7219 = 0.6692$ bit per slot.

Which step is wrong, and what is the correct result?

<details><summary>看答案</summary>

**答案**　Step 3 is wrong: the weights are swapped. Each row entropy must be weighted by the stationary probability of the state it starts from: $0.9091 \times 0.1414 + 0.0909 \times 0.7219 = 0.1942$ bit per slot.

**詳解**　$0.909091 \times 0.14144 = 0.12858$; $0.090909 \times 0.72193 = 0.06563$; sum $0.19421$ bit/slot.

**出處**　Cover & Thomas, Elements of Information Theory (entropy rate of a stationary Markov chain)

</details>

**3.7.1S060**　Another student computes the entropy rate:
1. $\pi_G = 0.2/0.22 \approx 0.9$, $\pi_B \approx 0.1$.
2. Entropy rate $= 0.9 \times H_b(0.02) + 0.1 \times H_b(0.2) = 0.9 \times 0.14144 + 0.1 \times 0.72193 = 0.12730 + 0.07219 = 0.1995$ bit per slot.

Which step is wrong, and what is the correct result?

<details><summary>看答案</summary>

**答案**　Step 1 is wrong: the stationary probabilities are rounded too early (0.9091 and 0.0909 rounded to 0.9 and 0.1), which shifts the four-decimal result. Correct: $0.909091 \times 0.14144 + 0.090909 \times 0.72193 = 0.1942$ bit per slot.

**詳解**　$0.12858 + 0.06563 = 0.19421$ bit/slot. The early rounding overstates the bad-state weight by 10 %, giving a 2.7 % error.

**出處**　Cover & Thomas, Elements of Information Theory (entropy rate of a Markov chain)

</details>
