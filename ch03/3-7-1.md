# 3.7.1 熵與互資訊

所屬：[3.7 資訊理論與編碼](3-7.md)

## 內文

#### 為什麼要學

電信網路裡所有「能壓多小」和「能傳多快」的問題，最後都回到熵（entropy）與互資訊（mutual information）。語音與影像編碼器能把位元率壓到多低，下限是信源的熵；一條通道在給定雜訊下最多能可靠傳送多少位元，上限是輸入與輸出之間互資訊的最大值，也就是通道容量。調變編碼方案（MCS）的碼率設計、鏈路自適應的目標頻譜效率，以及近年用互資訊當指標來評估接收機效能的做法，都以這兩個量為基礎。學會用機率表直接算出熵、條件熵與互資訊，後面談信源編碼、通道編碼與容量時才有共同的語言。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $X, Y$ | 離散隨機變數（例如通道的輸入與輸出） | 無 |
| $p(x)$ | $X$ 取值 $x$ 的機率 | 無（0～1） |
| $p(x,y)$ | $X=x$ 且 $Y=y$ 的聯合機率 | 無 |
| $p(y\mid x)$ | 已知 $X=x$ 時 $Y=y$ 的條件機率 | 無 |
| $H(X)$ | $X$ 的熵 | bit（以 $\log_2$ 計算時） |
| $H(X,Y)$ | 聯合熵 | bit |
| $H(Y\mid X)$ | 已知 $X$ 時 $Y$ 的條件熵 | bit |
| $I(X;Y)$ | $X$ 與 $Y$ 的互資訊 | bit |
| $H_b(p)$ | 二元熵函數 | bit |

#### 公式與推導

熵是「平均而言，知道一個符號的結果能得到多少資訊」：

$$H(X) = -\sum_{x} p(x)\log_2 p(x)$$

約定 $0\log_2 0 = 0$。若 $X$ 有 $M$ 種可能的取值，則 $0 \le H(X) \le \log_2 M$；完全確定時為 0，各取值機率相等時達到上限。只有兩種取值、機率為 $p$ 與 $1-p$ 時，熵寫成二元熵函數：

$$H_b(p) = -p\log_2 p-(1-p)\log_2(1-p)$$

兩個變數一起看時，聯合熵與條件熵為

$$H(X,Y) = -\sum_{x,y} p(x,y)\log_2 p(x,y),\qquad H(Y\mid X) = -\sum_{x,y} p(x,y)\log_2 p(y\mid x)$$

兩者滿足連鎖律 $H(X,Y)=H(X)+H(Y\mid X)$。這條式子可以直接由 $p(x,y)=p(x)\,p(y\mid x)$ 取對數後求期望值得到。

互資訊是「知道 $Y$ 之後，$X$ 的不確定性減少了多少」：

$$I(X;Y) = H(X)-H(X\mid Y) = H(Y)-H(Y\mid X) = H(X)+H(Y)-H(X,Y)$$

三種寫法等價，計算時挑手上資料最好算的那一個。互資訊恆不為負，而且對 $X$、$Y$ 對稱；兩者獨立時為 0，$Y$ 完全決定 $X$ 時等於 $H(X)$。由 $I(X;Y)\ge 0$ 可以得到「取條件不會讓熵變大」：$H(X\mid Y)\le H(X)$。

適用條件：以上是離散隨機變數的定義，對數取 2 為底時單位是 bit，取自然對數時單位是 nat（1 nat $=1/\ln 2\approx 1.4427$ bit）。連續變數要改用微分熵，性質不完全相同（例如可以為負），不能直接套用這裡的界限。

#### 算例

**算例 1（信源的熵）** 已知某信源有四種符號，機率為 $0.5,\ 0.25,\ 0.125,\ 0.125$。求熵。

選公式 $H(X)=-\sum p\log_2 p$。代入：

$$H = 0.5\times 1 + 0.25\times 2 + 0.125\times 3 + 0.125\times 3 = 0.5+0.5+0.375+0.375 = 1.75\ \text{bit}$$

合理性檢查：四種符號的上限是 $\log_2 4 = 2$ bit，機率不均勻所以低於 2，合理。

**算例 2（通道兩端的互資訊）** 已知輸入 $X$ 為二元，$P(X=0)=0.7$、$P(X=1)=0.3$；通道把每個位元以機率 0.1 翻轉。求 $H(X)$、$H(Y)$、$H(Y\mid X)$、$I(X;Y)$ 與 $H(X\mid Y)$。

1. 輸入的熵：$H(X)=H_b(0.7) = 0.3602+0.5211 = 0.8813$ bit。
2. 輸出分布：$P(Y=0)=0.7\times 0.9+0.3\times 0.1 = 0.66$，所以 $H(Y)=H_b(0.66)=0.3956+0.5292=0.9248$ bit。
3. 條件熵：不論送 0 或 1，輸出的不確定性都來自那 0.1 的翻轉，$H(Y\mid X)=H_b(0.1)=0.3322+0.1368=0.4690$ bit。
4. 互資訊：$I(X;Y)=H(Y)-H(Y\mid X)=0.9248-0.4690=0.4558$ bit。
5. $H(X\mid Y)=H(X)-I(X;Y)=0.8813-0.4558=0.4255$ bit。

合理性檢查：用聯合機率 $0.63,\ 0.07,\ 0.03,\ 0.27$ 直接算聯合熵得 $H(X,Y)=1.3503$ bit，與 $H(X)+H(Y\mid X)=0.8813+0.4690=1.3503$ 一致。另外，若輸入改成各 0.5，互資訊會升到 $1-H_b(0.1)=0.5310$ bit，比 0.4558 大，這正是 3.7.9 要談的容量。（以上取到小數第 4 位。）

#### 常見錯誤

- 對數底用錯：用 $\log_{10}$ 或 $\ln$ 算完卻標 bit。以 2 為底才是 bit；用計算機時可用 $\log_2 x=\ln x/\ln 2$ 換算。
- 把 $H(Y\mid X)$ 和 $H(X\mid Y)$ 當成同一個量。兩者一般不相等，只有互資訊是對稱的。
- 機率沒有先確認總和為 1，或把條件機率直接當聯合機率代入聯合熵公式。
- 以為互資訊只跟通道有關。互資訊同時取決於輸入分布與通道；對輸入分布取最大值之後才是通道容量。

#### 和其他小節的關係

本節的熵是 3.7.2 信源編碼平均碼長的下限；互資訊對輸入分布取最大值就是 3.7.9 的離散通道容量。連續通道的對應結果是 3.2 的 Shannon 容量公式。3.5 的機率基礎（條件機率、期望值）是本節計算的前提。

**出處**　C. E. Shannon, "A Mathematical Theory of Communication," Bell System Technical Journal, 1948；Cover & Thomas, Elements of Information Theory（熵、相對熵與互資訊一章）。
