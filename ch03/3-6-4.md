# 3.6.4 答案格式與有效位數

所屬：[3.6 解題方法](3-6.md)

## 內文

#### 為什麼要學

同一個計算結果可以寫成 $-120.96$ dBm、$-121$ dBm、$8.01\times10^{-16}$ W 或 0.0000000000000008 W，哪一個「對」，取決於題目要求的單位與取位方式。答案的格式本身帶有資訊：寫 31.6 Mbps 表示大約準到 0.1 Mbps，寫 31.608044 Mbps 則暗示輸入資料有八位數的準確度，這在工程上幾乎不可能。反過來，中間值取位太早會讓最後答案出現不該有的誤差。規格書、測試報告與自動評分系統都依賴固定的寫法，答案數值對了但單位漏寫或取位不符，實務上等同答錯。

#### 定義與符號

| 項目 | 意思 | 例子 |
|---|---|---|
| 有效位數（significant figures） | 從第一個非零數字起算的位數，表示相對精確度 | 0.00347 有 3 位；$8.01\times10^{-16}$ 有 3 位 |
| 小數位數（decimal places） | 小數點後的位數，表示絕對精確度 | $-120.96$ 有 2 位小數、5 位有效數字 |
| 四捨五入（rounding） | 捨去位的第一個數字為 5 以上則進位，否則捨去 | 97.181 取小數 2 位為 97.18 |
| 科學記號（scientific notation） | 寫成 $a\times10^{n}$，$1\le a<10$，可以明確表示有效位數 | $3.16\times10^{7}$ bit/s |
| 保護位數（guard digit） | 中間值比答案多留的位數 | 答案取小數 2 位時，中間值留 4 位 |
| 過早取位（premature rounding） | 在中間步驟就取到最後答案的位數，誤差被後續運算放大 | 熵 1.846 先取成 1.8 |
| 單位標示 | 答案的數值後面必須有單位，一般數值與單位之間留一個空格，平面角符號 °、′、″ 為例外，不留空格 | 31.6 Mbps、$-48.33$ dBm |

#### 公式與推導

**有效位數與小數位數的差別。** 有效位數管的是相對誤差，小數位數管的是絕對誤差，兩者不能互換。$8.0078\times10^{-16}$ W 取 3 位有效數字是 $8.01\times10^{-16}$ W；若要求「小數第 2 位」，以 W 為單位就會變成 0.00，沒有意義。因此極大或極小的線性量用有效位數配科學記號（或換一個合適的詞頭，例如 nW），dB 類的對數量則用小數位數（通常 1 或 2 位）。

**數零的規則。** 開頭的零不算有效位數（0.00347 是 3 位）；夾在中間的零算（1.05 是 3 位）；小數點後結尾的零算（2.50 是 3 位）；整數結尾的零則有歧義（2500 可能是 2、3 或 4 位），要明確時改寫成 $2.50\times10^3$。

**四則運算後留幾位。** 乘除的結果，有效位數取輸入中最少的那個；加減的結果，小數位數取輸入中最少的那個。這是估計用的經驗法則，題目有指定取位時以題目為準。對數運算有一點要留意：dB 值的小數位對應線性值的有效位數，$\pm0.01$ dB 相當於線性值約 $\pm0.23\%$，所以 dB 值寫到小數第 2 位大約對應線性值 3 位有效數字。

**常數的精確度會限制答案的精確度。** 熱雜訊密度的精確值是

$$10\log_{10}\!\left(\frac{1.380649\times10^{-23} \times 290}{10^{-3}}\right) = -173.98\ \text{dBm/Hz}$$

慣用的 $-174$ 已經取過位，用它算出來的結果在小數第 2 位並不可靠。同理，光速取 $3\times10^8$ m/s、FSPL 常數取 32.44 或 92.45，都會讓答案在 0.01 dB 的層級有出入。題目若要求小數第 2 位，應說明採用哪個常數值。

**取位的時機。** 準則是「算到最後才取位，而且只取一次」。中間值至少比答案多留 2 位；dB 轉成的線性值至少留 4 位有效數字。過早取位的誤差會被後面的運算放大，尤其是相減（兩個相近的數相減，有效位數會大幅減少）、相除與指數運算（$10^{x/10}$ 中 $x$ 差 0.1，結果差約 2.3%）。

**答案的寫法。** 依序檢查五件事：單位是不是題目要的；取位方式是不是題目要的；數值與單位之間有沒有空格（例如 31.6 Mbps）；單位符號大小寫是否正確（k 小寫、M 與 G 大寫，mW 與 MW 差 $10^9$ 倍）；有沒有把題目未指定而採用的假設一併寫出。百分比與小數擇一，並寫清楚（0.0522 或 5.22%）。

#### 算例

**算例 1（小數位數與有效位數）** 求 290 K 下頻寬 200 kHz 的熱雜訊功率，分別以 W（3 位有效數字）與 dBm（小數第 2 位）表示。公式見 3.1.5，$N = kTB$。

$$N = 1.380649\times10^{-23} \times 290 \times 2\times10^{5} = 8.0078\times10^{-16}\ \text{W}$$

取 3 位有效數字：$8.01\times10^{-16}$ W。

$$N_{\text{dBm}} = 10\log_{10}\!\left(\frac{8.0078\times10^{-16}}{10^{-3}}\right) = -120.96\ \text{dBm}$$

寫法比較：

| 寫法 | 判斷 |
|---|---|
| $8.01\times10^{-16}$ W | 正確：3 位有效數字，有單位 |
| $-120.96$ dBm | 正確：小數第 2 位，有單位 |
| $8.0\times10^{-16}$ W | 只有 2 位有效數字，不符要求 |
| 0.00 W | 把「3 位有效數字」誤解成小數位數 |
| $-120.96$ | 漏了單位，無法分辨是 dBm 還是 dBW |
| $-120.99$ dBm | 用 $-174 + 10\log_{10}(2\times10^5) = -174 + 53.01$ 算出；$-174$ 已取過位，小數第 2 位不可靠 |

最後一列說明：題目要求小數第 2 位時，應該用精確常數計算；若題目指定「熱雜訊密度取 $-174$ dBm/Hz」，則 $-120.99$ dBm 才是符合題意的答案。兩者相差 0.03 dB，來源是常數而不是計算。

**算例 2（中間值不要太早取位）** 某信源有 4 個符號，機率為 0.4、0.3、0.2、0.1，以霍夫曼編碼（3.7.2）得到碼長 1、2、3、3。求編碼效率，以百分比表示，取小數第 2 位。

熵（3.7.1），中間值保留 4 位小數：

$$H = 0.4\log_2\frac{1}{0.4} + 0.3\log_2\frac{1}{0.3} + 0.2\log_2\frac{1}{0.2} + 0.1\log_2\frac{1}{0.1} = 0.5288 + 0.5211 + 0.4644 + 0.3322 = 1.8464\ \text{bit/符號}$$

（四項取位後相加為 1.8465，未取位的總和為 1.84644，以後者為準；這 0.0001 的差異正是保護位數要吸收的誤差。）

平均碼長：$\bar{L} = 0.4\times1 + 0.3\times2 + 0.2\times3 + 0.1\times3 = 1.9$ bit/符號。

$$\eta = \frac{H}{\bar{L}} = \frac{1.8464}{1.9} = 0.97181 \Rightarrow 97.18\%$$

過早取位的後果：若先把 $H$ 取成 1.8，得到 $1.8/1.9 = 94.74\%$，差了 2.44 個百分點；取成 1.85 則得到 97.37%，仍差 0.19 個百分點。兩者都不符合「小數第 2 位」的要求。合理性檢查：霍夫曼碼的平均碼長滿足 $H \le \bar{L} < H + 1$，效率必須小於或等於 100%，97.18% 符合。

#### 常見錯誤

1. **把有效位數和小數位數當成同一件事。** 「3 位有效數字」寫成小數 3 位，或對 $10^{-16}$ 等級的量取小數位。
2. **中間值過早取位。** 特別是 dB 轉線性之前、相減之前、做除法之前。
3. **答案沒有單位或單位寫錯。** dBm 寫成 dB、Mbps 寫成 MBps、mW 寫成 MW。
4. **寫出過多位數。** 把計算機顯示的十幾位全部抄上，而輸入資料只有 2～3 位有效數字；或用 $-174$、$3\times10^8$ 這類取過位的常數卻報到小數第 3 位。

#### 和其他小節的關係

3.6.2 的中間值保留位數依本節的準則決定；3.6.3 處理單位換算，本節處理單位與數值的寫法。算例用到 3.1.5 的熱雜訊功率、3.7.1 的熵與 3.7.2 的霍夫曼編碼效率。3.6.5 驗算時要留意：取位造成的微小差異不算錯誤，差到 3 dB、10 dB 或 30 dB 才是。

#### 單題：Subtracting close numbers without losing precision

<details><summary>看答案</summary>

**詳解**　Step 1, the frequency term and constant cancel, so $\Delta = 20\log_{10}(3.55) - 20\log_{10}(3.42)$. Step 2, $20\log_{10}(3.55) = 11.004567$ dB and $20\log_{10}(3.42) = 10.680522$ dB.
