# 3.5.2 機率與隨機變數

所屬：[3.5 基礎數理](3-5.md)

## 內文

#### 為什麼要學

電信網路裡幾乎所有關鍵指標都是機率：封包錯誤率、掉話率、涵蓋機率、告警的誤報率。使用者何時發起通話、封包何時到達、通道此刻好不好，都無法事先確定，只能用隨機變數描述。條件機率與貝氏定理用來回答「告警響了，真的故障的機率有多少」；期望值與變異數用來描述平均負載與波動；二項分布描述固定次數傳送中的錯誤個數，卜瓦松分布描述一段時間內的到達數或稀有錯誤個數，高斯分布則是熱雜訊與陰影衰落（以 dB 計）的標準模型。後面的排隊、錯誤率與涵蓋機率計算都建立在這些工具上。

#### 定義與符號

| 符號 | 意思 | 單位 |
|---|---|---|
| $P(A)$ | 事件 $A$ 發生的機率 | 無單位（0～1） |
| $P(A\mid B)$ | 已知 $B$ 發生時 $A$ 的條件機率 | 無單位 |
| $X$ | 隨機變數 | 視情境而定 |
| $E[X]$、$\mu$ | 期望值（平均） | 與 $X$ 相同 |
| $\mathrm{Var}(X)$、$\sigma^2$ | 變異數 | $X$ 單位的平方 |
| $\sigma$ | 標準差 | 與 $X$ 相同 |
| $n$、$p$ | 二項分布的試驗次數、單次成功（或錯誤）機率 | 次、無單位 |
| $\lambda$ | 卜瓦松分布的平均個數 | 個（每個觀察區間） |
| $Q(x)$ | 標準常態分布的右尾機率 | 無單位 |

#### 公式與推導

條件機率的定義是 $P(A\mid B) = P(A\cap B)/P(B)$，前提是 $P(B) > 0$。把事件 $B$ 依互斥且涵蓋全部的情況 $A_1,\dots,A_m$ 拆開，得到全機率公式 $P(B) = \sum_i P(B\mid A_i)P(A_i)$，再代回定義就是貝氏定理（Bayes' theorem）：

$$P(A_k\mid B) = \frac{P(B\mid A_k)\,P(A_k)}{\sum_i P(B\mid A_i)\,P(A_i)}$$

其中 $P(A_k)$ 稱為事前機率，$P(A_k\mid B)$ 稱為事後機率。若 $P(A\cap B) = P(A)P(B)$，則 $A$、$B$ 獨立。

離散隨機變數的期望值是 $E[X] = \sum_x x\,P(X = x)$，變異數是 $\mathrm{Var}(X) = E[(X-\mu)^2] = E[X^2] - \mu^2$。期望值永遠可以相加：$E[X+Y] = E[X] + E[Y]$；變異數只有在 $X$、$Y$ 不相關（例如獨立）時才能相加。

三個常用分布如下。

二項分布（binomial）：$n$ 次獨立試驗、每次成功機率同為 $p$，成功次數 $K$ 滿足

$$P(K = k) = \binom{n}{k}p^k(1-p)^{n-k},\qquad E[K] = np,\quad \mathrm{Var}(K) = np(1-p)$$

卜瓦松分布（Poisson）：平均個數為 $\lambda$，

$$P(K = k) = \frac{\lambda^k e^{-\lambda}}{k!},\qquad E[K] = \mathrm{Var}(K) = \lambda$$

當 $n$ 很大、$p$ 很小時，二項分布可以用 $\lambda = np$ 的卜瓦松分布近似，這就是「稀有事件」模型的由來。

高斯分布（Gaussian，又稱常態分布）$X\sim\mathcal{N}(\mu,\sigma^2)$ 的機率密度是

$$f(x) = \frac{1}{\sqrt{2\pi}\,\sigma}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

計算機率時先標準化 $Z = (X-\mu)/\sigma$，再用 $Q$ 函數：$P(X > a) = Q\big((a-\mu)/\sigma\big)$，其中 $Q(x) = \frac{1}{\sqrt{2\pi}}\int_x^\infty e^{-t^2/2}\,dt$。常用值：$Q(1.645)\approx0.05$、$Q(1.96)\approx0.025$、$Q(2.576)\approx0.005$。

#### 算例

**算例 1：告警的可信度（貝氏定理）。** 已知（假設）：某時段有 2% 的基地台真的故障；監控規則在故障時有 95% 的機率發出告警，在正常時有 5% 的機率誤報。某站發出告警，求它真的故障的機率。

1. 設 $F$ 為故障、$A$ 為告警。$P(F) = 0.02$，$P(A\mid F) = 0.95$，$P(A\mid \bar F) = 0.05$。
2. 全機率：$P(A) = 0.95\times0.02 + 0.05\times0.98 = 0.019 + 0.049 = 0.068$。
3. 貝氏定理：$P(F\mid A) = 0.019/0.068 = 0.279$，約 27.9%。

合理性檢查：以 1,000 個站來看，20 個故障站中有 19 個告警，980 個正常站中有 49 個誤報，共 68 個告警，其中 19 個是真的，$19/68 = 0.279$，一致。雖然偵測率高達 95%，但因為故障本來就少，告警中仍有七成以上是誤報。

**算例 2：封包錯誤個數（二項與卜瓦松）。** 已知（假設）：一次傳送 1,000 個封包，每個封包獨立出錯，錯誤機率 $p = 0.002$。求平均錯誤個數、沒有任何錯誤的機率、至少 3 個錯誤的機率。

1. 平均 $\lambda = np = 1000\times0.002 = 2$ 個；變異數 $np(1-p) = 1.996$，標準差約 1.41 個。
2. 用卜瓦松近似：$P(0) = e^{-2} = 0.1353$；$P(1) = 2e^{-2} = 0.2707$；$P(2) = \frac{2^2}{2}e^{-2} = 0.2707$。
3. $P(K\le2) = 0.1353 + 0.2707 + 0.2707 = 0.6767$，所以 $P(K\ge3) = 1 - 0.6767 = 0.3233$。

合理性檢查：用二項分布精確計算，$P(0) = 0.998^{1000} = 0.1351$，$P(K\ge3) = 0.3233$，與卜瓦松近似在小數第三位以內一致，表示在 $n = 1000$、$p = 0.002$ 的情況下近似很好。

#### 常見錯誤

- 把 $P(A\mid B)$ 和 $P(B\mid A)$ 當成同一個數。算例 1 中「故障時會告警」是 95%，「告警時真的故障」只有 27.9%。
- 忽略事前機率（基本比率）。事件越稀有，同樣的誤報率造成的假告警比例越高。
- 在試驗不獨立時套用二項或卜瓦松分布。衰落通道上的錯誤常成串出現，這時要用 3.5.4 的馬可夫模型。
- 把標準差當成變異數相加。獨立變數相加時，相加的是變異數，標準差要最後再開根號。

#### 和其他小節的關係

卜瓦松分布延伸為 3.5.4 的卜瓦松到達過程，並用於 3.4.1～3.4.3 的話務與排隊模型；高斯分布與 $Q$ 函數用於 3.1.3 的涵蓋機率與 3.2.3 的錯誤率；由樣本估計 $p$、$\lambda$、$\mu$ 的方法在 3.5.3。
