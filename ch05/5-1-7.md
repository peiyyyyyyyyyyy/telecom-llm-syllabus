# 5.1.7 UE 量測量：RSRP、RSRQ、SINR

所屬：[5.1 資料的種類](5-1.md)

## 內文

#### 是什麼、什麼時候會用到

RSRP、RSRQ、SINR 是終端（UE）量測下行訊號的三個基本量，NR 以同步訊號（SS/PBCH block）量測時分別稱為 SS-RSRP、SS-RSRQ、SS-SINR，定義在 TS 38.215；終端回報時把量到的值換成整數索引，對應表在 TS 38.133。這三個量出現在許多資料裡：RRC 量測報告與信令追蹤（5.1.4）、路測與 MDT（5.1.5）、切換與小區選擇的判斷。維運人員要判斷「訊號弱」還是「干擾大」、確認切換時機合不合理、或核對客訴地點的無線品質時，都要先讀懂這三個量的定義、單位與回報範圍。

#### 怎麼讀

**1. 定義（TS 38.215 V18.4.0）。**

| 量測量 | 條號 | 定義重點 | 單位 | 適用狀態 |
|---|---|---|---|---|
| SS-RSRP | clause 5.1.1 | 承載輔同步訊號（SSS）的資源元素上，功率貢獻（以 W 計）的線性平均 | dBm | RRC_IDLE、RRC_INACTIVE、RRC_CONNECTED 的同頻與異頻 |
| SS-RSRQ | clause 5.1.3 | N × SS-RSRP ／ NR carrier RSSI，N 是 RSSI 量測頻寬內的資源區塊數 | dB | RRC_IDLE、RRC_INACTIVE、RRC_CONNECTED 的同頻與異頻 |
| SS-SINR | clause 5.1.5 | 承載 SSS 的資源元素功率的線性平均，除以雜訊加干擾功率的線性平均 | dB | RRC_CONNECTED 的同頻與異頻 |

幾個細節：SS-RSRP 只在同一個 SS/PBCH block 索引、同一個 PCI 的參考訊號之間量測；**SS-RSRP 量測時間限於 SMTC 視窗，但用於 L1-RSRP 時此限制不適用（TS 38.215 clause 5.1.1）**。NR carrier RSSI 包含所有來源的總接收功率，例如同頻服務與非服務小區、鄰頻干擾、熱雜訊（clause 5.1.3）。FR1 的參考點是 UE 的天線接頭；若終端使用接收分集，回報值不得低於任一個接收分支的值（clause 5.1.1、5.1.3、5.1.5）。

換成 dB 運算時，SS-RSRQ(dB) = 10·log10(N) + SS-RSRP(dBm) − RSSI(dBm)。

**2. 回報範圍與對應表（TS 38.133 V18.15.0）。**

| 量測量 | 回報範圍與解析度 | 回報值 | 條號 |
|---|---|---|---|
| SS-RSRP（L3） | -156 dBm 到 -31 dBm，1 dB | RSRP_0～RSRP_127 | clause 10.1.6，Table 10.1.6.1-1 |
| SS-RSRP（L1） | -140 dBm 到 -44 dBm，1 dB | 同一張表的 L1 欄 | clause 10.1.6 |
| SS-RSRQ | -43 dB 到 20 dB，0.5 dB | SS-RSRQ_0～SS-RSRQ_127 | clause 10.1.11.1，Table 10.1.11.1-1 |
| SS-SINR（L3 與 L1） | -23 dB 到 40 dB，0.5 dB | SINR_0～SINR_127 | clause 10.1.16.1，Table 10.1.16.1-1 |

把表格整理成換算規則（以 L3 為準）：
- **SS-RSRP**：RSRP_0 是 < -156 dBm；RSRP_n（n = 1～125）是 (n − 157) ≤ SS-RSRP < (n − 156) dBm；RSRP_126 是 ≥ -31 dBm。RSRP_127 的值是 Infinity，原文註明只用於網路設定的 RSRP 門檻，不用於量測回報。
- **SS-RSRQ**：SS-RSRQ_0 是 < -43 dB；SS-RSRQ_n（n = 1～126）是 (−43.5 + 0.5n) ≤ SS-RSRQ < (−43 + 0.5n) dB；SS-RSRQ_127 是 ≥ 20 dB。
- **SS-SINR**：SINR_0 是 < -23 dB；SINR_n（n = 1～126）是 (−23.5 + 0.5n) ≤ SINR < (−23 + 0.5n) dB；SINR_127 是 ≥ 40 dB。

原文另註明，信令中的範圍可能大於保證精確度的範圍（clause 10.1.6、10.1.11.1、10.1.16.1）。

L1 與 L3 的差別要特別留意。L3 是一般量測報告用的層三回報，也就是切換、MDT 與路測最常看到的值；L1 是實體層的波束回報。同一張 Table 10.1.6.1-1 裡，L3 欄從 RSRP_0 到 RSRP_126 都有對應區間，L1 欄只有 -140 到 -44 dBm 這一段有效，其餘標為 Not valid（TS 38.133 V18.15.0 clause 10.1.6）。SS-SINR 則不同，L3 與 L1 共用 -23 到 40 dB 的範圍（clause 10.1.16.1）。解析度方面，SS-RSRP 每一格是 1 dB，SS-RSRQ 與 SS-SINR 每一格是 0.5 dB，所以同樣差 10 格，RSRP 代表差 10 dB，RSRQ 與 SINR 只代表差 5 dB。另外，SS-SINR 依 TS 38.215 V18.4.0 clause 5.1.5 只適用於 RRC_CONNECTED，閒置或非活動狀態的資料中通常不會有這個量。

**3. 在 RRC 訊息裡的位置。** TS 38.331 的 MeasResults 中，服務小區結果在 `measResultServingMOList`，鄰區結果在 `measResultNeighCells`；每個小區的 `MeasResultNR` 帶 `physCellId`，SSB 小區層級結果放在 `resultsSSB-Cell`，型別是 `MeasQuantityResults`，內含 `rsrp`、`rsrq`、`sinr` 三個選填欄位。`RSRP-Range`、`RSRQ-Range`、`SINR-Range` 都是 INTEGER(0..127)（TS 38.331 V18.11.0 clause 6.3.2）。

#### 實際例子

下面是一則仿真的 RRC 量測報告解碼片段，欄位名稱照 TS 38.331，PCI 與數值虛構：

```
measResults
  measId                      3
  measResultServingMOList
    servCellId                0
    measResultServingCell
      physCellId              301
      resultsSSB-Cell         rsrp 62, rsrq 64, sinr 60
  measResultNeighCells
    measResultListNR
      physCellId              118
      resultsSSB-Cell         rsrp 68, rsrq 70, sinr 72
```

逐欄換算（TS 38.133 V18.15.0 Table 10.1.6.1-1、10.1.11.1-1、10.1.16.1-1）：

| 小區 | rsrp → SS-RSRP | rsrq → SS-RSRQ | sinr → SS-SINR |
|---|---|---|---|
| 服務 PCI 301 | 62 → -95 ≤ x < -94 dBm | 64 → -11.5 ≤ x < -11 dB | 60 → 6.5 ≤ x < 7 dB |
| 鄰區 PCI 118 | 68 → -89 ≤ x < -88 dBm | 70 → -8.5 ≤ x < -8 dB | 72 → 12.5 ≤ x < 13 dB |

讀法與結論：
- 報告裡的 62、68 不是 dBm，是回報索引。62 − 157 = -95，所以服務小區 SS-RSRP 落在 -95 到 -94 dBm 之間；鄰區 68 − 157 = -89，落在 -89 到 -88 dBm 之間，比服務小區強約 6 dB。
- RSRQ 的自洽檢查：假設量測頻寬 N = 24 個資源區塊、RSSI = -70 dBm，則 10·log10(24) ≈ 13.8，SS-RSRQ ≈ 13.8 − 95 + 70 = -11.2 dB，落在 SS-RSRQ_64 的區間（-11.5 到 -11 dB），與報告一致。
- 這項檢查的用意，是確認報告中的三個量彼此說得通。如果 RSRP 很強、RSRQ 卻很差，代表 RSSI 偏高，也就是負載或干擾大，問題不在覆蓋；本例 RSRQ 落在合理區間，表示服務小區只是訊號偏弱。
- 服務小區 SINR 約 6.5 到 7 dB，鄰區約 12.5 到 13 dB，差距約 6 dB，與 RSRP 的差距相近，**單則報告只能說明此刻鄰區較強；是否正往鄰區移動需比較前後多則報告**。
- 鄰區在三個量上都比服務小區好，這則報告可以合理地觸發切換到 PCI 118。如果事後追蹤（5.1.4）顯示切換沒有發生或失敗，就要查切換參數與鄰區設定，而不是懷疑量測本身。

#### 容易搞混的地方

1. **回報值不是實際值。** RRC 與部分追蹤紀錄裡的 rsrp、rsrq、sinr 是 0～127 的索引，要查 TS 38.133 的表才換得成 dBm 或 dB；而且每個索引代表一個區間，不是單一數值。
2. **三個量的解析度不同。** SS-RSRP 每格 1 dB；SS-RSRQ 和 SS-SINR 每格 0.5 dB。不要用同一個公式換算三者。
3. **SS-SINR 只適用 RRC_CONNECTED。** TS 38.215 列的 SS-SINR 適用狀態只有 RRC_CONNECTED；SS-RSRP、SS-RSRQ 在 IDLE、INACTIVE 也適用。所以 Logged MDT（IDLE／INACTIVE）記錄的是 RSRP 與 RSRQ（見 5.1.5）。
4. **RSRP_127 不是很強的訊號。** 表中 RSRP_127 對應的值是 Infinity，原文註明它只用於網路設定的 RSRP 門檻，不用於量測回報；在報告中看到 127 應懷疑資料解碼有誤，不能當成訊號極強。

#### 和其他小節的關係

路測與 MDT（5.1.5）的量測欄位就是本節的量；信令追蹤（5.1.4）在 Medium 深度會帶無線量測 IE；看到干擾或覆蓋問題時，要對照 5.1.6 的 PCI 與頻點設定。dB 與 dBm 的單位陷阱見 5.2.3。量測結果可作為 6.1 判斷根因屬於覆蓋或干擾的依據。
