# 5.2.3 指標單位

所屬：[5.2 對齊資料](../5-2.md)

## 練習題

**1.** Which naming pattern is used when a measurement includes both subcounters and filters?

- A. "<familyName>.<measurementName>.<Subcounter1>.<...>.<SubcounterM>"
- B. "<familyName>.<measurementName>_<Filter1>_..._<FilterN>"
- C. "<familyName>.<measurementName>.<Subcounter1>.<...>.<SubcounterM>_<Filter1>_..._<FilterN>"
- D. "<familyName>"

<details><summary>看答案</summary>

正解：C。The pattern with both subcounters and filters concatenates subcounters with dots and filters with underscores.

</details>

**2.** If a KPI is reported without any subcounters or filters, which string form correctly represents it?

- A. "<familyName>"
- B. "<familyName>.<measurementName>"
- C. "<familyName>.<measurementName>_<Filter1>"
- D. "<familyName>.<measurementName>.<Subcounter1>"

<details><summary>看答案</summary>

正解：B。The specification defines this exact form for a measurement result without subcounters or filters.

</details>

**3.** What does the string "<familyName>" represent according to TS 28.552 §4.3?

- A. A single measurement result with no subcounters or filters.
- B. A list of measurement results of all applicable measurementNames without any Subcounter or Filter.
- C. A measurement result that includes only filters.
- D. An invalid measurement type.

<details><summary>看答案</summary>

正解：B。The specification explicitly states that a lone family name requests a list of all measurements in that family.

</details>
