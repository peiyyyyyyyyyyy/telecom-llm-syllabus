## 練習題

**1.** A NETCONF client wants to receive only alarms of severity CRITICAL, MAJOR, and MINOR. Which mechanism does the specification provide for this?

- A. Use a different NETCONF port
- B. Apply a subtree filter in the <create-subscription> RPC
- C. Change the alarm’s perceivedSeverity attribute
- D. Modify the objectDN value

<details><summary>看答案</summary>

正解：B。The client can define a subtree filter in the <create-subscription> RPC to select alarms by severity.

</details>

**2.** When an alarm is cleared, what happens to it in a system that maintains a historical‑alarm‑list?

- A. It is removed permanently
- B. It is added with is‑cleared set to "true"
- C. Its perceivedSeverity changes to warning
- D. It is moved to the active‑alarm‑list

<details><summary>看答案</summary>

正解：B。Cleared alarms are appended to the historical list with the attribute is‑cleared set to true.

</details>

**3.** Which alarm type conveys a degradation in service quality and can be combined with any perceived severity?

- A. EQUIPMENT_ALARM
- B. PROCESSING_ERROR_ALARM
- C. QUALITY_OF_SERVICE_ALARM
- D. ENVIRONMENTAL_ALARM

<details><summary>看答案</summary>

正解：C。The specification defines QUALITY_OF_SERVICE_ALARM as indicating service degradation and combinable with any severity.

</details>
