# 第 5 章　告警與資料判讀

- 階段：第二階段　判讀與推理
- 從哪裡來：N4 維運排障、N3 規劃 → A5 監控與告警判讀
- 學完要做到：從一批告警挑出最源頭的那一個；寫出時間軸與影響範圍，每一句都對得回原始紀錄。
- 怎麼考：兩種題：一張障礙單的早期紀錄、一份活動尖峰的流量資料。核對時間、設備、指標、影響範圍。
