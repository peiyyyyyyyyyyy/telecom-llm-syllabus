## 內文

讀取基地台日誌時，可以先辨認一筆記錄的時間、來源名稱、層級、上下文及訊息本體，再回頭確認相關通道是否啟用。兩個模組即使同時輸出同樣層級，來源名稱與上下文仍可能不同。反過來說，觀察到日誌沒有某個事件時，必須先核對格式器、各層開關及輸出目的地，才能判斷缺的是這筆記錄、整個模組的輸出，還是目前層級看不到的細節。固定版本下，這些項目可以沿著格式器與啟動設定兩條路徑逐一定位。

```cpp
void contextual_text_formatter::format_metadata(const detail::log_entry_metadata& metadata, fmt::memory_buffer& buffer)
{
  // Time stamp data preparation.
  std::tm current_time = fmt::gmtime(std::chrono::high_resolution_clock::to_time_t(metadata.tp));
  auto    us_fraction =
      std::chrono::duration_cast<std::chrono::microseconds>(metadata.tp.time_since_epoch()).count() % 1000000u;
  fmt::format_to(std::back_inserter(buffer), "{:%F}T{:%H:%M:%S}.{:06} ", current_time, current_time, us_fraction);

  // Format optional fields if present.
  if (!metadata.log_name.empty()) {
    fmt::format_to(std::back_inserter(buffer), "[{: <8}] ", metadata.log_name);
  }
  if (metadata.log_tag != '\0') {
    fmt::format_to(std::back_inserter(buffer), "[{}] ", metadata.log_tag);
  }
  if (metadata.context.enabled) {
    fmt::memory_buffer ctx_buffer;
    fmt::format_to(std::back_inserter(ctx_buffer),
                   "{}.{}",
                   uint32_t(metadata.context.value64 >> 32),
                   uint32_t(metadata.context.value64));
    ctx_buffer.push_back('\0');
    fmt::format_to(std::back_inserter(buffer), "[{: >8}] ", ctx_buffer.data());
  }
  if (metadata.log_label != nullptr && !metadata.log_label->empty()) {
    fmt::format_to(std::back_inserter(buffer), "{}", *metadata.log_label);
  }
}
```

格式器先把記錄建立時的 `metadata.tp` 轉為 UTC 日曆時間，再從同一欄位的 epoch 計數取得六位微秒尾數，因此使用者應把日期、時分秒和小數分量視為同一時間戳。接下來逐項檢查可選欄位。來源名稱非空才加上括號欄，名稱依指定寬度靠左排列。層級字元非空才寫入下一個欄位。通道上下文已啟用時，格式器取其高、低兩個 32 位元值，以點號串起並靠右排列。這兩個值的業務意義來自寫入上下文的呼叫端。末尾的 `log_label` 另經非空指標及非空字串檢查，再附加文字。這個步驟只組出前綴，實際訊息及可選的十六進位資料由文字格式器的後續步驟產生。應注意欄位可以省略，按固定欄數切割容易把訊息前半段誤當上下文。 [`lib/srslog/formatters/text_formatter.cpp:58–85`](https://github.com/srsran/srsRAN_Project/blob/d2f4b70dda8e2c557d5b05a0ac5f92dbddda19bc/lib/srslog/formatters/text_formatter.cpp#L58-L85)

設定層級時，`set_level` 先取得鎖。選擇 `none` 會停用所有通道後返回。其餘情況按通道序號與層級值比較。基本記錄器的順序是 `error`、`warning`、`info`、`debug`，因此選 `info` 時也保留警告與錯誤。讀設定應區分內建值、通用層級繼承，以及明確指定的單層選項。以 gNB 啟動程式為例，`CONFIG` 使用 `config_level`。若其除錯通道開啟，會用 YAML 輸出組合後設定，否則改採資訊通道輸出非預設值。這可解釋設定檔沒有出現在某些日誌時，為何先檢查 `CONFIG` 的實際等級與輸出目的地。 [`include/srsran/srslog/logger.h:152–160`](https://github.com/srsran/srsRAN_Project/blob/d2f4b70dda8e2c557d5b05a0ac5f92dbddda19bc/include/srsran/srslog/logger.h#L152-L160) [`apps/gnb/gnb.cpp:159–167`](https://github.com/srsran/srsRAN_Project/blob/d2f4b70dda8e2c557d5b05a0ac5f92dbddda19bc/apps/gnb/gnb.cpp#L159-L167) [`apps/gnb/gnb.cpp:309–320`](https://github.com/srsran/srsRAN_Project/blob/d2f4b70dda8e2c557d5b05a0ac5f92dbddda19bc/apps/gnb/gnb.cpp#L309-L320)

#### Hex dump line structure

**情境 177**　Hex dump line structure

[`lib/srslog/formatters/text_formatter.cpp`, lines 40–55](https://github.com/srsran/srsRAN_Project/blob/d2f4b70dda8e2c557d5b05a0ac5f92dbddda19bc/lib/srslog/formatters/text_formatter.cpp#L40-L55)

```cpp
/// Formats into a hex dump a range of elements, storing the result in the input
/// buffer.
static void format_hex_dump(const std::vector<uint8_t>& v, fmt::memory_buffer& buffer)
{
  const size_t elements_per_line = 16;

  for (auto i = v.cbegin(), e = v.cend(); i != e;) {
    auto num_elements = std::min<size_t>(elements_per_line, std::distance(i, e));

    fmt::format_to(std::back_inserter(buffer),
                   "    {:04x}: {:02x}\n",
                   std::distance(v.cbegin(), i),
                   fmt::join(i, i + num_elements, " "));

    std::advance(i, num_elements);
  }
```

{
  auto config_level_check = [](const std::string& value) -> std::string {
    if (auto level = srslog::str_to_basic_level(value); !level.has_value() ||
                                                        level.value() == srslog::basic_levels::error ||

    }

    return {};
  };

  app.add_option("--filename", log_params.filename, "Log file output path")->capture_default_str();

  app_helpers::add_log_option(

  app_helpers::add_log_option(app, log_params.lib_level, "--lib_level", "Generic log level ");

```cpp
  /// Builds the provided log entry and passes it to the backend. When the
  /// channel is disabled the log entry will be discarded.
  template <typename... Args>
  void operator()(const char* fmtstr, Args&&... args)
  {
    if (!enabled()) {
      return;
    }

    // Populate the store with all incoming arguments.
    auto* store = backend.alloc_arg_store();
    if (!store) {
      return;
    }
    (void)std::initializer_list<int>{(push_back(store, std::forward<Args>(args)), 0)...};

    // Send the log entry to the backend.
    log_formatter&    formatter = log_sink.get_formatter();
    detail::log_entry entry     = {&log_sink,
                                   [&formatter](detail::log_entry_metadata&& metadata, fmt::memory_buffer& buffer) {
                                 formatter.format(std::move(metadata), buffer);
                               },
                                   {std::chrono::high_resolution_clock::now(),
                                    {ctx_value64, should_print_context},
                                    fmtstr,
                                    store,
                                    log_name,
                                    log_tag}};
    backend.push(std::move(entry));
```
