# 4.2.6 排程器與資源區塊分配

所屬：[4.2 基地台軟體](4-2.md)

## 內文

排程器須在每個時段安排服務對象、控制資源和資料資源，並保留重傳所需的狀態。讀到某個終端有待傳資料卻沒拿到配置，先拆成候選優先順序、可用資源與實際 grant 三件事。候選順序反映策略，控制通道和資料通道的資源能否配置則各有條件。即使候選優先，遇到控制元素不足、回報資源無法配置或符合條件的區塊不夠，也可能只留下失敗原因而無法完成排程。

```cpp
std::optional<sch_mcs_index> ue_link_adaptation_controller::calculate_dl_mcs(pdsch_mcs_table mcs_table) const
{
  if (cell_cfg.expert_cfg.ue.dl_mcs.length() == 0) {
    // Fixed MCS.
    return cell_cfg.expert_cfg.ue.dl_mcs.start();
  }

  // Derive MCS using the combination of CQI + outer loop link adaptation.
  const float eff_cqi = get_effective_cqi();
  if (eff_cqi <= 0.0F) {
    // Special case, where reported CQI==0.
    return std::nullopt;
  }

  // There are fewer CQIs than MCS values, so we perform a linear interpolation.
  const float   cqi_lb = std::floor(eff_cqi), cqi_ub = std::ceil(eff_cqi);
  const float   coeff  = eff_cqi - cqi_lb;
  const float   mcs_lb = static_cast<float>(map_cqi_to_mcs(static_cast<unsigned>(cqi_lb), mcs_table).value().value());
  const float   mcs_ub = static_cast<float>(map_cqi_to_mcs(static_cast<unsigned>(cqi_ub), mcs_table).value().value());
  sch_mcs_index mcs{static_cast<uint8_t>(std::floor(mcs_lb * (1 - coeff) + mcs_ub * coeff))};

  // Ensures that the MCS is within the configured range.
  mcs = std::min(std::max(mcs, cell_cfg.expert_cfg.ue.dl_mcs.start()), cell_cfg.expert_cfg.ue.dl_mcs.stop());
  return mcs;
}
```

這段先看 MCS 是否設定為固定值，有固定值就直接回傳範圍起點。動態路徑讀取有效 CQI，非正值以空結果回報。對正的有效 CQI，分別向下及向上取整，把相鄰的 CQI 值映射到 MCS，再按小數部分插值。結果先取整、再限制於同一設定的上下界。這個值是候選 MCS。進到資源配置後，程式還會查同一時槽的 CSI-RS，於適用時用本專案邏輯調整下行值。接下來傳入 TBS 計算的是兩段實際配置的 CRB 長度總和，讀者須把搜尋用的 VRB 和映射後的 PRB／CRB 分開記。 [MCS 與 TBS 後續計算](https://github.com/srsran/srsRAN_Project/blob/d2f4b70dda8e2c557d5b05a0ac5f92dbddda19bc/lib/scheduler/ue_scheduling/ue_cell_grid_allocator.cpp#L49-L88)

      pdcch_sched.alloc_ul_pdcch_ue(pdcch_alloc, u.crnti, ue_cell_cfg, ss_cfg.get_id(), aggr_lvl);

    logger.info(
        "ue={} rnti={}: Failed to allocate PUSCH. Cause: No space in PDCCH.", fmt::underlying(u.ue_index), u.crnti);
    // Note: (Implementation-defined) Assuming all UEs share the same CORESET, if there are no more CCEs left in the
    // CORESET, stop attempting to allocate new PDCCHs in the slot.
    unsigned nof_cces_left = ss_info.coreset->get_nof_cces();

      nof_cces_left -= std::min(nof_cces_left, to_nof_cces(dl_pdcch.ctx.cces.aggr_lvl));
    }
    for (const auto& ul_pdcch : pdcch_alloc.result.dl.ul_pdcchs) {
      nof_cces_left -= std::min(nof_cces_left, to_nof_cces(ul_pdcch.ctx.cces.aggr_lvl));
    }
    return make_unexpected(nof_cces_left == 0 ? alloc_status::skip_slot : alloc_status::skip_ue);
  }
